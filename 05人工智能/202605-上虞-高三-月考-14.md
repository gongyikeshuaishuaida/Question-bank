# 题目 14

14. 人工智能超节点对温湿度有非常严格的要求，温度正常在 18～27℃，湿度正常在 45%～55%。某团队负责运营超节点的温湿度保障系统，该系统采用智能终端连接温湿度传感器、精密空调，每 30 秒采集一次温湿度数据，智能终端通过 IOT 模块将数据传输至服务器，存储到数据库中。如果服务器发现温度或湿度数据超出正常范围，将通过智能终端控制精密空调调节温湿度，3 分钟后温湿度若仍不正常，服务器将立即呼叫人工服务。团队成员可通过浏览器查看系统数据。请回答下列问题：

（1）智能终端中的代码在 PC 终端中烧录完成后，智能终端通过 IOT 模块将数据传输至服务器，服务器中 ______ 安装智能终端的驱动程序（单选）。
- A. 需要
- B. 不需要

（2）关于该系统中数据采集、传输、处理与呈现的说法正确的有 ______ （多选）。（注：全部选对的得 2 分，选对但不全的得 1 分，不选或有选错的得 0 分）
- A. 传感器采集的数据都存储在智能终端上
- B. 智能终端可以通过有线网络传输数据
- C. 智能终端中可以处理数据
- D. 浏览器中可以用图表的形式呈现温湿度数据

（3）智能终端提交数据到服务器的 URL 为 `http://182.188.12.26/ser?t=20&w=50`，则服务器端应用实例 `app` 中与该 URL 关联的路由设置语句是 `@app.route('______')`。

（4）随着超节点越来越强大，产生更多热量，原保障系统将无法保障温控正常，请写出 1 种合理的控温方法。

（5）将某天 24 小时的温湿度数据导出到文件 `data.xlsx` 中。部分数据如第 14 题图 a 所示。统计每小时温度数据超出正常范围的次数，选择次数最多的前 3 个小时的数据，绘制如第 14 题图 b 所示的水平柱形图。

![[attachments/202605上虞高三月考_14_图1.png]]

实现上述功能的部分 Python 程序如下：
```python
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib

matplotlib.rc("font", family="KaiTi")
df = pd.read_excel("data.xlsx")
df1 = df[(df.温度 > 27) | (df.温度 < 18)]  # 筛选温度大于 27 或小于 18 的数据
df2 = df1.groupby("时").count()
df3 = df2.sort_values("温度", ascending=False)
plt.barh(_____②_____, df3["温度"])
plt.title("温度超出正常范围次数统计")
plt.show()
```

- A. `[-3:]`
- B. `[:3]`
- C. `.tail(3)`
- D. `.head(3)`
② 请在程序中划线处填入合适的代码。

## 答案

**正确答案：** （1）B；（2）B、C、D；（3）`/ser`；（4）增加精密空调数量或功率、采用液冷等；（5）① B、D；② `df3.index`
