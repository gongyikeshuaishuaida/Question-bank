# 题目 12

12. 有如下 Python 程序段：

```python
que = [5, 9, 8, 10, 3, 4, 6, 1, 2, 7]
n = len(que)
st = [0] * (n//2)
top1 = -1
top2 = 5
head = 4
tail = 3
while head != tail and top1 + 1 != top2:
    x = que[head]
    if x % 2 == 0:
        if top1 < 0 or x > st[top1]:
            top1 += 1
            st[top1] = x
        head = (head + 1) % n
    else:
        if top2 >= len(st) or x > st[top2]:
            top2 -= 1
            st[top2] = x
        head = (head + 1) % n
```

执行该程序段后，`st[2]` 的值为（   ）

- A. 4
- B. 6
- C. 7
- D. 9

---

## 答案

**正确答案：** D

---

## 解析

`st` 用两端分别模拟两个栈，`que` 按环形队列方式从下标 4 开始处理。依次处理后，偶数栈写入 4、6，奇数栈写入 3、7、9；当两个栈顶相遇时退出，最终 `st=[4,6,9,7,3]`，所以 `st[2]=9`。
