# 题目 08

有以下 Python 程序段：

```python
# 输入 nums，代码略
stack = [0] * 10
top = -1
res = [-1] * len(nums)
for i in range(0, len(nums)):
    while top != -1 and nums[stack[top]] < nums[i]:
        res[stack[top]] = nums[i]
        top -= 1
    top += 1
    stack[top] = i
print(res)
```

执行该程序段后，得到的输出结果为 `[5,25,25,-1,-1,-1]`，则 `nums` 数据可能是（   ）

- A. `[4,5,25,25,24,23]`
- B. `[4,5,2,25,23,24]`
- C. `[4,5,2,25,24,23]`
- D. `[5,5,25,25,24,23]`

---

## 答案

**正确答案：** C

---

## 解析

程序用单调栈寻找每个元素右侧第一个比它大的元素。逐项检查，只有 `[4,5,2,25,24,23]` 的结果为 `[5,25,25,-1,-1,-1]`。
