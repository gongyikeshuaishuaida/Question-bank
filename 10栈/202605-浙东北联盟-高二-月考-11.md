# 题目 11

11. 有如下Python程序段：

```python
def remove_stack(num, k):
    n = len(num)
    t = n - k
    stack = [""] * n
    top = -1
    for i in num:
        while k > 0 and top != -1 and stack[top] > i:
            top -= 1
            k -= 1
        top += 1
        stack[top] = i
    while k > 0:
        top -= 1
        k -= 1
    result = "".join(stack[:t])
    # 执行语句print("".join(["a", "b", "c"]))，输出abc
    return result

# 主程序
num = "14325"
k = 2
print(remove_stack(num, k))
```

执行该程序段后，输出的值为（   ）

- A. `143`
- B. `125`
- C. `325`
- D. `132`

---

## 答案

**正确答案：** B

---

## 解析

遍历到`3`时弹出较大的`4`，遍历到`2`时弹出较大的`3`，两次删除用完后剩余栈序列为`1、2、5`，连接得到`125`。
