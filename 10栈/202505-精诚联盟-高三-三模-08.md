# 题目 08

8. 在程序运行过程中，函数调用会按照“栈”的机制入栈和出栈。假设函数按下列顺序调用（入栈）：

`main → Config → Network → Service → Status`

在执行过程中，函数按下列顺序完成并返回（出栈）：

`Config → Service → Network → main → Status`

栈容量至少是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** B

---

## 解析

按题目给定的入栈、出栈事件交错模拟，栈中元素最多时为 `[main, Network, Service]`，深度为 3，因此最小容量为 3。
