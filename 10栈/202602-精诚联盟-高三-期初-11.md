# 题目 11

有如下 Python 程序段：

```python
import random

a = [random.randint(1, 100) for i in range(10)]  # 随机生成10个1~100之间的整数
st = [0] * len(a)
top = f = -1
for i in range(len(a)):
    while top >= 0 and f * a[i] < f * st[top]:
        top -= 1
    top += 1
    st[top] = a[i]
    f = -f
print(st[0:top + 1])
```

执行该程序段后，输出结果不可能是（   ）

- A. `[65,78,13,92,75,85]`
- B. `[27,27,88]`
- C. `[41]`
- D. `[6,6,7,7,88,67,90,5]`

---

## 答案

**正确答案：** D

---

## 解析

变量 `f` 初值为 `-1`，每轮外循环后变号，因此弹栈时的比较方向交替改变：

- `f=-1` 时，条件等价于 `a[i]>st[top]`；
- `f=1` 时，条件等价于 `a[i]<st[top]`。

由最终栈顶向前检查，相邻元素的大小关系必须交替变化。D 中从末尾向前为 `5<90>67<88>7>7...`，在应继续交替的位置出现不符合约束的关系，因此该结果不可能出现；其余选项可以满足程序形成的交替关系。
