# 题目 11

11. 有如下 Python 程序段：

```python
st = [0] * len(a)
top = -1
temp = []
for i in range(len(a)):
    while len(temp) > 0 and a[i] < temp[-1]:
        top += 1
        st[top] = temp.pop()
    while top != -1 and a[i] > st[top]:
        temp.append(st[top])
        top -= 1
    top += 1
    st[top] = a[i]
while len(temp) != 0:
    top += 1
    st[top] = temp.pop()
```

其中上述第一个 `while` 代码块为①加框处，第二个 `while` 代码块为②加框处。

若 `a=[29,10,13,19,25,18]`，执行上述代码，下列说法正确的是（   ）

A. 该段代码的时间复杂度为 `O(n)`  
B. 交换①②加框处代码，对运行结果没有影响  
C. 运行过程中列表 `temp` 长度最大值为 4  
D. 运行后 `st=[10,13,18,19,25,29]`

---

## 答案

**正确答案：** B

---

## 解析

两段加框代码分别把不满足当前位置比较关系的元素在 `st` 与 `temp` 之间移动。对本题给定的 `a`，交换两段调整代码后，元素仍会在插入 `a[i]` 前被调整到相同状态，最终运行结果不变。实际运行后 `st` 为 `[29,25,19,18,13,10]`，`temp` 的最大长度为 3，所以 C、D 错；该过程存在多次来回移动，不能简单判为 `O(n)`。
