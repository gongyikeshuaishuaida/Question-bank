# 题目 12

有如下 Python 程序段：

```python
from random import randint

s = [0] * 10
a = [5,4,7,8,4,3,6,2]
top = 0
s[top] = a[0]
b = ""
n = randint(5, len(a) - 1)
for i in range(1, n):
    while top != -1 and a[i] > s[top]:
        top -= 1
    top += 1
    s[top] = a[i]
while top != -1:
    b = b + str(s[top])
    top -= 1
print(b)
```

程序运行后，输出的结果可能是（　　）

- A. 786
- B. 268
- C. 68
- D. 86

---

## 答案

**正确答案：** C

---

## 解析

`n` 的可能值为 5、6、7。程序维护一个从栈底到栈顶递减的单调栈，并最终从栈顶到栈底输出。三种情况下分别输出 `48`、`348`、`68`，选项中只有 `68` 可能出现。
