# 题目 12

12. 有如下 Python 程序段：

```python
s = [0,1,6,7,3,5,8,9]
st = [0]*10
top = -1
key = 0
for i in range(len(s)):
    if s[i] > key:
        while top >= 0 and s[i] <= st[top]:
            key = st[top]
            top -= 1
        top += 1
        st[top] = s[i]
```

运行该程序段后，变量 `top` 的值为（   ）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** A

---

## 解析

逐行追踪，st 模拟栈，初始 `top=-1`，`key=0`：

- i=0: `s[0]=0`, 0>0? No，跳过。
- i=1: `s[1]=1`, 1>0? Yes。top=-1, while 跳过。`top=0`, `st[0]=1`。栈：[1]
- i=2: `s[2]=6`, 6>0? Yes。`st[top]=1`, 6<=1? No。`top=1`, `st[1]=6`。栈：[1,6]
- i=3: `s[3]=7`, 7>0? Yes。`st[top]=6`, 7<=6? No。`top=2`, `st[2]=7`。栈：[1,6,7]
- i=4: `s[4]=3`, 3>0? Yes。`st[top]=7`, 3<=7? Yes。`key=7`, `top=1`。然后 `st[top]=6`, 3<=6? Yes。`key=6`, `top=0`。然后 `st[top]=1`, 3<=1? No。`top=1`, `st[1]=3`。栈：[1,3]，key=6。
- i=5: `s[5]=5`, 5>6? No，跳过。
- i=6: `s[6]=8`, 8>6? Yes。`st[top]=3`, 8<=3? No。`top=2`, `st[2]=8`。栈：[1,3,8]
- i=7: `s[7]=9`, 9>6? Yes。`st[top]=8`, 9<=8? No。`top=3`, `st[3]=9`。栈：[1,3,8,9]

最终 `top=3`。

该程序维护了一个递增栈，当遇到比 `key` 大但比栈顶小的元素时，会弹出栈顶并更新 key，本质是在构建一个筛选后的单调递增序列。
