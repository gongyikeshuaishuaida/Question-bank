# 题目 11

11. 有如下 Python 程序段：

```python
top1 = len(s1) - 1
top2 = -1
k = 0
while top1 != -1:
    temp = s1[top1]
    top1 -= 1
    k += 1
    while top2 != -1 and temp < s2[top2]:
        top1 += 1
        s1[top1] = s2[top2]
        top2 -= 1
    top2 += 1
    s2[top2] = temp
```

已知栈 s1、s2 最大容量均为 n，s1 有 n 个元素入栈，s2 初始为空，若 s1 初始值为 `['110','98','105','99','33']`，下列关于该程序段的说法，正确的是（   ）

A. 该算法的时间复杂度为 O(2^n)  
B. 执行该程序段后，s2 的值为 `['33','98','99','105','110']`  
C. 对任意 s1 的值，变量 k 的值一定大于 n  
D. 执行该程序段后，s1 的值为 `['99','98','33','33','33']`

---

## 答案

**正确答案：** D

---

## 解析

程序不断从 s1 弹出元素，并借助 s2 调整顺序，属于用两个栈维护有序序列的过程。给定初始 s1 后，程序执行结束时 s1 中留下的覆盖值与 D 项一致。
