# 题目 12

12. 有如下 Python 程序段：

```python
ans = []
s = []
p = 0
idx = -1
# 读取数据存入data，代码略
while p != -1:
    idx += 1
    ans.append(0)       # 在列表ans末尾添加元素0
    while s != [] and s[len(s) - 1][0] < data[p][0]:
        ans[s[len(s) - 1][1]] = data[p][0]
        s.pop()          # 将列表s末尾元素删除
    s.append([data[p][0], idx])
    p = data[p][1]
print(ans)
```

若输出 `ans` 的值为 `[7,0,4,5,0]`，则读取 `data` 的值可能为（   ）

- A. `[[5,4],[9,-1],[5,3],[5,1],[7,2]]`
- B. `[[7,2],[3,4],[4,1],[2,-1],[5,3]]`
- C. `[[4,3],[5,2],[4,-1],[7,4],[7,1]]`
- D. `[[2,4],[3,2],[4,3],[5,-1],[7,1]]`

---

## 答案

**正确答案：** D

---

## 解析

程序沿 `p=data[p][1]` 所表示的链式顺序访问数据，并用栈 `s` 维护尚未找到右侧更大值的元素。选项 D 的访问序列为 `2,7,3,4,5`，依次处理后得到每个位置右侧第一个更大值为 `[7,0,4,5,0]`，与输出一致。
