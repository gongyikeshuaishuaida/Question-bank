# 题目 09

9. Web 浏览器中有"前进"和"后退"的功能，原理是使用两个栈（back 栈和 for 栈）来存储用户访问的网址。若打开一个新网页，将原网页压入 back 栈中。若按下"←"键，将当前页面压入 for 栈，并从 back 栈中弹出一个页面作为当前页面，当 back 栈空时，命令忽略。若按下"→"键，将当前页面压入 back 栈，并从 for 栈中弹出一个页面作为当前页面，当 for 栈空时，命令忽略。现两栈共享空间 `V[0]~V[9]`，当前栈内存储网页情况如第 9 题图所示，topb 指针指向 back 栈顶，topf 指针指向 for 栈顶，▲表示访问新网页，经过"▲→▲→←▲→"后，topf 指向（   ）

## 解析

根据图中初始状态，back 栈中有 p1、p2（botb→topb 方向），元素 p0 为新页面。for 栈中有 p3、p4、p5（topf→botf 方向）。

操作序列"▲→▲→←▲→"：
1. ▲（访问新网页 p6）：原页面 p0 压入 back → back: p1,p2,p0，当前为 p6
2. →（前进）：back 不变，从 for 弹出 p3 → for: p4,p5，当前 p3
3. ▲（访问新网页 p7）：原页面 p3 压入 back → back: p1,p2,p0,p3，当前为 p7
4. ←（后退）：p7 压入 for → for: p7,p4,p5，从 back 弹出 p3 → back: p1,p2,p0，当前 p3
5. ▲（访问新网页 p8）：原页面 p3 压入 back → back: p1,p2,p0,p3，for 不变 → for: p7,p4,p5，当前 p8
6. →（前进）：p8 压入 back → back: p1,p2,p0,p3,p8，从 for 弹出 p7 → for: p4,p5，当前 p7

最终 for 栈从 botf 方向看：p7→p4→p5，加上 p7 被弹出后栈顶 topf 位置对应元素为 p4，即 topf 指向索引 9。

（具体索引方向以图中标注为准，答案是 topf 指向 9。）
