# 题目 11

11. 有如下 Python 程序段：

```python
a = "yyxzzzxyzxxyy"; s = ""
st = [""] * 100; top = -1
for i in a:
    if top == -1 or i != st[top]:
        top += 1; st[top] = i
    else:
        top = top - 1
while top >= 0:
    s = st[top] + s; top -= 1
```

执行该程序段后，变量 s 的值是（   ）

- A. `'yxzyx'`
- B. `'zyxzx'`
- C. `'yzxyy'`
- D. `'xzxyz'`

---

## 答案

**正确答案：** D

---

## 解析

程序模拟消除相邻重复字符。遍历 "yyxzzzxyzxxyy"：yy消除、x入栈、zzz→z消除后留一个z、x消除栈顶z、y消除栈顶x、xx消除、yy消除。最终栈中为 "xzxyz"。
