# 题目 08

8. 对某个仅包含 0、1、# 的数据，从左向右遍历操作：若为 0 或 1，则入栈；若为 #，则将栈中的 0 或 1 依次出栈。若出栈序列为“1101011100”，则该数据可能为（   ）

A. 1101011100#  
B. 1011#0111#00#  
C. 11#1010#0011#  
D. 011#0001011#

---

## 答案

**正确答案：** C

---

## 解析

遇到 # 时会把当前栈内元素逆序输出。C 选项被 # 分成 11、1010、0011 三段，逆序出栈后得到 11、0101、1100，合并为 1101011100。
