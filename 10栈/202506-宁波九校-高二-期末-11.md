# 题目 11

11. 执行如下程序段，下列说法正确的是（   ）

```python
s = [0] * 100
q = [0] * 100
top = -1
result = 0
exp = "+1+23+456"
for c in exp[::-1]:
    if "0" <= c <= "9":
        top += 1
        s[top] = int(c)
    elif top != -1:
        num = 0
        while top != -1:
            num = num * 10 + s[top]
            top -= 1
        result += num
print(result)
```

- A. 程序计算的是数学表达式 `654+32+1` 的运算结果  
- B. 若加框处代码改为 `range(len(exp)-1,-1,-1)`，程序运行结果不变  
- C. 若第三行代码改为 `exp="1+23+456"`，程序运行结果不变  
- D. 若第三行代码改为 `exp="+1+23+456+"`，程序运行结果不变

---

## 答案

**正确答案：** D

---

## 解析

程序从右向左扫描字符串，遇到数字压栈，遇到 `+` 时把栈中数字弹出并按原顺序组成一个数累加。末尾多一个 `+` 时，反向扫描第一个字符为 `+`，此时 `top=-1`，不会影响结果。去掉开头的 `+` 会使最后的 `1` 没有被触发累加；把遍历对象改为 `range(...)` 会遍历整数下标而不是字符。
