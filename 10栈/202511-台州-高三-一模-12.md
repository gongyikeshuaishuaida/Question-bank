# 题目 12

12. 列表s包含n个元素，现要对列表s进行消除操作：选择两个相邻且相同的元素进行删除。反复执行该操作，直到无法继续消除。例如：列表s为 `["a","b","b","a","c","a"]`，完成所有消除操作后，结果为 `["c","a"]`。实现上述功能的Python程序段如下：

```python
left, right = 0, 0
while right < len(s):
    s[left] = s[right]
    if left > 0 and s[left] == s[left-1]:
        （1）
    else:
        （2）
    （3）
print(（4）)
```

上述程序段中方框处可选代码为：

① `left = left + 1`
② `left = left - 1`
③ `right = right + 1`
④ `right = right - 1`
⑤ `s[0:left]`
⑥ `s[0:left+1]`

则（1）（2）（3）（4）处代码依次为（   ）

- A. ①②③⑤
- B. ①②④⑥
- C. ②①③⑤
- D. ②①③⑥

---

## 答案

**正确答案：** C

---

## 解析

该程序使用双指针模拟栈来消除相邻相同元素：

- `left` 指向栈顶（模拟栈的 top 指针），`right` 遍历原列表
- `s[left] = s[right]` 将当前元素复制到栈顶位置
- 当 `left > 0` 且栈顶元素与栈中前一个元素相同（`s[left] == s[left-1]`）时，说明找到相邻相同元素对，需要消除：`left = left - 1`（退栈，选 ②）
- 否则（不相同），栈增长：`left = left + 1`（选 ①）
- 每次循环 `right` 前进一步：`right = right + 1`（选 ③）
- 最终栈中剩余元素为 `s[0:left]`（选 ⑤）

填入顺序为 ②①③⑤，对应选项 C。

以 `["a","b","b","a","c","a"]` 验证：
- right=0: s[0]=a, left=0, left=1
- right=1: s[1]=b, left=1, s[1]≠s[0], left=2
- right=2: s[2]=b, left=2, s[2]=s[1]=b, left=1 (消除bb)
- right=3: s[1]=a, left=1, s[1]=s[0]=a, left=0 (消除aa)
- right=4: s[0]=c, left=0, left=1
- right=5: s[1]=a, left=1, s[1]≠s[0], left=2
- 最终 s[0:2] = ["c","a"] ✓
