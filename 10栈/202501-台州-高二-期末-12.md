# 题目 12

12. 有如下Python程序段：

```python
import random
a = ["A","B","*","C","D"]
t = []
for i in range(len(a)):
    op = random.randint(0, 1)
    if op == 1 and a[i] != "*":
        t.append(a[i])      #为t追加一个元素
        a[i] = "*"
    elif op == 0 and a[i] == "*" and len(t)>0:
        c = t.pop()         #在t中弹出最后一个元素
        a[i] = chr((ord(c) - ord("A") + 3) % 26 + ord("A"))
```

程序执行后，`a` 值不可能的是（   ）

- A. `["A","*","*","C","D"]`
- B. `["*","B","D","*","D"]`
- C. `["*","*","E","C","D"]`
- D. `["*","*","A","*","*"]`

---

## 答案

**正确答案：** D

---

## 解析

`t` 是栈，弹出的字符会变为后移3位的字母。原字符只可能由已入栈字符弹出后变成 `D、E、F、G` 等，不能在第3个位置由该规则得到 `A`，所以D不可能。
