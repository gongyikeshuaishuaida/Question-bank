# 题目 14

无人机在飞行时，会记录自身的飞行指令存储为 `path_log`。指令包含：`N`、`S`、`E`、`W`。当遇到禁飞区或飞鸟等障碍物时，无人机会紧急执行一条撤销指令 `B`。`B` 指令的作用是：作废并抵消掉上一步有效的飞行移动。例如，日志为 `"NEEBS"`，其路径为：向北(N)→向东(E)→向东(E)→B(作废最后一次向东)→向南(S)，最终有效路径为 `['N','E','S']`。现要求编写 Python 程序：根据日志，先推出真实有效路径，然后生成无人机原路安全返航的指令序列（即将有效路径按后进先出的原则反转，并取反方向）。请回答下列问题：

（1）若 `path_log` 的值为 `"EBSSBNEB"`，则生成的返航指令为 ______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
path_log = "NEEBSNBBWE"
stack = []
for cmd in path_log:
    if cmd == "B":
        if len(stack) > 0:
            ____①____
    else:
        stack.append(cmd)
opp = {'N':'S', 'S':'N', 'E':'W', 'W':'E'}
cmds = ""
while ____②____:
    curr = stack.pop()
    cmds += ____③____
print("安全返航的指令序列:", cmds)
```

---

## 答案

**正确答案：** （1）SN；（2）① `stack.pop()`；② `len(stack)>0`；③ `opp[curr]`

---

## 解析

遇到 `B` 时应删除上一条有效移动，所以使用栈弹出。返航时不断弹出有效路径最后一步，并按方向映射取反方向。`EBSSBNEB` 处理后有效路径为 `NS`，返航为 `SN`。
