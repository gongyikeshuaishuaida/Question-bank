# 题目 09

9. 某自定义函数如下：

```python
def func(x):
    i = 0; s = ""; num = 0
    while i < len(x):
        if x[i] in "0123456789":
            s += x[i]
        else:
            num += int(s)
            s = ""
        i += 1
    return num
```

调用自定义函数 `func("98a76t54")`，执行后输出的结果是（   ）

- A. 228
- B. 98
- C. 174
- D. 102

---

## 答案

**正确答案：** C

---

## 解析

遍历 "98a76t54"：遇到 'a' 时 s="98" → num=98, s=""；遇到 't' 时 s="76" → num=98+76=174, s=""；末尾 "54" 后无字母触发累加，未被计入。最终 num=174。
