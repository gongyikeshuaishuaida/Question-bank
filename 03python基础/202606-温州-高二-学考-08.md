# 题目 08

8. 该无人机喷洒药剂的规则为：如果检测到的病虫害面积超过 10% 或作物生长状况评级低于 3 级，则启动喷洒，否则不喷洒。实现该功能的部分程序如下：

```python
# 变量 area 存储病虫害面积比例，变量 level 存储生长状况等级，代码略
spray = False

# 方框处

if spray:
    print("喷洒")
else:
    print("不喷洒")
```

方框中填入下列选项中的代码，无法实现上述喷洒规则的是（　）

- A.

  ```python
  if area > 0.1:
      if level < 3:
          spray = True
  ```

- B.

  ```python
  if area > 0.1 or level < 3:
      spray = True
  ```

- C.

  ```python
  if area > 0.1:
      spray = True
  elif level < 3:
      spray = True
  ```

- D.

  ```python
  if area > 0.1:
      spray = True
  if level < 3:
      spray = True
  ```

---

## 答案

**正确答案：** A

---

## 解析

A的嵌套结构要求两个条件同时成立，相当于逻辑“与”，不符合题目的逻辑“或”。
