# 题目 10

10. 定义如下 Python 函数：

```python
def f(n, m):
    if n <= 1 or m <= 1:
        return 1
    if n >= m:
        return f(n - m, m) + 1
    else:
        return f(n, m - 1) + 1
```

执行语句 `k = f(5, 3)` 后，`k` 的值为

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C
