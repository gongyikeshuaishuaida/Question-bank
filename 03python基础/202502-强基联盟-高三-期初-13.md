# 题目 13

某评选活动有 `n` 个评委，需从 `m` 个品牌中评选一个最佳品牌。评选采取多轮淘汰制，每轮投票后得票最少的品牌被淘汰（得票并列最少的品牌一起淘汰）。若最后只剩下一个品牌，评选成功并输出品牌编号；若某轮所有未被淘汰的候选品牌得票数都相同，则评选失败并输出 `Fail`。

每位评委根据预设的态度序列投票，态度序列中的 `0` 表示弃权。示例投票过程如下：

![[attachments/202502强基联盟_13_图1.jpg]]

（1）若有 6 个评委、3 个品牌，评委评选态度序列为 `[[3,2,1], [3,1,0], [2,3,1], [2,1,3], [1,2,0], [3,1,0]]`，则告评选______（填“成功/失败”），输出结果为______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码：

```python
# 读入 n, m，代表评委数与品牌个数，代码略
# 读入评委态度列表，存储到 lst 中，代码略
ans = m
f = [0] * (m + 1)
while ans > 1:
    cnt = [0] * (m + 1)
    for i in range(n):
        for x in lst[i]:
            if ____①:
                cnt[x] += 1
                break
    min_c = cnt[1]
    for i in range(2, m + 1):
        if f[i] != -1 and min_c > cnt[i]:
            ____②
    for i in range(1, m + 1):
        if f[i] != -1 and cnt[i] == min_c:
            ____③
            f[i] = -1
if ans == 0:
    print("Fail")
else:
    for i in range(1, m + 1):
        if f[i] != -1:
            print(i)
```

---
## 答案

**正确答案：**（1）失败；`Fail`。 （2）① `x != 0 and f[x] != -1`（或 `f[x] != -1`）；② `min_c = cnt[i]`；③ `ans -= 1`。

---
## 解析

第一轮 1、2、3 号品牌分别得 1、2、3 票，淘汰 1 号；第二轮剩余评委投票后 2、3 号均得 3 票，所有候选品牌得票相同，因此评选失败并输出 `Fail`。代码中只统计未淘汰品牌的首个有效态度，逐轮更新最少票数并将并列最少品牌的数量从 `ans` 中减去。
