# 题目 11

有如下 Python 程序段：

```python
import random
b=[1,1,1,1,1,1]
i,j=0,len(b)-1
while i<len(b) and j>=i:
    if random.randint(0,1)==0:
        b[i]+=j
        i+=1
    else:
        b[j]+=i
        j-=1
```

运行程序，输出的结果不可能为（   ）

- A. `[1,1,1,1,1,1]`
- B. `[6,6,4,3,3,3]`
- C. `[5,5,3,3,3,1]`
- D. `[5,4,3,3,2,1]`

---
## 答案

**正确答案：** B

---
## 解析

i 从左端、j 从右端向中间移动，每次随机选择一端并把另一指针值加到该端。按所有可能的选择序列推演，A、C、D可实现；B中的各位置增量组合无法由这种双指针过程产生。
