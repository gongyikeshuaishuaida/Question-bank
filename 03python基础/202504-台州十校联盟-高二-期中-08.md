# 题目 08

下列 Python 表达式的结果为 True 的是（   ）

- A. 4 in {"a":3, "b":4, "c":5}
- B. `"ab34cf"[1:3] == "b34"`
- C. "1567" < "1467"
- D. `abs(int(-4.6)) == len("qwer")`

---
## 答案

**正确答案：** D

---
## 解析

字典的 in 判断键，4 不是键；切片 [1:3] 只取下标1、2，结果为 b3；字符串按字典序比较，1567 不小于 1467；int(-4.6) 为 -4，绝对值4等于字符串 qwer 的长度。
