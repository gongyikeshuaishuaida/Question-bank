# 题目 11

有如下 Python 程序:
```python
s = input("请输入字符串 s: ")
i = 0
while i < len(s):
    if "0" <= s[i] <= "9":
    s = s[:i] + s[i+1:]
    i += 1
print("处理后的字符串：",s)
```
执行该程序后，若输入 s 的值为"2A15BDF49"，则输出结果为（   ）

- A. "ABDF"
- B. "A5BDF9"
- C. "A1BDF4"
- D. "ABDF9"

---

## 答案

**正确答案：** B
