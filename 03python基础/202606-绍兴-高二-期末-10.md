# 题目 10

有如下 python 程序段:
```python
c="a3k72m"
p=input( )
t=""
for ch in c:
    if "0" <= ch <= "9":
	    t += p[int(ch)]
    else:
	    t=chr(ord(ch)-32)+t
```
若 p 为"abcdefgh", 执行该程序后, t 的值为（   ）

- A. dhcMKA
- B. AdKhMc
- C. MKAdhc
- D. dAhKcM

---

## 答案

**正确答案：** C
