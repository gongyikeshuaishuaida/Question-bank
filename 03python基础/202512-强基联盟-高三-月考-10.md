# 题目 10

10. 有如下 Python 程序段：

```python
def f(a, k):
    n = len(a)
    left, ssum, mlen = 0, 0, 0
    for right in range(n):
        ssum += a[right]
        while left <= right and ssum > k:
            ssum -= a[left]
            left += 1
        if ssum <= k:
            mlen = max(mlen, right - left + 1)
    return mlen

a = [-5, 8, 7, -4, 5, 2]
k = int(input("k="))
print(f(a, k))
```

运行程序，输入 `k` 的值为 5，输出结果为（   ）
- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** B

---

## 解析

按程序执行，最长满足当前窗口和不超过 5 的窗口长度为 3，例如处理到 `[-4, 5, 2]` 时窗口和为 3，长度为 3。程序中的 `mlen` 最终更新为 3，因此输出 B。
