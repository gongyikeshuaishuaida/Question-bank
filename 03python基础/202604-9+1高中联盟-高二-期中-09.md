# 题目 09

9. 已知 `a`、`b` 均为小于 26 的正整数，下列 Python 程序段中，能实现和语句 `y=(a+b)%26` 相同功能的是（   ）

- A.

```python
y = a % 26 + b % 26
```

- B.

```python
if a + b > 26:
    y = a + b - 26
else:
    y = a + b
```

- C.

```python
if a + b < 26:
    y = a + b
else:
    y = a + b - 26
```

- D.

```python
y = a + b
if y > 26:
    y = y - 26
```

---

## 答案

**正确答案：** C

---

## 解析

因为 `a`、`b` 都是小于 26 的正整数，`a+b` 的范围为 2 到 50。若 `a+b<26`，结果为 `a+b`；否则结果为 `a+b-26`，包含 `a+b=26` 时结果为 0，因此选 C。
