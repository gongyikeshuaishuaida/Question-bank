# 题目 11

11. 有如下 Python 程序段：

```python
from random import randint
a = [1]*8
p = randint(1,7)
a[0] = p
for i in range(1,len(a)):
    a[i] = a[i-1] + randint(1,5)*2
for i in range(len(a)-1,p,-1):
    a[i] = a[i-1]
a[i-1] = p
print(a)
```

执行该程序段后，输出的结果可能是（   ）

- A. `[4, 10, 18, 4, 20, 22, 24, 26]`
- B. `[6, 14, 22, 32, 40, 44, 6, 46]`
- C. `[1, 1, 7, 11, 19, 31, 33, 41]`
- D. `[2, 5, 2, 7, 17, 19, 21, 29]`

---

## 答案

**正确答案：** B

---

## 解析

初始 `p` 的范围是 1 到 7，`a[0]=p`，随后各元素在前一项基础上增加偶数，因此移动前的列表从 `a[0]` 开始递增且差值为正偶数。最后循环把 `p` 插入到下标 `p` 位置附近，并会出现两个值为 `p` 的元素。B 中 `p=6`，前半部分差值均为正偶数，且插入位置符合程序逻辑；其它选项的差值或插入位置不符合。
