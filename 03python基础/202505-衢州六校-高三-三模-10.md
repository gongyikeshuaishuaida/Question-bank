# 题目 10

10. 定义如下函数：

```python
def f(x):
    if len(x) == 1:
        return ""
    if x[0] == x[-1]:
        return f(x[:-1]) + x[0]
    return f(x[1:])
```

执行语句 `t=f("abababb")` 后，`t` 的值为（   ）

- A. "bbb"
- B. "bba"
- C. "abb"
- D. "aa"

---
## 答案

**正确答案：** C

---
## 解析

递归从两端比较字符串首尾字符，不相等时去掉首字符，相等时递归处理去掉末字符的字符串并把首字符追加到结果。按调用链逐步计算，`f("abababb")` 的返回值为 `"abb"`。
