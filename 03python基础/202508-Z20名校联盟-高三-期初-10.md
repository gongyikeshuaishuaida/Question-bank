# 题目 10

10. 编写如下所示甲、乙Python程序段：

甲程序段：

```python
k = 0
while k < int(len(a) / 2):
    a[k], a[len(a) - k - 1] = a[len(a) - k - 1], a[k]
    k += 1
```

乙程序段：

```python
x = 0
y = len(a) - 1
while x < y:
    a[x], a[y] = a[y], a[x]
    x += 1
    y -= 1
```

下列对甲、乙程序段的描述，不正确的是（   ）

- A. 甲、乙程序段的时间复杂度均为$O(n)$
- B. 若列表`a`的值为`[1, 2, 3, 4, 5]`，分别执行甲、乙程序段，列表`a`的运行结果一致
- C. 将甲程序段循环条件中的“`<`”改为“`<=`”，修改前后的程序段功能不一致
- D. 对任意列表`a`，甲、乙程序段分别运行结束后，`x+y`的值为`k`的两倍

---

## 答案

**正确答案：** D

---

## 解析

两段程序都通过约一半次数的交换将列表逆序，时间复杂度均为$O(n)$，结果一致。甲改成`<=`后，偶数长度列表会多交换一次中间两个元素，功能发生变化。乙程序结束后`x+y`恒为`len(a)-1`，甲程序的`2*k`仅在部分长度下与之相等，因此D错误。
