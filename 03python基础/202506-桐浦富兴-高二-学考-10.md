# 题目 10

10. 有如下 Python 程序段：

```python
a = "book"
s = ""
sum = 0
for ch in a:
    s = s + str(ord(ch) - ord("a") + 1)
for ch in s:
    sum += int(ch)
print(sum)
```

程序执行后，输出结果为（   ）

- A. 11
- B. 16
- C. 27
- D. 43

---

## 答案

**正确答案：** B

---

## 解析

第一个循环将每个字母转为字母序数值：
- `b` → `ord('b') - ord('a') + 1 = 2`
- `o` → `ord('o') - ord('a') + 1 = 15`
- `o` → `15`
- `k` → `ord('k') - ord('a') + 1 = 11`

`s = "2151511"`

第二个循环求和：`2 + 1 + 5 + 1 + 5 + 1 + 1 = 16`。
