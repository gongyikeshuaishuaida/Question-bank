# 题目 15

15. 字符串加密先按`key1`给出的区间（允许首尾环接）依次翻转，再按`key2`给出的
`[L,X]`把每个长度为L的分段循环右移X位。解密时逆序撤销这些操作。

（1）明文 `s` 为 `"transform"`，密钥 `key1` 为 `[[2,5]]`，密钥 `key2` 为 `[[4,1],[8,2]]`，加密后得到的密文第一个字符为______。

（2）有如下 `get_length()` 和 `rev()` 两个函数，其中 `rev()` 函数加框处的语句有误，请改正。

```python
# 求长度为 n 的列表中下标 st 到 ed 区间的长度（含 st 和 ed）
def get_length(n, st, ed):
    return (ed - st + n) % n + 1

# 将列表 data 中下标 st 到 ed（含 st 和 ed）的区间进行翻转
def rev(data, st, ed):
    n = len(data)
    t = get_length(n, st, ed)
    for i in range(t):
        p = (st + i) % n
        q = (ed - i) % n
        data[p], data[q] = data[q], data[p]
```

（3）实现加密和解密的 Python 程序如下，请在划线处填入合适的代码。

## 答案

（1）`a`

（2）`t = get_length(n, st, ed) // 2`

（3）

- ① `rev(data, key[i][0], key[i][1])`
- ② `rev(data, st, ed)`
- ③ `shift = le - key[i][1]`

---

## 解析

区间翻转只需交换区间长度的一半，否则会再次换回。解密要按加密操作的逆序执行；循环右移的逆操作可通过相应的分段翻转实现。
