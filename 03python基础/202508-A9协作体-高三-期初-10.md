# 题目 10

10. 有如下Python程序：

```python
n = len(s)
max = c = 0
for i in range(n):
    if "a" <= s[i] <= "z" or "A" <= s[i] <= "Z":
        c += 1
    else:
        if c > max:
            max = c
        c = 0
```

若`s`为`"Python is a popular language"`，执行该程序段后，`max`的值为（   ）

- A. 8
- B. 7
- C. 6
- D. 5

---

## 答案

**正确答案：** B

---

## 解析

遇到非字母时才更新max。前四个单词长度为6、2、1、7；末尾language后没有分隔符，长度8不会写入max，因此结果为7。
