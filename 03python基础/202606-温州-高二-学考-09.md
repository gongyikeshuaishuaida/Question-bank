# 题目 09

9. 某 Python 程序段如下：

```python
s = "22114415"
c = ""
for i in range(0, len(s), 2):
    r = int(s[i])
    k = int(s[i + 1])
    p = (r - 1) * 5 + (k - 1)
    if p >= 10:
        p += 1
    c += chr(p + ord("a"))
print(c)
```

该程序运行后，输出的结果是（　）

- A. `gage`　B. `gate`　C. `gase`　D. `gaze`

---

## 答案

**正确答案：** B

---

## 解析

四对坐标22、11、44、15依次得到字母g、a、t、e，输出`gate`。
