# 题目 10

10.有如下 Python 代码：

```python
n=int(input("n="))
i=2
k=c=0
while n>1:    #①
    if n%i==0:
        if k!=i:
            c+=1
            k=i
        n=n//i
    else:
        i+=1    #②
print(c)
```

运行该代码，并输入28，下列说法正确的是（   ）

- A. 变量c的值为3
- B. 变量k的值为7
- C. ②处代码执行了6次
- D. ①处代码"n>1"改为"n>0"，对程序没有影响

---

## 答案

**正确答案：** B

---

## 解析

程序统计n的不同质因数个数。n=28时：28含质因数2和7，c=2≠3，A错；最终k=7，B正确。跟踪：i从2开始，28÷2=14(c=1,k=2)，14÷2=7，7%2≠0→i=3,4,5,6,7共执行②5次，C错；n>1改为n>0后n=0时无限循环，D错。
