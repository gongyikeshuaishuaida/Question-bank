# 题目 08

阅读下列材料，回答第 08 题。

为了保障道路通畅，减缓交通压力，杭州在规定区域和时间段实行浙 A 号牌小型、微型载客汽车限行，规则如下：按机动车牌最后一位阿拉伯数字，施行尾号限行，星期一至五，限行尾号依次为：1 和 9、2 和 8、3 和 7、4 和 6、5 和 0。如车牌号“浙 A1234H”的最后一位阿拉伯数字为“4”，则在周四限行。

根据车牌号码获取车牌尾号的代码如下：
```python
s = input("请输入浙A车牌号码：")
for i in range(①):
    if ②:
        break
```
程序中下划线处应填入的正确代码为（   ）

- A. `①1,len(s) ②'0'<=s[i]<='9'`
- B. `①len(s)-1,0,-1 ②0<=s[i]<=9`
- C. `①1,len(s) ②0<=s[i]<=9`
- D. `①len(s)-1,0,-1 ②'0'<=s[i]<='9'`

---

## 答案

**正确答案：** D
