# 题目 09

下列 Python 表达式中，值最大的是（   ）

- A.
  ```python
  3**2//8
  ```
- B.
  ```python
  int("1234"[-1])
  ```
- C.
  ```python
  len("123456"*2)//10
  ```
- D.
  ```python
  max([2,0,3,1])
  ```

---

## 答案

**正确答案：** B

---

## 解析

A 的值为 1，B 的值为 4，C 的值为 1，D 的值为 3，因此最大的是 B。
