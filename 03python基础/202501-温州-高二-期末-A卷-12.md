# 题目 12
有如下 Python 程序段：

```python
s=input()
i=0; n=len(s)
while i<n-1:
    if s[i]==s[i+1]:
        s=s[:i]+s[i+2:]
        n=2
        if i>0:
            i-=1
    else:
        i+=1
```

若输入 `s` 的值为 `"HHHOJHHHHHJOOJJG"`，执行程序段后，`s` 的值变为（　　）

- A. `"G"`
- B. `"HOG"`
- C. `"HOJG"`
- D. `"HO"`

---
## 答案
**正确答案：** B（答案表；题面代码存在不一致）

---
## 解析
参考答案表给出B。逐字核对原卷后，题面删除相邻字符后将`n`赋值为常数2；按该字面代码执行，在首次删除后循环条件立即限制为`i<1`，最终字符串为`"HOJHHHHHJOOJJG"`，并不落入四个选项。若将该行按常见意图修正为每次删除后令`n=len(s)`，程序运行结果为`"HOJHJG"`，仍与选项不符。因此本题保留官方答案B，同时在解析中明确题面代码与选项/答案无法复现，需人工回看原始命题稿。
