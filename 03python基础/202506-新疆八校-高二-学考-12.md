# 题目 12

某班举行“智力问答比赛”，共 25 小题，每小题答对得 1 分，答错或缺答得 0 分。原始小题分存储在文本文件 `score.txt` 中，每行记录一位同学的姓名和 25 道小题分，姓名和小题分之间以空格分隔。等级评判标准如下：

| 分数 | 分数 ≥ 21 | 16 ≤ 分数 < 21 | 11 ≤ 分数 < 16 | 分数 < 11 |
|---|---:|---:|---:|---:|
| 等级 | A | B | C | D |

程序运行结果为：A 等级有 3 人、B 等级有 14 人、C 等级有 12 人、D 等级有 1 人。

（1）某位同学的 25 道小题答题情况为 `1111100011111111011111001`，则该同学的总分为 **19** 分，属于 **B** 等级。

（2）自定义 `sumx` 函数，将每位同学的小题分求和：

```python
def sumx(x):
    sum = 0
    for i in x:
        sum = sum + int(i)
    return sum
```

划线处应填：`sum = 0`。

（3）自定义 `grade` 函数，获取分数对应的 A、B、C、D 等级：

```python
def grade(zf):
    if zf >= 21:
        dj = 'A'
    elif zf >= 16:
        dj = 'B'
    elif zf >= 11:
        dj = 'C'
    else:
        dj = 'D'
    return dj
```

划线处应填：`'D'`（或 `"D"`）。

（4）自定义 `stat` 函数，统计各个等级的同学人数：

```python
def stat(scores):
    result = [0, 0, 0, 0]
    for i in scores:
        dj = grade(i)
        result[ord(dj) - 65] += 1
    return result
```

划线处应填：`grade(i)`。

（5）主程序最后输出各等级人数：

```python
for i in range(len(result)):
    print(chr(i + 65) + '等级有' + str(result[i]) + '人')
```

划线处应填：`str(result[i])`。

## 答案

（1）①19，②B；（2）`sum=0`；（3）`'D'`；（4）`grade(i)`；（5）`str(result[i])`。

## 解析

答题串中共有 19 个字符 `1`，所以总分为 19，落在 16—20 分的 B 等级。`sumx` 需要先初始化累加变量；最低等级返回字符串 `D`；`stat` 对每个总分调用 `grade`，输出时需将人数整数转换为字符串后与中文文本拼接。
