# 题目 14

14. 某 Python 程序如下：

```python
n = int(input("请输入一个正整数："))
total = 0
while n > 0:
    digit = n % 10
    total += digit
    n = n // 10
print("各位数字之和是：", total)
```

如果输入的数为 7256，则 while 循环体执行的次数是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C

---

## 解析

输入 `7256`，while 循环逐次剥离个位数字：

- 第 1 次：`n=7256`，`digit=6`，`n=725`
- 第 2 次：`n=725`，`digit=5`，`n=72`
- 第 3 次：`n=72`，`digit=2`，`n=7`
- 第 4 次：`n=7`，`digit=7`，`n=0`
- `n=0`，不满足 `n>0`，退出。

共计执行 4 次，选 C。
