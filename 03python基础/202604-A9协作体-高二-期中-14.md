# 题目 14

服务器根据温度数据生成状态码，满足一定条件时发送给智能终端以控制风扇运行，当温度持续 20 分钟以上高于 30℃ 时，发出警报。生成和发送状态码的规则如下：

① 温度≤20℃时，状态码为 0；温度≥30℃时，状态码为 2；其他温度范围，状态码为 1。

② 当状态码连续 `k`（`k>1`）个相同，且与最近已发送状态码不同时，则发送该状态码。

请回答下列问题：

（1）若 `k` 为 2，最近已发送状态码为 1，随后生成的状态码序列为“0, 0, 0, 2, 0, 0, 1, 1, 1, 0”，则由该序列触发的状态码发送次数为 ________ 次。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适代码。

```python
sent = last = -1
time = 0
# 获取 k 值，代码略
while True:
    # 获取温度数据保存到变量 t 中，代码略
    code = 0
    if t >= 30:
        code = 2
        time += 1
        if time > 20:
            # 发出警报，代码略
    ________①:
        code = 1
    if code != 2:
        time = 0
    if ________②:  # 比较当前状态码与最近已发送状态码
        if code == last:
            ________③
            if cnt == k:
                # 发送状态码 code，代码略
                sent = code
        else:
            cnt = 1
        last = code
    # 延时 1 分钟，代码略
```

---

## 答案

（1）2

（2）

- ① `elif t > 20`（或 `if 20 < t < 30` 等价答案）
- ② `code != sent`
- ③ `cnt += 1`（或 `cnt = cnt + 1`）

---

## 解析

（1）前两个 0 触发发送状态码 0；随后单个 2 不满足连续 2 个，接下来的 0 与最近已发送的 0 相同，不再发送；前两个 1 又触发发送状态码 1，因此共发送 2 次。

（2）状态码初值为 0，温度≥30℃的分支置为 2，中间温度范围应通过 `elif t>20` 置为 1。只有当前状态码与最近已发送状态码不同才需要继续累计；若它还与上一时刻状态码相同，则把连续计数 `cnt` 加 1。
