# 题目 09

某二分查找算法如下：

```python
i=0; j=len(a)-1
n=0
while i<=j:
    m=(i+j)//2
    n+=1
    if key<=a[m]:
        j=m-1
    else:
        i=m+1
```

若 `a=[1,2,2,3,4,4,5,6]`，查找 `key=2`，执行后 `n` 的值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---
## 答案
**正确答案：** C
---
## 解析
中点依次为下标 3、1、0，共执行 3 次循环。
