# 题目 09


阅读下列材料，回答第 09 题。

某地部署了一套智能交通路口抓拍系统。该系统利用高清摄像头与 LED 补光灯协同工作，完成车辆通行信息的采集与自动识别，并将数据上传至数据中心。工作人员可通过终端设备查看相关数据。

LED 补光灯支持三种智能控制模式（满足任一条件即可）：

(1) 手动控制：工作人员可通过终端设备进行远程开关；  
(2) 光敏控制：当光照强度低于 200 时自动开启，高于 300 时关闭；  
(3) 时间控制：在 18:00 至次日 5:59 时段内自动开启。

9. 在不考虑手动控制的情况下，`lux` 表示光照强度，`time` 表示时间（单位：小时），`flag` 表示是否开启补光灯（`True` 为开启、`False` 为关闭，初始值为 `False`），下列表达光敏控制和时间控制的代码，不正确的是（   ）

- A.

```python
if time >= 18 or time < 6:
    flag = True
elif lux > 300:
    flag = False
elif lux < 200:
    flag = True
```

- B.

```python
if time >= 18 or time < 6:
    flag = True
else:
    if lux > 300:
        flag = False
    elif lux < 200:
        flag = True
```

- C.

```python
if 6 <= time < 18 or lux > 300:
    flag = False
else:
    flag = True
```

- D.

```python
if lux < 200 or not 6 <= time < 18:
    flag = True
elif lux > 300:
    flag = False
```


---

## 答案

**正确答案：** C

---

## 解析

白天 6:00 至 18:00 之间，如果光照强度低于 200，也应该自动开启补光灯。C 选项只要处于白天就把 `flag` 设为 `False`，忽略了低照度开启的条件，因此不正确。
