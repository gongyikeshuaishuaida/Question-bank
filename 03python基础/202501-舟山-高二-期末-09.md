# 题目 09

9. 小明编写自定义函数判断正整数 `x` 是否是素数，函数 Python 代码如下：

```python
def prime(x):
    if x == 1:
        return False
    if x == 2:
        return True
    for i in range(2, x):
        if x % i == 0:
            return False
        else:
            return True
```

此函数存在问题，能测试出问题的 `x` 的值为（   ）

- A. 2
- B. 8
- C. 11
- D. 25

---

## 答案

**正确答案：** D

---

## 解析

函数在循环中第一次 `x % i != 0` 时就返回 True，而非检查完所有因子。`prime(25)`：i=2 时 25%2=1 ≠ 0，进入 else 直接返回 True（错误，25=5×5）。`prime(2)` 在循环前直接返回 True（正确），`prime(8)` 被 2 整除返回 False（正确），`prime(11)` 被 2 不能整除 → else → 返回 True（恰好正确，因为下一个因子 3 也不会整除）。
