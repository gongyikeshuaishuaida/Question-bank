# 题目 13

13. 小明收集了一批对联存于文件“对联.txt”中，每行以逗号分隔，依次为 4 字横批、上联、下联；上下联字数相同。该文件收录的对联均为五言、七言或十言，且这三种类型的对联皆有出现。部分数据如第 13 题图所示。小明编写 Python 程序，从“对联.txt”文件读取数据并按对联字数分类，再根据输入的对联字数和数量，随机输出符合条件的对联。

![[attachments/202603名校协作体高二月考_13_图1.png]]

（1）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
import random
dic = {}
f = open("对联.txt", "r")
line = f.readline()  # 读取当前行内容并返回字符串
while line:
    # 将 line 转为列表 s，代码略。如首行 s=["前程似锦","奋蹄追晓日","昂首笑春风"]
    x = ____①____  # 获取当前对联的上联字数
    if x not in dic:
        dic[x] = [____②____]
    else:
        dic[x].append(s)  # 在列表末尾追加元素
    line = f.readline()
f.close()
num = [5, 7, 10]
while True:
    n = int(input("输入上联字数(5/7/10): "))
    m = int(input("输入所需对联数量: "))
    if n in num and ____③____:
        d = random.sample(dic[n], m)
        for i in range(m):
            print("横批:", d[i][0])
            print("上联:", d[i][1], "下联:", d[i][2])
        break
    elif n not in num:
        print("输入的上联字数不符合要求，请重新输入！")
    else:
        print("所需的对联数量超过该字数对联总量，请重新输入！")
```

（2）利用上述程序，能否同时查询不同字数的对联______（单选，填字母：A. 能 / B. 不能）。

---

## 答案

（1）① `len(s[1])` 或 `len(s[2])`；② `s`；③ `m <= len(dic[n])` 或 `n in dic and m <= len(dic[n])`

（2）B

---

## 解析

列表 `s` 中第 2、3 个元素分别是上联和下联，字数相同，因此可用 `len(s[1])` 或 `len(s[2])` 作为分类键。字典的每个键对应同字数对联列表，新类别要保存当前列表 `s`。抽样前必须保证所需数量不超过 `dic[n]` 中的数量。程序每次只输入一个字数 `n` 并在成功输出后 `break`，不能同时查询不同字数的对联。
