# 题目 11

11. 有如下 Python 程序：

```python
import random
a = [1, 2, 3, 4, 5]
r = random.randint(0, 3)
right = len(a) - r
for i in range(r - 1, -1, -1):
    temp = a[i]
    for j in range(i + 1, i + right + 1):
        a[j - 1] = a[j]
    a[i + right] = temp
```

执行该程序段后，列表 `a` 中各元素的值不可能是（   ）

- A. `[3,4,5,2,1]`  
- B. `[1,2,3,4,5]`  
- C. `[4,5,1,2,3]`  
- D. `[2,3,4,5,1]`

---

## 答案

**正确答案：** A

---

## 解析

`r` 只能取 0、1、2、3。取 0 时列表不变，对应 B；取 1 时得到 `[2,3,4,5,1]`，对应 D；取 3 时得到 `[4,5,1,2,3]`，对应 C。无法得到 `[3,4,5,2,1]`。
