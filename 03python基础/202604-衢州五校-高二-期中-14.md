# 题目 14

在智慧物流园区中，一台自动导引车需要依次处理 N 个搬运任务。每个任务有两个属性：①耗时：完成该任务需要的时间；②截止时间：该任务期望完成的时间点。AGV 一次只能执行一个任务，且执行过程中不可中断。若任务实际完成的时间点晚于其截止时间，则产生延迟。为了优化物流调度，调度系统遵循如下规则：优先处理截止时间早的任务，以期最小化所有任务中的最大延迟时间。编写 Python 程序计算 N 个任务的最大延迟时间。请回答下列问题。

（1）若某轮的任务用 `tasks` 列表存储：`tasks = [[3, 5], [1, 4], [2, 8], [4, 6]]`（每一个任务列表 `[耗时, 截止时间]`），则该轮任务的最大延迟时间为 ________。

（2）实现上述功能的 Python 程序如下，请在划线处填写合适代码。

```python
tasks = [[3, 5], [1, 4], [2, 8], [4, 6]]

# 按照任务截止时间进行升序排序
n = len(tasks)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if ________①________:
            tasks[j], tasks[j + 1] = tasks[j + 1], tasks[j]

# 模拟调度过程，计算最大延迟时间
current_time = 0
________②________
for task in tasks:
    duration = task[0]  # 任务耗时（索引 0）
    deadline = task[1]  # 任务截止时间（索引 1）
    current_time += duration  # 更新当前时刻（任务完成时刻）
    delay = ________③________  # 计算当前任务的延迟
    if delay > max_delay:
        max_delay = delay
print("最大延迟时间：", max_delay)
```

---

## 答案

（1）2

（2）

① `tasks[j][1] > tasks[j + 1][1]`

② `max_delay = 0`

③ `current_time - deadline`

---

## 解析

先按截止时间升序排列，任务顺序为 `[1,4]、[3,5]、[4,6]、[2,8]`。各任务完成时刻依次为 `1、4、8、10`，相对截止时间的延迟分别为 `-3、-1、2、2`，最大延迟为 2。

冒泡排序中当前任务的截止时间大于后一任务时应交换，因此①比较下标 1；最大延迟初始化为 0；单个任务的延迟等于当前完成时刻减去截止时间。
