# 题目 05


阅读下列材料，回答第 05 题。

浙江居民家用充电桩电价为每千瓦时0.558元。开通峰谷电后，峰时段（8:00-22:00）电价为每千瓦时0.588元，谷时段（22:00-次日8:00）电价为每千瓦时0.308元。

5. 第4题图中的虚线框部分用Python程序段实现，下列选项正确的是（   ）

- A.

```python
if t>=8 and t<22:
    d = 0.308
else:
    d = 0.588
```

- B.

```python
if 8<=t<22:
    d = 0.308
else:
    d = 0.588
```

- C.

```python
if t>22 or t<=8:
    d = 0.308
d = 0.588
```

- D.

```python
d = 0.308
if 8<=t<22:
    d = 0.588
```


---

## 答案

**正确答案：** D

---

## 解析

峰时段是 `8<=t<22`，该时段电价为0.588，其他时段为0.308。D先设谷时段电价，再在峰时段改为0.588，逻辑正确。
