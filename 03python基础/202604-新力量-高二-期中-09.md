# 题目 09

9. 有如下 Python 程序，运行后输出结果是（   ）

```python
s = "s2t7ar"
k = 5
d = {}
for i in range(26):
    d[chr(ord('a') + i)] = chr(ord('a') + (i + k) % 26)
t = ""
for ch in s:
    if ch in d:
        t = t + d[ch]
    else:
        t = ch + t
print(t)
```

- A. `x2y7fw`
- B. `72xyfw`
- C. `n2o7vm`
- D. `72novm`

---

## 答案

**正确答案：** B

---

## 解析

字母按字母表循环后移 5 位：`s→x,t→y,a→f,r→w`；非字母 `2`、`7` 依次添加到已有字符串前端，因此最终为 `72xyfw`。
