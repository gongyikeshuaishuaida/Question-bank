# 题目 13

13. 用 Python 编写字符串查找替换程序：输入原文字符串、要查找的字符串和替换字符串，从左到右依次查找；找到就替换，并从替换处继续查找，最后输出替换结果；若未找到则输出“要查找的内容不存在”。

（1）若原文为 `"we put the bed in the bedroom"`，查找 `"bed"`，替换为 `"chair"`，则替换次数为______次。

（2）请在划线处填入合适代码。

```python
# 原文存入 text，查找串存入 key，替换串存入 rs
result = ""
①
i = 0
n = len(text)
while i < n - len(key) + 1:
    s = text[i:i + len(key)]
    if key == s:
        result += rs
        count += 1
        ②
    else:
        result += s[0]
        i += 1
③
if count > 0:
    print("替换后的结果：", result)
else:
    print("要查找的内容不存在")
```

---

## 答案

（1）2

（2）

① `count = 0`

② `i += len(key)`（或 `i += len(s)`）

③ `result += text[i:]`

---

## 解析

`bed` 在独立单词 `bed` 和 `bedroom` 开头各出现一次。匹配成功后必须越过整个查找串，避免重复处理；循环结束时还需把未扫描的尾部追加到结果。
