# 题目 11

11. 若甲、乙程序段输出结果相同，则甲程序段加框处的正确代码为

甲程序段与乙程序段如下：

```python
# 甲程序段
def fun(n):
    if n==10:
        return 1
    else:
        return __________  # 此处是方框处
print(fun(1))

# 乙程序段
r = 1
n = 10
for i in range(n-1,0,-1):
    r=(r+1)*2
print(r)
```

- A. `2*(fun(n+1)+1)`
- B. `2*fun(n+1)+1`
- C. `2*(fun(n)+1)`
- D. `2*fun(n)+1`

---
## 答案

**正确答案：** A

---
## 解析

乙程序从 `r=1` 反复执行 `r=(r+1)*2`。甲程序从 `fun(1)`递归到 `fun(10)`，每层应按相同规律先加1再乘2，因此递归表达式为 `2*(fun(n+1)+1)`。
