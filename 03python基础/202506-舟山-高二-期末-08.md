# 题目 08

8. 下列 Python 表达式的结果值最小的是（   ）

- A. `3 * (5 - 2) + 1`
- B. `abs(ord("b") - ord("d")) // len("AI")`
- C. `random.randint(0, 8) - 2 ** 3`
- D. `7 % 4 + len("Hi!")`

---

## 答案

**正确答案：** D

---

## 解析

A: 3×3+1=10。B: abs(98-100)//2=2//2=1。C: [0,8]-8=[-8,0]。D: 3+3=6。最小值可能为C（-8），但random每次不同；确定值中B=1最小。
