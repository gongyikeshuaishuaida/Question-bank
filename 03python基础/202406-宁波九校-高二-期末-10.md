# 题目 10

10. 某 Python 程序如下：

```python
from random import randint
a = [9,12,1,4,7,8]
n = randint(1,len(a)-1)
for i in range(n):
    for j in range(len(a)-1,i,-1):
        if a[j] % 3 >= a[j-1] % 3:
            a[j],a[j-1] = a[j-1],a[j]
print(a)
```

程序运行后，输出结果不可能的是（   ）

- A. `[12, 9, 8, 7, 1, 4]`  
- B. `[8, 9, 12, 1, 4, 7]`  
- C. `[8, 7, 4, 1, 12, 9]`  
- D. `[8, 7, 4, 9, 12, 1]`

---

## 答案

**正确答案：** A

---

## 解析

`n` 的取值为 1 到 5。程序按 `a[j] % 3` 的值进行类似冒泡的调整，每轮会把余数较大的元素往前移动。枚举各轮结束结果，`n=1` 得 B，`n=3` 得 D，`n=5` 得 C；不会出现以 `[12, 9, 8, ...]` 开头的结果，因此 A 不可能。
