# 题目 08

8. 有如下 Python 程序段，`info` 列表中存储了学生的性别与成绩：

```python
info = ["男", 79, "女", 98, "女", 90, "男", 90, "男", 96, "女", 92, "男", 96]
tot = c = 0
for i in range(0, len(info), 2):
    if info[i] == "女" or info[i + 1] < 90:
        continue
    tot += info[i + 1]
    c += 1
print(round(tot / c, 1))
```

执行该程序段后，输出的结果是（   ）

- A. 90.3  
- B. 91.6  
- C. 93.3  
- D. 94.0

---

## 答案

**正确答案：** D

---

## 解析

程序跳过女生和成绩低于 90 的记录，只统计男生且成绩不低于 90 的成绩：90、96、96，平均值为 `(90+96+96)/3=94.0`。
