# 题目 10

有如下 Python 程序段：

```python
a = "12345"
b = "acd"
s = ""
j = -1
for i in range(len(a)):
    j = (j + 1) % len(b)
    c = (9 - (int(a[i]) + ord(b[j]) - 97)) % len(a)
    s = str(c) + s
print(s)
```

执行该程序段后，输出结果为（   ）

- A. `85352`
- B. `25358`
- C. `30302`
- D. `20303`

---

## 答案

**正确答案：** D

---

## 解析

`j` 依次取 `0、1、2、0、1`，对应字符相对 `'a'` 的偏移量为 `0、2、3、0、2`。各轮计算出的 `c` 依次为 `3、0、3、0、2`，且每次都把新字符添加到字符串前端，因此 `s` 的变化为 `"3" → "03" → "303" → "0303" → "20303"`，最终输出 `20303`。
