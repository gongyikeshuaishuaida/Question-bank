# 题目 14

14. 某兴趣小组开发了“睡眠质量监测系统”，用于记录分析同学们的睡眠状况。系统根据“睡眠时长”和“入睡时间”两个指标对睡眠质量进行评分。其中“睡眠时长”的评分标准如第 14 题图 a 所示。“入睡时间”分为 1～4 共 4 个时间段，评分标准如第 14 题图 b 所示。睡眠质量评分=睡眠时长评分+入睡时间评分。当睡眠质量评分连续 3 天下降时，系统会发出提醒。请回答下列问题：

![[attachments/202601湖州高二期末_14_题图1.png]]

(1) 小张的入睡时间段为 2，睡眠时长为 6.5 小时，则其睡眠质量评分为   ▲   （填数字）。

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
ps, n = 0, 0
ru = [5, 3, 2, 1]        # 列表 ru 存储各入睡时间段对应的评分
while True:
    # 接收当天采集到的睡眠时长和入睡时间段数据，分别存入变量 t、d，代码略
    s = 1
    if t >= 8:
        ①
    elif t >= 7:
        s = 3
    elif t >= 6:
        s = 2
    ②
    if s < ps:
        n += 1
        if n >= 3:
            print("睡眠质量下降，请注意调整作息")
    else:
        n = 0
    ③
```

(3) 若将加框处代码 `elif t >= 7:` 改为 `if t >= 7:`，对程序运行结果是否有影响   ▲   （选填：是/否）。

---

## 答案

**正确答案：** (1) 5；(2) ① `s = 5`；② `s += ru[d-1]` 或等价代码；③ `ps = s`；(3) 是

---

## 解析

睡眠时长 6.5 小时对应 2 分，入睡时间段 2 对应 3 分，总分为 5。变量 `s` 先计算睡眠时长分，再加上列表 `ru` 中对应入睡时间段的评分，循环末尾要用当前得分更新前一天得分 `ps`。若把 `elif t >= 7` 改为 `if t >= 7`，当 `t >= 8` 时会先赋 5 分又被后一个 `if` 覆盖为 3 分，因此结果会受影响。
