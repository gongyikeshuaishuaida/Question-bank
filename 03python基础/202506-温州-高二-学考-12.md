# 题目 12

某充电桩计费规则如下：电费 = 充电电量（千瓦时）× 单价（元/千瓦时），其中充电电量由功率（千瓦）与时间（时）相乘得到。充电功率随当前电量百分比动态调整，单价分时段变化。某电车最大电池容量为 `mb` 千瓦时，当前电量百分比为 `soc`。

表 1：

| 电量百分比 | [0%, 10%) | [10%, 20%) | [20%, 60%) | [60%, 70%) | [70%, 80%) | [80%, 90%) | [90%, 100%) | 100% |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 充电功率（kW） | 45 | 55 | 60 | 53 | 45 | 30 | 20 | 0 |

表 2：

| 时段规则 | 0 点~8 点前 | 8 点~10 点前 | 10 点~14 点前 | 14 点~17 点前 | 17 点~22 点前 | 22 点~24 点前 |
|---|---:|---:|---:|---:|---:|---:|
| 单价（元/千瓦时） | 0.6 | 1.2 | 0.5 | 1.2 | 0.9 | 0.6 |

（1）若某电车开始充电时间为 10:20，10 分钟充了 6 千瓦时的电，此时电费总额为 **3** 元。

（2）定义如下函数 `getpower(b)`，参数 `b` 表示电车当前电量（千瓦时）。

```python
rates = [45, 55, 60, 60, 60, 60, 53, 45, 30, 20, 0]

def getpower(b):
    idx = int(b / mb * 10)
    power = rates[idx]
    return power
```

划线处应填：**`rates[idx]`**。

（3）实现上述功能的部分主程序如下：

```python
def tosec(s):
    return int(s[:2]) * 3600 + int(s[3:5]) * 60 + int(s[6:])

# 读取充电开始时间，存入变量 st，如 st="09:50:00"，代码略
# 读取车辆电量百分比，存入变量 soc，如 soc=0.5，代码略
ntime = tosec(st)
b = soc * mb
result = 0

while isquit() == False:
    price = getprice(ntime)
    power = getpower(b)
    t = power * 1 / 3600
    result = result + t * price
    ntime = (ntime + 1) % (24 * 3600)
    b += t
```

①程序中加框处应改为：`while b < mb and isquit() == False`（写成 `while getpower(b) != 0 and isquit() == False` 亦可），这样电池充满时会自动结束充电。  
②划线处应填入：`result + t * price`。

## 答案

（1）3；（2）`rates[idx]`；（3）① `while b < mb and isquit() == False`（或等价条件）；② `result + t * price`。

## 解析

10 点至 14 点前单价为 0.5 元/千瓦时，6 千瓦时费用为 3 元。`idx` 根据当前电量占最大容量的比例定位功率表，直接取 `rates[idx]`。循环应同时满足电池未充满且用户未停止，电费累计表达式为上一时刻费用加上本秒充电量乘单价。
