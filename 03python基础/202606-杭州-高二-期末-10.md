# 题目 10

有如下Python程序段：
```python
i, res = 0, ""
while i < len(s):
    if "g" <= s[i] <= "j":
        res += chr(ord(s[i]) + 1)
        i += 2
    else:
        res += s[i]
        i += 3
```
若s为"technology”，执行该程序段后，res的值为（   ）

- A. "tioh"
- B. "tcnlh"
- C. "uhpg"
- D. "udomg"

---

## 答案

**正确答案：** A
