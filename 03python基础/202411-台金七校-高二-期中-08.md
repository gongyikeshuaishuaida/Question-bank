# 题目 08

8. 某编码包含了“设备类型、区域、场地、位置”等信息，最后一位为校验码，如第 8 题图所示。

![[attachments/202411台金七校_08_图1.jpg]]

若编码“0200301112347”存储在变量 s 中，下列选项中能获取该编码“位置”信息的是（   ）
- A.
  ```python
  s[1:4]
  ```
- B.
  ```python
  s[9:13]
  ```
- C.
  ```python
  s[8:11]
  ```
- D.
  ```python
  s[8:-1]
  ```

---

## 答案

**正确答案：** D

## 解析

本题正确答案为 D。根据题干条件逐项判断，符合概念、代码执行结果或题图流程的选项为 D。
