# 题目 10

10. 有如下 Python 程序段：

```python
b = []; n = len(a)
for i in range(n):
    for j in range(i + 1, len(a[i])):
        if a[i][j] == a[j][i]:
            b.append(a[i][j])
```

执行该程序段后，若数组 b 的值为 `[3, 5]`，数组 a 的值可能是（   ）

- A. `a = [[1,3,7],[3,1,5],[6,5,3]]`
- B. `a = [[1,3,5],[3,1,2],[5,2,3]]`
- C. `a = [[1,3,4],[3,1,5],[4,5,3]]`
- D. `a = [[2,4,5],[3,1,3],[5,3,3]]`

---

## 答案

**正确答案：** A

---

## 解析

程序检查矩阵对称位置 `a[i][j] == a[j][i]`。A 中：a[0][1]=3==a[1][0]=3 → b=[3]；a[0][2]=7≠a[2][0]=6；a[1][2]=5==a[2][1]=5 → b=[3,5]。符合。
