# 题目 13

小华是班级的阅读小组长，为了提升大家的英文词汇量，分析课外阅读英文故事时的用词特点，他把同学们分享的英文童话统一整理在 `story.txt` 文件中。文件内容只包含大小写英文字母、空格、逗号和句号。现在需要统计所有单词首字母（不区分大小写）的出现频次，并输出出现次数最多的字母。若有多个字母并列最高，则全部输出。

![[attachments/202604杭州含周边高二_13_图1.png]]

（1）小华整理后发现小写字母 h 至 n 为首字母的出现频率依次为 50、70、75、60、68、75、75，则最后选出的首字母为（填小写字母，用逗号分隔）：________。

（2）实现上述功能的 Python 代码如下，请在划线处填入合适的代码。

```python
# 打开文件 story.txt，读取所有内容并转换成小写字母，存于字符串 text 中，代码略
dic = {}
word = ""
text += "."
for i in range(len(text)):
    ch = text[i]
    if "a" <= ch <= "z":
        ____①____
    else:
        if len(word) > 0:
            if word not in dic:
                dic[word] = 1
            else:
                ____②____
            word = ""
c = [0] * 26
for i in dic:  # 统计每个字母作为单词首字母出现的次数
    ____③____
max = 0
zm = []
for i in range(26):
    if c[i] > max:
        max = c[i]
        zm = [chr(i + 97)]
    elif c[i] == max:
        zm.append(chr(i + 97))
print(f"出现频率最高的首字母是:{zm}, 出现次数为:{max}")
```

---

## 答案

（1）`j,m,n`

（2）① `word += ch`；② `dic[word] += 1`；③ `c[ord(i[0])-97] += dic[i]`

---

## 解析

（1）h 至 n 对应频率中最大值为 75，对应 j、m、n。

（2）遇到字母时把它拼接到当前单词；遇到分隔符时用字典统计完整单词的出现次数；遍历字典时，根据单词首字母的 ASCII 码计算数组下标，并把该单词的频次累加到对应字母。
