# 题目 09

某研究表明，土壤微生物存活的最佳温度范围为 20～30℃。当土壤温度小于 20℃时，微生物的活性降低；当土壤温度大于 30℃时，微生物的活动受阻。设 `t` 为某一时刻的土壤温度，微生物的状态存储在变量 `f` 中，下列选项中不正确的是（　　）

**A**

```python
f = "活动旺盛"
if t < 20:
    f = "活性降低"
if t > 30:
    f = "活动受阻"
```

**B**

```python
f = "活动旺盛"
if t < 20:
    f = "活性降低"
else:
    f = "活动受阻"
```

**C**

```python
f = "活性降低"
if 20 <= t <= 30:
    f = "活动旺盛"
elif t > 30:
    f = "活动受阻"
```

**D**

```python
if t > 30:
    f = "活动受阻"
elif t >= 20:
    f = "活动旺盛"
else:
    f = "活性降低"
```

---

## 答案

**正确答案：** B

---

## 解析

B 中只要 `t<20` 不成立就执行 `else`，因此 20～30℃也会被错误标记为“活动受阻”。A 用初值覆盖中间区间，C、D 均正确划分三个温度范围。
