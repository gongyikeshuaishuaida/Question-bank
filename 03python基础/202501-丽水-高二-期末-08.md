# 题目 08
某公寓声控灯仅在光线暗且检测到声音时点亮。`x=0/1`分别表示光线亮/暗，`y=0/1`分别表示无声音/有声音。下列代码执行后，变量 `s` 的值不能正确描述声控灯状态的是（　　）。

- A.
  ```python
  if x==1:
      if y==1:
          s="开灯"
      else:
          s="不开灯"
  else:
      s="开灯"
  ```
- B.
  ```python
  if x==0 and y==0:
      s="不开灯"
  elif x==0 and y==1:
      s="不开灯"
  elif x==1 and y==0:
      s="不开灯"
  elif x==1 and y==1:
      s="开灯"
  ```
- C.
  ```python
  if x==1 and y==1:
      s="开灯"
  else:
      s="不开灯"
  ```
- D.
  ```python
  s="开灯"
  if x==0:
      s="不开灯"
  elif y==0:
      s="不开灯"
  ```

---
## 答案
**正确答案：** A

---
## 解析
A 在 `x!=1`（光线亮）时反而给出 `s="开灯"`，与“光线暗且有声音”条件矛盾。B逐一覆盖四种输入，C直接使用合取条件，D先默认开灯并在光线亮或无声音时关闭，三者均正确。
