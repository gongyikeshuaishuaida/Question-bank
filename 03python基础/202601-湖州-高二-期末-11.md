# 题目 11

11. 有如下 Python 程序段：

```python
m = "123"
i = 0; j = 0; c = ""
while i < len(s):
    t = int(m[j])
    c += s[(i + t) % len(s)]
    i += 1
    j = (j + 1) % len(m)
```

若 `s` 为 `"huzhou"`，运行该程序段后，变量 `c` 的值为（   ）

- A. `hzuhzu`  
- B. `uozouu`  
- C. `hzohuu`  
- D. `uhuohz`

---

## 答案

**正确答案：** D

---

## 解析

`m` 中的位移依次循环为 1、2、3。`s="huzhou"` 的长度为 6，取到的下标依次是 1、3、5、4、0、2，对应字符为 `u`、`h`、`u`、`o`、`h`、`z`，所以结果为 `uhuohz`。
