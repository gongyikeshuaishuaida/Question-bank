# 题目 11

11. 有如下 Python 程序段：

```python
import random

def f(s):
    i, j = 0, len(s) - 1
    k = random.randint(1, 3)
    ans = ""
    flag = True
    while i <= j:
        if flag and s[i] <= s[j]:
            ans += s[i]
            i += 1
        elif s[i] > s[j]:
            ans += s[j]
            j -= 1
        else:
            ans += s[k]
            i += 1
            j -= 1
        flag = not flag
    return ans
```

执行语句 `print(f("computer"))` 后，输出的结果不可能是（   ）

- A. coeopo
- B. cmempm
- C. cpeppp
- D. cpemmm

---

## 答案

**正确答案：** D

---

## 解析

随机变量 `k` 只可能取 1、2、3。分别代入跟踪循环，可得到 `coeopo`、`cmempm`、`cpeppp` 三种结果，不会得到 `cpemmm`。
