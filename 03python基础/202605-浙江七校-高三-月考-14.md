# 题目 14

某班为鼓励学生积极参加“阳光乐跑”，根据月累计跑步里程（里程均为正整数）设立以下三个奖项：乐跑达人：里程 ≥ 80 公里；乐跑先锋：60 公里 ≤ 里程 < 80 公里；乐跑新星：50 公里 ≤ 里程 < 60 公里。部分学生的月跑步数据如第 14 题图所示。现要分析该班获得“乐跑达人”和“乐跑新星”的学生所占的比例。请回答下列问题。

![[attachments/202605浙江七校_14_图1.png]]

（1）该班获得乐跑新星的学生至少有 ______ 人。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 学生月累计跑步里程存储在 data 列表中，列表各元素的数据存储格式 [姓名,里程]
max_km = max([d[1] for d in data])
total = len(data)
master = 80
star = 50
for i in range(len(data)):
    ____①____
s, j = 0, max_km
while ____②____:
    s += a[j]
    if j == master:
        master_rate = s / total * 100
        ____③____
        j = star + 10
    j -= 1
star_rate = s / total * 100
# 输出乐跑达人及乐跑新星占比，代码略
```


---

## 答案

**正确答案：** （1）1；（2）① `a[data[i][1]] += 1`；② `j >= 50` 或 `j >= star`；③ `s = 0`

---

## 解析

表中可见至少有一名学生里程 58，属于乐跑新星。程序用数组按里程计数，循环从最大里程统计到 50；统计完达人后清零，再统计新星区间。
