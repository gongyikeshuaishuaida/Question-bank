# 题目 15

某购票服务网站推出“拼全程票”功能。用户输入姓名、上车车站、下车车站；系统为同一车次中可衔接成全程票的用户拼票，拼票成功者不参与后续运算。

例如，沿线 5 个车站编号为 1–5，`data=[['A',3,5],['B',4,5],['C',2,4],['D',1,3],['E',1,2]]`，其中有两组拼票成功：D、A 和 E、C、B。

（1）若将 `['D',1,3]` 改为 `['D',1,4]`，则有____组用户拼票成功。

（2）定义 `check(j,b,g)`，其中 `b[j]` 存储在 j 号站上车的用户下标，`g[j]` 存储在 j 号站下车的用户下标。函数代码如下：

```python
def check(j,b,g):
    p=g[j]
    while p!=[]:
        # 函数 a.pop(i)：将列表a中下标为i的元素删除；若i不指定，默认删除最后一个
        y=p.pop()
        t=data[y][1]
        for z in range(len(b[t])):
            if t!=1 and b[t][z]==y:
                b[t].pop(z)
                if b[t]==[]:
                    p=p+g[t]
                break
```

调用该函数，若 `data=[['A',3,5],['B',4,5],['C',2,4],['D',1,4],['E',1,2]]`，`b=[[],[3,4],[2],[0],[1],[]]`，`g=[[],[],[4],[],[2,3],[0,1]]`，`j=4`，运行过程中变量 `y` 的值依次为____（用逗号间隔）。

（3）根据用户乘车信息输出拼全程票成功的用户组合。读取站点数、`data` 的代码略；`data` 已按下车车站编号降序排列。补全程序：

## 答案

（1）1

（2）`3，2，4`

（3）① `data[i][2]!=ed`；② `j=data[i][2]`；③ `data[x][0]`

---
## 解析

（1）修改后只能拼成一条连续全程路线。（2）按 `pop()` 后的扩展顺序依次处理下标 3、2、4。（3）先收集下车站为终点站的用户；拼接时用当前下车站更新 `j`，并把新用户姓名加入结果列表。
