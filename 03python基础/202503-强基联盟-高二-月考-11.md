# 题目 11

11. 有如下 Python 程序段：

```python
import random
s="abcdefghijklmnopqrstuvwxyz"
left=0
ans=""
for i in range(3,12,3):
    a=s[left:left+i]
    left+=i
    ans+=random.choice(a)
```

执行该程序段后，ans 的值可能是（   ）

- A. kfc
- B. ceo
- C. dgj
- D. adg

---
## 答案

**正确答案：** B

---
## 解析

三次切片分别为 abc、defghi、jklmnopqr，ans 的三个字符必须依次从这三个子串中选取。只有 ceo 的 c、e、o 分别满足来源范围；其余选项至少有一个字符不在对应子串中。
