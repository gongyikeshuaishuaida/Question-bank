# 题目 10

10. 某 Python 程序如下：

```python
q = [0]*7
s = 'abcdabc'
head, tail = 0, 0
for i in s:
    if tail - head == 3:
        head += 1
    elif i not in q[head: tail]:
        q[tail] = i
        tail += 1
print(q[head: tail])
```

执行上述程序后，输出的结果为（   ）

- A. `['c', 'a']`
- B. `['c', 'd']`
- C. `['d']`
- D. `['b', 'c']`

---

## 答案

**正确答案：** A

---

## 解析

程序模拟一个只保留不重复字符的队列，最大长度为 3。逐字符追踪：

- i='a'：tail-head=0<3，a 不在 [] 中，q[0]='a', tail=1。队列：[a]
- i='b'：tail-head=1<3，b 不在 [a] 中，q[1]='b', tail=2。队列：[a,b]
- i='c'：tail-head=2<3，c 不在 [a,b] 中，q[2]='c', tail=3。队列：[a,b,c]
- i='d'：tail-head=3==3，head=1，不添加。队列：[b,c]
- i='a'：tail-head=2<3，a 不在 [b,c] 中，q[3]='a', tail=4。队列：[b,c,a]
- i='b'：tail-head=3==3，head=2，不添加。队列：[c,a]
- i='c'：tail-head=2<3，c 在 [c,a] 中，不添加。队列：[c,a]

最终 `print(q[2:4])` 输出 `['c', 'a']`。
