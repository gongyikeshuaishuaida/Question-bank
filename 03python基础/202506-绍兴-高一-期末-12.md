# 题目 12

有如下 Python 程序段：

```python
import random
s = 'abc'
result = ""
i = 0
while i < len(s):
    num = random.randint(0, 1)
    # 随机生成整数 0 或 1
    if num == 1:
        result = s[i] + result
        i += 1
print(result)
```

执行程序段后，输出 `result` 的值不可能是（   ）

- A．`'abc'`
- B．`'c'`
- C．`'ba'`
- D．`'cba'`

---
## 答案

**正确答案：** A

---
## 解析

每次只有随机数为 1 时才处理下一个字符，并将该字符加到结果字符串左侧。因此按处理顺序只能得到选中字符的逆序串；三个字符全部选中时是 `cba`，不可能得到正序的 `abc`。
