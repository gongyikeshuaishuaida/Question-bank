# 题目 10

10. 有如下 Python 程序段：

```python
import random
s=''
n=random.randint(10,20)*2  # randint(10,20) 随机生成 10 到 20 之间的整数
while n>0:
    s=str(n%5)+s
    n=n//5
```

执行上述程序后，变量 s 的值可能的是（   ）

- A. "20"
- B. "41"
- C. "114"
- D. "132"

---
## 答案

**正确答案：** C

---
## 解析

n 是 20 到 40 之间的偶数，循环把它转换为五进制。"114" 的五进制值为 1×25+1×5+4=34，是范围内的偶数；"20" 对应 10，"41" 对应 21（奇数），"132" 对应 42，均不符合。
