# 题目 15

假设公交卡充值机只有 1 元、5 角、2 角、1 角、5 分、2 分、1 分这几种面值的硬币可供找零，且每种硬币现存数量均为 20 个。充值机找零时优先使用面值较大的硬币，以减少找零所需的硬币数量。程序运行效果如下：

![[attachments/202506绍兴高一_15_运行结果.png]]

（1）若需要找零 5.89 元，最少需要的硬币数量是（单选，填字母）。

- A．10
- B．11
- C．12
- D．13

**答案：B。** 找零方案为 5 个 1 元、1 个 0.5 元、1 个 0.2 元、1 个 0.1 元、1 个 0.05 元和 2 个 0.02 元，共 11 个。

（2）编写程序实现算法，部分代码补全如下：

```python
coins = [0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1]
coins_num = [20, 20, 20, 20, 20, 20, 20]
# 硬币面值按小到大排列；每种硬币现存数量

def f(money):
    for i in range(len(coins)-1, -1, -1):
        # 按大面额硬币优先原则遍历硬币面值
        if money >= coins[i]:
            n = min(int(money / coins[i]), coins_num[i])
            if n > 0:
                money = round(money - n * coins[i], 2)  # ①
                coins_num[i] -= n
                print("用了", n, "个面值为", coins[i], "的硬币")
                if money == 0:
                    break
    if money == 0:
        print("找零完成！")
    else:
        print("找零失败！剩余金额：", money)

money = float(input("请输入需要找的零钱："))
summ = 0
for i in range(len(coins)):  # 此处是方框处
    summ += coins[i] * coins_num[i]  # ②
if summ < money:
    print("零钱不够，无法找零！")
else:
    f(money)
```

①处为 **`money - n * coins[i]`**；②处为 **`coins[i] * coins_num[i]`**。

（3）程序加框处遍历顺序有误，应将 `range(len(coins))` 改为 **`range(len(coins)-1, -1, -1)`**，从大面额到小面额处理。

（4）程序③处的 `n` 表示（单选，填字母）：

- A．当前硬币的剩余数量
- B．当前硬币使用的数量
- C．当前硬币的面值
- D．当前硬币的库存

答案：**B**。

---
## 答案

（1）B；（2）① `money - n * coins[i]`，② `coins[i] * coins_num[i]`；（3）`len(coins)-1, -1, -1`；（4）B。

---
## 解析

程序先统计所有硬币库存的总价值，足额时按面值从大到小贪心取币。每次取 `n` 个当前面值硬币，就从待找金额中减去 `n * coins[i]` 并扣减库存；因此 `n` 是当前面值硬币本次使用的数量。
