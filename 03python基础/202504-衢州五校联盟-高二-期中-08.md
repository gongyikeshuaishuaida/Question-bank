# 题目 08

8.“数字山谷”是指连续子序列中存在先递减后递增，中间点为最低值的数据结构。例如数据“21432748”中存在“214”“4327”“748”三座“数字山谷”，现要统计一组数字中“数字山谷”的数量，实现该功能的程序段如下：

```python
num=input("请输入数字串:");c=0
# 此处是方框处
____①____  # 此处是方框处
for i in range(1,len(num)):
    if ____②____ and f==False:  # 此处是方框处
        f=True
    elif ____③____ and f==True:  # 此处是方框处
        c=c+1
        f=False
print("有",c,"座数字山谷")
```

方框(1)(2)(3)处可选代码有：①`f=True` ② `f=False` ③ `num[i-1]<num[i]` ④ `num[i-1]>num[i]`

方框处应填入的正确代码为（   ）

- A. ①③④
- B. ①④③
- C. ②③④
- D. ②④③

---
## 答案

**正确答案：** D

---
## 解析

开始统计前应令 `f=False`。当相邻数字由递减转为递增时，前一个数字应大于后一个数字，即使用 `num[i-1]>num[i]` 标记进入山谷；当已经进入山谷且出现递增，即 `num[i-1]<num[i]` 时计数并将 `f` 恢复为 False，因此选择 ②④③。
