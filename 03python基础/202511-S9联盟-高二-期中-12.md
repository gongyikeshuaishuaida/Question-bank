# 题目 12

有如下 Python 程序段：

```python
x = 2
y = 5
if x < y:
    y += 20
    x = x ** 2
if y >= 30:
    y = y * 2
elif y >= 5:
    if x < 5:
        x = x * 2
        y = x + y
    else:
        y = x
else:
    y = y * 2
print(x, y)
```

执行该程序段后，输出的结果为（   ）

- A. 4，60
- B. 4，4
- C. 8，33
- D. 4，25

---

## 答案

**正确答案：** C

---

## 解析

第一次判断成立，执行后 `y=25，x=4`。`y>=30` 不成立而 `y>=5` 成立；内层 `x<5` 成立，于是 `x=8`，再计算 `y=x+y=8+25=33`，最终输出 `8 33`。
