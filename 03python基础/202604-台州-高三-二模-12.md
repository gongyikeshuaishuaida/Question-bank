# 题目 12

12. 有如下 Python 程序段：

```python
from random import randint

a = [3, 1, 6, 8, 12, 14, 20, 9, 10, 11]
n, total = len(a), 0
for i in range(n-1, -1, -2):
    t = i - randint(0, i//2) * 2
    if a[t] % 2 == 0:
        total += 1
    else:
        total -= 1
    a[i], a[t] = a[t], a[i]
```

执行该程序段后，`total` 的值为（   ）

A. -1  
B. 1  
C. 3  
D. 5

---

## 答案

**正确答案：** A

---

## 解析

循环变量 `i` 依次取 9、7、5、3、1，`t` 始终为不大于 `i` 的奇数下标。程序等价于随机重排奇数下标元素并统计其奇偶性。初始奇数下标元素为 `1、8、14、9、11`，其中偶数 2 个、奇数 3 个，所以 `total=2-3=-1`。
