# 题目 10

10. 有如下 Python 程序段：

```python
s = "zj25@IT"; s1 = ""
for i in range(len(s)):
    c = s[i]
    if "A" <= c <= "Z":
        s1 += chr((ord(c) - ord("A") + 1) % 26 + ord("a"))
    elif "0" <= c <= "9":
        s1 += str((int(c) + 7) % 10)
    else:
        s1 = c + s1
```

执行该程序段后，`s1` 的值是（   ）

- A. `@jz92ju`
- B. `jz92@IT`
- C. `@jz29JU`
- D. `25@ju`

---

## 答案

**正确答案：** A

---

## 解析

逐字符处理 `s = "zj25@IT"`：

- `'z'`：小写字母，不匹配任何 if 条件，执行 else：`s1 = 'z' + '' = 'z'`
- `'j'`：小写字母，else：`s1 = 'j' + 'z' = 'jz'`
- `'2'`：数字，`(2+7)%10 = 9`，`s1 += '9'` → `s1 = 'jz9'`
- `'5'`：数字，`(5+7)%10 = 2`，`s1 += '2'` → `s1 = 'jz92'`
- `'@'`：符号，else：`s1 = '@' + 'jz92' = '@jz92'`
- `'I'`：大写字母，`(8+1)%26 = 9`，`chr(9+97)='j'`，`s1 += 'j'` → `s1 = '@jz92j'`
- `'T'`：大写字母，`(19+1)%26 = 20`，`chr(20+97)='u'`，`s1 += 'u'` → `s1 = '@jz92ju'`

最终 `s1 = '@jz92ju'`，选 A。
