# 题目 11

11. 有如下 Python 程序段：

```python
import random
a = [0] * 5
for i in range(5):
    a[i] = random.randint(1, 9)
for i in range(5):
    if i % 2 == 0:
        a[i] = a[i] // (i + 1)
    else:
        a[i] = a[i] % (i + 1)
print(a)
```

运行该段程序后，`a` 不可能的是（   ）

- A. `[4, 0, 0, 0, 0]`
- B. `[1, 1, 1, 1, 1]`
- C. `[9, 0, 1, 3, 1]`
- D. `[4, 1, 2, 3, 2]`

---

## 答案

**正确答案：** D
