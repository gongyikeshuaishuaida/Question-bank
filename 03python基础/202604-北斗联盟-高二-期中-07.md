# 题目 07

以下 Python 表达式的结果，结果与其他三个不同的选项是（   ）

- A. `not(10%3 < 10//3)`
- B. `"b" in {1:"a", 2:"b"}`
- C. `abs(3-6) == len("3*6")`
- D. `"python"[::-1][0] == "p"`

---

## 答案

**正确答案：** C

---

## 解析

A 中 `10%3` 为 1、`10//3` 为 3，结果为 `not True`，即 `False`。B 的 `in` 判断字典的键，键为 1 和 2，因此结果为 `False`。C 中两边均为 3，结果为 `True`。D 中字符串逆序后的首字符为 `"n"`，结果为 `False`。只有 C 与其余三项不同。
