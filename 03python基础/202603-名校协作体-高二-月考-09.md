# 题目 09


阅读下列材料，回答第 09 题。

国家实行居民阶梯电价，按月用电量分三档：

第一档：电量每户每月 210 度及以下，电价不变，执行每度 0.54 元；  
第二档：电量每户每月 210～400 度之间，在第一档电价基础上，每度加价 0.05 元；  
第三档：电量每户每月 400 度及以上，在第一档电价基础上，每度加价 0.3 元。  
某居民某月的用电量为 `x`，其所需支付费用为 `pay`。

9. 下列代码不能正确计算阶梯电价的是（   ）

- A.
```python
pay = x * 0.54
if x >= 400:
    pay += x * 0.3
elif x > 210:
    pay += x * 0.05
```

- B.
```python
pay = x * (0.54 + 0.3)
if x <= 210:
    pay = x * 0.54
if x < 400:
    pay = x * (0.54 + 0.05)
```

- C.
```python
if x <= 210:
    pay = x * 0.54
else:
    if x < 400:
        pay = x * (0.54 + 0.05)
    else:
        pay = x * (0.54 + 0.3)
```

- D.
```python
if 210 < x < 400:
    pay = x * (0.54 + 0.05)
elif x >= 400:
    pay = x * (0.54 + 0.3)
else:
    pay = x * 0.54
```


---

## 答案

**正确答案：** B

---

## 解析

B 中两个 `if` 是并列结构。当 `x<=210` 时，第一个 `if` 将 `pay` 设为第一档费用，但第二个 `if x<400` 仍会继续执行，把费用改成第二档单价，导致结果错误。A、C、D 都能按三个区间互斥计算。
