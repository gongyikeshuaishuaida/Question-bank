# 题目 11

11. 有如下 Python 程序段：

```python
import random

a = [0] * 6
i = 0
while i < 6:
    n = random.randint(1, 20)
    if i % 2 == 0 and n % 2 == 0:
        a[i] = n
        i = i + 1
    elif i % 2 == 1:
        a[i] = n
        i = i + 1
print(a)
```

`randint(a, b)` 随机生成一个 `[a, b]` 范围内的整数。运行该程序后，输出结果不可能是（　）

- A. `[10,6,10,12,15,19]`
- B. `[12,7,18,10,14,7]`
- C. `[18,13,12,17,14,11]`
- D. `[12,5,14,3,16,20]`

---

## 答案

**正确答案：** A

---

## 解析

下标 4 是偶数下标，必须生成偶数；A 中该位置为 15，因此不可能。
