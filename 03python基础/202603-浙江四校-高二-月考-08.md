# 题目 08

已知字典：

```python
dic = {1: "Monday", 2: "Tuesday", 3: "Wednesday"}
```

表达式 `dic[1][3] + dic[2][5:]` 的值是（   ）

- A. `"dda"`
- B. `"day"`
- C. `"nda"`
- D. `"nay"`

---

## 答案

**正确答案：** B

---

## 解析

`dic[1]` 是 `"Monday"`，索引 3 的字符为 `"d"`；`dic[2]` 是 `"Tuesday"`，切片 `[5:]` 的结果为 `"ay"`。拼接后得到 `"day"`，故选 B。
