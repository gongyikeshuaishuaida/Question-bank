# 题目 10

有如下 Python 程序段：

```python
s = input()
m = 0
n = 0
for ch in s:
    if "2" <= ch <= "8":
        m = int(ch)
    elif "m" <= ch <= "p":
        n = (ord(ch) - ord("m") + 3) % 5
ans = m * 5 + n
print(ans)
```

程序运行后，若输出为 `23`，则 `s` 可能输入的是（　）

- A. `a3b9mz`
- B. `12xyz7`
- C. `9p2k5n`
- D. `8c4p1m`

---

## 答案

**正确答案：** D

---

## 解析

程序以最后一次符合条件的数字字符更新 `m`，以最后一次位于 `"m"` 至 `"p"` 的字符更新 `n`。D 中最后一个符合数字范围的字符是 `4`，所以 `m=4`；最后一个符合字母范围的字符是 `m`，所以 `n=(0+3)%5=3`。于是 `ans=4×5+3=23`。

原卷 D 项中的 `1` 为数字 1。按原卷内容计算，D 是唯一符合条件的选项。
