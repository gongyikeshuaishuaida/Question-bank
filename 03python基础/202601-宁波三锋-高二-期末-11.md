# 题目 11

11. 有如下 Python 程序段：

```python
s1 = input("输入字符串1：")
s2 = input("输入字符串2：")
n1, n2 = len(s1), len(s2)
i = 0; j = n2 - 1
result = ""
while i < n1 and j > 0:
    if s1[i] > s2[j]:
        result += s2[j]; j -= 1
    elif s1[i] < s2[j]:
        result += s1[i]; i += 1
    else:
        i += 1; j -= 1
print(result)
```

执行该程序段，分别输入下列选项中的字符串 `s1 = "ED35"`、`s2 = "523ED"`，输出结果的是（   ）

- A. `"23D"`  
- B. `"ED53"`  
- C. `"D325"`  
- D. `"D32"`

---

## 答案

**正确答案：** D

---

## 解析

初始比较 `s1[0]` 的 `E` 与 `s2[4]` 的 `D`，因 `E>D`，输出 `D` 并令 `j=3`；随后 `E` 与 `E` 相等，两个指针同时移动；再比较 `D` 与 `3`、`D` 与 `2`，依次输出 `3`、`2`。当 `j=0` 时循环结束，结果为 `D32`。
