# 题目 14

14. 某 APP 根据用户每周运动情况进行积分。用户在一周内每达标 1 天积 1 分，若该周出现连续达标 3 天及以上，则增加额外积分，额外积分规则如第 14 题图所示。

| 连续达标天数 | 额外积分 |
| --- | --- |
| 3 | 1 |
| 4 | 2 |
| 5 | 4 |
| 6 | 8 |
| 7 | 16 |

(1) 若用户某周的运动情况为“0111101”，其中 0 表示未达标，1 表示达标，则该用户本周积分为 ______。

(2) 定义函数 `week(s)`，功能是计算一周积分，请在划线处填入合适的代码。

```python
def week(s):  # 参数s表示一周的运动情况，例如s="0111101"
    score = 0
    n = len(s)
    i = 0
    while i < n:
        if s[i] == "1":
            k = i
            while k < n and ____①____:
                k += 1
            length = k - i
            score += length
            if length >= 3:
                score += ____②____
            i = k
        else:
            ____③____
    return score
```

(3) 字符串变量 `year` 存储用户一年的运动情况，若调用 `week` 函数计算用户一年的总积分，则需要增加程序，增加程序的控制结构最合理的是 ______（单选：A. 顺序结构 / B. 分支结构 / C. 循环结构）。

---

## 答案

**正确答案：** (1) 7；(2) ① `s[k]=="1"`；② `2**(length-3)`；③ `i=i+1`；(3) C

---

## 解析

(1) 共有 5 天达标，其中连续 4 天额外加 2 分，总分为 7 分。(2) 内层循环统计连续的 `"1"`；连续天数为 3 时额外分从 1 开始，此后每增加一天翻倍；遇到 `"0"` 时需把下标后移。(3) 一年包含多周，需要循环调用 `week`。
