# 题目 09

某自定义函数如下：

```python
def func(x):
    i = 0
    s = 0
    num = 0
    while i < len(x):
        if "0" <= x[i] <= "9":
            s = s * 10 + int(x[i])
        else:
            num += int(s)
            s = 0
        i += 1
    return num
```

调用自定义函数 `func("98a76t54")`，执行后输出的结果是（   ）

- A. `228`
- B. `98`
- C. `174`
- D. `102`

---

## 答案

**正确答案：** C

---

## 解析

程序遇到非数字字符时，才把前面累计的数字加入 `num`。遇到 `a` 时加入 98，遇到 `t` 时加入 76，因此 `num=174`。末尾的 54 后面没有非数字字符触发累加，所以不会加入结果，故选 C。
