# 题目 10

某 Python 程序如下：

```python
mw = input("请输入明文:")
res = ""
for ch in mw:
    if "A" <= ch and ch <= "Z":
        res = chr(ord(ch) + 32) + res
    elif "a" <= ch and ch <= "z":
        res += chr((ord(ch) - ord("a") + 3) % 26 + ord("a"))
    elif "0" <= ch and ch <= "9":
        res += str(9 - int(ch))
    else:
        res += ch
print(res)
```

程序运行时，若输入 `"NDby@25"`，则输出结果是（   ）

- A．`ndeb@25`
- B．`ndbe@74`
- C．`dnbe@25`
- D．`dneb@74`

## 答案

**正确答案：** D

## 解析

大写 `N`、`D` 分别转成小写并插入结果首端，得到 `dn`；小写 `b`、`y` 分别向后移 3 位得到 `e`、`b`，追加为 `dneb`；数字按 9 减去原数字得到 7、4，最终为 `dneb@74`。
