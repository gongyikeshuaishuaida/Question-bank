# 题目 11

11. 有如下 Python 程序：

```python
s = input("请输入字符串")
f = 1
num = 0
snum = 0
maxm = 0
for i in range(len(s)):
    if '0' <= s[i] <= '9':
        num = num * 10 + int(s[i])
    else:
        if maxm < num:
            maxm = num
        snum += f * maxm
        f = -f
        num = 0
print(snum)
```

输入的字符串为 `3a2ab5abc6`，输出的结果是（   ）
- A. -2
- B. 6
- C. 0
- D. 5

---

## 答案

**正确答案：** A

---

## 解析

程序遇到非数字字符时，用当前已出现的最大数字 `maxm` 参与正负交替累加。依次处理分隔符时累加结果为 `3-3+3-5+5-5=-2`，末尾数字 6 后没有触发 `else`，不会再加入。
