# 题目 13

13. 手机验证码有效性判断。验证码要求为6位纯数字，校验规则如下：

- 若长度不等于6，输出“验证码长度错误！”；
- 若长度为6但含有非数字字符，输出“格式非法！”；
- 若为6位纯数字但以数字0开头，输出“验证码无效！”；
- 其他情况输出“验证码格式正确！”。

（1）若输入验证码字符串为`"087652"`，输出结果为______。

（2）补全程序：

```python
flag = [0] * 2
yzm = input("请输入手机验证码：")
n = len(yzm)
if n != 6:
    print("验证码长度错误！")
else:
    for ①:
        ch = yzm[i]
        if ch >= "0" and ch <= "9":
            flag[0] = 1
        else:
            ②
    if flag[1] == 1:
        print("格式非法！")
    else:
        if ③:
            print("验证码无效！")
        else:
            print("验证码格式正确！")
```

（3）若删除框内语句`ch = yzm[i]`，程序仍能正常运行，则①处应填写什么语句？

---

## 答案

（1）`验证码无效！`

（2）

- ① `i in range(n)`（或`i in range(len(yzm))`）
- ② `flag[1] = 1`
- ③ `yzm[0] == "0"`

（3）`ch in yzm`

---

## 解析

`"087652"`长度为6且全为数字，但首位是0，所以输出“验证码无效！”。`flag[1]`用于记录是否出现过非数字字符。若循环变量直接遍历字符串中的字符，写作`for ch in yzm`，就不再需要下标变量和`ch=yzm[i]`。
