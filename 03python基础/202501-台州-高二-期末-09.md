# 题目 09

9. 某Python程序段如下：

```python
c = 0
while len(s)>0:
    if "0"<=s[0]<="9":
        c += 1
    s = s[1:]
print(c)
```

若 `s="2024y12m30"`，程序运行后输出的结果是（   ）

- A. 10
- B. 6
- C. 7
- D. 8

---

## 答案

**正确答案：** D

---

## 解析

字符串中数字字符为 `2、0、2、4、1、2、3、0`，共8个，循环每次统计首字符后删去首字符。
