# 题目 11

若字符串 `s1` 的值为 `"BeiDou"`，执行如下程序段后，变量 `s2` 的值不可能是（   ）

```python
from random import randint

n = len(s1)
flag = [True] * n
s2 = ""
i = p = 0
while i < n:
    p = (p + randint(0, n // 3)) % n
    # randint(a, b) 随机生成一个 [a, b] 范围内的整数
    if flag[p]:
        s2 += s1[p] + chr(ord("a") + p)
        flag[p] = False
        i += 1
```

- A. `"BaicoeufebDd"`
- B. `"icufDdeboeBa"`
- C. `"ebicDdufoeBa"`
- D. `"icDdufeboeBa"`

---

## 答案

**正确答案：** B

---

## 解析

字符串长度为 6，每次 `p` 只能增加 0、1 或 2（再对 6 取模）。B 从索引 2 对应的 `"ic"` 开始，下一组却是索引 5 对应的 `"uf"`，需要一步增加 3，不可能发生。
