# 题目 11

有如下 Python 程序段：

```python
import random
s=[2,4,0,5,6,1,1,3,4,5,6]
a=[]
st=ed=ans=0
x=random.randint(0,len(s)-1) #随机生成一个[0,len(s)-1]范围内的整数
s.pop(x) #将 s 中索引为 x 的元素删除
for i in range(1,len(s)):
    if s[i]>s[i-1]:
        ed=i
    else:
        if ed-st+1>ans:
            ans=ed-st+1
        st=ed+1
        ed=st
```

执行该程序段后，`ans` 的值不可能的是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** D

---

## 解析

程序统计升序连续段长度，但循环结束时若最长升序段正好在末尾，未再与 `ans` 比较。逐项分析删除位置可得可能值为 2、3、4，不可能为 5。
