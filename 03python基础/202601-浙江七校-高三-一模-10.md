# 题目 10

10. 有如下 Python 程序段：

```python
def fun(s1, s2):
    p = 0
    for i in range(len(s1)):
        if s1[i] == s2[p]:
            p += 1
        if p == len(s2):
            return True
    return False
```

`s1` 和 `s2` 分别取下列值时，调用函数得到的结果与其他三项不同的是（　）

- A. `"12345","135"`
- B. `"36425","346"`
- C. `"98765","876"`
- D. `"24680","246"`

---

## 答案

**正确答案：** B

---

## 解析

A、C、D中的第二个字符串都能按顺序从第一个字符串中取出；B中3之后虽有4、6，但6在4之前，不能构成346。
