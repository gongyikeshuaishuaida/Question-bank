# 题目 07

7.有如下 Python 程序段：

```python
a=input()
t,s=0,0
for c in a[::-1]:
    if c.isdigit(): #判断c 是否是数字字符串
        t=t*10+int(c)
    else:
        s+=t ; t=0
s+=t
print(s)
```

当输入“456ABC123”时，程序输出的结果为（   ）

- A. 579
- B. 975
- C. 456
- D. 123

---
## 答案

**正确答案：** B

---
## 解析

字符串反向遍历为 `321CBA654`。遇到 `C` 时先把连续数字 321 加入 `s`，遍历到末尾再把连续数字 654 加入，因此输出 `321+654=975`。
