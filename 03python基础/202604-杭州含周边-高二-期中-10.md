# 题目 10

有如下 Python 程序段：

```python
a = ["abcd", "efgh", "ijkl", "mnop"]
s1 = "11,22,33,44"
i = 0
s2 = ""
while i < len(s1):
    ch = s1[i]
    if ch != ",":
        i += 1
        p = int(s1[i])
        s2 = a[p-1][int(ch)-1] + s2
    i += 1
print(s2)
```

执行该程序段后，`s2` 的结果为（   ）

- A. `"kafp"`
- B. `"afkp"`
- C. `"fpak"`
- D. `"pkfa"`

---

## 答案

**正确答案：** D

---

## 解析

程序依次把字符串中的 `11`、`22`、`33`、`44` 作为字符位置和列表位置，分别取出 `a`、`f`、`k`、`p`。每次都将新字符拼接到 `s2` 前端，因此 `s2` 依次变为 `"a"`、`"fa"`、`"kfa"`、`"pkfa"`。
