# 题目 12

有如下 Python 程序段：

```python
import random
a=[0]*6
for i in range(6):
    a[i]=random.randint(1,9)
    if i%2==0:
        a[i]+=a[i]%2
    elif a[i]%2==1:
        a[i]*=2
```

执行后，列表 `a` 的值可能是（   ）

- A. `[10,4,8,18,6,2]`
- B. `[3,4,6,10,8,14]`
- C. `[2,16,4,6,10,4]`
- D. `[8,7,8,6,10,10]`

---
## 答案
**正确答案：** A
---
## 解析
偶数下标元素若为奇数会加 1 变为偶数；奇数下标元素若为奇数会乘 2。A 中各位置均符合规则，其他选项至少有一项违反规则。
