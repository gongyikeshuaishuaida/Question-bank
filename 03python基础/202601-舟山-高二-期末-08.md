# 题目 08

8. 下列 Python 表达式中，值为 True 的是（   ）

- A. `2**3 + len("12") == 100**0.5`  
- B. `18 % 5 + 3 > 20 // 3`  
- C. `ord("D") - ord("A") != 3`  
- D. `not (3 > 2 or 6 < 5)`

---

## 答案

**正确答案：** A

---

## 解析

A 中左侧为 `8+2=10`，右侧为 `10.0`，比较结果为 True。B 中左侧为 6，右侧为 6，`6 > 6` 为 False；C 中 `ord("D")-ord("A")` 为 3，`3 != 3` 为 False；D 中括号内为 True，取反为 False。
