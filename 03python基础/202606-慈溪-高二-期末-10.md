# 题目 10

10. 有如下 Python 程序段：

```python
k = [0] * 26
c = ""
for i in range(len(s)):
    if "a" <= s[i] <= "z":
        c = c + s[i]
    elif s[i] == ",":
        j = ord(c[0]) - ord("a")
        k[j] += 1
        c = ""
```

若 `s` 为 `"ac,be,ac,ar,ca,bc,cte,"`，执行该程序段后，`k[2]` 的值为（   ）

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** C

---

## 解析

程序用每个逗号前字符串的首字母确定 `k` 中的下标并计数。`k[2]` 对应首字母 `c`，字符串中以 `c` 开头的单词为 `ca` 和 `cte`，共 2 个，因此选 C。
