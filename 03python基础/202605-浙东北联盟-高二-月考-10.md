# 题目 10

10. 有如下Python程序段：

```python
s = "PyThOn"
res = ""
count = 0
for c in s:
    m = ord(c)  # 大写字母"A"的ASCII码值为65
    if 65 <= m <= 90:
        new_c = chr((m - 65 + 2) % 26 + 97)
    else:
        new_c = chr((m - 97 - 1) % 26 + 65)
    if count % 2 == 0:
        res += new_c
    else:
        res = new_c + res
    count += 1
print(res)
```

运行该程序段后，输出的值为（   ）

- A. `rXvGqM`
- B. `mgxRVQ`
- C. `qvrXGM`
- D. `MGXrvq`

---

## 答案

**正确答案：** D

---

## 解析

各字符转换后依次为`r、X、v、G、q、M`。偶数位置追加到末尾，奇数位置插入开头，`res`依次为`r、Xr、Xrv、GXrv、GXrvq、MGXrvq`。
