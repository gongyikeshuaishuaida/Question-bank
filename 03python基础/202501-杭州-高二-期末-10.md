# 题目 10

有如下 Python 程序段：

```python
s1, s2 = "newpython", "132"
n1, n2, res = len(s1), len(s2), ""
i = j = 0
m = 0
while i < n1:
    x = int(s2[j]) - 1
    res = s1[m * n2 + x] + res
    i += 1
    j = (j + 1) % n2
    m = i // n2
```

执行以上程序段后，变量 `res` 的值是（　　）

- A. `"nweptyhno"`
- B. `"nwehnopty"`
- C. `"onhpytnwe"`
- D. `"onhytpewn"`

---

## 答案

**正确答案：** D

---

## 解析

程序按每 3 个字符一组，根据 `s2="132"` 指定的组内下标顺序取字符，并把每次取得的字符插到 `res` 前端。依次取得的字符为 `n、w、e、p、t、y、h、o、n`，逆序累加后得到 `onhytpewn`。
