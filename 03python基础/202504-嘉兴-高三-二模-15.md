# 题目 15

自动灌溉系统将 m 个园区和 n 个蓄水池按编号管理。先根据湿度数据计算每个园区的用水量，再按园区编号顺序灌溉。每次优先使用剩余水量最多的水池，水量相同时优先编号小的水池；若一个水池水量不足，则用完后继续使用剩余水量最多的水池。

（1）若有5个蓄水池，水量依次为50、35、28、45、16；4个园区，需水量依次为80、15、30、10，则3号园区使用的蓄水池编号依次为____。

（2）编写 sort 函数按蓄水池水量从高到低排序，加框代码有错，请改正。

```python
def sort(lst):
    n = len(lst)
    for i in range(n-1):
        for j in range(1, n-i):
            if lst[j][1] > lst[j-1][1]:
                lst[j], lst[j-1] = lst[j-1], lst[j]
    return lst
```

## 答案

**参考答案：** （1）3号园区依次使用 3、2 号水池；（2）lst[j][1] > lst[j-1][1]；（3）① tmp=lnk[head][2]；（4）① q!=-1 and lnk[q][1]<=num；② lnk[q][1]-=num；③ p=head。

---
## 解析

（1）第一次灌溉后，1号池和4号池分别被使用，4号池剩15；2号园区从2号池使用15后剩20。到3号园区时，3号池有28、2号池剩20，按“最多优先”先用3号池，再用2号池，因此编号为3、2。  
（2）列表元素形如 [编号, 水量]，应比较下标1的水量，使用 lst[j][1] > lst[j-1][1]。  
（3）头节点需要移到链表中间时，先用 tmp 保存原头节点的后继，再令原头节点接到 p 的后继、p 接原头节点，最后把 head 指向 tmp。  
（4）循环条件确保当前水池存在且水量不足以满足剩余需求；扣除部分用水量后记录水池编号。完成当前园区后更新水池剩余水量（②），若后继存在则重新调整降序链表（③ 用 p=head 初始化剩余链表遍历指针）。
