# 题目 11

有如下 Python 程序：

```python
a = ["123", "14", "35", "22", "9", "47", "81"]
p = q = a[0]
for x in a[1:]:
    if x > p:
        p, q = x, p
    elif x > q:
        q = x
print(p, q)
```

执行该程序段后，输出的结果是（   ）

- A. `9 81`
- B. `35 81`
- C. `9 123`
- D. `123 9`

---

## 答案

**正确答案：** A

---

## 解析

列表元素都是字符串，比较时按字符的字典序进行。依次处理后，`p` 的变化为 `"123"→"14"→"35"→"9"`；`q` 最终更新为 `"81"`，因此输出 `9 81`。
