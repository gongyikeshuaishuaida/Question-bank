# 题目 11

11. 有如下 Python 程序段：

```python
def bsort(arr):
    if len(arr) == 1:
        return arr
    for i in range(len(arr) - 1):
        if arr[i] > arr[i + 1]:
            arr[i], arr[i + 1] = arr[i + 1], arr[i]
    return bsort(arr[:-1]) + [arr[-1]]
```

若执行语句 `print(bsort([3, 1, 5, 4, 2]))`，则输出的结果是

- A. `[1, 3, 2, 4, 5]`
- B. `[1, 2, 3, 4, 5]`
- C. `[3, 1, 2, 4, 5]`
- D. `[5, 4, 3, 2, 1]`

**正确答案：** B
