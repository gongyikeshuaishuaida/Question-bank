# 题目 12

12. 有如下 Python 程序：

```python
# 输入 m，代码略
i = m
j = 0
while j < i and i < len(a):
    if a[j] > a[i]:
        t = a[i]
        for k in range(i, j, -1):
            a[k] = a[k - 1]
        a[j] = t
        i += 1
    j += 1
```

若 `a` 为 `[1, 5, x, 4, 6, 7]`，执行程序后 `a` 中数据满足 `a[0] <= a[1] <= ... <= a[n-1]`，则 `m`，`x` 不可能为

- A. 2，4
- B. 2，5
- C. 3，6
- D. 3，10

---

## 答案

**正确答案：** B
