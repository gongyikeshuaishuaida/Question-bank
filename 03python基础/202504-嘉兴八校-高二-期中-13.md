# 题目 13

有如下 Python 程序，输入任意字符串 s，统计 s 中数字子串的数值之和，以及非数字字符的个数并输出结果。例如输入 123ui45，输出数字字符串和为 168、非数字字符个数为 2。请在划线处补充代码。

```python
s = input("请输入字符串：")
(1)    # 遍历变量赋初值
c = 0  # 计数器赋初值
sum = 0
a = 0
while i < len(s):
    if '0' <= s[i] <= '9':
        a = a * 10 + (2)
    else:
        sum += a
        a = 0
        (3)
    i += 1
sum += a
print("数字字符串和为：", str(sum), "非数字字符个数为：", str(c))
```

---
## 答案

**参考答案：** ① i = 0；② int(s[i])；③ c += 1（或 c = c + 1）。

---
## 解析

i 从 0 开始逐字符遍历。遇到数字时，用 a=a*10+int(s[i]) 把连续数字字符累积成一个数字子串；遇到非数字字符时先把当前数字子串加入 sum，再把计数器 c 加 1 并清零 a。循环结束后再把末尾可能存在的数字子串加入总和。
