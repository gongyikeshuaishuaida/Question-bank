# 题目 09

猜价格游戏用 `g` 表示用户猜测、`p` 表示实际价格。下列代码不能实现一次价格判断功能的是（   ）

- A.
  ```python
  if g == p:
      res = "恭喜你，猜对了！"
  elif g > p:
      res = "高了！"
  else:
      res = "低了！"
  ```
- B.
  ```python
  if g == p:
      res = "恭喜你，猜对了！"
  else:
      if g > p:
          res = "高了！"
      else:
          res = "低了！"
  ```
- C.
  ```python
  if g == p:
      res = "恭喜你，猜对了！"
  if g > p:
      res = "高了！"
  else:
      res = "低了！"
  ```
- D.
  ```python
  if g > p:
      res = "高了！"
  else:
      res = "低了！"
  if g == p:
      res = "恭喜你，猜对了！"
  ```

---
## 答案
**正确答案：** C

---
## 解析
C 中两个 `if` 独立执行。当 `g==p` 时第一个分支先赋“猜对”，但第二个 `if` 为假，随后的 `else` 又将结果改成“低了”，因此不能正确处理相等情况。
