# 题目 14

书写下列 Python 程序段运行结果：

（1）

```python
a = len(max(["123cd", "a"]))
print(a)
```

（2）

```python
print(125 // 3 ** 2 * 3 % 8)
```

（3）

```python
a = [1, 2, 3] + ["S", 9]
print(a[2:4])
```

（4）

```python
list1 = [6, 6, 17, 20, 2, 9]
list2 = [12, 2, 3, 3, 5]
p1 = min(list1) + len(list2)
p2 = list1[3] // list2[3]
ans = p1 % p2
print(ans)
```

---

## 答案

（1）1

（2）7

（3）`[3, 'S']`

（4）1

---

## 解析

（1）字符串按字典序比较，`"a"` 大于 `"123cd"`，其长度为 1。

（2）先算乘方：`3**2=9`，随后 `125//9=13`，`13×3=39`，`39%8=7`。

（3）两个列表拼接为 `[1,2,3,"S",9]`，切片 `[2:4]` 取得下标 2、3 的元素。

（4）`p1=2+5=7`，`p2=20//3=6`，所以 `ans=7%6=1`。
