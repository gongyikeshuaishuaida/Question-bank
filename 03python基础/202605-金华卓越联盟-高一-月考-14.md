# 题目 14

14. 一同学编写程序实现剪刀石头布游戏，每局游戏进行 `n` 次，获胜次数多者赢。单次规则如下：剪刀胜布，石头胜剪刀，布胜石头，相同算平手。运行程序，玩家先输入一局游戏次数，然后依次输入数字，0 表示石头，1 表示剪刀，2 表示布，计算机随机产生数字。`n` 次比赛后输出本局游戏结果。

如某次游戏进行的情况如下图所示。

![[attachments/202605金华卓越联盟_14_图1.png]]

Python 程序如下，请在划线处填入合适的代码。

```python
from random import randint

n = int(input("输入一局游戏的次数"))
lst = ["石头", "剪刀", "布"]
____①____
for i in range(n):
    p = int(input("请输入一个0~2间的数字:"))
    c = randint(0, 2)
    print("第", i + 1, "次玩家出", lst[p], "计算机出:", lst[c])
    if (p + 1) % 3 == c:
        cnt += 1
    elif ____②____:
        cnt -= 1
    if ____③____ >= n - i:
        break  # 退出循环

res = "平局!"
if cnt > 0:
    res = "玩家赢!"
____④____:
    res = "计算机赢!"
print(res)
```

---

## 答案

① `cnt=0`；② `p!=c`（或 `(p+2)%3==c`）；③ `abs(cnt)`；④ `if cnt<0`（或 `elif cnt<0`）

---

## 解析

`cnt` 记录玩家领先局数：玩家获胜时加 1，双方不相同时且玩家未获胜，说明计算机获胜，减 1。当领先局数的绝对值已经不小于剩余可追赶的局数时，胜负已无法改变，可以提前结束。最终根据 `cnt` 的正、零、负分别输出玩家赢、平局或计算机赢。
