# 题目 09

9. 有如下 Python 程序段：

```python
a = [["5","1","8"],["4","3"],["2","2","2"],["5","8"],["1","2","9"],["5","18"]]
ms = ""
for i in a:
    s = ""
    for j in i:
        s = s + j
    if s > ms:
        ms = s
print(ms)
```

执行该程序段后，输出的结果为（   ）

- A. 23
- B. 58
- C. 518
- D. 921

---

## 答案

**正确答案：** B

---

## 解析

各子列表拼接：["518","43","222","58","129","518"]。字符串比较字典序，"58" > "518"（'8'>'1'），最大为 "58"。
