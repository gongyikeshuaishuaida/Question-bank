# 题目 09

9. 有如下 Python 程序段：

```python
import random
lst = ["1", "2", "3", "4", "5"]
res = ""
i = 0
while i < len(lst):
    n = random.randint(0, 4)
    if n > 1:
        res = lst[i] + res
    i += 1
print(res)
```

执行该程序段后，输出的结果不可能的是（   ）

- A. 1  
- B. 41  
- C. 5452  
- D. 54321

---

## 答案

**正确答案：** C

---

## 解析

每个列表元素最多被处理一次，若随机数大于 1，就把当前元素加到结果字符串左侧。因此输出只能是 `"54321"` 的某个子序列，且不会出现重复字符。`5452` 中字符 5 出现两次，不可能输出。
