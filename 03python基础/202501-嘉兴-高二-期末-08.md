# 题目 08
机动车超过限速未达 50% 罚 200 元；超过限速 50% 罚 500 元，每多超过 5 公里/小时加罚 200 元。最高限速为 `s`，车速为 `x`，下列计算罚款 `y` 的程序不正确的是（　　）

- A. `if x<=s:y=0; elif x<1.5*s:y=200; else:y=500+(x-1.5*s)//5*200`
- B. 先令 `y=500+(x-1.5*s)//5*200`，再用 `if x<=s:y=0; elif x<1.5*s:y=200`
- C. `if x<=s:y=0`，随后另起 `if x>=1.5*s:y=500+(x-1.5*s)//5*200; else:y=200`
- D. 先令 `y=200`，再分别用两个独立 `if` 处理 `x<=s` 和 `x>=1.5*s`
---
## 答案
**正确答案：** C
---
## 解析
C 的第二个 `if` 带 `else`，当 `x<=s` 时会把先前的 0 覆盖为 200。
