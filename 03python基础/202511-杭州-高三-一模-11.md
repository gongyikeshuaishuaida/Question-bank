# 题目 11

11. 有如下 Python 程序段：

```python
from random import randint
b = randint(2, 3)    # randint(2, 3) 随机生成 2 或 3
for i in range(len(a) - b):
    for j in range(b, len(a) - i):
        if a[j] % b > a[j - 1] % b:
            a[j], a[j - 1] = a[j - 1], a[j]
```

若序列 a 的长度为 6，运行该程序段后，a 的值可能为（   ）

- A. `[9, 7, 6, 4, 2, 1]`
- B. `[5, 4, 2, 4, 3, 1]`
- C. `[8, 6, 4, 2, 3, 5]`
- D. `[6, 7, 5, 4, 4, 9]`

---

## 答案

**正确答案：** D

---

## 解析

程序是一种变体冒泡排序：比较的是 `a[j] % b` 和 `a[j-1] % b`（即除以 b 的余数），若前者余数大于后者则交换。

b 随机为 2 或 3：
- 若 b=2：按奇偶性排序，余数为 1（奇数）的排在前面，余数为 0（偶数）排在后面。
- 若 b=3：按 mod 3 的余数（0,1,2）排序。

分析各选项：
- A `[9,7,6,4,2,1]`：按 b=2，奇(9,7,1)应在偶(6,4,2)之前 → 1 不在前，不可能。
- B `[5,4,2,4,3,1]`：按 b=2，奇数在前 → 5 在前合理，但 4,2,4 是偶，3,1 是奇，3 和 1 不应出现在偶数之后。
- C `[8,6,4,2,3,5]`：b=2时偶数在前奇数在后，与排序逻辑相反；b=3时无法形成此模式。
- D `[6,7,5,4,4,9]`：b=2 时，偶数在前(6,4,4)奇数在后(7,5,9)，但内部排序由冒泡过程决定，可能形成此结果。b=3 时检查各数 mod 3：6→0,7→1,5→2,4→1,4→1,9→0。按余数降序排列可得到此结果。故选 D。
