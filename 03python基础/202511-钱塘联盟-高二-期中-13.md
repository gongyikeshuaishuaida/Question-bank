# 题目 13

13. 寻找孪生素数（100 以内）。孪生素数又称双胞胎素数:指相差2 的素数对，例如（3，5）、（11，
13）、（17，19）等。实现上述功能的部分Python 程序如下，请在程序中划线处填入合适的代码。
```python
def prime(n):
    for i in range(2, n):
        if ________①___________:
            return False
    return True

c = 0
for i in range(3, 100):
    if prime(i) and ______②_______:
        _____③_______
        print(i, i + 2)

print("100 之内共有" + _____④______ + "对双胞胎素数！")
```

---

## 答案

**正确答案：** ① `n%i==0`；② `prime(i+2)`；③ `c+=1`；④ `str(c)`

---

## 解析

素数判断只要存在 2 到 `n-1` 的因子即可返回 False；孪生素数需要 `i` 与 `i+2` 都是素数，每找到一对计数加 1，最后输出计数的字符串形式。
