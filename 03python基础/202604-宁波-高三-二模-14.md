# 题目 14

14. 该厂房部署了火情预警和喷淋系统，根据历史数据建立基准线，将烟雾浓度超过基准线的采集时刻判定为异常波动点，异常波动可能预示火情风险。现需要对监测点 3 某天的历史数据进行分析，找出异常波动点最密集的连续 1 小时时段（即连续 12 个采集时刻），并输出该时段的起始时间。如果有多个时段异常点数量相同，取最早出现的时段。

（1）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取该天采集的烟雾浓度、温度等数据按时间顺序存储在列表 a 中
# a 中每项为 [小时, 分钟, 烟雾浓度, 温度]
# 计算烟雾浓度基准线并存储在变量 std 中，代码略
n = len(a)
flag = [0] * n
for i in range(n):
    if a[i][2] > std:
        flag[i] = 1
start_time = cnt = 0
for i in range(12):
    ______①______
max_cnt = cnt
for i in range(1, n - 11):
    cnt = cnt - flag[i - 1] + ______②______
    if cnt > max_cnt:
        max_cnt = cnt
        ______③______
if max_cnt > 0:
    print("异常点最密集时段的起始时间：", a[start_time][0], "时", a[start_time][1], "分")
else:
    print("未发现异常点")
```

（2）若将程序加框处代码更改为 `flag[i] += 1`，是否会影响程序功能？____（单选，A. 会 / B. 不会）

---

## 答案

**正确答案：** （1）① `cnt += flag[i]`；② `flag[i+11]`；③ `start_time = i`；（2）B。

---

## 解析

flag 标记每个采集时刻是否为异常点。先统计前 12 个时刻的异常点数量，再用滑动窗口每次减去移出的 `flag[i-1]`、加上新进入的 `flag[i+11]`，若数量更大则记录起始下标。`flag[i]` 初始为 0，因此改为 `flag[i] += 1` 不影响功能。
