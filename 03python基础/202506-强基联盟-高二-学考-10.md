# 题目 10

有如下 Python 程序段：

```python
s=input()
key=[2,5,1,3,4]
result=""
for i in range(len(s)):
    k=i%len(key)
    if "A"<=s[i]<="Z":
        result+=chr((ord(s[i])-ord("A")+key[k])%26+ord("A"))
    elif "a"<=s[i]<="z":
        result+=chr((ord(s[i])-ord("a")+key[k])%26+ord("a"))
    else:
        result+=s[i]
print(result)
```

运行程序，输入 `s` 为 `"Hello World!"`，程序输出的结果为（   ）

- A. `jJMOS bPUPF!`
- B. `Jjmos Ypupf!`
- C. `Jgnnq Yqtnf!`
- D. `Jjmos Bpupf!`

---
## 答案

**正确答案：** D

---
## 解析

按 `key=[2,5,1,3,4]` 循环移位，`Hello` 变为 `Jjmos`，空格后 `World` 变为 `Bpupf`，所以输出为 `Jjmos Bpupf!`。
