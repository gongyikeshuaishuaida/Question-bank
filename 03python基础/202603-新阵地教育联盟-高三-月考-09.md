# 题目 09

9. 有如下 Python 程序段：

```python
res, i, t = "", 0, 1
s = input()
while i < len(s) and t >= 0:
    ch = s[i]
    if ch == '@':
        t -= 1
    elif ch == '$':
        t += 1
    else:
        res += ch
    i += 1
```

若输入 `s` 为 `"a@b$c@d@e"`，执行该程序段后，`res` 的值为（   ）

- A. `"abc"`
- B. `"abcd"`
- C. `"ab"`
- D. `"a"`

---

## 答案

**正确答案：** B

---

## 解析

`t` 初值为 1，遇到 `@` 减 1，遇到 `$` 加 1，普通字符加入 `res`。依次处理得到 `a`、遇 `@` 后 `t=0`，加入 `b`，遇 `$` 后 `t=1`，加入 `c`，遇 `@` 后 `t=0`，加入 `d`，再遇 `@` 后 `t=-1` 循环结束，因此结果为 `abcd`。
