# 题目 09

某共享雨伞实行阶梯计费，2 小时以内（含 2 小时）收费 3 元，超过 2 小时至 12 小时（含 12 小时），超过部分每小时加收 1 元，超过 12 小时，超过部分每小时加收 2 元。设租借时长为 `t`（单位：小时，已向上取整），总费用为 `c`（单位：元），下列 Python 语句能正确实现计费功能的是（   ）

- A.

  ```python
  if t <= 2:
      c = 3
  elif t <= 12:
      c = 3 + (t - 2) * 1
  else:
      c = 3 + (t - 2) * 2
  ```

- B.

  ```python
  c = 13 + (t - 12) * 2
  if t <= 2:
      c = 3
  if t <= 12:
      c = 3 + (t - 2) * 1
  ```

- C.

  ```python
  c = 3
  if t > 2:
      c = 3 + (t - 2) * 1
  if t > 12:
      c = 13 + (t - 12) * 2
  ```

- D.

  ```python
  if t <= 2:
      c = 3
  if t <= 12:
      c = 3 + (t - 2) * 1
  else:
      c = 3 + (t - 2) * 2
  ```

---

## 答案

**正确答案：** C

---

## 解析

正确的分段费用为：

- `t<=2` 时，`c=3`；
- `2<t<=12` 时，`c=3+(t-2)`；
- `t>12` 时，前 12 小时费用为 13 元，超出部分每小时 2 元，即 `c=13+(t-12)*2`。

C 先设置基础费用，再用两个条件依次修正第二、第三阶段，能够正确实现计费。A、D 在超过 12 小时时错误地将超过 2 小时的全部时长按 2 元计费；B、D 还存在两个独立 `if` 导致前面结果被覆盖的问题。
