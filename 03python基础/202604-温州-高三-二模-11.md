# 题目 11

11. 有如下 Python 程序段：

```python
c = [0, 0]
for x in q:
    c[x] += 1
i = 0
while i < len(st) and c[st[i]] > 0:
    c[st[i]] -= 1
    i += 1
ans = len(st) - i
```

若 `q = [0, 1, 1, 0, 0, 1]`，`st = [1, 0, 1, 1, 1, 0]`，则执行程序后，`ans` 的值为

- A. 3
- B. 2
- C. 1
- D. 0

---

## 答案

**正确答案：** B
