# 题目 11

11. 有如下 Python 程序段：

```python
import random
arr = [0] * 7
arr[0] = int(input())
for i in range(3):
    v = arr[i]
    s = random.randint(0, 1)
    if v % 2 == s:
        a = v // 2 + s
    else:
        a = v // 2 - s
    arr[2 * i + 1] = a
    arr[2 * i + 2] = 2 * (v // 2) - a
```

运行程序后，若输入 16，则数组 arr 的值不可能为（   ）

A. [16,8,8,4,4,4,4]  
B. [16,8,8,3,5,3,5]  
C. [16,7,9,4,2,5,3]  
D. [16,7,9,3,3,4,5]

---

## 答案

**正确答案：** D

---

## 解析

输入 16 后第一轮可得到 [8,8] 或 [7,9]。当父节点为 7 时，其子节点可能为 [4,2] 或 [3,3]；当父节点为 9 时，其子节点可能为 [5,3] 或 [4,4]，不可能得到 [4,5]，因此 D 不可能。
