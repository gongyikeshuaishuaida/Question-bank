# 题目 10

10. 有如下 Python 程序段：

```python
from random import randint
a = [3, 5, 16, 9, 8, 5]; r = 0
t = randint(3, 5)
for i in range(len(a)):
    if a[i] % t != 0:
        a[r] = a[i]
        r = r + 1
x = a[:r]
```

运行程序后，`x` 的值不可能是（   ）

- A. `[5, 16, 8, 5]`
- B. `[3, 5, 9, 5]`
- C. `[3, 5, 16, 9]`
- D. `[3, 16, 9, 8]`

---

## 答案

**正确答案：** C

---

## 解析

`t` 的取值可能为 3、4、5。程序保留列表中不能被 `t` 整除的元素：

- `t = 3` 时，`x = [5, 16, 8, 5]`，对应 A。
- `t = 4` 时，`x = [3, 5, 9, 5]`，对应 B。
- `t = 5` 时，`x = [3, 16, 9, 8]`，对应 D。

因此 C 不可能出现。
