# 题目 10

有如下 Python 程序段：

```python
s = input()
ans = ""; n = len(s)
for i in range(n//2, 0, -1):
    if s[i] > s[n-i]:
        ans = ans + s[i]
    else:
        ans = s[n-i] + ans
```

运行该程序段，输入 `zjgkinfoa`，运行后 `ans` 的值为（  ）

- A. onkj  
- B. nfoa  
- C. jgki  
- D. nkoj

---

## 答案

**正确答案：** A

---

## 解析

`n=9`，循环中 `i` 依次为 4、3、2、1。比较结果依次得到 `n`、追加 `k`、前插 `o`、追加 `j`，最终 `ans` 为 `onkj`。
