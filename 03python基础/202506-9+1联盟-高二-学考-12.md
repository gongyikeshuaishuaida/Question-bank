# 题目 12

小明手上有若干张卡片，每张卡片上面有一个 1 到 10000 之间的整数，数字相同的卡片为同一种卡片。程序依次读取每张卡片上的数字，统计张数最多的卡片种类，输出该种卡片的数量及其卡片上的数字；若张数最多的卡片种类不止一种，根据读入顺序依次输出。

第 12 题图 a 中的卡片如下：

![[attachments/2025069加1联盟高二_12_卡片图.png]]

运行结果如下：

![[attachments/2025069加1联盟高二_12_运行结果.png]]

（1）若将第 12 题图 a 中第 1 张卡片上的数字 4 改为 2，则输出结果的第二行内容为：**2**。

（2）定义函数 `check(m, a)`，判断 `m` 是否在列表 `a` 中出现过，如果出现，返回其索引值，否则返回 -1：

```python
def check(m, a):
    for i in range(len(a)):
        if a[i] == m:
            return i
    return -1
```

划线处应填：`return i`。

（3）定义函数 `getmax(a)`，查找列表 `a` 中最大元素的索引值；如果最大元素有重复，按索引从小到大的顺序返回所有索引值：

```python
def getmax(a):
    tans = []
    m = max(a)
    for i in range(len(a)):
        if a[i] == m:
            tans.append(i)
    return tans
```

划线处应填：`a[i] == m`（写 `a[i] == max(a)` 亦可）。

（4）实现上述功能的主程序如下：

```python
# 依次读取每张卡片上的数字存入列表 d
n = len(d)
x = []
y = []
for i in range(n):
    t = check(d[i], x)
    if t == -1:
        x.append(d[i])
        y.append(1)
    else:
        y[t] += 1

ans = getmax(y)
k = ans[0]
print(y[k])
for i in range(len(ans)):
    t = ans[i]
    print(x[t])
```

划线处应填：`ans = getmax(y)`。

## 答案

（1）2；（2）`return i`；（3）`a[i] == m`（或 `a[i] == max(a)`）；（4）`ans = getmax(y)`。

## 解析

把第一张卡片改成 2 后，数字 2 出现 3 次，成为唯一最多的卡片种类，因此第二行输出 2。`check` 找到已有数字时返回其下标；`getmax` 将计数最大值的所有下标按遍历顺序加入列表；主程序用 `getmax(y)` 找到所有最多种类。
