# 题目 10

10. 有如下 Python 程序段：

```python
t, n = 1, len(a)
for i in range(1, len(a)):
    if a[i - 1] == a[i]:
        t += 1
    elif t != 1:
        n = n - t
        t = 1
```

若 `a` 为 `[1, 2, 2, 3, 4, 4, 4, 5]`，运行该程序段后，`n` 的值为（   ）

- A. 4  
- B. 3  
- C. 2  
- D. 1

---

## 答案

**正确答案：** B

---

## 解析

初始 `n=8`。连续的两个 2 结束时，`t=2`，遇到 3 后执行 `n=n-t` 得 `n=6`。连续的三个 4 结束时，`t=3`，遇到 5 后执行 `n=n-t` 得 `n=3`。
