# 题目 10

10. 有如下 Python 程序段：

```python
from random import randint
a = [randint(1, 5) for i in range(6)]
i, n = 0, len(a)
while i < n:
    r = i + 1
    for j in range(i + 1, n):
        if a[i] != a[j]:
            a[r] = a[j]
            r += 1
    n = r
    i += 1
```

执行该程序段后，a 的值可能是（   ）

- A. `[3, 4, 6, 5, 6, 5]`
- B. `[3, 4, 5, 5, 4, 3]`
- C. `[1, 3, 3, 5, 4, 3]`
- D. `[2, 3, 1, 5, 1, 3]`

---

## 答案

**正确答案：** B

---

## 解析

程序对每个 a[i]，将后面所有与 a[i] 不同的元素前移（去重 a[i] 的重复）。结果中每个值只保留首次出现。randint(1,5) 没有 6，所以 A 含 6 不可能。B 中值都在 1-5 范围内。
