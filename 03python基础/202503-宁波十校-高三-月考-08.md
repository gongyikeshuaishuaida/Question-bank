# 题目 08

8. 下列程序段中（输入 `n` 的值的代码略）与第 7 题流程图功能不一致的是（   ）

- A. 程序段①

```python
def f(n):
    if n < 2:
        return str(1 - n)
    else:
        return f(n // 2) + str((n - 1) % 2)

print(f(n))
```

- B. 程序段②

```python
def f(n):
    if n < 2:
        return str(1 - n)
    else:
        return str(1 - n % 2) + f(n // 2)

print(f(n))
```

- C. 程序段③

```python
a = 0
s = ""
while n > 0:
    a = (n + 1) % 2
    s = str(a) + s
    n = n // 2
print(s)
```

- D. 程序段④

```python
a = 0
s = ""
while n > 0:
    a = n % 2
    s = str(1 - a) + s
    n = n // 2
print(s)
```

---

## 答案

**正确答案：** B

---

## 解析

流程图每次取当前最低位的反码，并把新字符添加在字符串左端，因此最终结果按高位到低位排列。程序段①用递归返回高位结果后再拼接当前位，③、④都在字符串左端添加反码；程序段②先拼接低位再递归处理高位，输出顺序相反。
