# 题目 13

在某数字字符串中，寻找连续数字（全部分解为 1 位数）之和等于目标值的所有字符子串。如字符串 `"20250520"` 中，和为 5 的字符子串有 `"5"`、`"50"` 和 `"05"`。实现该功能的 Python 程序代码如下。

(1) 输入字符串 `"98010321456"`，目标值为 3，结合程序分析，符合条件的字符串有： ▲ 。

(2) 请在划线处填写正确的代码：

```python
s = input("请输入数字字符串：")
t = int(input("请输入目标值："))
i = 0; j = 0
sum = 0; flag = False
while j < len(s):
    ①
    sum += int(ch1)
    while sum > t:
        ch2 = s[i]
        ②
        i = i + 1
    if sum == t:
        print("符合条件的字符串为：", ③)
        flag = True
    j = j + 1

if not flag:
    print("没有符合条件的字符串")
```

---

## 答案

**正确答案：**

(1) `03` 和 `21`

(2) ① `ch1 = s[j]`；② `sum = sum - int(ch2)`；③ `s[i:j+1]`

---

## 解析

(1) 在 `"98010321456"` 中，连续数字子串和为 3 的有 `"03"`（0+3=3）和 `"21"`（2+1=3）。

(2) 滑动窗口算法：① 取右边界字符累加；② 超出目标值时，左边界右移并减去对应值；③ 匹配时输出 `s[i:j+1]`。
