# 题目 10

10. 有两个正整数 A、B，如果 A 的所有正因子和等于 B，B 的所有正因子和等于 A，因子包括 1 但不包括其本身，且 A 不等于 B，则称 A、B 为亲密数对。如下 Python 程序段可以实现输出 3000 以内的亲密数对，填入画线处合适的代码是（   ）

```python
def div(n):
    lis = []
    for i in range(1, n // 2 + 1):
        if n % i == 0:
            lis.append(i)
    return lis

for i in range(3000):
    sum1 = sum(div(i))
    sum2 = sum(div(sum1))
    if      ①      :
        print(i, sum1)
```

- A. `sum2 == i`  
- B. `sum2 == i and i < sum1`  
- C. `i != sum1`  
- D. `sum2 == i or i != sum1`

---

## 答案

**正确答案：** B

---

## 解析

`sum1` 是 `i` 的真因子和，`sum2` 是 `sum1` 的真因子和。亲密数对要求 `sum2 == i` 且两数不同；用 `i < sum1` 还能避免同一对数被重复输出，因此选 B。
