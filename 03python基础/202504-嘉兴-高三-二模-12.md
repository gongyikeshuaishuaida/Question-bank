# 题目 12

有如下 Python 程序段：

```python
from random import randint
n = 8
a = [randint(0, 4) * 2 for i in range(n)]
for i in range(2):
    j = i + 1
    while j < n - 1:
        if i % 2 == 0:
            if a[j-1] < a[j] and a[j] > a[j+1]:
                j += 2
            else:
                a[j] += 2
        else:
            if a[j-1] > a[j] and a[j] < a[j+1]:
                j += 2
            else:
                a[j] -= 1
print(a)
```

运行后，数组 a 中的值可能的是（   ）

- A. `[0, 4, 2, 12, 2, 10, 3, 4]`
- B. `[2, 4, 3, 4, 2, 4, 2, 4]`
- C. `[7, 10, 6, 8, 6, 10, 5, 6]`
- D. `[4, 8, 0, 10, 8, 10, 1, 2]`

---
## 答案

**正确答案：** D

---
## 解析

初始数组每个元素都为偶数。外层 i=0 时只会把中间位置加 2，仍为偶数；外层 i=1 时可能把位置减 1，只有相应位置会变为奇数。逐项按 while 条件和两层分支检查，D 可由某组随机初值得到；A 含有末尾奇数但不符合相邻条件，B、C 也不满足程序对奇偶和取值范围的约束。
