# 题目 09

正常人的心率（bpm）范围一般在60～100次/分钟，现有一心率监测系统，当检测到心率不正常时，会提示异常信息。下列 Python 程序段符合要求的是（   ）

- A.

  ```python
  if bpm<60:
      sta="异常"
  if bpm>100:
      sta="异常"
  else:
      sta="正常"
  ```

- B.

  ```python
  sta="正常"
  if bpm>100:
      sta="异常"
  elif bpm<60:
      sta="异常"
  ```

- C.

  ```python
  if not(bpm>100 and bpm<60):
      sta="正常"
  else:
      sta="异常"
  ```

- D.

  ```python
  sta="异常"
  if bpm<=100:
      sta="正常"
  elif bpm>=60:
      sta="正常"
  ```

---
## 答案

**正确答案：** B

---
## 解析

B 覆盖 bpm 大于100、小于60和正常区间；A 的 else 只与第二个 if 配对，C 的条件不可能表示正常区间，D 会把大于100的部分设为正常。
