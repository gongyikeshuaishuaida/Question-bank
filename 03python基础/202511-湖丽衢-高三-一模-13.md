# 题目 13

13. 某电商平台每分钟监测当前排队等待客服服务的用户数，根据等待用户数动态调整客服模式（人工模式或"AI+人工"混合模式）。当排队用户数超过上限阈值 N 时，系统切换到混合模式；当排队用户数低于下限阈值 M（M<N）时，系统切换到人工模式。每种模式一旦激活，至少持续 3 分钟。系统记录每次混合模式的起止时间点，为招聘客服提供数据支持。

（1）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 设置上限阈值 N 和下限阈值 M，代码略
c = 0
ct = []  # 记录混合模式的起止时间点
mode = 0  # 0表示人工模式，1表示"AI+人工"混合模式
ctime = 1
while True:
    # 读取当前排队用户数，存入 s，代码略
    if s > N and mode == 0 or ①:
        c = c + 1
        if ②:
            mode = 1 - mode
            ct.append(ctime)
            c = 0
    else:
        c = 0
    ③
    # 延时 1 分钟，代码略
```

（2）下面代码实现的功能是输出 ct 中每次混合模式的起止时间，加框处代码有误，请改正。

```python
i = 0
while i < len(ct):      # 加框处有误
    st = ct[i]
    ed = ct[i + 1]
    # 输出混合模式的起止时间点，代码略
    i = i + 2
```

---

## 答案

（1）
① `s < M and mode == 1` 或 `s < M and mode != 0`
② `c == 3` 或 `c >= 3`
③ `ctime += 1`

（2）`i < len(ct) - 1` 或 `i <= len(ct) - 2`

---

## 解析

（1）程序逻辑分析：
- `mode=0` 表示人工模式，`mode=1` 表示混合模式。
- 切换条件：当 `s > N` 且当前为人工模式，或 `s < M` 且当前为混合模式时，触发切换。① 处需要判断从混合模式切换回人工模式的条件，即 `s < M and mode == 1`。
- `c` 记录当前模式持续的分钟数。每种模式至少持续 3 分钟，因此 `c` 达到 3 后才可以切换。② 处判断 `c == 3`（或 `c >= 3`）时执行模式切换，并记录混合模式的起始时间。
- ③ 处每分钟 `ctime` 递增 1，即 `ctime += 1`。

（2）原代码 `while i < len(ct)` 中，当 `i = len(ct) - 1` 时（最后一个元素），访问 `ct[i+1]` 会越界。因为 ct 中成对存储起止时间，循环只需到倒数第二个元素，改为 `i < len(ct) - 1`。
