# 题目 10

有如下 Python 程序段：

```python
a = [1, 2, 2, 3, 3, 3, 3, 5, 5, 5]
L = 1
for i in range(1, len(a)):
    if a[i] == a[i - L]:
        L += 1
print(L)
```

执行该程序段后，输出的结果是（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** D

---

## 解析

程序比较 `a[i]` 与其前面第 `L` 个位置的元素：

- `i=2` 时，`a[2]=a[1]=2`，`L` 变为 2；
- `i=5` 时，`a[5]=a[3]=3`，`L` 变为 3；
- `i=6` 时，`a[6]=a[3]=3`，`L` 变为 4。

其余位置比较不相等，最终输出 4。
