# 题目 10

有如下 Python 程序段：

```python
s1="p#y##thon#"
s2=""
i=0; j=len(s1)-1
while i<=j:
    if s1[j]=="#":
        j-=1
    else:
        if s1[i]=="#":
            s2+=s1[j]
            j-=1
        else:
            s2+=s1[i]
            i+=1
```

运行该程序段后，字符串 `s2` 的值为（   ）

- A. `python`
- B. `pnohty`
- C. `pnyoht`
- D. `pnoyht`

---
## 答案
**正确答案：** C
---
## 解析
从左、右指针依次取字符并跳过 `#`，最终按程序追加顺序得到 `pnyoht`。
