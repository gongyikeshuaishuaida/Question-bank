# 题目 11

11. 有如下 Python 程序：

```python
import random
a = [1, 2, 3, 4, 5]
r = random.randint(0, 3)
right = len(a) - r
for i in range(r - 1, -1, -1):
    temp = a[i]
    for j in range(i + 1, i + right + 1):
        a[j - 1] = a[j]
    a[i + right] = temp
```

执行该程序段后，列表 `a` 中各元素的值不可能是（   ）

- A. `[3,4,5,2,1]`  
- B. `[1,2,3,4,5]`  
- C. `[4,5,1,2,3]`  
- D. `[2,3,4,5,1]`

---

## 答案

**正确答案：** A

---

## 解析

`r` 的取值为 0、1、2、3。分别跟踪程序可得：`r=0` 时列表不变；`r=1` 得到 `[2,3,4,5,1]`；`r=2` 得到 `[3,4,5,1,2]`；`r=3` 得到 `[4,5,1,2,3]`。选项 A 的 `[3,4,5,2,1]` 不会出现。
