# 题目 09

9. 有如下 Python 程序段：

```python
def encrypt(code, key):
    code_new = ""
    for s in code:
        if "0" <= s <= "9":
            s1 = (ord(s) - ord("0") + key) % 10 + ord("0")
            code_new += chr(s1)
        elif "a" <= s <= "z":
            s1 = (ord(s) - ord("a") + key) % 26 + ord("a")
            code_new = chr(s1) + code_new
        else:
            s1 = s
            code_new += s1
    return code_new

code = input("code=")
code_new = encrypt(code, 6)
```

若 `code` 为 `Zs2026`，执行该程序段后，`code_new` 的值为（   ）

- A. `yZ8682`
- B. `8682yZ`
- C. `2868yZ`
- D. `yZ2868`

---

## 答案

**正确答案：** D
