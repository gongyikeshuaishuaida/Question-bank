# 题目 07

7. 某超市进行促销活动，若单笔消费满 100 元打九折，满 200 元打八折，单笔消费只享受一次打折优惠，输入单笔消费金额 `t` 元，输出实付金额。以下程序段不正确的是（   ）

- A.
```python
t = int(input("输入单笔消费金额(元):"))
if t >= 200:
    t = t * 0.8
elif t >= 100:
    t = t * 0.9
print("实付金额(元):", t)
```

- B.
```python
t = int(input("输入单笔消费金额(元):"))
if t >= 200:
    t = t * 0.8
if 100 <= t < 200:
    t = t * 0.9
print("实付金额(元):", t)
```

- C.
```python
t = int(input("输入单笔消费金额(元):"))
if t >= 100:
    t = t * 0.9
elif t >= 200:
    t = t * 0.8
print("实付金额(元):", t)
```

- D.
```python
t = int(input("输入单笔消费金额(元):"))
if t < 100:
    t = t
elif t < 200:
    t = t * 0.9
else:
    t = t * 0.8
print("实付金额(元):", t)
```

---

## 答案

**正确答案：** C

---

## 解析

C 不正确：当 `t >= 200` 时，第一个条件 `t >= 100` 先匹配，执行九折而非八折。`elif t >= 200` 永远不会执行。A、B、D 均正确实现了满 200 打八折、满 100 打九折的逻辑。
