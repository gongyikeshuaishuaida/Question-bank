# 题目 10

10. 有如下 Python 程序段：

```python
ans, num = 0, 0
for x in s:
    if "0" <= x <= "9":
        num += 1
    else:
        ans = max(ans, num)
        num = 0
```

若 `s` 为 `"1234Go321Jinhua66@"`，执行该程序段后，`ans` 的值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** D

---

## 解析

`num` 记录当前连续数字的长度，遇到非数字时用它更新 `ans` 后清零。字符串中的连续数字段依次为 `"1234"`、`"321"`、`"66"`，长度分别为 4、3、2，因此最终 `ans=4`。
