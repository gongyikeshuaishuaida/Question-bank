# 题目 12

12. 有如下 Python 程序段：

```python
s="Banana Icecream Gracenmar"
f=[0]*26
i=0
while i<len(s):
    ch=s[i]
    if "A"<=ch<="Z":
        ch=chr(ord(ch)+32)
    if "a"<=ch<="z":
        f[ord(ch)-ord("a")]+=1
    i+=1
for i in range(26):
    if f[i]==1:
        print(chr(i+ord("a")), end="")
```

运行以上程序段后，输出结果为（   ）

- A. rnmigecba
- B. abcegimnr
- C. big
- D. bgi

---
## 答案

**正确答案：** D

---
## 解析

程序先把大写字母转换为小写，再统计每个字母出现次数，最后按字母顺序输出出现 1 次的字母。逐字统计后只有 b、g、i 的次数为 1，因此输出 bgi。
