# 题目 11

11. 某 Python 程序如下，运行后输出的结果是（   ）

```python
x = "ax1c4z"
s = ""
i = 0
w = [4, 3, 2, 1]
while i < len(x):
    if "a" <= x[i] <= "z":
        n = i % 4
        t = chr((ord(x[i]) - ord("a") + w[n]) % 26 + ord("a"))
        s += t
    else:
        s = x[i] + s
    i += 1
print(s)
```

- A. `"1eadc4"`
- B. `"41eadc"`
- C. `"41cade"`
- D. `"c41ead"`

---

## 答案

**正确答案：** B

---

## 解析

字母按其下标对应的 `w[i%4]` 循环移位：`a→e`、`x→a`、`c→d`、`z→c`；非字母 `1`、`4` 依次插到字符串最前面，最终得到 `"41eadc"`。
