# 题目 11

11. 某 Python 程序如下：

```python
student = {"name": "ZhangSan", "age": 16, "grade": "高一", "scores": [92, 88, 95]}
print(student["name"][1:4] + str(student["scores"][-1]))
```

程序运行后，输出的结果是（   ）

- A. `han95`
- B. `han92`
- C. `hang95`
- D. `hang92`

---

## 答案

**正确答案：** A

---

## 解析

`student["name"] = "ZhangSan"`，切片 `[1:4]` 取索引 1、2、3，即 `"han"`。

`student["scores"][-1]` 取列表最后一个元素 `95`，`str(95) = "95"`。

拼接结果：`"han" + "95" = "han95"`，选 A。
