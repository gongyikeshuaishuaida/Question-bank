# 题目 10

10. 有如下 Python 程序段：

```python
i, t = 0, ""
while i < len(s):
    c = s[i]
    if "a" <= c <= "z":
        c = chr((ord(c)-ord("a")+n) % 26 + ord("a"))
    elif "0" <= c <= "9":
        c = str((int(c)-n) % 10)
    t += c
    i += 1
```

若 `s` 为 `"9y#A3"`，`n` 为 4，执行该程序段后，`t` 的值为（   ）

- A. `"5c#A9"`
- B. `"3c#A7"`
- C. `"5c9"`
- D. `"3c7"`

---

## 答案

**正确答案：** A

---

## 解析

数字字符减 4 后对 10 取模，小写字母向后循环移动 4 位，其他字符保持不变：

- `9` 变为 `5`
- `y` 变为 `c`
- `#`、`A` 不变
- `3` 变为 `9`

因此结果为 `"5c#A9"`。
