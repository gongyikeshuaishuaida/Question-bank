# 题目 11

11. 有如下 Python 程序段：

```python
a = [8,2,4,3,1,4,4,7,1,4]
b = [8,4,1,3,6,5,9,2,7,0]
i, j = 0, len(a)-1
key = int(input("输入待查找的数:"))
s = ""
while i <= j:
    m = (i+j+1)//2
    if a[b[m]] > key:
        j = m - 1
        s += "L"
    else:
        i = m + 1
        s += "R"
print(s)
```

执行该程序段后，输入 key 的值为 4，输出结果是（   ）

- A. RLR
- B. RLLR
- C. LRLR
- D. LRL

---

## 答案

**正确答案：** A

---

## 解析

输入 `key=4`，逐轮跟踪：
- 初始 `i=0, j=9`，`m=(0+9+1)//2=5`，`b[5]=5`，`a[5]=4`，不大于 4，执行右移，`i=6`，`s="R"`。
- `i=6, j=9`，`m=8`，`b[8]=7`，`a[7]=7`，大于 4，执行左移，`j=7`，`s="RL"`。
- `i=6, j=7`，`m=7`，`b[7]=2`，`a[2]=4`，不大于 4，执行右移，`i=8`，`s="RLR"`。

此时 `i > j`，循环结束，输出 `RLR`。
