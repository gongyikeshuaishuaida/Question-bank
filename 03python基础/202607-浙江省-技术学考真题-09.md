# 题目 09

某 Python 程序如下：

```python
st = [[1, 2.5], [2, 5], [3, 5], [5, 6], [7, 9]]
n = len(st)
c = -1
t = 0
i = 0
while i < n:
    f = st[i][0]
    s = st[i][1]
    if f >= t:
        c += 1
        t = s
    i += 1
print(c)
```

程序运行后，输出的结果是（   ）

- A．2
- B．3
- C．4
- D．5

## 答案

**正确答案：** B

## 解析

依次检查 `f >= t`：第 1、3、5、7 项满足条件，`c` 从 -1 增加四次，最终输出 3。
