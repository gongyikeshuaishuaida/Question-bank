# 题目 15

15. 某工厂车间拥有多条可同时运行的生产流水线，现有若干零件加工生产任务。每个加工任务均有固定的开始加工时刻、结束加工时刻，且单个任务全程需要同时占用若干条流水线，加工过程不可中断、不可拆分。同一时间段相互重叠的加工任务，所占用流水线不可共用。

| 编号  | 开始加工时刻 | 结束加工时刻 | 占用流水线数量 |
| --- | ------ | ------ | ------- |
| 1   | 9:00   | 10:55  | 2       |
| 2   | 9:30   | 11:20  | 1       |
| 3   | 10:40  | 12:00  | 2       |
| 4   | 11:00  | 12:50  | 2       |

例如有 4 个零件要加工（如上表），零件的情况可以表示为 `[["9:00", "10:55", 2], ["9:30", "11:20", 1], ["10:40", "12:00", 2], ["11:00", "12:50", 2]]`（其中每个三元组分别表示零件开始加工时刻、结束加工时刻以及占用流水线数量），工厂高峰期 10:40 至 10:55 和 11:00 至 11:20 至少同时需要使用 5 条流水线，累计用时 35 分钟。现开发一个系统，用于统计高峰期至少同时需要几条流水线，以及高峰期所用流水线累计时间。请回答下列问题：

（1）零件的情况为 `[["9:00", "10:45", 2], ["9:30", "11:20", 1], ["10:50", "12:00", 2], ["11:00", "13:10", 1]]`，高峰期至少同时需要 ______ 条流水线。

（2）定义如下 `sort_data(a)` 函数，参数 `a` 的每个元素由时间（已经转化为分钟）、占用流水线数量以及状态（0 表示开始，1 表示结束）3 个数据项组成。函数的功能是根据时间大小，对 `a` 进行升序排序。

```python
def sort_data(a):
    n = len(a)
    for i in range(n - 1):
        flag = 0
        for j in range(n - 1, i, -1):
            if a[j][0] < a[j - 1][0]:
                a[j], a[j - 1] = a[j - 1], a[j]
                flag = 1
        if flag == 0:
            break
    return
```

## 答案

**正确答案：** （1）4；（2）① A；② 3；（3）① `h*60+m`；② `s-=a[j][1]`；③ `a[j][0]-a[j-1][0]`或`a[j][0]-a[i][0] `
