# 题目 11

有如下程序段：

```python
s = input()
k = 0
n = 0
for x in s:
    if "a" <= x <= "e":
        k = (ord(x) - ord("a") + 3) % 5 + 1
    elif "1" <= x <= "5":
        n = int(x)
key = n * 5 + k
print(key)
```

程序运行时，若输出为 20，则可能的输入是（   ）

- A. Ac4
- B. kb3
- C. a4A
- D. 9k3

---
## 答案

**正确答案：** B

---
## 解析

只有字符 a 到 e 会更新 k，数字 1 到 5 会更新 n。输入 kb3 时，b 使 k=(1+3)%5+1=5，3 使 n=3，所以 key=3×5+5=20。A、C、D 分别得到 21、24、15。
