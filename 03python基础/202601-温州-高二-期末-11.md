# 题目 11

11. 有如下 Python 程序段：

```python
def f(s):
    cnt = 0
    for ch in s:
        n = int(ch)
        if n % 2 == 1:
            cnt += 1
        elif cnt <= 0:
            return False
        else:
            cnt -= 1
    return cnt == 0
```

若函数返回值是 `False`，则 `s` 的值可能是（   ）

- A. `"9876"`  
- B. `"7744"`  
- C. `"9889"`  
- D. `"567890"`

---

## 答案

**正确答案：** C

---

## 解析

函数遇到奇数时 `cnt` 加 1，遇到偶数时需要消耗一个已有计数；若没有可消耗的计数就返回 `False`，循环结束还要求 `cnt==0`。`"9889"` 中处理到第二个 8 时 `cnt` 已为 0，因此直接返回 `False`。
