# 题目 14

14. 有以下 Python 程序：

```python
s = "4857296"
k = 3
while k > 0:
    i = 0
    while i < len(s) - 1 and s[i] >= s[i+1]:
        i += 1
    if i == len(s) - 1:
        if k > 0:
            s = s[:-k]
            k = 0
    else:
        if i == 0:
            s = s[1:]
        else:
            s = s[:i] + s[i+1:]
        k -= 1
print(s)
```

执行该程序段后，输出的值为（   ）

- A. 8796
- B. 87296
- C. 876
- D. 8526

---

## 答案

**正确答案：** A

---

## 解析

算法在字符串 `s` 中删除 `k=3` 个字符，使得剩余数字最大。策略是贪心删除第一个"升序"位置（`s[i] < s[i+1]`）的较小字符。

`s = "4857296"`，k=3：
1. 找第一个 `s[i] < s[i+1]`：4<8（i=0），删 4 → `"857296"`
2. 5<7（i=1），删 5 → `"87296"`
3. 2<9（i=2），删 2 → `"8796"`

输出 `"8796"`。
