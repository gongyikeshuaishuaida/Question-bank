# 题目 11

在 `b` 列表中存储了几个数学兴趣小组的数学成绩，现在想统计各组 100 分的人数。实现统计功能的程序如下：

```python
b = [[100, 89, 67, 99, 100, 92],
     [98, 95, 100, 94, 100],
     [88, 78, 92, 100, 100],
     [100, 100, 91, 100, 100]]
for i in ________(1):
    a = {}
    j = 0
    while ________(2):
        if b[i][j] in a:
            ________(3)
        else:
            a[b[i][j]] = 1
        j += 1
    print("第" + str(i+1) + "组" + str(a[100]) + "人")
```

从以下可选代码中依次选出上述程序中划线处的代码：

① `b`　② `range(len(b))`　③ `j<5`　④ `j<=len(i)-1`

⑤ `j<=len(b[i])-1`　⑥ `a[b[i][j]]+=1`　⑦ `a[i[j]]+=1`

- A. ①④⑦
- B. ①③⑦
- C. ②⑤⑥
- D. ②③⑥

---

## 答案

**正确答案：** C

---

## 解析

外层循环应遍历各小组的下标，填 `range(len(b))`；每组人数不同，内层循环边界应根据当前子列表长度写成 `j<=len(b[i])-1`；遇到字典中已有的成绩时应将该成绩的计数加 1，写成 `a[b[i][j]]+=1`。因此依次为②⑤⑥。
