# 题目 07

该超市推出了满减优惠活动：满 100 减 15，满 200 减 40，满 300 减 80，最多仅优惠一次。根据活动政策，编写 Python 程序计算优惠后价格。

```python
# pay 表示消费金额
________
print("优惠后价格：", pay)
```

要实现上述功能，下列选项中，可以填入加框处的代码是（   ）

- A.

  ```python
  if pay >= 100:
      pay -= 15
  elif pay >= 200:
      pay -= 40
  elif pay >= 300:
      pay -= 80
  ```

- B.

  ```python
  if pay >= 100:
      pay -= 15
  if pay >= 200:
      pay -= 40
  if pay >= 300:
      pay -= 80
  ```

- C.

  ```python
  if pay >= 300:
      pay -= 80
  elif pay >= 200:
      pay -= 40
  elif pay >= 100:
      pay -= 15
  ```

- D.

  ```python
  if pay >= 300:
      pay -= 80
  if pay >= 200:
      pay -= 40
  else:
      pay -= 30
  ```

---

## 答案

**正确答案：** C

---

## 解析

题目要求“最多仅优惠一次”，应按优惠门槛从高到低使用 `if-elif-elif`。这样金额达到多个门槛时只会执行最高档优惠。C 的判断顺序和分支关系均正确。
