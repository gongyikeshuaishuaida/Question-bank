# 题目 12

有如下Python程序段：

```python
import random
lst=[]
n=20
for i in range(n):
    k=random.randint(0,5)   # 随机生成0~5的整数
    lst.append(k*2)          # 在列表lst末尾添加元素k*2
s=0;maxs=0;c=0
for i in range(n):
    s+=lst[i]
    c+=1
    while c==5 or s>20:
        s-=lst[i+1-c]
        c-=1
    if s>maxs:
        maxs=s
```

执行该程序段后，maxs的值不可能是（   ）

- A. 0  
- B. 8  
- C. 16  
- D. 19

---

## 答案

**正确答案：** D

---

## 解析

第一个for循环随机产生20个元素，每个元素为 `k*2`（k为0~5的整数），因此列表元素均为偶数（0、2、4、6、8、10）。

第二个for循环依次将元素值累加到s中，用c统计当前窗口元素个数。当窗口元素个数为5或累加值大于20时，从左侧移除元素（滑动窗口）。然后记录s的最大值到maxs。

由于列表中所有元素都是偶数，每次累加偶数、每次减去偶数，s始终为偶数。因此maxs也始终为偶数。选项D（19）是奇数，不可能出现。
