# 题目 07

7. 三个互不相等的整数 `a`、`b` 和 `c`，下列程序段能输出其最大值的是（   ）

- A.

```python
max = a
if b > c:
    max = b
else:
    max = c
```

- B.

```python
if a > b > c:
    max = a
elif b > a > c:
    max = b
elif c > a > b:
    max = c
```

- C.

```python
if a > b and a > c:
    max = a
if b > a and b > c:
    max = b
else:
    max = c
```

- D.

```python
max = c
if a > c or b > c:
    if a > b:
        max = a
    else:
        max = b
```

---

## 答案

**正确答案：** D

---

## 解析

D 先假设 `c` 最大；若 `a` 或 `b` 中存在比 `c` 大的数，再比较 `a` 和 `b` 并取较大者，能覆盖三数互不相等的所有情况。A 忽略了 `a` 可能最大但 `b <= c` 的情况；B 只判断了部分排列；C 的 `else` 只与第二个 `if` 配对，可能覆盖前面已得到的 `a`。
