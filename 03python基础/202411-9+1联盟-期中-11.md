# 题目 11

11. 下列 Python 程序段执行后的结果是（   ）

```python
a = [0, 0, 0]
for i in range(17):
    m = 0
    a[m] += 1
    while a[m] == 3:
        a[m] = 0
        m = m + 1
        a[m] = a[m] + 1
print(str(a[0]) + str(a[1]) + str(a[2]))
```

- A. 211  
- B. 221  
- C. 1011  
- D. 122

---

## 答案

**正确答案：** B

---

## 解析

程序用列表 `a` 模拟三进制计数，`a[0]` 是低位，每次循环加 1，满 3 向高位进位。循环 17 次后，17 的三进制表示为 `122`，按低位到高位存储为 `[2,2,1]`，输出顺序是 `a[0]a[1]a[2]`，所以结果为 `221`。
