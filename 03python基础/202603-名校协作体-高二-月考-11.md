# 题目 11

11. 定义如下函数：

```python
def find(nums):
    miss = []
    p, q = min(nums), max(nums)
    b = [0] * (q - p + 1)
    for i in nums:
        b[i - p] += 1
    for j in range(len(b)):
        if b[j] == 0:
            miss.append(p + j)
    return miss
```

若 `nums = [3, 4, 1, 8, 7]`，执行语句 `k = find(nums)` 后，`k` 的值为（   ）

- A. `[0,2,5]`  
- B. `[2,5]`  
- C. `[0,2,5,6]`  
- D. `[2,5,6]`

---

## 答案

**正确答案：** D

---

## 解析

`p=1`，`q=8`，函数统计区间 1 到 8 中出现过的数。`nums` 中已有 1、3、4、7、8，缺失的是 2、5、6，因此返回 `[2,5,6]`。
