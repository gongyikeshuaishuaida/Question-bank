# 题目 12

12. 有如下Python程序段：

```python
a = [5, 8, 6, 4, 2, 5, 4, 5, 8, 3, 1, 6, 3]
b = [0, 2, 3, 6, 7, 8, 9, 12]
k = 0; m = 0
for i in range(b[len(b) - 2]):
    if i == b[k]:
        k += 2
    j = b[k]
    while j <= b[k + 1]:
        if a[i] + a[j] < m or m == 0:
            m = a[i] + a[j]
        j += 1
```

运行程序段后，m的值是（   ）

- A. 4
- B. 6
- C. 7
- D. 8

---

## 答案

**正确答案：** B

---

## 解析

程序逻辑：列表 `b` 定义了若干区间 `[b[0], b[1]]`, `[b[2], b[3]]`, `[b[4], b[5]]`, `[b[6], b[7]]`，即 `[0,2]`, `[3,6]`, `[7,8]`, `[9,12]`。

外层循环 `i` 从 0 到 `b[-2]-1 = 8`。当 `i` 等于某个区间起点的 `b[k]` 时，`k` 增加 2 切换到下一区间。

程序对每个 `i` 在对应区间 `[b[k], b[k+1]]` 内遍历 `j`，计算 `a[i] + a[j]` 的最小值存于 `m`。

逐区间追踪：

- **i=0,1,2**（区间[3,6]）：k=2，j 遍历 3,4,5,6
  - i=0: a[0]=5, min(5+4,5+2,5+5,5+4)=7 → m=7
  - i=1: a[1]=8, min=10, m 保持 7
  - i=2: a[2]=6, min=8, m 保持 7

- **i=3,4,5,6**（区间[7,8]）：k=4，j 遍历 7,8
  - i=3: a[3]=4, min(4+5,4+8)=9
  - i=4: a[4]=2, min(2+5,2+8)=7
  - i=5: a[5]=5, min=10
  - i=6: a[6]=4, min=9
  - m 保持 7

- **i=7,8**（区间[9,12]）：k=6，j 遍历 9,10,11,12
  - i=7: a[7]=5, min(5+3,5+1,5+6,5+3)=6 → m=6
  - i=8: a[8]=8, min(8+3,8+1,8+6,8+3)=9, m 保持 6

最终 m = 6。
