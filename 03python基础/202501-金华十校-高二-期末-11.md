# 题目 11

11. 有如下 Python 程序段，输入相同 `hc` 值时，输出可能与另外三项不同的是（   ）

- A.
```python
d = "安全区域"
if hc > 0.08:
    d = "轻度污染"
elif hc > 0.1:
    d = "高度污染"
```

- B.
```python
d = "安全区域"
if hc > 0.1:
    d = "高度污染"
elif hc > 0.08:
    d = "轻度污染"
```

- C.
```python
if hc <= 0.08:
    d = "安全区域"
if hc > 0.08:
    d = "轻度污染"
if hc > 0.1:
    d = "高度污染"
```

- D.
```python
if hc <= 0.08:
    d = "安全区域"
elif hc <= 0.1:
    d = "轻度污染"
else:
    d = "高度污染"
```

---

## 答案

**正确答案：** A

---

## 解析

选项 A 中 `elif hc > 0.1` 永远无法执行——因为 `hc > 0.08` 先捕获了所有 > 0.08 的情况（包括 > 0.1）。因此 A 只有 2 种输出："安全区域"和"轻度污染"，缺少"高度污染"。B、C、D 均正确区分了三个区间。
