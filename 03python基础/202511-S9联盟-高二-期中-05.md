# 题目 05

下列 Python 表达式中，值为 `False` 的是（   ）

- A. `not "ac" in "abcabc"`
- B. `9 // 3 ** 2 == 1`
- C. `abs(-4.3) > 9 % 2`
- D. `int("12") == len("123456")`

---

## 答案

**正确答案：** D

---

## 解析

`"ac"` 不是 `"abcabc"` 的子串，所以 A 为 `not False`，结果为 `True`；B 中 `3**2=9`，`9//9=1`；C 中 `4.3>1`。D 比较 `12` 和字符串长度 `6`，结果为 `False`。
