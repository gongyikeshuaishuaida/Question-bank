# 题目 08

下列 Python 表达式中，值与其他三项不同的是（　）

- A. `2034 % 1000 // 10`
- B. `int(4.9) - 1`
- C. `ord("D") - ord("A")`
- D. `["1", "2", "3", "4"][2]`

---

## 答案

**正确答案：** D

---

## 解析

A、B、C 的值都是整数 `3`；D 取出列表中下标为 2 的元素，结果是字符串 `"3"`。D 的值类型与其余三项不同，因此选 D。
