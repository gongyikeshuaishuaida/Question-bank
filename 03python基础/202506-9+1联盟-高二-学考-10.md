# 题目 10

某 Python 程序如下：

```python
s = input()
i, t1, t2 = 0, 0, 0
while i < len(s):
    if '0' <= s[i] <= '9':
        t1 += int(s[i])
    elif 'a' <= s[i] <= 'z':
        t2 += ord(s[i]) - ord('a')
    i += 1
if t1 == t2:
    print('Yes')
else:
    print('No')
```

程序运行时，若输出为 `Yes`，则可能的输入是（   ）

- A．`ed32c4`
- B．`adc312`
- C．`e7b4c2`
- D．`235fed`

## 答案

**正确答案：** A

## 解析

程序将数字字符转换后求和，并将小写字母转换为相对于 `a` 的序号求和。A 中数字和为 (3+2+4=9)，字母和为 (e=4,d=3,c=2)，也是 9，因此输出 `Yes`。
