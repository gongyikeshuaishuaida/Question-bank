# 题目 10

10. 有如下 Python 程序段：

```python
s = "Imformation"; s2 = ""
for i in range(len(s)):
    if i % 2 == 0:
        if "a" <= s[i] <= "z":
            s2 = s[i] + s2
        else:
            s2 = s2 + s[i]
```

运行该程序，`s2` 的结果为（   ）

- A. `"niarfI"`
- B. `"iarnI"`
- C. `"Ifrain"`
- D. `"niarfl"`

---

## 答案

**正确答案：** A

---

## 解析

程序仅处理偶数索引的字符（`i % 2 == 0`）：小写字母前插到 `s2` 头部，大写字母追加到 `s2` 尾部。

`s = "Imformation"`，偶数索引字符：`I`(0)、`f`(2)、`r`(4)、`a`(6)、`i`(8)、`n`(10)。

| i | s[i] | 操作 | s2 |
|---|------|------|-----|
| 0 | I | 大写，追加 | `"I"` |
| 2 | f | 小写，前插 | `"fI"` |
| 4 | r | 小写，前插 | `"rfI"` |
| 6 | a | 小写，前插 | `"arfI"` |
| 8 | i | 小写，前插 | `"iarfI"` |
| 10| n | 小写，前插 | `"niarfI"` |

最终 `s2 = "niarfI"`。
