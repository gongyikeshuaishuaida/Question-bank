# 题目 09

9. 某书店的会员优惠规则为：单笔订单金额`t`达到80元，或购买书籍数量`b`达到4本，订单金额打8.5折。下列程序段中，能正确实现该规则的是（　）

程序1：

```python
c = 1
if t >= 80 and b >= 4:
    c = 0.85
print("金额：", t * c)
```

程序2：

```python
c = 1
if t >= 80 or b >= 4:
    c = 0.85
print("金额：", t * c)
```

程序3：

```python
c = 1
if t >= 80:
    c = 0.85
elif b >= 4:
    c = 0.85
print("金额：", t * c)
```

程序4：

```python
c = 1
if t >= 80:
    c = 0.85
if b >= 4:
    c = 0.85
print("金额：", t * c)
```

- A. 1、2、3
- B. 2、3、4
- C. 1、2、4
- D. 1、3、4

---

## 答案

**正确答案：** B

---

## 解析

程序2直接实现“或”；程序3、4在任一条件满足时也都会把折扣设为0.85；程序1要求两条件同时满足，错误。
