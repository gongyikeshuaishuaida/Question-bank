# 题目 13

阅读下列材料，回答第 13 题。

某款运动手表，具备运动状态、静息状态、睡眠状态三种场景心率监测，每分钟生成一次心率值，若连续四次及以上监测到心率值超出阈值，将发出警报。

13. 调用第 12 题的函数 `Heart_Rate(t)`，实现静息状态下心率异常时手表发出警报，其代码如下：

```python
# 列表 s 存放心率数据，如 s=[120,78,90,56,……]，代码略
count = 0
for i in range(len(s)):
    if __________:
        count = count + 1
    else:
        __________
    if count >= 4:
        # 手表发出警报，代码略
```

上述程序段中划线处可选代码有：

① `not Heart_Rate(i)`　② `Heart_Rate(i)`　③ `count=0`　④ `count=count-1`

则划线处应填入的正确代码顺序为（   ）

- A. ①③
- B. ②③
- C. ①④
- D. ②④

---

## 答案

**正确答案：** A

---

## 解析

函数返回 `False` 表示心率异常，因此异常条件应写为 `not Heart_Rate(i)`。检测到异常时连续计数加 1；一旦当前心率恢复正常，就应把连续异常次数清零，即执行 `count=0`，所以依次填①、③。
