# 题目 10

10. 有如下程序段：

```python
i, c, t = 1, 0, 0
while i <= len(s) - 1:
    if s[i] <= s[i - 1]:
        c = c + int(s[t:i])
        t = i
    i += 1
print(c)
```

若 `s` 为 `"142633189"`，执行该程序段后，`c` 的值为

- A. 43
- B. 46
- C. 73
- D. 235

---

## 答案

**正确答案：** B
