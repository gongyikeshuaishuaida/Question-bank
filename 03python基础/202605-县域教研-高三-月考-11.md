# 题目 11

11. 有如下 Python 程序段：

```python
stk = [0] * len(a)
top, sum_val, min_avg = -1, 0, 8
for i in a:
    if top != -1 and abs(i - stk[top]) < k:
        sum_val -= stk[top]
        top -= 1
    else:
        top += 1
        stk[top] = i
        sum_val += i
    if top != -1:
        avg = sum_val / (top + 1)
        if avg < min_avg:
            min_avg = avg
```

若 `a` 为 `[5, 5, 6, 4, 4, 7, 3, 3, 8, 2]`，执行该程序段后，`min_avg` 的值为 `3.0`，则程序中 `k` 的值为

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** C
