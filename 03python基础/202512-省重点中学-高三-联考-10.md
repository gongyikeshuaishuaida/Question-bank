# 题目 10

有如下 Python 程序段：

```python
s = input()
i, j, k = 0, len(s) - 1, 0
while i < j:
    if s[i] != s[j]:
        t1 = s[i:j]
        t2 = s[i+1:j+1]
        if t1 == t1[:-1] or t2 == t2[:-1]:
            k = 1
            break
    i += 1
    j -= 1
```

程序运行结束后，`k` 的值为 1，则输入的 `s` 值可能是（   ）

- A．`DACAAC`
- B．`ABCDECA`
- C．`CAADBBAC`
- D．`BCBAACB`

## 答案

**正确答案：** D

## 解析

程序从两端向中间比较；出现不相等字符时，检查删除左端或右端字符后形成的子串是否满足条件。逐项模拟可知 `BCBAACB` 能使 `k=1`，其余输入不能满足判断。
