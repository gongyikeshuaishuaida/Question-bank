# 题目 13

某地举办菊花展期间，为提升游客观赏体验，举办方将不同品种的菊花穿插摆放，让游客走最少的路，观赏到尽可能多的品种。输入菊花品种的摆放序列（用大写字母标识菊花的品种），输出最长连续不重复品种序列的区间；若有多段，输出最前面那段。如某段展区菊花摆放序列为 `"ABCABE"`，则最长连续不重复品种序列的区间为 2～5。

（1）若某段展区菊花摆放序列为 `"ABCCDB"`，最长连续不重复品种序列的区间为 **0～2**。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码：

```python
s = input()
index = [-1] * 26  # 保存字符最后出现的位置
mx = left = start = 0
n = len(s)  # ①
for right in range(n):
    c = s[right]
    t = ord(c) - 65
    if index[t] >= left:
        left = index[t] + 1  # ②
    index[t] = right
    length = right - left + 1  # ③
    if length > mx:
        mx = length
        start = left
print("最长连续不重复品种序列的区间为:", start, "~", start + mx - 1)
```

① **`n = len(s)`**；② **`index[t] + 1`**；③ **`length = right - left + 1`**（也可写 `length = index[t] - left + 1`）。

---
## 答案

（1）0～2；（2）① `n=len(s)`；② `index[t]+1`；③ `length=right-left+1`（或 `length=index[t]-left+1`）。

---
## 解析

用 `index` 记录每个品种最后出现的位置。若该位置仍在当前窗口内，就把左边界移动到重复字符上次出现位置的下一位；每次更新右边界后计算窗口长度并保留最长且最早的区间。`ABCCDB` 的最早最长窗口是下标 0～2 的 `ABC`。
