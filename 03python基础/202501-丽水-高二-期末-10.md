# 题目 10
有如下 Python 函数：

```python
def f(x,n):
    if x<n:
        return str(x)
    else:
        return f(x//n,n)+str(x%n)
```

执行 `w=f(11,2)` 后，`w` 的值为（　　）

- A. `"1010"`
- B. `"1111"`
- C. `"1011"`
- D. `"1101"`

---
## 答案
**正确答案：** C

---
## 解析
函数递归地输出除法所得的高位到低位余数：`11` 除以2得到余数1，商5；5得到余数1，商2；2得到余数0，商1；最后得到1，拼接为字符串 `"1011"`，所以选 C。
