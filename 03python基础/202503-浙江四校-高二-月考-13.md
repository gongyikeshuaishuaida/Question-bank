# 题目 13

13. “动动有奖”是某手机走路计步器程序，它能根据系统传递给它的走路步数给运动者奖励，运动者可以用累计的“奖金”去换取软件开发商提供的各种体育用品。具体的奖励规则如下：

1. 每天走路满 1000 步奖励 0.3 金（不足 1000 步没有奖励），1000 步之后“奖金”按照每 2000 步再奖励 0.1 金的规律递增，每天最高奖励不超过 3 金。
2. 每天必须到计步器页面点击“领奖”按钮，才能领取昨日走路奖金。
3. 如果连续 3 天领奖成功，从第 4 天起走路奖金翻 1 倍；翻倍期间若有 1 天没有领奖，翻倍权益取消，重新连续 3 天领奖成功才能继续翻倍。

程序如下，请在划线处填入合适的语句：

```python
n = int(input("输入总天数 n:"))
total = 0
c = 0
①
while i <= n:
    x = int(input("输入每天走路步数 x:"))
    f = int(input("输入领奖标志 f:"))
    # 通过输入的步数 x 计算对应的奖金 t
    if x < 1000:
        t = 0
    ②:
        t = 0.3
    elif x <= 1000 + 2000 * 27:
        t = 0.3 + (x - 1000) // 2000 * 0.1
    else:
        t = 3
    if f == 1:       # 判断是否领奖，1:已领取，0:未领取
        c += 1
        if c <= 3:
            total += t
        else:
            ③
    else:
        ④
    i += 1
print(total)
```

---
## 答案

**参考答案：** ① i = 1；② elif x < 3000；③ total += 2 * t；④ c = 0

---
## 解析

用 i 从 1 计数到 n，故 ① 为 i = 1。步数达到 1000 且小于 3000 时奖励固定为 0.3，故 ② 为 elif x < 3000；达到 3000 后进入第三段按每 2000 步递增。领奖成功时 c 记录连续领奖天数，c≤3 时计入 t，c>3 时应把当日奖金按规则翻倍，故 ③ 为 total += 2 * t；未领奖会中断连续领奖，故 ④ 为 c = 0。
