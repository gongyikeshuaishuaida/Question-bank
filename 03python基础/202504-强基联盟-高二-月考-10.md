# 题目 10

有如下 Python 程序段：

```python
s='2025-DpSeek'
new_s=''
keys=[1,3,2]
for i in range(len(s)):
    c=s[i]
    j=i%len(keys)
    if '0'<=c<='9':
        new_s+=str((int(c)+keys[j])%10)
    else:
        if 'a'<=c<='z':
            c=chr((ord(c)-97+keys[j-1])%26+97)
        new_s=c+new_s
print(new_s)
```

运行程序，输出的结果为（   ）

- A. mefSpD-3036
- B. 3346-DrShgl
- C. 6433-DpSfem
- D. 1ghSrD-3346

---
## 答案

**正确答案：** D

---
## 解析

数字按当前密钥右移后追加到结果末尾；字母用前一位密钥循环移位后从结果左侧加入；其他字符也从左侧加入。按程序逐字符执行，得到1ghSrD-3346。
