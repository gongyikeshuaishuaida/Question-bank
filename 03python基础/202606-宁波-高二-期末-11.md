# 题目 11

11. 编写如下 Python 程序，输入一个数字字符串 `s`，删除 `s` 中开头和结尾的 0，并输出结果。如 `s="00012003100000"`，输出 `"120031"`。

```python
s = input()
p = i = 0
q = j = len(s) - 1
while i < len(s) and j >= 0:
    if s[i] != "0":
        ________①________
    i = i + 1
    if s[j] != "0":
        ________②________
    j = j - 1
print(s[________③________])
```

则程序划线处的代码正确的是（   ）

- A. ① `q=i`　② `p=j`　③ `q:p+1`
- B. ① `p=i`　② `q=j`　③ `q:p+1`
- C. ① `q=i`　② `p=j`　③ `p:q+1`
- D. ① `p=i`　② `q=j`　③ `p:q+1`

---

## 答案

**正确答案：** B

---

## 解析

循环没有在发现非零字符后停止。`i` 从左向右扫描时，执行 `p=i` 会使 `p` 最终停在最后一个非零字符的位置；`j` 从右向左扫描时，执行 `q=j` 会使 `q` 最终停在第一个非零字符的位置。因此应输出 `s[q:p+1]`。

以样例为例，最终 `q=3`、`p=8`，切片 `s[3:9]` 的结果为 `"120031"`。
