# 题目 10

有如下 Python 自定义函数，其功能是查找字符串 `s` 中每个单词索引为 `k` 的字母，索引 `k` 存储在每个单词的最前面。

```python
def search(s):
    s1, c = "", 0
    for i in range(len(s)):
        if "0" <= s[i] <= "9":
            c = c * 10 + int(s[i])
        else:
            if c > 0:
                s1 = s[i:][c] + s1
            c = 0
    return s1
```

为发现该函数中存在的问题，下列选项中最适合作为测试数据的是（　　）

- A. `"3test1no2yes"`
- B. `"2test1no1yes"`
- C. `"1test0no2yes"`
- D. `"1test1no2yes"`

---

## 答案

**正确答案：** C

---

## 解析

程序只有在 `c>0` 时才提取字符，因此索引为 0 的情况会被跳过。C 含有 `0no`，能直接暴露这一边界错误；其他选项的索引均为正数，无法检验该问题。
