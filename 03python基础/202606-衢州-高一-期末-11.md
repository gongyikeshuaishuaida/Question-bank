# 题目 11

11. 有如下 Python 程序段：

```python
def f(n):
    result = []
    for i in range(1, int(n**0.5) + 1):
        if n % i == 0:
            result.append(i)
            if i != n // i:
                result.append(n // i)
    return result

print(f(16))
```

执行该程序段后，输出的结果是（   ）

- A. `[1,16,2,8,4]`
- B. `[2,8,4]`
- C. `[1,2,8,4]`
- D. `[1,16]`

---

## 答案

**正确答案：** A

---

## 解析

循环依次检查 `i=1、2、3、4`。1、2、4 是 16 的因数，分别加入配对因数 16、8；当 `i=4` 时配对因数仍为 4，不重复添加，因此结果为 `[1,16,2,8,4]`。
