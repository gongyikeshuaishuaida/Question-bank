# 题目 09

已知变量 `t`、`x`、`y` 的值分别为 30、40 和 20，下列 Python 表达式的值与其他三项不同的是（   ）

- A．`t <= x and t >= y`
- B．`not(t > x or t < y)`
- C．`(y <= t) and (t <= x)`
- D．`y > t or t > x`

---
## 答案

**正确答案：** D

---
## 解析

前三个表达式都表示 `20<=t<=40`，在 `t=30` 时值为 `True`。D 表达式表示 `t<y` 或 `t>x`，此时为 `False`。
