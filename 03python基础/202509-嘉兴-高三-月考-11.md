# 题目 11

11. 有如下 Python 程序段：

```python
from random import randint
def func(s):
    r1 = ""
    r2 = ""
    i = 0
    while i < len(s):
        f = randint(0, 1)
        if f == 0:
            r1 = r1 + s[i]
        else:
            r2 = r2 + s[i]
        i = i + 1
    return r1 + r2
```

若 `s = "ABCDE"`，执行语句 `res = func(s)` 后，`res` 的值不可能是（   ）

- A. `"BCDAE"`
- B. `"CEABD"`
- C. `"ACBDE"`
- D. `"ACEDB"`

---

## 答案

**正确答案：** D

---

## 解析

函数 `func` 将字符串 s 的每个字符随机分配到 `r1`（f=0）或 `r2`（f=1），最终返回 `r1 + r2`。这意味着：
- 结果中，r1 中的字符保持原字符串中的相对顺序（取出的先后顺序），r2 中的字符也保持原顺序。
- 整个结果串 = r1（原序）+ r2（原序）。

分析各选项：
- A `"BCDAE"`：r1="BCD", r2="AE"，B→C→D 在原串中顺序为 1,2,3（正确），A→E 在原串中顺序为 0,4（正确）。✓
- B `"CEABD"`：r1="CEA", r2="BD"，C→E→A 在原串中顺序为 2,4,0 — 不对！0(A)在2(C)之前但在r1中排在最后，破坏了原序。但实际上如果所有字符都进入r1就不对了...让我重新分析。
  
重新分析更严谨的方法：每个字符独立随机分配到 r1 或 r2。最终结果 = r1部分（保持原序）+ r2部分（保持原序）。

选项 D `"ACEDB"`：设 r1="ACE", r2="DB"。在原串 ABCDE 中，D 在 E 之前（D 是第3位，E 是第4位），但在 r2 中 D 排在 B 前面没问题，关键是 D(3) 和 B(1) 在 r2 中：D 在 B 后面出现是对的（D 原序在 B 之后）。看 r1="ACE"：A 原序0, C 原序2, E 原序4，相对顺序正确。看 r2="DB"：D 原序3, B 原序1 — B 在 D 之前但 r2 中 D 在 B 之前！破坏了原序。所以 D 不可能。

验证：选项 D 中 `"ACEDB"`，从后往前找 r2 的字符必须保持递增的原索引顺序。DB 中 D 索引 3，B 索引 1，3>1 破坏了顺序要求。故 D 不可能。
