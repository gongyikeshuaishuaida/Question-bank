# 题目 10

定义如下函数：

```python
def trans(n):
    if n <= 1:
        return str(1-n%2)
    else:
        return trans(n//2) + str(1-n%2)
print(trans(13))
```

执行该程序后，输出的结果是（   ）

- A. 1101
- B. 0010
- C. 1011
- D. 0100

---

## 答案

**正确答案：** B

---

## 解析

递归展开：trans(1)=0，trans(3)=00，trans(6)=001，trans(13)=0010，因此选 B。
