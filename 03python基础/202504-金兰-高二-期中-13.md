# 题目 13

尼科梅彻斯定理表明：任何大于等于1的整数的立方等于一串连续奇数之和，例如 1³=1、2³=3+5、3³=7+9+11。程序输入一个大于1的整数并验证该定理。

```python
n = int(input("输入一个大于1的整数："))
for i in range(1, n**3, 2):
    sum = 0
    ①
    flag = False
    while sum < n**3 and not flag:
        sum = sum + t
        t = t + 2
        if ②:
            flag = True
    if flag:
        break
s = str(n) + "**3="
while sum > 0:
    sum = sum - i
    if sum == 0:
        s = s + str(i)
    else:
        s = s + str(i) + "+"
        ③
print(s)
```

（1）请在划线处填入合适代码。  
（2）通过观察分析，该程序段采用的算法属于（解析算法 / 枚举算法）。

---
## 答案

**参考答案：** ① t=i；② sum==n**3；③ i=i+2；（2）枚举算法。

---
## 解析

外层循环枚举连续奇数的首项 i；每次把 t 从 i 开始按2递增并累加，直到和达到 n³，故①为 t=i、②为 sum==n**3。输出表达式后要把首项 i 加2，进入下一项，故③为 i=i+2。算法通过逐个尝试候选首项验证目标，属于枚举算法。
