# 题目 12

有如下 Python 程序：

```python
a = list("Technology")
res = ""
k = 1
for i in range(len(a)-2):
    if ord(a[i])*k < ord(a[i+2])*k:
        a[i], a[i+2] = a[i+2], a[i]
    k = -k
for s in a:
    res += s
print(res)
```

运行该程序后输出结果正确的是（   ）

- A. Technology
- B. Tceghlnooy
- C. lenhgocoTy
- D. cenhlogoTy

---
## 答案

**正确答案：** D

---
## 解析

k 在每次循环后变号，比较条件因此交替改变方向；按程序逐次比较并交换 i 与 i+2 位置的字符，最终列表拼接为 cenhlogoTy，选 D。
