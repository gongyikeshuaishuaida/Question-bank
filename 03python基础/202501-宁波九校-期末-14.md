# 题目 14

14. 小 y 同学最近迷上了数字相关的游戏，现在他在探索 `n` 阶幻方的填写方式。幻方是一种中国传统游戏，`n` 阶幻方要求将数字 `1~n*n` 安排在 `n*n` 大小的正方形格子中，使每行、每列和对角线上的数字之和都相等。例如图 a 是 3 阶幻方的一种填写方式。

![[attachments/202501宁波九校_14_图1.png]]

小 y 只是一个初学者，因此他只发现了奇数阶幻方的填写方式：

①先将 1 放在第一行中间一列，然后向右上方的位置填下一个数；  
②如果行、列范围超出边界，则回绕，例如 1 在第 1 行，则 2 放在 1 的右上将超出行的边界，因此回绕至最下面的行，且列数加 1；  
③如果右上方已经填有数字，则把下一个数填入当前数的下方，例如 3 的右上方已经填有 1，则把 4 填入 3 的下方位置。

（1）小 y 填写了一个 5 阶幻方，请问用上述方法填写后第 3 行第 4 列的数字是 ______。

（2）小 y 想要写出任意奇数幻方，因此他决定编写程序完成这一任务，请在划线处填入合适代码。

```python
n = int(input("幻方的阶数是（必须是奇数）："))
a = [[0]*n for i in range(n)]
x = 0
y = n//2
a[x][y] = 1
cnt = 2
while cnt <= n*n:
    xx =      ▲
    yy = (y+1) % n
    if a[xx][yy] == 0:
        a[xx][yy] = cnt
    else:
        xx = (x+1) % n
        yy = y
        a[xx][yy] = cnt
    x = xx; y = yy
    cnt += 1
for i in range(n):
    for j in range(n):
        print(a[i][j], end=' ')
    print()
```

（3）通过学习后，小 y 掌握了一种特殊偶数阶幻方（`n` 是 4 的倍数）的填写方式：

①先把数字按顺序填，第 1 行填 `1~n`，第 2 行填 `n+1~2*n`，以此类推；  
②按 `4×4` 分割成小方阵，例如图 b 是 `8*8` 的幻方，要分成 4 个小方阵；  
③每个小方阵对角线上的数字和大方阵中与其成中心对称的数字交换，图 b 中每组中心对称的对角线已经用不同的斜线标出。

![[attachments/202501宁波九校_14_图2.png]]

小 y 又编写了程序来完成这种偶数阶幻方的填写，请在划线处填入合适代码。

```python
n = int(input("幻方的长度是（必须是4的倍数）："))
a = [[     ①      for i in range(n)] for j in range(n)]
for i in range(0,n,4):
    for j in range(0,n,4):
        for x in range(0,4):
            if a[i+x][j+x] == (i+x)*n+(j+x)+1:
                     ②
            if a[i+x][j+3-x] == (i+x)*n+(j+3-x)+1:
                a[i+x][j+3-x], a[n-1-i-x][n-4-j+x] = a[n-1-i-x][n-4-j+x], a[i+x][j+3-x]
for i in range(n):
    for j in range(n):
        print(a[i][j], end=' ')
    print()
```

---

## 答案

**正确答案：** （1）20；（2）`(x-1)%n`；（3）① `j*n+i+1`；② `a[i+x][j+x],a[n-1-i-x][n-1-j-x]=a[n-1-i-x][n-1-j-x],a[i+x][j+x]`

---

## 解析

奇数阶幻方每次尝试向右上移动，行号减 1 并回绕，所以 `xx` 应为 `(x-1)%n`；按该规则填写 5 阶幻方后，第 3 行第 4 列的值为 20。偶数阶幻方初始化时，第 `j` 行第 `i` 列应为 `j*n+i+1`。主对角线位置与整个大方阵中心对称的位置为 `[n-1-i-x][n-1-j-x]`，因此第 ② 空应交换这两个位置。
