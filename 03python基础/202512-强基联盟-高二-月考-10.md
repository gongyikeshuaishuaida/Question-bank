# 题目 10

有如下Python程序段：

```python
a=[4,6,3,1,2,5]
for i in range(len(a)-1):
    if a[i]<a[i+1]:
        a[i],a[i+1]=a[i+1],a[i]
```

执行该程序段后，列表a的值是（   ）

- A. `[6,4,3,1,5,2]`  
- B. `[6,4,3,2,5,1]`  
- C. `[6,4,3,2,1,5]`  
- D. `[1,4,6,3,2,5]`

---

## 答案

**正确答案：** B

---

## 解析

程序遍历列表（除最后一个元素），当 `a[i] < a[i+1]`（左边小于右边）时交换两元素。这是一个从左到右的冒泡过程，将较大的值向左"冒泡"。

执行过程（初始 `[4,6,3,1,2,5]`）：
- i=0: a[0]=4 < a[1]=6 → 交换 → `[6,4,3,1,2,5]`
- i=1: a[1]=4 > a[2]=3 → 不交换
- i=2: a[2]=3 > a[3]=1 → 不交换
- i=3: a[3]=1 < a[4]=2 → 交换 → `[6,4,3,2,1,5]`
- i=4: a[4]=1 < a[5]=5 → 交换 → `[6,4,3,2,5,1]`

最终结果为 `[6,4,3,2,5,1]`。
