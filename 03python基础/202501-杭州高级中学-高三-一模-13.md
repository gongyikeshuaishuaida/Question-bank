# 题目 13

操作系统管理 `n` 个连续的内存单元，地址编号为 0～`n-1`，分配给各任务使用。现有一个内存空闲块队列存储在列表 `d` 中，各个空闲内存块由起始地址、块大小组成，并按起始地址升序。例如：`[1, 3]` 表示地址编号 1、2、3 是空闲内存块。当有新空闲块系统回收时，若存在连续的多个空闲块，则合并为一块，例如有连续空闲内存块 `[1, 3]` 和 `[4, 2]`，合并为一个空闲块 `[1, 5]`。编写 Python 程序模拟空闲块合并过程，请回答下列问题：

（1）若系统当前空闲块为 `[[3, 2], [6, 4]]`，新回收空闲块为 `[5, 1]`，则合并后的空闲块为______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 当前空闲内存块存储在列表 d，系统新回收一块空闲块存储在列表 f，代码略
n = len(d)
k = 0
while k < n and d[k][0] < f[0]:
    ①
if (k > 0 and k <= n - 1
        and d[k - 1][0] + d[k - 1][1] == f[0]
        and f[0] + f[1] == d[k][0]):
    d[k - 1][1] = d[k - 1][1] + f[1] + d[k][1]
    for i in range(k, n - 1):
        d[i] = d[i + 1]
    n -= 1
elif k > 0 and d[k - 1][0] + d[k - 1][1] == f[0]:
    d[k - 1][1] += f[1]
elif ②:
    d[k][0] = f[0]
    d[k][1] += f[1]
else:
    d.append([-1, -1])
    for i in range(n - 1, k - 1, -1):
        ③
    d[k][0] = f[0]
    d[k][1] = f[1]
    n += 1
```

---

## 答案

（1）`[3, 7]`

（2）① `k += 1`；② `k < n and f[0] + f[1] == d[k][0]`；③ `d[i + 1] = d[i]`

---

## 解析

新空闲块 `[5, 1]` 分别与 `[3, 2]`、`[6, 4]` 首尾连续，三块合并为从地址 3 开始、长度为 7 的空闲块。程序先用 `k` 找插入位置；若只与右侧块连续，需把右侧块起始地址前移并扩大长度；若不能合并，则从后向前搬移元素，为新块腾出位置。
