# 题目 09
```python
s = "527,5,9,107,24,"
m = t = 0
for c in s:
    if "0" <= c <= "9":
        t = t * 10 + int(c)
    else:
        if t > m:
            m = t
        t = 0
print(m)
```
程序输出的是（　　）

- A. 5
- B. 24
- C. 107
- D. 527
---
## 答案
**正确答案：** D
---
## 解析
程序逐个解析逗号分隔的整数并保留最大值 527。
