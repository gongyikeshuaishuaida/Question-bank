# 题目 12

12. 有如下Python程序段：

```python
import random
s = [0]*6; i = 0
while i < len(s):
    n = random.randint(2,6)*2
    if i%2 == 0 and n%3 == 0:
        s[i] = n
        i += 1
    elif n%4 == 0:
        s[i] = n
        i += 1
print(s)
```

执行该程序段后，输出 `s` 的值可能是（   ）

- A. `[6,12,4,6,4,14]`
- B. `[8,8,6,4,12,8]`
- C. `[12,4,10,8,6,10]`
- D. `[8,12,12,8,10,4]`

---

## 答案

**正确答案：** B

---

## 解析

`n` 只能是4、6、8、10、12。奇数下标只能通过 `n%4==0` 赋值，因此只能是4、8、12；偶数下标可为6、12或4、8、12，但不能为10。B满足所有限制，其他选项含有14、奇数下标6或偶数下标10等不可能情况。
