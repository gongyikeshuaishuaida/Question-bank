# 题目 10

有如下 Python 程序：

```python
import random
s = "Python"; code = ""; f = 1
for c in s:
    r = random.randint(1, 3)  # 生成 1~3 之间（含 1、3）的随机整数
    code = code + chr(ord(c) + f * r)
    f = -1 * f
print(code)
```
运行后输出的结果可能是（   ）

- A. qwwfpm
- B. Mzsjlo
- C. Qzwiqp
- D. Rvveqk

---

## 答案

**正确答案：** D
