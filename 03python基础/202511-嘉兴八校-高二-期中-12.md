# 题目 12

12. 用 Python 算法控制结构描述"某商场根据会员积分 p 发放礼品：若积分大于 500 则送'电影票'，若积分小于 100 则送'小零食'，否则送'饮料'"。下列选项正确的是（   ）

- A.
```python
if p > 500:
    a = "电影票"
if p < 100:
    a = "小零食"
else:
    a = "饮料"
print(a)
```

- B.
```python
a = "饮料"
if p < 100:
    a = "小零食"
elif p > 500:
    a = "电影票"
print(a)
```

- C.
```python
a = "小零食"
if p > 100:
    a = "饮料"
elif p > 500:
    a = "电影票"
print(a)
```

- D.
```python
a = "电影票"
if p < 100:
    a = "小零食"
if p <= 500:
    a = "饮料"
print(a)
```

---

## 答案

**正确答案：** B

---

## 解析

分析：当 `p > 500` 送电影票，`p < 100` 送小零食，`100 ≤ p ≤ 500` 送饮料。

- A：当 `p > 500` 时，先执行 `a = "电影票"`，然后 `p < 100` 不成立，else 将 `a` 改为 `"饮料"`，结果错误。
- B：默认 `a = "饮料"`，若 `p < 100` 改小零食，否则若 `p > 500` 改电影票，正确。
- C：`p > 100` 和 `p > 500` 逻辑重叠，当 `p > 500` 时 `p > 100` 先匹配返回饮料，不会进入 `elif`，错误。
- D：当 `p > 500` 时，`p <= 500` 不成立，但 `p < 100` 也不成立，a 保持"电影票"，正确。但当 `100 ≤ p ≤ 500` 时，第二个 if 会将 a 改为"饮料"，正确。但当 `p < 100` 时，先设"小零食"，然后 `p <= 500` 也会成立，覆盖为"饮料"，错误。

只有 B 完全正确。
