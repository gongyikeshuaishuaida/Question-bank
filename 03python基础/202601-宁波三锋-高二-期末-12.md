# 题目 12

12. 有如下程序段：

```python
from random import randint
i, n = 0, 4; a = [0, 0, 0, 0, 0]
while i <= n:
    x = randint(1, 9)
    if i % 2 == 1:
        a[i] = x
    elif x % 2 == 0:
        a[n] = x
        n = n - 1
    i = i + 1
```

运行程序后，`a` 的值可能是（   ）

- A. `[1, 1, 0, 8, 6]`  
- B. `[2, 7, 0, 9, 8]`  
- C. `[0, 2, 0, 1, 0]`  
- D. `[0, 2, 7, 6, 4]`

---

## 答案

**正确答案：** C

---

## 解析

奇数下标位置会直接赋随机数，偶数下标只有当随机数为偶数时才把该偶数放到当前 `n` 位置并左移 `n`。例如在 `i=0`、`i=2`、`i=4` 时随机到奇数，不触发赋值；`i=1` 随机到 2、`i=3` 随机到 1，就可能得到 `[0,2,0,1,0]`。
