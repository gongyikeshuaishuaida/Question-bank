# 题目 11

11. 某地块示意图（如第 11 题图所示），地块边长分别为 `L1`、`L2`、`L3`、`L4`、`L5`。利用海伦公式分别计算出两个三角形的面积 `S1` 和 `S2`，从而得到此块的总面积 `S`（`S=S1+S2`）。

![[attachments/202601嘉兴高二期末_11_题图1.png]]

实现上述功能的部分 Python 程序如下：

```python
import math           # 导入 math 模块
def area(a, b, c):    # 定义 area 函数
    p = (a + b + c) / 2
    s = math.sqrt(p * (p - a) * (p - b) * (p - c))
    return         ①          # 返回计算得到的面积值

# L1, L2, L3, L4, L5 由键盘输入，代码略
print(area(L1, L2, L5) +            ②            )
```

请回答下列问题：

(1) 下列选项中，与方框内语句功能相同的 Python 表达式是   ▲   。（单选，填字母）

- A. `√p(p-a)(p-b)(p-c)`  
- B. `(p*(p-a)*(p-b)*(p-c))**0.5`  
- C. `(p*(p-a)*(p-b)*(p-c))**(1/2)`  
- D. `(p*(p-a)*(p-b)*(p-c))**1/2`

(2) 请在画线处填入合适的代码。

---

## 答案

**正确答案：** (1) B；(2) ① `s`；② `area(L3, L4, L5)`

---

## 解析

方框内 `math.sqrt(...)` 表示对乘积开平方，等价于乘积的 `0.5` 次方。函数 `area` 已把面积计算结果保存在 `s` 中，应返回 `s`。总面积由左侧三角形 `L1,L2,L5` 与右侧三角形 `L3,L4,L5` 的面积相加得到。
