# 题目 10

有如下 Python 程序段：

```python
s = input()
st = ""
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        st = s[i] + st
    elif "a" <= s[i] <= "z":
        st = st + s[i]
```

执行该程序段，输入 `"2026.04S9cs"`，则 `st` 的值是（   ）

- A. `"9406202cs"`
- B. `"sc2026049"`
- C. `"9S40.6202cs"`
- D. `"scS.2026049"`

---

## 答案

**正确答案：** A

---

## 解析

数字字符每次插入 `st` 的最前端，依次得到逆序数字串 `9406202`；小写字母 `c、s` 依次追加到末尾；句点和大写字母 `S` 被忽略，最终得到 `"9406202cs"`。
