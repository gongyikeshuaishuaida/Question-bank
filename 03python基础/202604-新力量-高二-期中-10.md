# 题目 10

10. 某 Python 代码如下。下列列表中，可能是代码执行后输出结果的是（   ）

```python
import random
lst = [5]
for i in range(5):
    num = random.randint(1, 15) * 3 + 2
    if num > lst[-1]:
        lst = lst + [num]
    elif num < lst[-1]:
        if len(lst) > 1:
            lst = lst[:-1] + [num]
print(lst)
```

- A. `[5, 8, 11, 14, 17, 48]`
- B. `[5, 20, 17, 17, 14]`
- C. `[5, 20, 17, 14, 11]`
- D. `[5, 14, 11, 20]`

---

## 答案

**正确答案：** D

---

## 解析

随机数只能是 5、8、11、…、47，A 中的 48 不可能。新数较大时列表增长，较小时只替换末元素，不增长，因此 B、C 的长度变化与连续下降不符。D 可由先追加 14、再用 11 替换末项、最后追加 20 得到。
