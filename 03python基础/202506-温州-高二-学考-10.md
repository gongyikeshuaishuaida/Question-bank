# 题目 10

某 Python 程序如下：

```python
s = input()
res = ""
flag = True
for i in range(len(s)):
    if s[i] != "-" and flag:
        if s[i] not in res:
            res += s[i]
        flag = False
    elif s[i] == "-":
        flag = True
```

程序运行后，`res` 的值是 `"wl"`，则输入的值不可能是（   ）

- A．`w-l`
- B．`wl`
- C．`we-love-wenzhou`
- D．`we-love-learning`

## 答案

**正确答案：** B

## 解析

程序只在字符串开头或连字符后取一个尚未出现过的字符。`w-l`、`we-love-wenzhou` 和 `we-love-learning` 都可依次得到 `w`、`l`；输入 `wl` 没有连字符，循环只会取首字符 `w`，不能得到 `wl`。
