# 题目 08

8．根据国家标准，室内空气质量指数的正常范围为0.5～2.5，如果空气质量指数大于2.5，则表明空气质（   ）
量较差，空气质量指数小于0.5，表明空气质量较好，下列选项能正确表示这三种情况的是
- A.
  ```python
  if zs > 2.5:
      print("较差")
  elif 0.5 < zs < 2.5:
      print("正常")
  else:
      print("较好")
  ```
- B.
  ```python
  if 2.5 > zs > 0.5:
      print("正常")
  elif zs < 0.5:
      print("较好")
  else:
      print("较差")
  ```
- C.
  ```python
  if zs > 2.5:
      print("较差")
  elif not zs > 0.5:
      print("较好")
  else:
      print("正常")
  ```
- D.
  ```python
  if zs < 0.5:
      print("较好")
  elif not zs > 2.5:
      print("正常")
  elif zs > 2.5:
      print("较差")
  ```

---

## 答案

**正确答案：** D
