# 题目 14

字符串处理。输入一个由大写字母和数字组成的字符串，如果字符串中存在连续三个或更多的相同字符，则将连续的多个字符删除，然后对组成的新字符串重新进行检测，重复上面步骤，直到全部字符检测完毕。如输入字符串 `"A11BBCCCB12D"`，则处理过程如下：

`A11BBCCCB12D → A11BBB12D → A1112D → A2D`

实现上述功能的 Python 程序如下，请回答下列问题。

（1）如输入的字符串为 `"ABC12DDD2211CCB"`，则处理后的字符串为 ________。

（2）请在程序划线处填入合适的代码。

```python
def cal(s, m):
    x = y = m
    while ________①:
        x -= 1
    while y + 1 < len(s)-1 and s[y] == s[y+1]:
        y += 1
    return x, y


s = input("请输入字符串：")
i = 0
while i < len(s):
    begin, end = cal(s, i)
    if ________②:
        s = s[:begin] + s[end+1:]
        ________③
    i = i + 1
print("处理后的字符串为：", s)
```

---

## 答案

（1）`ABB`

（2）

- ① `x - 1 >= 0 and s[x] == s[x-1]`
- ② `end - begin >= 2`（或 `end - begin + 1 >= 3`）
- ③ `i = begin - 1`

---

## 解析

（1）依次删除 `DDD`、拼接后形成的 `222`、再次形成的 `111` 和最后形成的 `CCC`，剩余 `"ABB"`。

（2）`cal` 从位置 `m` 向左右寻找相同字符段的边界；当区间长度至少为 3 时删除该段。删除后字符串两侧可能拼接出新的连续相同字符，所以令 `i=begin-1`，配合循环末尾的 `i=i+1` 从拼接位置重新检查。
