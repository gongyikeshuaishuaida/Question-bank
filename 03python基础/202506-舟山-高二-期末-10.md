# 题目 10

10. 有如下 Python 程序段：

```python
mw = "mkgysa"
st = "325041"
n = len(st)
a = [""] * n
i = 0
while i < n:
    t = int(st[i])
    a[t] = mw[i]
    i += 1
result = ''.join(a)
```

运行该程序段后，result 的值为（   ）

- A. `"yakmsg"`
- B. `"gsmkay"`
- C. `"msgyak"`
- D. `"aymkgs"`

---

## 答案

**正确答案：** A

---

## 解析

st="325041"：i=0→t=3,a[3]='m'；i=1→t=2,a[2]='k'；i=2→t=5,a[5]='g'；i=3→t=0,a[0]='y'；i=4→t=4,a[4]='s'；i=5→t=1,a[1]='a'。result="yakmsg"。
