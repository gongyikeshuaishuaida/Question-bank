# 题目 13

13. 模拟七局四胜制乒乓球比赛。每局一方至少得 11 分且领先至少 2 分才结束。

（1）根据比分规则，若某一局比赛的比分为 10:13，是否合理？（单选，填字母：A. 合理 / B. 不合理）

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

![[attachments/202604宁波三锋_13_图1.jpg]]

```python
import random

m = 4
count = 1
wa = wb = 0
while wa < m and wb < m:
    a = b = 0  # 表示比赛双方此局的得分
    while ①:
        t = random.randint(0, 1)
        a += t
        ②
    print("第", count, "局:", a, ":", b)
    if a > b:
        wa += 1
    else:
        wb += 1
    ③
print("胜负情况:", wa, ":", wb)
```

---

## 答案

（1）B（不合理）

（2）

- ① `a < 11 and b < 11 or abs(a-b) < 2`
- ② `b += 1-t`
- ③ `count += 1`

---

## 解析

当双方都未达 11 分，或分差不足 2 分时继续本局。每球只给一方加分，`t` 为 0/1，所以另一方加 `1-t`；每局结束后局号加 1。
