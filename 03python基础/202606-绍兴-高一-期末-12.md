# 题目 12

有如下 Python 程序:
```python
import random
lst = [0,0,0,0,0,0,0]
for k in range(1,7):
    a = random.randint(3,7) # 随机产生 3\~7 之间的整数
    b = random.randint(1,4) # 随机产生 1\~4 之间的整数
    if k % 2 == 1:
	    lst[k-1] = a + b
    else:
	    lst[k-1] = a * b

print(lst)
```
执行该段程序后，lst 列表不可能为（   ）

- A. [7,14,12,21,11,28]
- B. [8,16,6,12,7,28]
- C. [6,28,9,7,4,6]
- D. [7,20,6,14,11,3] ## 二、综合题（本题共3小题，其中第13题8分，第14题8分，第15题10分，共26分）

## 答案

**正确答案：** A
