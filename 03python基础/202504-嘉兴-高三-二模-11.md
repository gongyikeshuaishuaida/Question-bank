# 题目 11

甲、乙程序段的功能相同，乙程序段加框处的正确代码为（   ）

甲程序段：

```python
a = 1
b = 1
m = int(input("请输入m的值："))
while a + b <= m:
    c = a + b
    a = b
    b = c
print(b)
```

乙程序段：

```python
def f(a, b):
    c = a + b
    if c > m:
        return b
    else:
        return ______  # 此处是方框处

m = int(input("请输入m的值："))
print(f(1, 1))
```

- A. `f(b,c)`
- B. `f(a,b)`
- C. `f(a,c)`
- D. `f(c,b)`

---
## 答案

**正确答案：** A

---
## 解析

当 a+b 不超过 m 时，递归函数要模拟甲程序中 a=b、b=c 的更新，因此下一次调用应传入 f(b,c)，选 A；当 c>m 时返回当前 b，与甲程序退出循环后的输出一致。
