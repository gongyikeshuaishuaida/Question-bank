# 题目 13

某智能灯控系统采集红外信号 `p`（`p=1`：有人，`p=0`：无人）、人体与检测点距离 `pos`（单位：米，无人状态 `pos` 为 0），通过计算相邻距离差值控制灯的开关，规则如下：

①开灯：灯灭时，有人且连续 2 次相邻距离差值 >0.3 米；  
②关灯：灯亮时，单次检测到无人则立即关灯。

请回答下列问题：

(1) 初始灯灭，6 次采集的 `p` 和 `pos` 值为：`p=[1, 1, 1, 0, 1, 1]`，`pos = [1.2, 1.6, 2.1, 0, 0.5, 0.7]`，则开灯次数为 ____▲____ 次；

(2) 测试上述功能的 Python 程序如下，请在划线处填入合适代码。

```python
p = [1, 1, 1, 0, 1, 1]
pos = [1.2, 1.6, 2.1, 0, 0.5, 0.7]
n = len(p)    # 采集次数
s = 0         # 灯状态：0 灭，1 亮
c = 0
pre = 0       # 存储上一次距离值
t = 0
for i in range(n):
    if s == 1 and p[i] == 0:
        ____①____
        c = 0
    elif s == 0:
        d = abs(pos[i] - pre)
        if ____②____:
            c += 1
            if c >= 2:
                s = 1
                t += 1
                c = 0
        else:
            c = 0
    ____③____
print("开灯次数为：", t)
```

---

## 答案

**正确答案：** (1) 1；(2) ① `s=0`；② `p[i] == 1 and d > 0.3`；③ `pre = pos[i]`

---

## 解析

前 3 次检测均有人，距离差 `0.4`、`0.5` 连续两次大于 `0.3`，触发一次开灯；第 4 次无人后关灯；第 5、6 次的距离差未形成连续两次满足条件，因此总开灯次数为 1。灯亮且无人时需令 `s=0`；灯灭时只有有人且距离差满足阈值才累计；循环末尾更新上一次距离值。
