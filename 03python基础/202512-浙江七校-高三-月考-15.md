# 题目 15

某通信系统对一个明文字符串s进行加密和解密操作。加密过程包含两个步骤：

**步骤一：翻转。** 将明文s中多段连续的区间进行翻转，区间存储在密钥 `key1` 中，每个元素为 `[st, ed]`。若 `st < ed`，表示将st到ed区间（即 `s[st:ed+1]`）进行翻转；若 `st > ed`，表示将st到字符串末尾再连接字符串开头到ed的完整区间（即 `s[st:]+s[:ed+1]`）进行翻转。

**步骤二：旋转。** 将步骤一得到结果划分成若干个长度为L的连续子串，对每个子串分别循环右移k位（包括最后一个长度可能不足L的子串），然后重新拼接。密钥 `key2` 的每个元素表示一次旋转操作（即 `[L,k]`），如果key2中有多个元素，则表示进行了多轮旋转操作。

例如，明文s为 `"Hello"`，密钥key1为 `[[1,4],[3,1]]`，密钥key2为 `[[2,1]]`，加密过程如图所示：

请回答下列问题：

（1）若明文s为 `"transform"`，密钥key1为 `[[2,5]]`，密钥key2为 `[[4,1],[8,2]]`，则加密后得到的密文第一个字符为 ▲ 。

（2）有如下 `get_length` 和 `rev` 两个函数，其中 `rev` 函数加框处的语句有误，请改正。

```python
# get_length函数求长度为n的列表中下标st到ed区间的长度（含st和ed）
def get_length(n, st, ed):
    return (ed - st + n) % n + 1

# rev函数将列表data中从下标st到ed（含st和ed）的区间进行翻转
def rev(data, st, ed):
    n = len(data)
    t = get_length(n, st, ed) // 2
    for i in range(t):
        p = (st + i) % n
        q = (ed - i) % n
        data[p], data[q] = data[q], data[p]
```

## 答案

**正确答案：**

（1）a

（2）`t = get_length(n, st, ed) // 2`

（3）① `rev(data, key[i][0], key[i][1])`

② `ring_shift(data, st, ed, le - key[i][1])`

---

## 解析

（1）加密：先翻转key1[2,5]区间，再依次执行key2两轮旋转，密文首个字符为a。

（2）`get_length` 计算环形区间长度，其一半作为交换次数。有误处是缺少 `// 2`。

（3）① `transform1` 中对每个key1元素执行翻转：`rev(data, key[i][0], key[i][1])`。② 解密时逆旋转：左移位数 = 子串长度 − 右移位数，即 `ring_shift(data, st, ed, le - key[i][1])`。
