# 题目 14

14. 有如下 Python 程序段：

```python
s = "abcccbbbac"
ch = s[0]
i = 1
while i < len(s):
    if s[i] != ch[-1]:
        ch += s[i]
    i += 1
```

执行该程序段后，`ch` 的值为（   ）

- A. `abccba`
- B. `abcabc`
- C. `abc`
- D. `abcbac`

---

## 答案

**正确答案：** D

---

## 解析

程序从左到右扫描字符串，仅当当前字符与 `ch` 的最后一个字符不同时才追加，因此连续重复字符只保留一个。`"abcccbbbac"` 的连续字符段依次为 `a、b、c、b、a、c`，最终得到 `"abcbac"`。
