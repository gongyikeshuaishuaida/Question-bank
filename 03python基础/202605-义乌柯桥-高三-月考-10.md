# 题目 10

10. 数组 `a` 有 `n` 个元素，现要将数组中值为 `x` 的元素全部删除。例如：`n` 为 6，`x` 为 2，数组 `a` 为 `[3, 2, 5, 4, 1, 2]`，则输出结果为 `[3, 5, 4, 1]`。实现该功能的程序段如下，则方框中应填入的正确代码为

```python
c = 0
for i in range(n):
    if a[i] == x:
        c += 1
    else:
        _____
print(a[:n - c])
```

- A. `a[i] = a[i + c]`
- B. `a[i - c] = a[i]`
- C. `a[i] = a[i + 1]`
- D. `a[i - 1] = a[i]`

## 答案

**正确答案：** B
