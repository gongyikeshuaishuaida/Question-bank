# 题目 11

11. 有如下程序段，输出结果为（   ）

```python
def f(n):
    s = 0
    while n > 0:
        s += n % 2
        n = n // 2
    return s

m = 0
for i in range(8, 10):
    m += f(i)
print(m)
```

- A. 3
- B. 5
- C. 10001001
- D. 10011000

---

## 答案

**正确答案：** A

---

## 解析

函数 `f` 通过不断除以 2 并累加余数，统计二进制表示中 1 的个数。`8` 的二进制表示为 `1000`，`f(8)=1`；`9` 的二进制表示为 `1001`，`f(9)=2`，所以最终输出 `1+2=3`。
