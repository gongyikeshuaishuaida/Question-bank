# 题目 07

7. 某校每月采用积分制对学生寝室实行星级评定，若积分 85 分及以上的，星级定为 1；积分在 75 到 84 分的，星级定为 2；低于 75 分的，星级定为 3。积分和星级分别保存在变量 `jf` 和变量 `g` 中。下列 Python 程序段中符合星级评定要求的是（   ）

- A.

```python
if jf >= 85:
    g = 1
if 85 > jf >= 75:
    g = 2
else:
    g = 3
```

- B.

```python
if jf >= 75:
    g = 2
elif jf >= 85:
    g = 1
else:
    g = 3
```

- C.

```python
g = 1
if jf < 85:
    g = 2
elif jf < 75:
    g = 3
```

- D.

```python
g = 2
if jf >= 85:
    g = 1
if jf < 75:
    g = 3
```

---

## 答案

**正确答案：** D

---

## 解析

D 先把默认星级设为 2，再把 `jf>=85` 的情况改为 1，把 `jf<75` 的情况改为 3，三段区间都能正确覆盖。A 中高分会被后一个 `else` 改成 3；B 先判断 `jf>=75`，导致 85 分以上也被定为 2；C 中 `elif jf<75` 只有在 `jf<85` 不成立时才会判断，无法处理低于 75 的情况。
