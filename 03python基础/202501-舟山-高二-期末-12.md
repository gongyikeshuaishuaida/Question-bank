# 题目 12

12. 有如下 Python 程序段：

```python
import random
rule = {1: "温", 2: "良", 3: "恭", 4: "俭", 5: "让"}
res = ""
for i in range(1, 6):
    k = random.randint(1, 5)
    if i % 2 != k % 2:
        res += rule[i]
    else:
        res += rule[k]
```

执行该程序段后，`res` 的值不可能是（   ）

- A. `"温良恭俭让"`
- B. `"恭俭恭俭恭"`
- C. `"俭良恭俭让"`
- D. `"温良恭良让"`

---

## 答案

**正确答案：** C

---

## 解析

程序逻辑：当 `i` 和 `k` 奇偶性不同时取 `rule[i]`，相同时取 `rule[k]`。分析 C `"俭良恭俭让"`：第 1 位 `俭`(4)，i=1(奇)，rule[i]=温(1,奇)，要得到 俭(4,偶) 只能是取 rule[k] 且 k%2==i%2(奇)，k 为奇数 → rule[k] 为奇数位值(温/恭/让)，不可能得到 俭(4)。C 不可能。
