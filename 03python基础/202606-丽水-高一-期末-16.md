# 题目 16

16. 某智慧停车场分为 A、B 两个区域，每个区域有 80 个车位并统一编码，车位编码如 A03 表示 A 区第三个车位。入口处设有显示屏，实时显示停车场空余车位数量及车位编码。每个车位装有传感器，当其检测到车位被占用，系统立即更改车位状态（0 表示车位空闲，1 表示车位被占用）并更新空余车位数量；当停车场内无空余车位，屏幕提示“无空位，请勿驶入”。根据上述设计，编写 Python 程序。

(1) 列表 `lst1` 用于存储车位编号及状态，如 `"A031"` 表示 A 区第 3 个车位被占用。若 B 区前 5 个车位状态如下 `["B011","B020","B031","B041","B050"]`，这 5 个车位还可以停 ______（填数字）辆车。

(2) 完成该程序的代码如下，请在划线处填入合适的代码。

```python
while True:
    # 获取当前车位信息，存入列表 s 中，如 s=["A010","A021",……]，代码略
    c = 0
    ss = []
    for i in range(____①____):
        wz = s[i][0:3]
        zt = ____②____
        if zt == "0":
            ____③____
            ss.append(wz)
    if c != 0:
        print("当前空余车位为：", c, "个")
        print("空闲车位编号：", ss)
    else:
        print("无空位，请勿驶入")
```

---

## 答案

**正确答案：** (1) 2；(2) ① `len(s)`；② `s[i][3]`（或 `s[i][-1]`）；③ `c+=1`（或 `c=c+1`）

---

## 解析

(1) 状态字符串末位为 `0` 表示空闲，给出的 5 个车位中 B02、B05 为空闲，因此还可停 2 辆车。(2) 循环需要遍历列表 `s` 的全部元素，故①为 `len(s)`；状态位是字符串的第 4 个字符，即 `s[i][3]`，也可用末位 `s[i][-1]`；发现空闲车位后应将计数器 `c` 加 1。
