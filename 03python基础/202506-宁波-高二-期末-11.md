# 题目 11

11.有如下 Python 程序段：

```python
s="RGGBRRGBB"
r=s[0]
for i in range(1, len(s)):
    if len(r)==0 or s[i]!=r[-1]:
        r=r+s[i]
    else:
        r=r[:len(r)-1]
print(r)
```

执行该程序段后，输出结果是（   ）

- A. RBB
- B. RGB
- C. GRB
- D. RBG

---

## 答案

**正确答案：** D

---

## 解析

程序用列表r模拟栈：当前字符与栈顶不同则入栈，相同则弹栈（消除相邻重复）。跟踪"RGGBRRGBB"：R→RG→(GG)R→RB→RBR→(RR)RB→RBG→RBGB→(BB)RBG。最终输出RBG。
