# 题目 13

13. 某同学设计了一个 Python 程序，其基本功能是将字符串中的小写字母转换成大写字母，其它字符保持不变。

(1) 程序代码如下，请在划线处填上合适的代码。

```python
def change(t):
    if "a" <= t <= "z":
        t = ____①____
    return t

s = input("输入字符串：")
n = ____②____
ans = ""
for i in range(n):
    c = ____③____
    ans = ans + c
print("输出：", ans)
```

(2) 如果输入字符串为“Python123”，则输出结果为________。

---

## 答案

① `chr(ord(t)-32)`；② `len(s)`；③ `change(s[i])`

(2) `PYTHON123`

---

## 解析

小写英文字母与对应大写字母的 Unicode 编码值相差 32，因此先用 `ord` 得到编码值、减 32 后再用 `chr` 转回字符。程序遍历字符串 `s` 的每个字符，调用 `change` 完成转换，因此 `"Python123"` 被转换为 `"PYTHON123"`。
