# 题目 10

10. 有如下 Python 程序段：

```python
a = [2, 3, 5, 1, 4, 6, 8, 7]
s = 0
flag = True
for i in range(len(a)):
    if flag and a[i] % 2 == 0:
        s += a[i]
        flag = False
    elif a[i] % 2 == 1:
        flag = True
print(s)
```

执行该程序段后，输出的结果是

- A. 6
- B. 8
- C. 12
- D. 16

**正确答案：** A
