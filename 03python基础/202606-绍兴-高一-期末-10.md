# 题目 10

m、n 均为小于 40 的正整数。下列 Python 程序段中，能实现和语句 `cnt = (n + m) // 40` 相同功能的是（   ）

- A. `cnt = n // 40 + m // 40`
- B. `cnt = int((n + m) / 40)`
- C.

```python
if n + m > 40:
    cnt = 1
else:
    cnt = 0
```

- D.

```python
if n <= 40 - m:
    cnt = 1
else:
    cnt = 0
```

---

## 答案

**正确答案：** B
