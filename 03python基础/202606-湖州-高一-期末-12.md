# 题目 12

12. 有如下 Python 程序段：

```python
import random
lst = [10, -20, 30, 40]
k = random.randint(0, 3)
sum = 0
for i in range(k):
    sum += lst[i]
print(sum)
```

执行该程序段后，`sum` 的值不可能是（   ）

- A. 0
- B. 10
- C. 20
- D. 60

---

## 答案

**正确答案：** D

---

## 解析

`k` 可能为 0、1、2、3，对应累加列表前 `k` 个元素，结果依次为 0、10、-10、20。因此 60 不可能出现。
