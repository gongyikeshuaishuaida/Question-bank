# 题目 12

12. 有如下 Python 程序段：

```python
import random

a = [0] * 6
for i in range(6):
    k = random.randint(1, 8)
    if i % 2 == 1:
        a[i] = 2 * k - 1
    elif k % 2 == 0:
        a[i] = k // 2
    else:
        a[i] = k + 1
```

执行该程序段后，`a` 的值可能是（   ）

- A. `[2,12,4,15,4,9]`
- B. `[2,13,3,11,6,5]`
- C. `[4,7,9,11,2,5]`
- D. `[4,13,4,19,8,15]`

---

## 答案

**正确答案：** B

---

## 解析

奇数下标位置的值为 `2*k-1`，只能是 1～15 的奇数；偶数下标位置在 `k` 为偶数时取 1～4，在 `k` 为奇数时取 2、4、6、8。四个选项中只有 B 的每个位置均满足对应取值范围。
