# 题目 13

某款无人机具备自动返航功能，当满足以下任一条件时自动返航：①信号连续丢失达 3 秒；②电量低于 20%；③距起点超出 200 米。无人机启动后每隔 1 秒采集一次条件数据 `[a,b,c]`，其中 a 为信号是否丢失（1 为没有丢失，0 为丢失），b 为电量，c 为距起点距离。

（1）某次飞行从第 1 秒开始的数据依次为 `[1,0.28,5]`、`[1,0.26,12]`、`[0,0.23,20]`、`[0,0.19,30]`、`[0,0.17,40]`、`[1,0.15,45]`、……，无人机从第 ______ 秒开始返航。

（2）实现上述功能的部分程序如下，请填空。

```python
reasons = ["信号连续丢失达3秒", "电量不足20%", "距起点超出200米"]
r = -1
j = 0
b = [1, 1, 1]
for i in range(len(data)):
    ①
    j = (j + 1) % 3
    if b[0] + b[1] + b[2] == 0:
        r = 0
        break
    if data[i][1] < 0.2 or ②:
        if data[i][1] < 0.2:
            r = 1
        else:
            r = 2
        break
if r != -1:
    print("无人机在第", i + 1, "秒，因为", ③, "自动返航。")
else:
    print("本次飞行，无人机没有自动返航。")
```

---
## 答案

**参考答案：** （1）4；（2）① b[j] = data[i][0]；② data[i][2] > 200；③ reasons[r]。

---
## 解析

前三秒中只有第3秒出现一次信号丢失；第4秒电量 0.19 已低于 0.2，因此在第4秒立即返航。数组 b 用长度为3的循环窗口保存最近三次信号状态，①把当前状态写入 b[j]；窗口全为0时判定连续丢失。距离条件为 data[i][2] > 200，输出原因用 reasons[r] 索引取得。
