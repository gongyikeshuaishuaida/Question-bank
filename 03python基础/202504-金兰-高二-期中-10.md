# 题目 10

某 Python 程序段如下，程序运行结束后，输出的结果为（   ）

```python
s = "2015_9_1_GIWW"
c = ""
d = 0
for ch in s:
    if "0" <= ch <= "9":
        c += ch
    elif "A" <= ch <= "Z":
        c += chr((ord(ch)-ord("A")+3)%26+ord("A"))
    else:
        d += int(c)
        c = ""
print(d, c)
```

- A. 2015 JLZZ
- B. JLZZ 2015
- C. JLZZ 2025
- D. 2025 JLZZ

---
## 答案

**正确答案：** D

---
## 解析

第一个下划线把 2015 加入 d；第二个下划线把 9 加入；第三个下划线把1加入，因此 d=2015+9+1=2025。四个大写字母分别向后移3位得到 JLZZ，最后输出 2025 JLZZ。
