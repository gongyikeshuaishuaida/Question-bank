# 题目 11

11. 有如下 Python 程序段：

```python
p, s, m = 0, 0, 0
while p != -1:
    s += data[p][0]
    if s > m:
        m = s
    if s < 0:
        s = 0
    p = data[p][1]
```

若 `data` 为 `[[3, 2], [2, 4], [-2, 3], [-3, 1], [-1, 6], [-1, -1], [4, 5]]`，运行该程序后 `m` 的值为

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** D
