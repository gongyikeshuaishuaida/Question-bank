# 题目 10

10. 定义如下函数：

```python
def f(n,c):
    if n<=c:
        return 1
    else:
        return f(n//c,c)+2*c
```

执行语句 `rt = f(17,2)`，函数f被调用的次数是（　　）

- A. 7
- B. 6
- C. 5
- D. 4

---
## 答案

**正确答案：** D

---
## 解析

递归调用的参数依次为 `(17,2)`、`(8,2)`、`(4,2)`、`(2,2)`，最后一次满足 `n<=c`，共调用4次。
