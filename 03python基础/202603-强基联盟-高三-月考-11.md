# 题目 11

11. 有如下 Python 程序段：

```python
def fun(k):
    if k == 0:
        return [1]
    prev = [1, 1]
    for i in range(2, k + 1):
        curr = [1]
        left, right = 0, 1
        while right < len(prev):
            curr.append(prev[left] + prev[right])
            left += 1
            right += 1
        curr.append(1)
        prev = curr
    return prev

print(fun(4))
```

运行程序，输出结果为

- A. `[1, 3, 3, 1]`
- B. `[1, 4, 6, 4, 1]`
- C. `[1, 5, 10, 10, 5, 1]`
- D. `[1, 6, 15, 20, 15, 6, 1]`

---

## 答案

**正确答案：** B

---

## 解析

程序逐层生成杨辉三角的第 `k` 行。`fun(4)` 返回第 4 行，结果为 `[1, 4, 6, 4, 1]`。
