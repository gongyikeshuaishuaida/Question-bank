# 题目 13

学校有一排可供安排的座位，共有 N 个，这些座位分布在一条直线上，坐标分别为 `x1，x2…xn`（坐标值为整数，且座位位置已固定，不可更改）。现在需要安排若干名学生参加考试，保证每名学生独占一个座位，学生人数小于座位数。为了尽量减少学生之间的相互干扰，需合理排布学生位置，使得任意相邻两名学生之间的最近距离尽可能大。例如，有一排五个座位的坐标依次为 1、5、9、12、18，需要安排三名学生，合理的间距是 8，安排在 1、9、18 这三个座位。现要求设计一个 Python 程序计算满足该最优排布要求时，相邻两名考生之间的最大的最近距离（结果取整数）。请回答下列问题：

(1) 假设现有 8 个座位，在直线上的坐标分别为 `[18,4,25,1,14,7,21,10]`，若按照上述要求安排 5 名学生，相邻两个学生的最大的最近距离为______。

(2) 程序输入的座位坐标可能是无序的，需要对无序的座位坐标进行排序，请完成下列排序算法函数。

```python
def sort(nums):
    last = -1
    for i in nums:
        if ______①______:
            last = i + 1
    t = [0] * last
    for i in nums:
        t[i] += 1
    ans = []
    for i in range(len(t)):
        if ______②______:
            ans.append(i)
    return ans
```

请在划线处填入合适代码：______①______；______②______。

(3) 请完成下列寻找最大的最近距离的函数。

```python
def find(C, pos):
    pos = sort(pos)
    left, right = 0, pos[-1] - pos[0]
    while left <= right:
        mid = (left + right) // 2
        count, last = 1, pos[0]
        for p in pos[1:]:
            if p - last >= mid:
                count += 1
                last = p
        if ______①______:
            left = mid + 1
        else:
            right = mid - 1
    return ______②______

C = int(input())  # 输入学生人数
pos = [18,4,25,1,14,7,21,10]  # pos 储存所有座位的位置信息
print(find(C, pos))
```

请在划线处填入合适代码：______①______；______②______。

---

## 答案

**正确答案：** (1) 4；(2) ① `i >= last`；② `t[i] > 0`；(3) ① `count >= C`；② `right`

---

## 解析

座位排序后为 `[1,4,7,10,14,18,21,25]`，安排 5 人时最大最近距离为 4。排序函数先找最大坐标以确定计数数组长度，再输出出现过的下标。`find` 用二分法试探间距 `mid`：若能安排不少于 C 人，则增大下界；循环结束时 `right` 是最大可行间距。
