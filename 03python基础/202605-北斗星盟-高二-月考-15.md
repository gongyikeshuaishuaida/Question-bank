# 题目 15

问题描述：某仓库需要安排工人搬运送达的货物。每辆货车记录有到达时间和货物箱数。所有货物必须在截止时间 T 内完成搬运。

搬运规则：每个工人一次最多连续搬运 4 箱（同一产品），每箱搬运耗时 3 单位时间。每次连续搬运结束后（无论搬了几箱），必须休息 1 单位时间才能进行下一车次搬运。货车到达时：若存在“已启用且空闲”的工人（空闲时间≤货车到达时间），则优先安排其中最早空闲的工人。否则，启用一名新工人（新工人从到达时刻开始工作）。已启用的工人总数不能超过公司提供的上限 n。求在不超过 n 人的前提下，能否完成任务。若能，输出最少需要的工人数；若最少需要人数>n，或截止时间 T 内不可能完成，输出“任务无法完成！”。

（1）若货车记录列表 `data=[[1,5],[9,7],[17,6]]`，`T=30`，则需要的工人数量为 ______。

（2）定义 `wsort(data)` 函数，任务列表 `data` 中每个元素包含到达时间、货物箱数两个数据项，函数的功能是根据到达时间对 `data` 进行升序排序。

```python
def wsort(data):

            if data[j][0]>data[j+1][0]:
                data[j],data[j+1]=data[j+1],data[j]

```

（3）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

## 答案

**正确答案：** （1）4；（2）A、D；（3）① `len(worker)>0 and worker[idx]<=st`；② `st+once*dt+ft`；③ `ans==-1`

---

## 解析

冒泡排序内层可从前往后到 `len(data)-i-1`，也可从后往前到 `i`，对应 A、D。若已有工人最早空闲时间不晚于货车到达时间，则复用该工人；本次结束空闲时间为到达时间加搬运时间和休息时间。返回 -1 表示任务无法完成。
