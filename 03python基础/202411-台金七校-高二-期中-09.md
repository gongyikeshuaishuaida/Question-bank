# 题目 09

9. 某商场开展双11 促销活动，活动规则如下：（   ）
①购买商品不超过100 元，按9.5 折结算；
②购买商品超过100 元，其中100 元按9.5 折结算，超过100 元的部分按9 折结算；
使用Python 程序计算实际支付费用res，顾客所选商品金额为m，下列选项中不．正确
的是
- A.
  ```python
  if m <= 100:
      res = m * 0.95
  else:
      res = 95 + (m - 100) * 0.9
  ```
- B.
  ```python
  if m > 100:
      res = 95 + (m - 100) * 0.9
  else:
      res = m * 0.95
  ```
- C.
  ```python
  if m > 100:
      res = 95 + (m - 100) * 0.9
  if m <= 100:
      res = m * 0.95
  ```
- D.
  ```python
  res = m * 0.95
  if m > 100:
      res = res + (m - 100) * 0.9
  ```

---

## 答案

**正确答案：** D

---

## 解析

本题正确答案为 D。根据题干条件逐项判断，符合概念、代码执行结果或题图流程的选项为 D。
