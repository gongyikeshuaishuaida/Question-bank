# 题目 12

有如下 Python 程序：

```python
import random

def encode(msg, key):
    result = ""
    for i in range(0, len(msg)):
        c = msg[i]
        if "a" <= c <= "z":
            result = chr((ord(c) + key[0] - ord("a")) % 26 + ord("a")) + result
        elif "A" <= c <= "Z":
            result = result + chr((ord(c) + key[1] - ord("A")) % 26 + ord("A"))
        elif "0" <= c <= "9":
            result = result + str((int(c) + key[2]) % 10)
        else:
            result = c + result
    return result

keys = [-3, -2, -1, 1, 2, 3]
msg = '8mA3-!'
key = random.sample(keys, 3)
re = encode(msg, key)
print(re)
```

程序运行后，输出结果可能是（   ）

- A. `!-k9Y6`
- B. `!-6pB4`
- C. `!-nY00`
- D. `!-n7D2`

---
## 答案

**正确答案：** D

---
## 解析

随机抽取的三个偏移量分别用于小写字母、大写字母和数字，并且小写字母和非字母字符采用头插、其他字符采用尾插。枚举 `keys` 的三元排列后，只有 `key=[1, 3, -1]` 能得到 `!-n7D2`，因此 D 是可能的输出。
