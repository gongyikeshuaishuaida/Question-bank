# 题目 09

舞台上的机器人运动状态会随着声音分贝值变化而改变，用变量 `status` 表示运动状态，变量 `db` 表示声音分贝值。当分贝值低于 20 时，机器人静止；分贝值大于等于 20 并且小于 60 时，机器人抬手；分贝值大于等于 60 时，机器人踏步。机器人静止、抬手、踏步的状态分别为 0、1、2。下列 Python 程序段符合要求的是（   ）

- A.

  ```python
  if db < 20:
      status = 0
  if 20 <= db < 60:
      status = 1
  else:
      status = 2
  ```

- B.

  ```python
  if db >= 60:
      status = 2
  elif db >= 20:
      status = 1
  else:
      status = 0
  ```

- C.

  ```python
  status = 0
  if db >= 20:
      status = 1
  elif db >= 60:
      status = 2
  else:
      status = 2
  ```

- D.

  ```python
  status = 1
  if db < 20:
      status = 0
  elif db < 60:
      status = 2
  else:
      status = 2
  ```

---

## 答案

**正确答案：** B

---

## 解析

B 按从高到低的边界依次判断，三个分支恰好对应 `db>=60`、`20<=db<60` 和 `db<20`。A 在 `db<20` 时会被第二个 `if` 的 `else` 覆盖；C 的 `db>=60` 分支无法到达；D 把中间区间错误地赋值为 2。
