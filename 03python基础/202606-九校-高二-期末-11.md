# 题目 11

11. 有如下 Python 程序段：

```python
s = "261355276"
i = 0
tot = 0
j = 0
while i < len(s) - 1:
    if s[i] <= s[i + 1]:
        tot += int(s[j:i + 1])
        j = i + 1
    i += 1
print(tot)
```

执行该程序段后，tot 的值为（   ）

- A. 76
- B. 123
- C. 129
- D. 199

---

## 答案

**正确答案：** B

---

## 解析

依次比较相邻字符，满足前一位小于等于后一位时，将从 j 到 i 的子串转为整数累加，并更新 j。字符串 `261355276` 中触发累加的片段依次为 `26`、`13`、`5`、`52`、`27`，总和为 123。
