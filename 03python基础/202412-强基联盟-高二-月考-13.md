# 题目 13

13. 有如下 Python 程序：

```python
s = input()
k, t, v = 0, 0, 0
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        t += 1
    else:
        v = int(s[i-t:i])
        k += v
        t = 0
print(k)
```

运行程序，输入 `"23a4d56e7f90"`，输出结果为（   ）

- A. 234567
- B. 90
- C. 56
- D. 180

---

## 答案

**正确答案：** B

---

## 解析

程序遍历字符串，遇到数字则 `t` 计数，遇到非数字则取出前面连续的数字串转为整数累加到 `k`。注意：末尾 `"90"` 后没有非数字字符触发取值，所以 `90` 未被累加。

| 字符 | t | 动作 | k |
|------|---|------|---|
| 2 | 1 | - | 0 |
| 3 | 2 | - | 0 |
| a | - | `int("23")=23` | 23 |
| 4 | 1 | - | 23 |
| d | - | `int("4")=4` | 27 |
| 5 | 1 | - | 27 |
| 6 | 2 | - | 27 |
| e | - | `int("56")=56` | 83 |
| 7 | 1 | - | 83 |
| f | - | `int("7")=7` | 90 |

最终 `k = 90`。末尾 `"90"` 未被处理。
