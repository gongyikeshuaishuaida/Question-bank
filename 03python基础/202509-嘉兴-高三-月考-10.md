# 题目 10

10. 有以下 Python 程序段：

```python
a = [1,9,8,2,0]
x = 2
t1 = a[0]
for i in range(1, x+1):
    t2 = a[i]
    a[i] = t1
    t1 = t2
a[0] = t1
```

运行该程序段后，`a` 的值为（   ）

- A. `[9,1,8,2,0]`
- B. `[2,1,9,8,0]`
- C. `[8,1,9,2,0]`
- D. `[1,9,2,0,8]`

---

## 答案

**正确答案：** C

---

## 解析

逐行追踪（`range(1, 3)` 即 i=1,2）：

初始：`a=[1,9,8,2,0]`, `t1=a[0]=1`

i=1：`t2=a[1]=9`, `a[1]=t1=1`, `t1=t2=9` → `a=[1,1,8,2,0]`
i=2：`t2=a[2]=8`, `a[2]=t1=9`, `t1=t2=8` → `a=[1,1,9,2,0]`

循环结束：`a[0]=t1=8` → `a=[8,1,9,2,0]`

相当于将 `a[0]` 到 `a[x]` 的元素循环右移一位，最后 `a[0]` 被赋值为原来的 `a[x]`。
