# 题目 11

11. 有如下 Python 程序段：

```python
a = [10, 20, 30, 40, 50, 60]
i, j = 0, len(a) - 1
key = int(input("请输入查找的数："))
while i <= j:
    m = (i + j) // 2
    if a[m] < key:
        i = m + 1
    else:
        j = m - 1
print(m)
```

如果将加框处的代码改为 `a[m] <= key`，下列选项中修改前后运行结果不同的是

- A. 20
- B. 30
- C. 40
- D. 60

---

## 答案

**正确答案：** B

---

## 解析

原程序相当于查找首个不小于 key 的位置，改成 `<=` 后相当于查找首个大于 key 的位置。只有 key 为 30 时最后一次输出的 `m` 发生变化。
