# 题目 09

9. 有如下 Python 程序段：

```python
a = 10
if a > 10:
    a //= 2
elif a > 5:
    a -= 2
elif a > 0:
    a += 3
if a > -10:
    a *= 2
print(chr(a % 26+97))
```

该程序运行后输出的结果为（   ）

- A. k  
- B. i  
- C. m  
- D. q

---

## 答案

**正确答案：** D

---

## 解析

初始 `a=10`，满足 `a > 5`，执行 `a -= 2` 后 `a=8`。第二个 `if` 独立判断，`8 > -10` 成立，执行 `a *= 2` 后 `a=16`。`16 % 26 + 97 = 113`，`chr(113)` 为 `'q'`。
