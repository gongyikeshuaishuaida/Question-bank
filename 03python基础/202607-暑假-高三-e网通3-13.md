# 题目 13

2025 年 4 月亚洲羽毛球锦标赛混双采用三局两胜制，先赢得两局的组合获胜。每局比赛实行 21 分制，即当一方得分达到 21 分且领先对手至少 2 分时，该局比赛结束。小明编写程序模拟混双比赛过程，依次输出每局比赛比分，程序某次执行结果如图所示。请回答下列问题：

![[attachments/202607暑假高三e网通3_13_图1.png]]

(1) 根据比分规则，若一局比赛的比分为 20∶23，是否合理？______（选填：合理/不合理）

(2) 实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
import random
m = 3
count = 1
wa = wb = 0
ms = 21
while ______①______:
    a = b = 0  # 表示比赛双方此局的分数
    while a < ms and b < ms or abs(a-b) < 2:
        t = random.randint(0, 1)
        a += t
        ______②______
    print("第", count, "局：", a, "：", b)
    if a > b:
        wa += 1
    else:
        wb += 1
    ______③______
print("胜负情况：", wa, ":", wb)
```

请在划线处填入合适代码：______①______；______②______；______③______。

---

## 答案

**正确答案：** (1) 不合理；(2) ① `wa < 2 and wb < 2`；② `b += 1-t`；③ `count += 1`

---

## 解析

21 分制需至少领先 2 分，20∶23 不会成为终局比分。外层循环在任一方赢 2 局时结束；每球只有一方得分，故 B 方加 `1-t`；每局结束后局号加 1。
