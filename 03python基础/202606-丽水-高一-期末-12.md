# 题目 12

阅读下列材料，回答第 12 题。

某款运动手表，具备运动状态、静息状态、睡眠状态三种场景心率监测，每分钟生成一次心率值，若连续四次及以上监测到心率值超出阈值，将发出警报。

12. 定义函数 `Heart_Rate(t)`，参数 `t` 表示心率值，其功能为判断静息状态心率是否在正常范围。`flag=True` 表示心率正常，`flag=False` 表示心率异常。

```python
def Heart_Rate(t):
    # 加框处代码
    return flag
```

加框处代码不可行的是（   ）

- A.

  ```python
  flag = False
  if t >= 60:
      flag = True
  if t > 100:
      flag = False
  ```

- B.

  ```python
  flag = True
  if t < 60:
      flag = False
  elif t > 100:
      flag = False
  ```

- C.

  ```python
  if t > 100:
      flag = False
  if t >= 60:
      flag = True
  else:
      flag = False
  ```

- D.

  ```python
  if t < 60:
      flag = False
  elif t <= 100:
      flag = True
  else:
      flag = False
  ```

---

## 答案

**正确答案：** C

---

## 解析

C 中当 `t>100` 时，第一条 `if` 先把 `flag` 设为 `False`，但紧接着第二条 `if t>=60` 又把它改为 `True`，会把高于上限的心率误判为正常。其余三段代码都能正确判断 60～100 的闭区间。
