# 题目 13

某活动共有 `n` 件奖品（`n>0`），奖品编号依次为 `0~n-1`，每件奖品有对应重量及价值。活动规则如下：

①每件奖品不能分割，只能选择拿或不拿；

②所拿奖品的总重量不能超过 `m`。

在遵循活动规则的前提下，如何选取奖品使奖品总价值最高（假设有且只有一种最优方案）。

**（1）** 若 `n=3`，`m=6`，编号 `0~2` 的奖品重量依次为 `3,1,5`，价值依次为 `5,4,2`，则选取编号 ______ 奖品可以使总价值最高。（填数字）

**（2）** 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取奖品总件数，存入 n，读取所拿奖品的最大总重量，存入 m，代码略
# 读取各奖品重量及价值，依次存入列表 w 和 v，
# w[i] 和 v[i] 存放编号 i 奖品的重量及价值，代码略
i=0
wsum=0; vsum=0; max_v=0
ans=[]
while ____①____:
    s=[]; x=i; j=0
    while x>0:
        r=x%2
        if r==1:
            wsum+=w[j]
            ____②____
            s.append(j) # 列表 s 末尾添加元素 j
        x=x//2
        j+=1
    if ____③____:
        ans=s; max_v=vsum
    wsum=0; vsum=0
    i=i+1
print("最高总价值为",max_v)
print("选择商品编号:",ans)
```

---

## 答案

**正确答案：** （1）`0,1` 或 `1,0`；（2）① `i<2**n` 或 `i<=2**n-1`；② `vsum+=v[j]` 或 `vsum=vsum+v[j]`；③ `wsum<=m and vsum>max_v`

---

## 解析

该算法用二进制枚举所有奖品选择状态。共有 `n` 件奖品，枚举范围为 `0` 到 `2**n-1`；当某位为 1 时累加对应重量和价值；若总重量不超过 `m` 且总价值超过当前最大值，则更新最优方案。
