# 题目 09
有如下 Python 程序段：

```python
s=input()
st=""
for ch in s:
    if "0"<=ch<="9":
        st=st+ch
    elif "a"<=ch<="z":
        st=ch+st
```

执行程序，输入 `"12abC34d"`，则 `st` 的值是（　　）

- A. `"dba1234"`
- B. `"dCba1234"`
- C. `"dC34ba12"`
- D. `"d34ba12"`

---
## 答案
**正确答案：** A

---
## 解析
数字按出现顺序追加，得到`1234`；小写字母每次插到当前字符串最前端，依次处理`a`、`b`、`d`后得到`dba1234`。大写字母`C`不满足任一条件，被忽略。
