# 题目 15

15. 有如下 Python 程序段：

```python
import random as rd
nums = []
for i in range(5):
    nums.append(rd.randint(1, 9))  # 随机生成[1,9]范围内的整数
i = 1; minn = 10
while i <= 5:
    for j in range(len(nums)):
        if nums[j] < minn:
            minn = nums[j]; t = j
    nums[t] = nums[t] * 2
    i = i + 1; minn = 10
```

执行该程序段后，`nums` 的值可能的是（   ）

- A. `[18, 18, 18, 18, 20]`
- B. `[12, 8, 10, 7, 14]`
- C. `[4, 8, 5, 4, 5]`
- D. `[9, 10, 14, 6, 10]`

---

## 答案

**正确答案：** C

---

## 解析

算法：每次找出当前列表中的最小值，将其乘以 2，重复 5 次。由于初始值为 [1,9] 随机且每次翻倍最小值，最终数据范围在 [2, 18] 之间，且每个数都是原值的 2^k 倍。

反向验证：C 中 [4,8,5,4,5] 可通过初始 [2,8,5,4,5]（合法随机值）经 5 次操作得到。A 中出现了 20（需要原值 5 翻倍 2 次得 20，但翻倍后不再是唯一最小值），不合理。B 和 D 中出现了奇数，但最小值翻倍后必然变偶数，奇数无法保留到最后。
