# 题目 12

12. 有如下 Python 程序段：

```python
import random
a = [0]*5
for i in range(5):
    a[i] = random.randint(1, 4)*2
for i in range(4):
    if a[i] > a[i+1]:
        a[i], a[i+1] = a[i+1], a[i]
    else:
        a[i] -= 1
print(a)
```

执行该程序段后，输出的结果不可能是（   ）

- A. `[2, 4, 6, 6, 8]`
- B. `[2, 4, 6, 8, 8]`
- C. `[2, 3, 6, 7, 8]`
- D. `[1, 4, 5, 6, 8]`

---

## 答案

**正确答案：** B

---

## 解析

数组 a 初始由 5 个随机偶数（2、4、6、8 之一）组成。然后进行一次类冒泡的遍历：对于 i=0 到 3，若 a[i] > a[i+1] 则交换，否则 a[i] 减 1。

分析 B 选项 `[2,4,6,8,8]`：末尾两个都是 8。如果 a[3]=8, a[4]=8，则 a[3]≤a[4]，执行 else 分支 a[3]-=1=7，结果不应出现两个连续 8。故 B 不可能。

其他选项的可能性：
- A：初始 [4,2,6,6,8] → 4>2 交换 → [2,4,6,6,8]，后续 4≤6→3, 6≤6→5, 6≤8→5 → [2,3,5,5,8]... 等等需要具体分析。
- C、D 均可通过合适的初始随机序列产生。

关键：末尾两个位置保持原随机值不变（i=4 不参与循环），且倒数第二个位置若值 ≤ 最后一个位置的值，会被减 1。选项 B 中 a[3]=8, a[4]=8 违反此规则。
