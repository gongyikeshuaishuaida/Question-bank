# 题目 11

计算表达式“1+1/2+1/4+1/6……+1/98+1/100”的值的 Python 程序段如下：

```python
sum=1
i=0
while （1）：
    （2）
    （3）
```

上述程序段中划线（1）（2）（3）处可选代码为：① i<50；② i<100；③ sum=sum+1/i；④ i+=2；⑤ i+=1。则划线（1）（2）（3）处填入代码依次是（   ）

- A. ①③④
- B. ②③⑤
- C. ①⑤③
- D. ②④③

---
## 答案

**正确答案：** D

---
## 解析

i 从0开始，循环体要先执行 i+=2 再计算1/i，条件应为 i<100，因此选择②④③。
