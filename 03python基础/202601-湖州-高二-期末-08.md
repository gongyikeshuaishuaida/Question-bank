# 题目 08

8. 有如下 Python 程序段：

```python
def check(x):
    if x[0] < x[1]:
        x[0], x[1] = x[1], x[0]
    if x[0] > x[2]:
        return x[0]
    else:
        return x[2]
```

若 `x` 为 `[4, 2, 5]`，调用函数 `check(x)` 后的返回值为（   ）

- A. 2  
- B. 4  
- C. 5  
- D. `[2, 4, 5]`

---

## 答案

**正确答案：** C

---

## 解析

`x[0] < x[1]` 即 `4 < 2` 不成立，列表不交换。随后判断 `x[0] > x[2]` 即 `4 > 5` 不成立，执行 `else` 返回 `x[2]`，结果为 5。
