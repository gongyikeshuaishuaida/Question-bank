# 题目 10

10. 有如下 Python 程序段：

```python
result, flag = "", 1
for ch in s:
    if flag == 1 and "a" <= ch <= "z":
        result += chr(ord(ch) - 32)
    elif ch == "#":
        flag = 1 - flag
    elif flag == 0:
        result += ch
```

若字符串 s 的值为 `ab#cd#23e#!`，执行该程序段后，变量 result 的值为（   ）

- A. `ABcdE!`  
- B. `AbcdE!`  
- C. `ABCDE`  
- D. `aBcdE!`

---

## 答案

**正确答案：** A

---

## 解析

flag 为 1 时小写字母转为大写，遇到 `#` 切换 flag 且不输出；flag 为 0 时非 `#` 字符原样输出。字符串 `ab#cd#23e#!` 处理后得到 `ABcdE!`。
