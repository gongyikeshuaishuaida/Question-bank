# 题目 09

09. 如图所示的流程图，实现的功能是输入重量 vol（单位：克），根据重量计算价格 p（单位：元）。下列程序段中不能实现流程图功能的是（   ）

![[attachments/202503精诚联盟高二_09_图1.png]]

- A.

  ```python
  vol = int(input())
  if Vol < 500:
      p = 0.5
  elif vol < 1200:
      p = 1.5
  else:
      p = 2.5
  print(P)
  ```

- B.

  ```python
  vol = int(input())
  p = 2.5
  if vol < 500:
      p = 0.5
  else:
      if V < 1200:
          p = 1.5
  print(p)
  ```

- C.

  ```python
  vol = int(input())
  if vol < 500:
      p = 0.5
  if Vol >= 1200:
      p = 2.5
  else:
      p = 1.5
  print(p)
  ```

- D.

  ```python
  vol = int(input())
  p = 1.5
  if vol < 500:
      p = 0.5
  if vol >= 1200:
      p = 2.5
  print(p)
  ```

原卷选项表中 Vol、V、P 的大小写写法依原样保留；按题目答案标准将其视为 vol、p 的排版差异后比较逻辑。

---
## 答案

**正确答案：** C

---
## 解析

流程图要求 vol<500 时 p=0.5，500≤vol<1200 时 p=1.5，vol≥1200 时 p=2.5。按答案标准忽略选项中变量大小写排版差异后，C 使用两个相互独立的 if，vol<500 时第二个 if 的 else 仍会把 p 改为 1.5，不能实现流程图功能。A、B、D 的分支逻辑等价于流程图。
