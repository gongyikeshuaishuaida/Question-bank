# 题目 10

10. 有如下 python 程序段：

```python
i = 0; j = len(s) - 1
while i <= j:
    if s[j] == "#":
        j -= 1
    elif s[i] == "#":
        s[i] = s[j]
        j -= 1
    else:
        i += 1
print(s[:i])
```

若列表 `s` 为 `['p','#','y','#','t','h','#','o','n','#']`，执行该程序段后，输出的结果是（   ）

- A. `['p', 'n', 'y', 'o', 't', 'h']`  
- B. `['p', 't', 'y', 'o', 't', 'h']`  
- C. `['p', 'n', 'y', 'o', 'h', 't']`  
- D. `['p', 'y', 't', 'h', 'o', 'n']`

---

## 答案

**正确答案：** A

---

## 解析

程序用右侧非 `#` 元素依次替换左侧的 `#`，并用 `i` 记录前部有效元素长度。执行后前 6 个有效元素为 `['p','n','y','o','t','h']`，因此输出选项 A。
