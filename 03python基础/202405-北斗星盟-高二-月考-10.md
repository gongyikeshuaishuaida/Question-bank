# 题目 10

10. 某加密程序的代码如下：

```python
s = input("请输入明文：")
q = "1896720354"; mw = ""
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        mw += q[int(s[i])]
    elif "a" <= s[i] <= "z":
        mw += chr((ord(s[i])-ord("a")+i%2)%26+ord("a"))
    else:
        mw = s[i] + mw
print(mw)
```

运行该程序段，若输入 `s` 的值为 `"Win98@qq.com"`，则输出结果是（   ）

- A. `.@Wjn45qrdon`
- B. `Wjn53@qr.don`
- C. `Wjn32@qr.don`
- D. `.@Wkp45sseqo`

---

## 答案

**正确答案：** A

---

## 解析

大写字母和符号进入 `else` 分支，被加到当前密文串最前面；数字按 `q` 中对应下标替换，`9→4`、`8→5`；小写字母按下标奇偶位移，`i%2=1` 时后移一位。逐字符处理 `"Win98@qq.com"` 后得到 `.@Wjn45qrdon`。
