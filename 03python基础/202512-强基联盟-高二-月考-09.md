# 题目 09

有如下Python程序段：

```python
s="acedb"
res=""
i=0;j=len(s)-1
while i<=j:
    if s[i]<s[j]:
        res+=s[i]
        i+=1
    else:
        res+=s[j]
        j-=1
print(res)
```

执行该程序段后，输出的结果是（   ）

- A. `ace`  
- B. `bde`  
- C. `acdbe`  
- D. `abcde`

---

## 答案

**正确答案：** D

---

## 解析

程序使用双指针从字符串两端向中间比较。变量 `i` 指向左端、`j` 指向右端，每次比较 `s[i]` 和 `s[j]`，将较小的字符添加到结果 `res` 中。

执行过程：
- 初始：s="acedb", i=0('a'), j=4('b'), a<b → res="a", i=1
- i=1('c'), j=4('b'), c>b → res="ab", j=3
- i=1('c'), j=3('d'), c<d → res="abc", i=2
- i=2('e'), j=3('d'), e>d → res="abcd", j=2
- i=2('e'), j=2('e'), e不小于e → res="abcde", j=1
- i=2, j=1, i>j 退出循环

输出 `abcde`。
