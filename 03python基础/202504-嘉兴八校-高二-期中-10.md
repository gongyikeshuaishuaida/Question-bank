# 题目 10

有如下程序段，目的是使输出的 z 值有 0、1、2 三种情况，但程序段中存在问题。若要测试出其中的问题，下列哪组输入数据合适（   ）

```python
n = int(input())
if n <= 20:
    z = 0
if n <= 50:
    z = 1
else:
    z = 2
print(z)
```

- A. 20，50，60
- B. 10，20，60
- C. 30，40，60
- D. 10，60，70

---
## 答案

**正确答案：** A

---
## 解析

两个 if 是独立的。输入 20 时第一段先令 z=0，随后第二个条件又令 z=1，所以无法得到目标的 0；输入 50 得到 1，输入 60 得到 2。A 同时覆盖 20、50、60 三个边界和分支，能够暴露问题。
