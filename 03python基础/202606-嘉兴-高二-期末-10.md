# 题目 10

10. 某 Python 程序段如下：

```python
s = "abacbd"
dic = {}  # 记录每个字母最后一次出现的索引
max_len = 0
left = 0
right = 0
for ch in s:
    if ch in dic and dic[ch] >= left:
        left = dic[ch] + 1
    dic[ch] = right
    cur = right - left + 1
    if cur > max_len:
        max_len = cur
    right = right + 1
print(max_len)
```

该程序段运行后，输出的结果是（　）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** B

---

## 解析

最长无重复连续子串可取`acbd`，长度为4。
