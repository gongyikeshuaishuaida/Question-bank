# 题目 10

10. 有如下 Python 程序段：

```python
s = "P3yThEn@2026"
upper = digit = 0
other = ""
for ch in s:
    if "A" <= ch <= "Z":
        upper += 1
    elif "0" <= ch <= "9":
        digit += int(ch)
    else:
        other = ch + other
```

程序运行后，`upper` 与 `other` 的值分别是（   ）

- A. `3`，`"@nhy"`
- B. `6`，`"yhn@"`
- C. `3`，`"yhn@"`
- D. `6`，`"@nhy"`

---

## 答案

**正确答案：** A
