# 题目 10

10. 某 Python 程序如下：

```python
s = input("请输入数字字符串：")
m1 = 0
m2 = 0
r = 0
i = 0
while i < len(s):
    if i % 2 == 0:
        m1 = m1 + int(s[i])
    else:
        m2 = m2 + int(s[i])
    r = m1
    if m1 > m2:
        r = m2
    i = i + 1
print(r)
```

程序运行时，若输入 `"4753"`，则输出的结果是（   ）

- A. 1
- B. 8
- C. 9
- D. 11

---

## 答案

**正确答案：** C

---

## 解析

输入 "4753"：i=0(4)→m1=4, r=m1=4, m1>m2?(4>0)→r=m2=0；i=1(7)→m2=7, r=m1=4, 4>7? No→r=4；i=2(5)→m1=9, r=m1=9, 9>7? Yes→r=m2=7；i=3(3)→m2=10, r=m1=9, 9>10? No→r=9。输出 9。
