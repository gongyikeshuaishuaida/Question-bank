# 题目 13

13. 某软件通过计算密码的“局部复杂度”判断密码强度。局部复杂度定义为密码中不含重复字符的最长连续子串的长度。例如，密码 `ape123@p1` 中最长的不含重复字符的连续子串为 `e123@p1`，局部复杂度为 7。

（1）密码为 `jinlan#2026` 时，其局部复杂度为______。

（2）以下程序用于计算输入密码的局部复杂度，请在划线处填入合适代码。

```python
s = input("请输入密码：")
index = [-1] * 128
mx = left = i = 0
while i < len(s):
    ①
    if index[c] >= left:
        ②
    index[c] = i
    ③
    if length > mx:
        mx = length
    i += 1
print("局部复杂度为：", mx)
```

---

## 答案

（1）6

（2）

① `c = ord(s[i])`

② `left = index[c] + 1`

③ `length = i - left + 1`

---

## 解析

用区间 `[left, i]` 表示当前不含重复字符的滑动窗口，`index[c]` 记录字符 `c` 上一次出现的位置。若当前字符在窗口内出现过，就把左端点移动到其上一次出现位置的后一位；当前窗口长度为 `i-left+1`。

对于 `jinlan#2026`，从开头开始的 `jinla` 长度为 5；遇到第二个 `n` 后移动左端点，后续最长无重复子串的长度为 6，因此局部复杂度为 6。
