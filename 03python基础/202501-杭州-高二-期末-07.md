# 题目 07

六岁以上人群在安静状态下的正常心率通常为 60～100 次/分钟。低于 60 称为心动过缓，高于 100 称为心动过速。体检时将测得的某人心率存入变量 `rate`，下列 Python 程序段不能正确输出心率状态的是（　　）

**A**

```python
sta = "心动过缓"
if rate > 100:
    sta = "心动过速"
elif rate <= 100:
    sta = "正常"
print(sta)
```

**B**

```python
if rate > 100:
    sta = "心动过速"
elif rate < 60:
    sta = "心动过缓"
else:
    sta = "正常"
print(sta)
```

**C**

```python
sta = "心动过速"
if rate < 60:
    sta = "心动过缓"
elif rate <= 100:
    sta = "正常"
print(sta)
```

**D**

```python
if rate < 60:
    sta = "心动过缓"
if rate > 100:
    sta = "心动过速"
if 60 <= rate <= 100:
    sta = "正常"
print(sta)
```

---

## 答案

**正确答案：** A

---

## 解析

A 中当 `rate<60` 时，条件 `rate>100` 不成立，随后 `rate<=100` 成立，`sta` 被错误改为“正常”。其余程序都能分别覆盖小于 60、60～100、大于 100 三个互斥区间。
