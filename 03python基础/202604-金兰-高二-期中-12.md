# 题目 12

12. 有如下 Python 程序段：

```python
# 生成 6 个 [1,9] 随机数存入列表 a
b = []
dic = {}
for i in range(len(a)):
    if a[i] not in dic:
        dic[a[i]] = []
    dic[a[i]].append(i)
for i in dic:
    for j in dic[i]:
        b.append(a[j])
print(b)
```

若输出结果为 `[9,4,4,6,6,8]`，则 `a` 不可能是（   ）

- A. `[9,4,4,6,6,8]`
- B. `[9,6,4,8,6,4]`
- C. `[9,4,6,8,4,6]`
- D. `[9,4,6,6,4,8]`

---

## 答案

**正确答案：** B

---

## 解析

字典按各数字首次出现的顺序保存键，随后把相同数字按原下标集中输出。B 中键的首次出现顺序为 9、6、4、8，输出应为 `[9,6,6,4,4,8]`，不可能得到题设结果。其余三项的首次出现顺序均为 9、4、6、8，且重复次数相同。
