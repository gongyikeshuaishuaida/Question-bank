# 题目 11

11. 有如下 Python 程序段：

```python
s1="vbdyc++dcydyvbdyvbcdy"
s2="dy"
i=0; m=0
while i<=len(s1)-len(s2):
    if s1[i:i+len(s2)]==s2:
        i=i+len(s2)
        m+=1
    else:
        i+=1
print(m)
```

该程序段执行后，m 的值为（   ）

- A. 8
- B. 7
- C. 5
- D. 4

---
## 答案

**正确答案：** D

---
## 解析

程序从左到右查找子串 dy，找到后跳过该子串，避免重复计数。在 vbdyc++dcydyvbdyvbcdy 中依次找到下标 2、10、14、19 的四处，m=4，故选 D。
