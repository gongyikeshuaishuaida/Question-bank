# 题目 07

7. 下列不能表示“x 既能被 3 整除，又能被 4 整除”的表达式是（   ）

- A. `x % 12 == 0`
- B. `x // 12 == 0`
- C. `x % 3 == 0 and x % 4 == 0`
- D. `x // 12 == x / 12`

---

## 答案

**正确答案：** B

---

## 解析

同时能被 3 和 4 整除等价于能被 12 整除。`x % 12 == 0` 和 `x % 3 == 0 and x % 4 == 0` 都能直接判断；当 `x` 能被 12 整除时，整除结果和普通除法结果相等。`x // 12 == 0` 只表示整除商为 0，不能表示能被 12 整除。
