# 题目 10

10. 有如下 Python 程序段：

```python
s = "h3a2p5p4y6"
r = ""
for i in s:
    if "0" <= i <= "9":
        if r == "" or i >= r[-1]:
            r += i
        elif i < r[0]:
            r = i
```

执行该程序段后，`r` 的值为（   ）

- A. `"256"`
- B. `"46"`
- C. `"356"`
- D. `"246"`

---

## 答案

**正确答案：** A

---

## 解析

程序只处理数字字符。数字依次为 3、2、5、4、6，`r` 的变化为：

`"" → "3" → "2" → "25" → "25" → "256"`。

遇到 2 时因其小于 `r[0]` 而重置；遇到 4 时既不大于等于末尾的 5，也不小于开头的 2，因此不改变 `r`。
