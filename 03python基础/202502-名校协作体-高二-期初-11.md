# 题目 11

有如下 Python 程序：

```python
def f(s):
    n = len(s)
    i = 0
    j = n - 1
    ans = ""
    while i < n // 2 and j >= n // 2:
        if s[i] >= s[j]:
            ans += s[i]
            j -= 1
        else:
            ans += s[j]
            i += 1
    return ans

s = input("输入字符串：")
print(f(s))
```

执行程序，分别输入下列选项中的字符串，输出结果不为“ppp”的是（   ）

- A. `python`
- B. `public`
- C. `purple`
- D. `phrase`

---
## 答案

**正确答案：** D

---
## 解析

程序每次比较字符串左、右两端未处理字符，取字典序较大的字符加入结果。运行可得 `python`、`public`、`purple` 均输出 `ppp`，`phrase` 输出 `psss`，所以 D 不为“ppp”。
