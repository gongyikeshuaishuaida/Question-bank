# 题目 10

有如下 Python 程序段：

```python
ans = 0; num = 0
for i in range(len(s)):
    if s[i] in "0123456789":
        num += 1
        if num > ans:
            ans = num
    else:
        num = 0
```

若 `s` 为 `"a07ab2626c071"`，执行该程序段后 `ans` 的值为（   ）

- A. 5
- B. 4
- C. 3
- D. 2

---

## 答案

**正确答案：** B

---

## 解析

程序统计字符串中连续数字字符的最长长度。`"a07ab2626c071"` 中连续数字段为 `07`、`2626`、`071`，最长长度为 4。
