# 题目 10

10．有如下 Python 程序段：

```python
def code(t):
    if len(t)==0:
        return ""
    k=int(t[0])
    return code(t[1:])+str((k+3)%8)
s=input("输入原始数据：")
answer=code(s)
print("加密结果为：",answer)
```

若最终输出的加密结果为 2174，则输入的原始数据是

- A．7641
- B．1467
- C．5427
- D．7245

---
## 答案

**正确答案：** B

---
## 解析

递归先处理 `t[1:]`，再把当前数字加3后对8取模并拼接到末尾。输入 `1467` 时从后往前产生 `2、1、7、4`，加密结果为 `2174`。
