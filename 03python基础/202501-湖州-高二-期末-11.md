# 题目 11

11. 有如下 Python 程序段：

```python
def fun(x, y, z):
    s = 1
    for i in range(y):
        s = s * (x - i)
        if not z:
            s = s // (i + 1)
    return s
```

执行语句 `r = fun(7, 3, False)`，变量 `r` 的值是（   ）

- A. 21
- B. 35
- C. 42
- D. 210

---

## 答案

**正确答案：** B

---

## 解析

`z=False`，`not z` 恒为 True，每次循环都会执行整除：

| i | s 更新 | s // (i+1) |
|---|--------|------------|
| 0 | 1×7=7 | 7//1=7 |
| 1 | 7×6=42 | 42//2=21 |
| 2 | 21×5=105 | 105//3=35 |

最终 `r = 35`。
