# 题目 08

流程图中的分支结构可以用 if 语句实现，下列选项中正确的是（   ）

| 选项 | 代码 |
|---|---|
| ① | if a%2==1:；c+=1；else:；c-=1 |
| ② | if a%2==1:；c+=1；if a%2==0:；c-=1 |
| ③ | c-=1；if a%2==1:；c+=1 |
| ④ | c+=1；if a%2==0:；c-=1 |

- A. ①②
- B. ①③
- C. ②③
- D. ③④

---
## 答案

**正确答案：** A

---
## 解析

流程图要求奇数使 c 加1、偶数使 c 减1。①用 if/else 完整表达两种分支；②用两个互斥的 if，也能得到同样结果。③和④在执行前先无条件修改 c，奇偶分支结果不再等价。
