# 题目 11

有如下 Python 程序：

```python
def fac(n):
    s = {}
    for i in range(2, n+1):
        while n % i == 0:
            if i in s:
                s[i] += 1
            else:
                s[i] = 1
            n //= i
    return s
print(fac(2025))
```

程序运行后，输出的结果是（   ）

- A. {3: 4, 2: 5}
- B. {3: 4, 5: 2}
- C. {4: 3, 2: 5}
- D. {4: 3, 5: 2}

---
## 答案

**正确答案：** B

---
## 解析

2025=81×25=3⁴×5²，函数依次除尽因子并在字典中累计次数，输出 {3:4, 5:2}，选 B。
