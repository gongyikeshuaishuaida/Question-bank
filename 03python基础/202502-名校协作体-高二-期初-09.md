# 题目 09

图书馆读者的借阅状态根据借阅次数更新：一个月内借阅次数少于 3 次为“不活跃”，3～8 次为“活跃”，超过 8 次为“非常活跃”。根据该算法设计程序，下列选项不正确的是（   ）

- A.
  ```python
  status = "非常活跃"
  if times <= 8:
      if times < 3:
          status = "不活跃"
      else:
          status = "活跃"
  ```
- B.
  ```python
  status = "活跃"
  if times < 3:
      status = "不活跃"
  elif times > 8:
      status = "非常活跃"
  ```
- C.
  ```python
  status = "非常活跃"
  if times < 3:
      status = "不活跃"
  if 3 <= times <= 8:
      status = "活跃"
  ```
- D.
  ```python
  status = "不活跃"
  if times > 8:
      status = "非常活跃"
  if times >= 3:
      status = "活跃"
  ```

---
## 答案

**正确答案：** D

---
## 解析

D 中当 `times > 8` 时先赋值“非常活跃”，随后第二个独立 `if times >= 3` 又覆盖为“活跃”，所以不能正确处理超过 8 次的情况。A、B、C 对三个区间的判断均正确。
