# 题目 12

字符串 `d` 中 `-1` 表示学生缺考，其他数字表示得分。程序统计平均分：

```python
s, m = 0, len(d)
for i in range(len(d)):
    if d[i] == "-":
        ____
    else:
        s = s + int(d[i])
avg = s / m
```

选项：

- A. `s -= 1`；`m -= 2`
- B. `s -= 1`；`m -= 1`
- C. `m -= 1`
- D. `m -= 2`

---
## 答案
**正确答案：** A

---
## 解析
循环遇到 `-` 时，下一位的 `1` 仍会进入 `else` 并被加到 `s`，所以先用 `s-=1` 抵消它；一个缺考标记占两个字符，分母需用 `m-=2` 排除，故选 A。
