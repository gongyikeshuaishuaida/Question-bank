# 题目 08

小明是该连锁超市的分店长，需要对每天的销售数据进行分析，进而确定是否需要补货。他编写了一个 Python 程序，其中统计每种商品销售总量的部分代码如下：

```python
# 销售数据存储于列表 data 中，形如 [[商品名称, 数量], ...]
# 例如 [["可乐", 3], ["薯片", 2], ...]
dic = {}
for i in range(len(data)):
    t = data[i]
    if ________①:
        dic[t[0]] = t[1]
    else:
        ________②
```

下列选项中，划线处代码正确的是（   ）

- A. ① `t[0] in dic`；② `dic[t[0]] += t[1]`
- B. ① `t[0] not in dic`；② `dic[t[0]] += t[1]`
- C. ① `t[0] in dic`；② `dic[t[0]] += 1`
- D. ① `t[0] not in dic`；② `dic[t[0]] += 1`

---

## 答案

**正确答案：** B

---

## 解析

商品第一次出现时，其名称不在字典中，应建立键值对 `dic[t[0]] = t[1]`；再次出现时，应把本次销量累加到原销量中，即 `dic[t[0]] += t[1]`。因此选择 B。
