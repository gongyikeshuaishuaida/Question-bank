# 题目 10

10. 定义如下递归函数：

```python
def f(n, c):
    if n <= c:
        return 1
    else:
        return f(n // c, c) + 2 * c

print(f(15, 2))
```

程序运行结束后，输出结果为（   ）
- A. 10
- B. 13
- C. 12
- D. 11

---

## 答案

**正确答案：** B

---

## 解析

`f(15,2)=f(7,2)+4=f(3,2)+8=f(1,2)+12=1+12=13`，所以输出 13。
