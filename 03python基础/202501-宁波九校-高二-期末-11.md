# 题目 11

11. 有如下 Python 程序段：

```python
import random
a = [0]*6
i = 0
while i < 6:
    a[i] = random.randint(1, 10)
    if i % 3 == 0 or a[i] % 2 == i % 2:
        i += 1
print(a)
```

该程序运行后，下列选项中可能是输出结果的是（   ）

- A. `[1, 7, 10, 8, 6, 3]`  
- B. `[0, 1, 8, 3, 4, 5]`  
- C. `[5, 3, 6, 1, 1, 4]`  
- D. `[6, 8, 1, 5, 8, 9]`

---

## 答案

**正确答案：** A

---

## 解析

当 `i` 为 0 或 3 时，`i % 3 == 0` 成立，当前位置随机数任意即可前进；当 `i` 为 1、2、4、5 时，必须满足 `a[i] % 2 == i % 2`，即第 1、5 位为奇数，第 2、4 位为偶数。程序结束时所有位置都已赋值为 1 到 10 的整数。A 满足这些条件；B 含有 0，C 的下标 5 处为偶数，D 的下标 1 处为偶数，均不可能。
