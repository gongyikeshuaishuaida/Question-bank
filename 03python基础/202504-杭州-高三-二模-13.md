# 题目 13

13.小明在实验室搭建一套花园智能灌溉系统，该系统中每个灌溉阀门都能独立控制。当阀门关闭时，若传感器检测到土壤水分值持续20分钟低于10，则打开阀门；当阀门打开时，若土壤水分值高于40，或阀门持续30分钟处于打开状态，则关闭阀门。

（1）若分区1在某时刻的水分值为11，阀门状态是关闭的，18分钟后测得水分值为9，此时阀门状态为 ______（单选，填字母：A. 打开 / B. 关闭）。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码：

```python
n = 5
a = [0] * n
b = [0] * n
t = [0] * n
mmin, mmax = 10, 40
while True:
    # 从传感器获取各分区土壤水分值，保存到 a 中，代码略
    for i in range(n):
        if ①:
            if a[i] < mmin:
                t[i] += 1
            else:
                t[i] = 0
            if t[i] >= 20:
                ②
                b[i] = 1
        else:
            ③
            if a[i] > mmax or t[i] >= 30:
                t[i] = 0
                b[i] = 0
```

---
## 答案

**参考答案：** （1）B；（2）① b[i] == 0；② t[i] = 0；③ t[i] += 1。

---
## 解析

关闭状态用 b[i]==0 表示，只有连续低于阈值20分钟才打开，因此①为 b[i]==0；打开后重新计时，故②将 t[i] 清零；阀门保持打开时需要累计持续时间，故③为 t[i] += 1。18分钟低于阈值仍不足20分钟，阀门保持关闭，选 B。
