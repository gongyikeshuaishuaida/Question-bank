# 题目 11

有如下 Python 程序段：

```python
q=[3,1,5,9,2,6]
head=0
tail=1
for i in range(1,len(q)):
    if q[i]<q[tail-1]:
        print(tail-head,end="-->")
        head=tail
    tail+=1
```

运行该程序段后，输出结果为（   ）

- A. `0->2->1->`
- B. `1->3->2->`
- C. `0->2->`
- D. `1->3->`

---
## 答案
**正确答案：** D
---
## 解析
当 `q[i]` 小于当前段首元素时输出段长：在 `i=1` 与 `i=4` 时分别输出 `1->`、`3->`。
