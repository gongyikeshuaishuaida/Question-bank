# 题目 13

13. 某 Python 程序如下：

```python
def add(a, b):
    return a + b

def mul(x, y):
    return x * y

m = 2
n = 3
result = mul(add(m, n), m)
print(result)
```

程序运行后，输出的结果是（   ）

- A. 6
- B. 8
- C. 10
- D. 12

---

## 答案

**正确答案：** C

---

## 解析

`add(m, n) = add(2, 3) = 2 + 3 = 5`。

`mul(add(m, n), m) = mul(5, 2) = 5 * 2 = 10`。

输出 `10`，选 C。
