# 题目 12

某电商平台需要对销售的某品牌手机评分。计算每条评论的情感分规则：① 统计积极词语出现次数；② 每个积极词语第 1 次出现得 1 分，后面每次得分是前一次的 80%。评分 = 0.8 × 情感分 + 0.98（上限 5 分，下限 1 分）。

(1) 若某条评论为"体验 perfect，相机满意，battery 表现一般，总体满意！"，则该条评论的情感分为 ▲ 。

(2) 定义函数 `ptext(text)`，将大写字母转为小写，请在划线处填入合适代码：

```python

```

(3) 定义函数 `gs(words)` 计算情感分：

```python
def gs(words):

print("该手机的最终评分为:", round(sum / cnt, 2))
```

---

## 答案

**正确答案：**

(1) 2.8

(2) `nt = nt + chr(ord(ch) + 32)`（或 `nt = nt + chr(ord(ch) + ord('a') - ord('A'))`）

(3) `wf[word] = 1`

(4) `pr = min(5, pr)`（或 `if pr > 5: pr = 5`）

---

## 解析

(1) 积极词 perfect(1分)、满意(1分)、满意(0.8分) → 1+1+0.8=2.8。

(2) 大写转小写：ASCII 码差 32，`ord(ch)+32 → chr()`。

(3) 积极词首次出现时 `wf[word] = 1`。

(4) 评分不能超 5 分：`pr = min(5, pr)`。
