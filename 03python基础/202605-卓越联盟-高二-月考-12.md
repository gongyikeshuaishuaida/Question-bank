# 题目 12

12. 在升序数组 `a = [12, 25, 38, 44, 56, 61, 73, 89]` 中查找目标值 `key`，部分 Python 程序如下：
```python
import random

key = random.randint(1, 18) * 5
i, j, n = 0, 7, 0
while i <= j:
    m = (i + j) // 2
    if a[m] == key:
        break
    elif key < a[m]:
        j = m - 1
        n -= 1
    else:
        i = m + 1
        n += 1
print(n)
```

执行该程序后，关于变量 `n` 的说法正确的是

- A. `n` 的值可能为 3
- B. `n` 的值不可能为 4
- C. `n` 的值有 5 种可能
- D. 若 `n` 的值为 -1，则 `key` 的值一定是 25

---

## 答案

**正确答案：** A
