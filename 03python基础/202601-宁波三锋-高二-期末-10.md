# 题目 10

10. 某 Python 程序段如下：

```python
c = 0
for i in range(0, 21):
    if i % 3 == 0 or i % 5 == 0:
        c += 1
print(c)
```

运行该程序段，输出结果是（   ）

- A. 10  
- B. 9  
- C. 6  
- D. 4

---

## 答案

**正确答案：** A

---

## 解析

`range(0,21)` 包含 0 到 20。满足能被 3 或 5 整除的数为 0、3、5、6、9、10、12、15、18、20，共 10 个，因此输出 10。
