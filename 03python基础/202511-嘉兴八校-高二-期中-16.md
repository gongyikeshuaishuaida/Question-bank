# 题目 16

16. 小明使用 Email 跟朋友交流，为了增加趣味性，他们一起设计了一种加密算法：对字符串中的所有英文字母进行处理，按照字母"a""b"……"z"的排列顺序，将字符串中的小写字母都取其后一个字母，大写字母都取其前一个字母，重组得到密文（规定字符"z"的后一个字符取"a"，字符"A"的前一个字符取"Z"）。程序运行结果及部分程序代码如 16 题图 a 所示，请回答下列问题：

![[attachments/202511嘉兴八校_16_图1.jpg]]

（1）若输入的明文为 `"Amaze"`，则输出的密文为（   ）。

（2）请将程序代码补充完整。

（3）加框处程序代码有误，请改正。

```python
pw = input("请输入你要加密的明文:")
mw = ""
n = ①

for i in range(n):
    t = pw[i]
    if "a" <= t <= "z":
        t = ②
    else "A" <= t <= "Z":      # 加框处
        t = chr((ord(t) - 65 - 1 + 26) % 26 + 65)
    mw = ③

print(mw)
```

---

## 答案

（1）**Znbaf**

（2）
① `len(pw)`
② `chr((ord(t) + 1 - 97) % 26 + 97)`
③ `mw + t`

（3）`elif "A" <= t <= "Z":`

---

## 解析

（1）加密规则：小写字母→后一个字母（z→a），大写字母→前一个字母（A→Z）。
- 'A' → Z，'m' → n，'a' → b，'z' → a，'e' → f。结果：Znbaf。

（2）① `n = len(pw)` 获取字符串长度。② 小写字母 a-z（ASCII 97-122），后移一位：`chr((ord(t) - 97 + 1) % 26 + 97)`。③ 将处理后的字符追加到密文：`mw = mw + t`。

（3）`else` 后面跟条件判断需要使用 `elif`，改为 `elif "A" <= t <= "Z":`。
