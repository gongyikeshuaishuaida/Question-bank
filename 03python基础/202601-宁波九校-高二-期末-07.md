# 题目 07

7. 三个互不相等的整数 `a`、`b` 和 `c`，下列程序段能输出其最大值的是（   ）

- A.

```python
max = a
if b > c:
    max = b
else:
    max = c
```

- B.

```python
if a > b > c:
    max = a
elif b > a > c:
    max = b
elif c > a > b:
    max = c
```

- C.

```python
if a > b and a > c:
    max = a
if b > a and b > c:
    max = b
else:
    max = c
```

- D.

```python
max = c
if a > c or b > c:
    if a > b:
        max = a
    else:
        max = b
```

---

## 答案

**正确答案：** D

---

## 解析

D 先假设 `c` 最大；若 `a` 或 `b` 大于 `c`，则最大值必在 `a`、`b` 中，再比较 `a` 与 `b` 即可。A 没有把 `a` 与另外两数充分比较；B 只覆盖部分大小关系；C 的 `else` 只与第二个 `if` 配对，可能覆盖前面已经得到的最大值。
