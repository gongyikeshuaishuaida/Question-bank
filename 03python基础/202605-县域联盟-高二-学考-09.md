# 题目 09

9. 有如下 Python 程序段：

```python
s = input()
n = len(s)
i = 0
while i < n:
    ch = s[i]
    if "0" <= ch <= "9":
        s = ch + s[0:i] + s[i + 1:]
        i += 1
    else:
        s = s[0:i] + s[i + 1:] + ch
        n -= 1
print(s)
```

执行该程序段后，若输出结果为 `1234abcd`，则输入的 `s` 不可能为（ ）

- A. `ab12cd34`
- B. `abcd4321`
- C. `43ab21cd`
- D. `4abc3d21`

---

## 答案

**正确答案：** A

---

## 解析

程序遇到数字时把该数字移到字符串最前端，因此数字按处理顺序逆序排列；遇到非数字字符时将其移到末尾并保持相对顺序。输入 A 的数字处理顺序为 1、2、3、4，最终数字部分会是 4321，不可能输出 1234abcd。
