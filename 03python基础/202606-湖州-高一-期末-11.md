# 题目 11

11. 某商场会员等级规则：设消费金额 `m` 为整数，1000 元以下（不包含）为普通会员，1000 元以上（包含）、3000 元以下（不包含）为银卡，3000 元以上（包含）为金卡。用 Python 语句描述，则下列选项中正确的是（   ）

- A.

  ```python
  if m >= 1000:
      print("银卡")
  elif m >= 3000:
      print("金卡")
  else:
      print("普通会员")
  ```

- B.

  ```python
  if m < 3000:
      print("银卡")
  elif m < 1000:
      print("普通会员")
  else:
      print("金卡")
  ```

- C.

  ```python
  if m < 1000:
      print("普通会员")
  else:
      if m < 3000:
          print("银卡")
      else:
          print("金卡")
  ```

- D.

  ```python
  if m >= 3000:
      print("金卡")
  else:
      print("银卡")
  if m < 1000:
      print("普通会员")
  ```

---

## 答案

**正确答案：** C

---

## 解析

C 先判断 `m<1000`，否则再用 `m<3000` 区分银卡和金卡，三个区间互斥且覆盖完整。A 中金额达到 3000 时会先进入银卡分支；B 会把 1000 以下误判为银卡；D 在 1000 以下会同时输出银卡和普通会员。
