# 题目 11

有如下Python程序段：

```python
def b_search(a, key, left, right):
    while left <= right:
        mid = (left + right) // 2
        if a[mid] > key:
            right = mid - 1
        else:
            left = mid + 1
    return ①

for i in range(1, len(a)):
    key = a[i]
    pos = b_search(a, key, 0, i-1)
    for j in range(②):
        a[j+1] = a[j]
    a[pos] = key
```

为实现数组a升序排序，则程序划线①②处应填入的语句为（   ）

- A. `① left`；`② i-1, pos, -1`  
- B. `① right`；`② i-1, pos, -1`  
- C. `① left`；`② i-1, pos-1, -1`  
- D. `① right`；`② i-1, pos-1, -1`

---

## 答案

**正确答案：** C

---

## 解析

该程序实现二分插入排序。核心：用二分查找确定插入位置pos，再将 pos~i-1 的元素后移一位腾出空间。

①处：二分查找返回插入位置。当 `a[mid] > key` 时向右缩小区间，最终 `left` 指向大于key的第一个元素位置，即插入位置。所以返回 `left`。

②处：将索引 pos~i-1 的元素后移，`range(i-1, pos-1, -1)` 从右向左逐位移动。
