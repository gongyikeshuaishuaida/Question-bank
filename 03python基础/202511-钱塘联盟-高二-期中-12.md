# 题目 12

12. 有如下Python 程序：（   ）
```python
import random

a = [0] * 6
flag = True
i = 0
while i < 6:
    x = random.randint(10, 100)
    if not flag or x < 50:
        a[i] = x
        flag = not flag
        i += 1
```
