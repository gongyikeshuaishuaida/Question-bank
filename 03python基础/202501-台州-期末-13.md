# 题目 13

随着智能家居的发展，越来越多的家庭选择安装带有指纹锁的入户门。某指纹锁的指纹解锁模块采用的是光学指纹识别，其部分工作流程如第13题图所示：

![[attachments/202501台州_13_图1.png]]

请结合第13题图回答下列问题：

（1）为了提高指纹识别率，以下选项操作方法不合理的是____（单选，填字母）。

- A. 在采集指纹图像环节，采集时要让手指干净
- B. 在指纹注册环节，需要关注指纹特征的完整性和清晰度
- C. 在指纹特征对比环节，将指纹数据的匹配率由80%改为10%
- D. 在指纹特征模板库中，尽量多地采集不同角度的指纹数据

（2）在“图像预处理”环节，需对原始灰度图像进行平滑、锐化、增强、二值化等处理，从而使特征提取等操作能够有效进行。下列部分Python代码实现对灰度图像二值化的过程，请在划线处填入合适的代码。

```python
#打开图像，代码略
rows, cols = img.shape      #图像的高和宽分别赋值
hd = 200                    #定义灰度界限
for i in range(rows):       #图像二值化（0:黑，1:白）
    for j in range(cols):
        ____①____
        if img[i,j] > hd:
            b = 1
        ____②____
#根据img数组生成新的图像并显示，代码略
```

（3）基于上述代码，在测试时发现图像信息丢失过多，则需对____变量参数进行调整。

---

## 答案

**正确答案：** （1）C；（2）①`b=0`；②`img[i,j]=b`；（3）`hd`

---

## 解析

匹配率阈值由80%降到10%会显著增加误识别，不能提高可靠识别率。二值化时先默认像素为黑色0，若灰度值大于阈值则改为白色1，再把结果写回 `img[i,j]`。图像信息丢失过多与二值化阈值 `hd` 有关。
