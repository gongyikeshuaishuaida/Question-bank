# 题目 10

阅读下列材料，回答第 10 题。

某生鲜超市通过“超市管理系统”实现商品入库、信息查询、会员注册、销售支付等功能。顾客通过自助机输入商品编号或扫描商品条形码获取商品名称、生产商、单价、保质期等信息；门店管理员有权限查询商品存量，对促销商品进行价格调整等操作。开业期间，实行满减优惠，单笔交易 100 元内打 9 折，满 100 元打 8.5 折，满 200 元打 8 折。

根据超市满减优惠政策，下列程序段中，无法实现该功能的是（   ）

- A.

  ```python
  res = "打9折"
  if pay >= 200:
      res = "打8折"
  else:
      res = "打8.5折"
  ```

- B.

  ```python
  res = "打9折"
  if pay >= 200:
      res = "打8折"
  elif pay >= 100:
      res = "打8.5折"
  ```

- C.

  ```python
  if pay < 100:
      res = "打9折"
  elif pay >= 200:
      res = "打8折"
  else:
      res = "打8.5折"
  ```

- D.

  ```python
  if 200 > pay >= 100:
      res = "打8.5折"
  elif pay < 100:
      res = "打9折"
  else:
      res = "打8折"
  ```

---

## 答案

**正确答案：** A

---

## 解析

A 中只要 `pay<200` 就会执行 `else`，把 100 元以内的交易也设为“打8.5折”，覆盖了初始的“打9折”，因此无法实现题意。B、C、D 均能正确区分三个价格区间。
