# 题目 10

10. 甲、乙两段 Python 程序，功能完全相同。阅读下列程序，下列说法正确的是

```python
# 甲
def sum_rea(a):
    s = 0
    for i in range(len(a)):
        s += a[i]
    return s

# 乙
def sum_re(a):
    if len(a) == 1:
        return a[len(a) - 1]
    else:
        return a[len(a) - 1] + sum_re(a[:len(a) - 1])
```

- A. 甲程序使用递归算法，乙程序使用迭代算法
- B. 甲程序通过循环重复执行实现计算，乙程序通过调用自身实现计算
- C. 甲程序不需要边界条件，乙程序必须设置边界条件
- D. 一般来说，乙程序比甲程序占用内存更少，算法效率更高

---

## 答案

**正确答案：** B

---

## 解析

甲程序通过 `for` 循环累加，属于迭代；乙程序在函数内部调用自身，属于递归。递归需要边界条件，且通常会带来额外调用开销。
