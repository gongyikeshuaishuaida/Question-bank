# 题目 12

12. 有如下 Python 程序段：

```python
ans, top = 0, 0
n = len(a)
st = [0] * (n + 1)
for i in range(n):
    while 0 < top and a[st[top]] < a[i]:
        j = st[top]
        top -= 1
        if top == 0:
            break
        k = st[top]
        w = i - k - 1
        h = min(a[k], a[i]) - a[j]
        ans += w * h
    top += 1
    st[top] = i
print(ans)
```

若程序执行后输出值为 5，则输入的数组 `a` 不可能为

- A. `[2, 0, 0, 3, 1, 2]`
- B. `[3, 1, 0, 4, 1]`
- C. `[3, 1, 1, 4, 0, 2]`
- D. `[5, 2, 4, 0, 3]`

---

## 答案

**正确答案：** C
