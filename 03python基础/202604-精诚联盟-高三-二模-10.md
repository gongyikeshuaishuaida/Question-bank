# 题目 10

10. 有如下 Python 程序段：

```python
s = input()
m = 0
n = 0
for ch in s:
    if "0" <= ch <= "9":
        m = 9 - int(ch)
    elif "a" <= ch <= "f":
        n = (ord(ch) - ord("a") + 2) % 26
ans = m * 5 + n
print(ans)
```

程序运行后，若输出为 28，则 s 输入的是（   ）

- A. `2d6b4p`
- B. `7k4e3c`
- C. `5f6dg3`
- D. `8q3b5g`

---

## 答案

**正确答案：** A

---

## 解析

循环结束后，m 取最后一个数字字符的加密值 `9-数字`，n 取最后一个位于 a 到 f 的小写字母的加密值。A 中最后一个数字为 4，m=5；最后一个 a-f 字母为 b，n=3，`5*5+3=28`。
