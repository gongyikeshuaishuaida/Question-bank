# 题目 08

08. 有如下 Python 程序段：

```python
s="ABCD01234"
lst=["6","7","8","9"]
dic={"A18":1,"B28":2,"C29":3,"D39":4}
print(dic[s[:9:5]+lst[2]])
```

该程序运行后的输出结果为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---
## 答案

**正确答案：** A

---
## 解析

s[:9:5] 取下标 0 和 5 的字符，结果为 A1；lst[2] 为 8，拼接得到键 A18，字典对应值为 1，故选 A。
