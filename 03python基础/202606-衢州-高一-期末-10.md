# 题目 10

阅读下列材料，回答第 10 题。

某医院医疗管理系统收集的部分患者数据如下表所示，其中患者姓名已脱敏处理，例如“王小五”脱敏处理为“王*五”。

| 病历号 | 患者姓名 | 性别 | 挂号费 | 付费状态 | 就诊状态 |
| --- | --- | --- | --- | --- | --- |
| NK0104 | 张*三 | 男 | 15.0 | 已付费 | 未就诊 |
| WK0104 | 李*四 | 女 | 50.0 | 未付费 | 未就诊 |
| FK0088 | 王*五 | 女 | 25.5 | 已付费 | 已就诊 |

10. 该医院药品分为甲、乙、丙三类，按照药价的 40%、20%、10% 的比例减免药费，若计算类别为 `s`、药价为 `value` 的药品减免费用 `fee`，则下列 Python 程序段不符合要求的是（   ）

- A.

```python
if s == "甲":
    fee = value * 0.4
if s == "乙":
    fee = value * 0.2
if s == "丙":
    fee = value * 0.1
```

- B.

```python
if s == "甲":
    fee = value * 0.4
elif s == "乙":
    fee = value * 0.2
else:
    fee = value * 0.1
```

- C.

```python
fee = value * 0.4
if s == "乙":
    fee = value * 0.2
else:
    fee = value * 0.1
```

- D.

```python
fee = value * 0.4
if s == "乙":
    fee = value * 0.2
elif s == "丙":
    fee = value * 0.1
```

---

## 答案

**正确答案：** C

---

## 解析

选项 C 中当 `s=="甲"` 时，第一个条件不成立，随后执行 `else`，会把已经设置为 40% 的减免费用覆盖为 10%，不符合要求。
