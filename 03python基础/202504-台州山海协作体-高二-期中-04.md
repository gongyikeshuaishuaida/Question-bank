# 题目 04

4. 健康成年人的心率一般是 60~100 次/分。用 Python 语言编写程序代码，`t` 表示输入的心率，程序运行结束后，若 `flag` 为 True，则表示心率正常，若 `flag` 为 False，则表示心率异常。下列语句不能正确表示心率情况的是（   ）

- A.
```python
flag = False
if t >= 60:
    flag = True
if t > 100:
    flag = False
```

- B.
```python
flag = True
if t < 60:
    flag = False
elif t > 100:
    flag = False
```

- C.
```python
if t > 100:
    flag = False
if t >= 60:
    flag = True
else:
    flag = False
```

- D.
```python
if t < 60:
    flag = False
elif t <= 100:
    flag = True
else:
    flag = False
```

---

## 答案

**正确答案：** C

---

## 解析

C 选项中两个 `if` 是顺序执行的独立判断。当 `t > 100` 时，第一段先将 `flag` 设为 False，但第二个 `if t >= 60` 又会把 `flag` 改回 True，导致高于 100 的异常心率被误判为正常。其他选项均能正确表示心率正常范围判断。
