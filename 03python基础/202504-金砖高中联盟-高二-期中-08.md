# 题目 08

下列 Python 表达式中，结果为 True 的是（   ）

- A. 6/2**3>1
- B. "sh" in "Shangyu"
- C. `len("2345")==12345%100//10`
- D. `int("1"+"1")%2==0`

---

## 答案

**正确答案：** C

---

## 解析

A 的值为0.75，不大于1；B 区分大小写，sh 不在 Shangyu 中；C 左边为4，右边先算取模再整除得到4；D 中11%2=1。因此只有 C 的结果为 True。
