# 题目 14

14. 某图书馆的座位以行列的形式排列，读者可根据所需空位数通过程序查看系统推荐位置。系统推荐的规则如下：

① 若所需空位数为 `r`，则 `r` 个位置必须为同一行的连续空位。

② 若有多处连续空位数大于等于 `r`，则优先选择连续空位数最少的。

③ 若存在多个符合要求的连续空位，则优先行号最小的，相同行号选列号最小的。

请回答下列问题：

(1) 若座位如第 14 题图所示，`r` 为 2，则推荐位置的起始行列号是第 ______ 行，第 ______ 列。

![[attachments/202606台州高二_14_图1.png]]

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 获取行数 n，列数 m，所需空位数 r，代码略
# 读取当前座位状态存入二维数组 seat 中。
# seat[0][0] 表示第 1 行第 1 列，元素值为 0 表示空位，
# 为 1 表示座位已被占用，代码略
length = 0  # 推荐位置的连续空位数，初值为 0
for i in range(n):
    ①
    while j < m:
        if seat[i][j] == 0:
            start = j
            while j < m and seat[i][j] == 0:
                j += 1
            ②
            if t >= r:
                if ③:
                    length = t
                    pos = [i+1, start+1]  # 推荐位置的起始行列号
        else:
            j += 1

# 若不存在推荐位置则输出提示，否则输出推荐位置，代码略
```

---

## 答案

**正确答案：** (1) 2；1；(2) ① `j=0`；② `t=j-start`；③ `length==0 or t<length`

---

## 解析

(1) 第 1 行连续空位长度为 3；第 2 行有两段长度为 2 的连续空位；第 3 行也有一段长度为 2。按规则优先选择长度最少的合格区间，再选行号、列号最小者，因此选择第 2 行第 1 列。

(2) 每扫描一行都要令 `j=0`；内层循环结束后，连续空位长度为 `j-start`；`length==0` 表示尚未找到推荐位置，之后只有当前长度 `t` 更小时才更新。由于按行列顺序扫描，长度相同时保留先找到的位置即可满足行号、列号优先规则。
