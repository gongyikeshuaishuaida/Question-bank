# 题目 10

10. 有如下 Python 程序段：

```python
st = i = 0
while i < len(d) - 1:
    if d[i] >= d[i + 1]:
        if i - st + 1 > 2:
            st = i + 1
    i += 1
```

若 `d = [1, 3, 5, 5, 2, 4, 4, 6]`，执行该程序段后，`st` 的值为

- A. 3
- B. 5
- C. 6
- D. 7

---

## 答案

**正确答案：** C
