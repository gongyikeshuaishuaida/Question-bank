# 题目 13

13. 小明是班长，学校艺术节期间他将班级支出明细记录了下来，现在想将各项支出的结果做一个统计。他编写了一个实现该功能的 Python 程序，程序运行时读取文本文件中内容存入字符串变量 `s`，并提取其中的数值进行计算，输出班级支出总额。实现上述功能的程序如下：

(1) 实现上述功能的程序如下，请在划线处填入合适的代码。

```python
# 读取文本文件并存入字符串 s，并输出，代码略
# 例如：s = "演出服 2400;荧光棒 300; 饮料 500; 其他 800"
s = s + "。"      # 加框处代码
        ①
i, t, sum = 0, 0, 0
while i < n:
    ch = s[i]
    if "0" <= ch <= "9":
        ②
    else:
        sum += t
        t = 0
    ③
print("一共支出：", str(sum), "元")
```

(2) 删除加框处代码后，若字符串 `s` 值为 `"演出服 2400;荧光棒 300; 饮料 500; 其他 800"`，程序运行后的输出结果为“一共支出：   ▲   元”。

---

## 答案

**正确答案：** (1) ① `n = len(s)`；② `t = t * 10 + int(ch)`；③ `i = i + 1` 或 `i += 1`；(2) 3200

---

## 解析

程序逐字符扫描字符串，遇到数字时用 `t = t * 10 + int(ch)` 累积当前数值，遇到非数字时把当前数值加入总额并清零。`n` 应为字符串长度，循环末尾要更新下标 `i`。加框处 `s = s + "。"` 的作用是补一个非数字结尾，使最后的 800 也能被加入；删除后最后一项不会遇到非数字触发累加，因此只得到 `2400+300+500=3200`。
