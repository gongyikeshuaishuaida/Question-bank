# 题目 10

有如下 Python 程序段：

```python
# suma 存放字符串 st 所有字符的 ASCII 码之和
sumL = 0; sumR = suma; pos = -1
for i in range(0, len(st)):
    sumR = sumR - ord(st[i])
    if sumR == sumL:
        pos = i
    sumL = sumL + ord(st[i])
```

字符串 st 为 `"dbhacdbahcd"`，执行该程序段后，`pos` 的值为（   ）

- A. -1
- B. 5
- C. 6
- D. 7

---

## 答案

**正确答案：** B

---

## 解析

程序在每个位置 `i` 先把当前字符从右侧和中扣除，再判断左右两侧 ASCII 码和是否相等。对字符串逐位累加可得在 `i=5` 时左右两侧和相等，因此 `pos` 被更新为 5，后续不再出现新的平衡位置。
