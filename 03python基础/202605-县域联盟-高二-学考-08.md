# 题目 08


阅读下列材料，回答第 08 题。

某校搭建了校园门禁系统。学生出入校园通过摄像头识别人脸，显示屏显示识别结果，若识别成功打开闸机，同时出入校园数据上传至服务器。家长可通过移动终端 APP 查看学生的出入校门信息，还可在 APP 上帮学生请假。请假时，家长需要输入请假时间及理由，并上传照片加以佐证。

8. 根据系统要求，家长请假上传照片的存储容量 `k` 的大小范围为 `t1～t2`（`t1 < t2`），若在范围之内则提示“可上传”，否则提示“不可上传”。下列 Python 程序段中，不能实现该规则的是（ ）

- A.

```python
s = "可上传"
if k < t1 or k > t2:
    s = "不可上传"
```

- B.

```python
if k < t1 or k > t2:
    s = "不可上传"
else:
    s = "可上传"
```

- C.

```python
if k >= t1:
    s = "可上传"
if k <= t2:
    s = "可上传"
else:
    s = "不可上传"
```

- D.

```python
if k < t1:
    s = "不可上传"
elif k <= t2:
    s = "可上传"
else:
    s = "不可上传"
```


---

## 答案

**正确答案：** C

---

## 解析

C 中两个 if 相互独立。当 k<t1 且 k<=t2 时，第二个 if 仍会把 s 设为“可上传”，因此不能正确实现范围判断；其余程序均能覆盖区间内外情况。
