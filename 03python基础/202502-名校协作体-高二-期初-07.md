# 题目 07

正读和反读都一样的字符串称为“回文字符串”。现要判断某非空字符串 `s` 是否为回文字符串，程序段如下，划线处应填入的正确代码为（   ）

```python
s = input("请输入字符串:")
n = len(s)
k = n // 2
if ____:
    print("字符串:", s, "是回文字符串")
else:
    print("字符串:", s, "不是回文字符串")
```

- A. `s[:k] == s[k + 1:][::-1]`
- B. `s[:k] == s[n - k:][::-1]`
- C. `s[:k + 1] == s[(n + 1) // 2:][::-1]`
- D. `s[:k + 1] == s[k + n % 2:][::-1]`

---
## 答案

**正确答案：** B

---
## 解析

前半段 `s[:k]` 的长度为 `n//2`，后半段从下标 `n-k` 开始，反向切片后长度相同；奇数长度时中间字符被自然跳过，偶数长度时两半恰好对应。因此 B 能同时处理奇偶长度。
