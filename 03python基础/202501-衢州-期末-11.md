# 题目 11


阅读下列材料，回答第 11 题。

某台无人售货机某月的销售数据整理后存入列表 `a` 中，列表 `a` 的每个元素由订单号、设备ID、商品名称、支付时间、支付金额五项构成，例如 `["749375954","EA07631","可口可乐","2024/12/3 9:41:00",3.0]` 表示列表 `a` 中的某个元素。

11. 对数据中的“设备ID”进行加密，部分程序如下：

```python
a = ""; j = int(input())      #j为移动位数
for i in range(len(s)):
    if "A" <= s[i] <= "Z":
        a += chr((ord(s[i])+3-ord("A"))%26+ord("A"))
    elif "a" <= s[i] <= "z":
        a += chr((ord(s[i])-100)%26+97)
    else:
        a += s[i]
a = a[j:] + a[:j]
```

若 `s` 为 `"EA07631"`，`j` 为2，则 `a` 的值为（   ）

- A. BX07631
- B. 07631BX
- C. 07631HD
- D. 31HD076


---

## 答案

**正确答案：** C

---

## 解析

`E` 和 `A` 分别后移3位得到 `H` 和 `D`，数字不变，先得到 `HD07631`；再左移2位得到 `07631HD`。
