# 题目 12

12. 某 Python 程序如下，其输出结果如第 12 题图所示。

```python
s = 0; i = 0
x = input("请输入整数：")
while x != "#":
    □□□□
    □□□□
    □□□□
    □□□□
print("\n 输入个数为：", i)
print("输入数和为", s)
```

![[attachments/202501金华十校_12_图1.jpg]]

方框中的备选代码为：① `s += y`　② `x = input("请输入整数：")`　③ `i += 1`　④ `y = int(x)`

方框中代码的正确顺序是（   ）

- A. ②④①③
- B. ④②①③
- C. ①②③④
- D. ③②④①

---

## 答案

**正确答案：** B

---

## 解析

关键约束：④（`y = int(x)`）必须在②（读下一个 x）之前，①（累加）必须在④之后。③顺序相对灵活。B 选项 ④②①③ 正确。
