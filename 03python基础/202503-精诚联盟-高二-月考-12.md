# 题目 12

12. 某 Python 程序段如下：

```python
import random
list1=[0]*6
i=0; temp=0
while i<6:
    temp=random.randint(1,100)
    if temp%2==i%2:
        i-=1
    elif temp>50 or i%2==0 and temp<=50:
        list1[i]=temp
    i+=1
```

运行该程序段，`list1[0]`—`list1[5]` 各元素值不可能的是（   ）

- A. `[47, 0, 9, 0, 83, 0]`
- B. `[29, 43, 89, 64, 87, 80]`
- C. `[9, 0, 49, 0, 43, 0]`
- D. `[69, 98, 89, 0, 1, 0]`

---
## 答案

**正确答案：** B

---
## 解析

偶数下标最终写入的数必须为奇数；奇数下标只有大于 50 的偶数才会写入，否则保持初始值 0。B 的下标 1 出现 43（奇数且不可能写入），且多个奇数下标出现不符合条件的值，因此不可能。
