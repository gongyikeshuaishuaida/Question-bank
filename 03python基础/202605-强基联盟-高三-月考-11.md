# 题目 11

11. 有如下 Python 程序：

```python
def func(n):
    if n == -1:
        return ""
    elif n % 3 == 0:
        return str(n % 2) + func(n - 1)
    else:
        return func(n - 1) + str(n % 2)
```

执行语句 `result = func(5)` 后，`result` 的值为

- A. 110010
- B. 010101
- C. 100101
- D. 101001

---

## 答案

**正确答案：** D

---

## 解析

`func` 递归到 -1 后回溯；当 `n%3==0` 时把当前奇偶值放在前面，其余情况放在后面，依次回溯得到 `101001`。
