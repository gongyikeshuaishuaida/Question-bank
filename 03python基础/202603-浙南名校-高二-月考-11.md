# 题目 11

有如下 Python 程序段，能实现去重功能，执行该程序段后输出的值为 `"progame"`。方框中应填入的正确代码为（   ）

```python
s = "programmer"
j = len(s)
i = 1
while i < j:
    if s[i] in s[:i]:
        ________
    i += 1
print(s[:j])
```

- A.

  ```python
  s = s[:i] + s[i+1:j]
  j -= 1
  i -= 1
  ```

- B.

  ```python
  s = s[:i-1] + s[i:j]
  j -= 1
  i -= 1
  ```

- C.

  ```python
  s = s[:i-1] + s[i:j]
  j = len(s) - 1
  ```

- D.

  ```python
  s = s[:i] + s[i+1:j]
  j = len(s) - 1
  ```

---

## 答案

**正确答案：** A

---

## 解析

当 `s[i]` 已在前面的子串中出现时，需要删除当前字符，因此应拼接 `s[:i]` 和 `s[i+1:j]`。删除后有效长度 `j` 减 1；同时令 `i` 减 1，可在循环末尾 `i += 1` 后重新检查移到当前位置的新字符。A 能正确得到 `"progame"`。
