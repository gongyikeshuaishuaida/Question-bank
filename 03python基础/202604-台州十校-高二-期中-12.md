# 题目 12

12. 有如下 Python 程序段，执行后显示的值不可能是（   ）

```python
import random
s1 = "PROGRESS"
s2 = ""
f = [False] * 8
for i in range(1, 5):
    t = random.randint(0, 3) * 2 + 1
    while f[t]:
        t = random.randint(0, 3) * 2 + 1
    f[t] = True
    s2 = s2 + s1[t]
print(s2)
```

- A. `EGRS`
- B. `GERS`
- C. `SEOR`
- D. `RESG`

---

## 答案

**正确答案：** C

---

## 解析

随机下标只能取 1、3、5、7，且不重复，对应字符恰为 R、G、E、S。输出一定是这四个字符的某种排列，不可能含有 O，因此 C 不可能。
