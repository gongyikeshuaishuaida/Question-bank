# 题目 10

10. 有如下程序段：

```python
a = [2, -1, -4, 0, 0, -2]
L = -1; R = 6; i = 0
while i < R:
    if a[i] < 0:
        L = L + 1
        a[i], a[L] = a[L], a[i]
        i = i + 1
    elif a[i] > 0:
        R = R - 1
        a[i], a[R] = a[R], a[i]
    else:
        i = i + 1
```

运行程序后，列表 `a` 的值为（   ）

- A. `[-4, -1, -2, 0, 0, 2]`
- B. `[-2, -1, -4, 0, 0, 2]`
- C. `[0, 0, -2, -1, -4, 2]`
- D. `[-1, -2, -4, 0, 0, 2]`

---

## 答案

**正确答案：** B

---

## 解析

这是三路划分（Dutch national flag）算法，将数组分为负数区、零区、正数区。

初始：`a = [2, -1, -4, 0, 0, -2]`，`L=-1, R=6, i=0`。

- `i=0`：`a[0]=2>0`，`R=5`，`a[0]↔a[5]`，`a=[-2,-1,-4,0,0,2]`
- `i=0`：`a[0]=-2<0`，`L=0`，`a[0]↔a[0]`，`i=1`
- `i=1`：`a[1]=-1<0`，`L=1`，`a[1]↔a[1]`，`i=2`
- `i=2`：`a[2]=-4<0`，`L=2`，`a[2]↔a[2]`，`i=3`
- `i=3`：`a[3]=0`，`i=4`
- `i=4`：`a[4]=0`，`i=5`
- `i=5`：`i>=R(5)`，退出。

结果：`[-2, -1, -4, 0, 0, 2]`，选 B。
