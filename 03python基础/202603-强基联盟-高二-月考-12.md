# 题目 12

有如下 Python 程序段：

```python
s = input("请输入字符串s：")
d = [-1] * 26
c = 0
for i in range(len(s)):
    t = ord(s[i]) - ord("a")
    if d[t] != -1:
        if i - d[t] > c:
            c = i - d[t]
    d[t] = i
print(c)
```

执行该程序段后，若输出为 3，则可能的输入是（   ）

- A. `abcdabcd`
- B. `aabbccdd`
- C. `abbacdcd`
- D. `ababcdcd`

---

## 答案

**正确答案：** C

---

## 解析

列表 `d` 记录每个小写字母最近一次出现的位置，`c` 记录相同字符相邻两次出现位置之差的最大值。

- A 中最大间距为 4；
- B 中最大间距为 1；
- C 中 `a` 位于下标 0 和 3，最大间距为 3；
- D 中最大间距为 2。

因此可能的输入是 C。
