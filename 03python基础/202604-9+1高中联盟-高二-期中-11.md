# 题目 11

11. 有如下 Python 程序段：

```python
s = "abbcabccb"
ch = s[0]
i = 1
while i < len(s):
    if len(ch) == 0 or s[i] != ch[0]:
        ch = s[i] + ch
    else:
        ch = ch[1:len(ch)]
    i += 1
```

执行该段代码后，`ch` 的值为（   ）

- A. `aca`
- B. `aac`
- C. `cac`
- D. `ccc`

---

## 答案

**正确答案：** A

---

## 解析

逐字符处理：若当前字符与 `ch` 首字符不同，则把当前字符接到最前面；否则删除 `ch` 首字符。按 `abbcabccb` 依次跟踪，最终 `ch` 为 `aca`。
