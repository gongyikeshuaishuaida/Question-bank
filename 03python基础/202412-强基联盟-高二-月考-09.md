# 题目 09

阅读以下材料，回答第 09 题：

双 11 大促作为电商行业的年度盛事，不仅是一次销售狂欢，更是技术应用的竞技场。电商平台通过深度学习算法分析用户历史购买记录、浏览习惯等数据，构建用户画像，基于用户画像，实时、精准地为用户推送商品广告；AI 客服与人工客服共同为用户解答问题，既减轻了客服工作量，又增加了平台销售额和用户粘性。

9. 电商平台采集用户对每个类目商品的累计浏览时间，作为构建用户画像的重要依据，列表 `lst` 记录了某用户浏览商品的数据，前后两个数据为一组，分别表示商品类目和当次浏览时间，以下 Python 代码用于统计每个类目的累计浏览时间，方框处正确的代码为（   ）

```python
# 读取 lst，形如["电子", 101, "家居", 8, "服装", 225, "运动", 63, ...]，代码略。
dic = {}
for i in range(len(lst) // 2):
    □□□□□□□□□□
```

- A. `if lst[2*i] in dic: dic[lst[2*i]] = lst[2*i+1]` / `else: dic[lst[2*i]] += lst[2*i+1]`
- B. `if lst[2*i] not in dic: dic[lst[2*i]] = lst[2*i+1]` / `else: dic[lst[2*i]] += lst[2*i+1]`
- C. `if lst[2*i] in dic: dic[lst[2*i]] = 1` / `else: dic[lst[2*i]] = dic[lst[2*i]] + 1`
- D. `if lst[2*i] not in dic: dic[lst[2*i]] = 1` / `else: dic[lst[2*i]] = dic[lst[2*i]] + 1`

---

## 答案

**正确答案：** B

---

## 解析

`lst` 中偶数索引（0,2,4,...）为商品类目，奇数索引（1,3,5,...）为浏览时间。使用字典统计累计浏览时间：若类目不在字典中则新建键并设初始值 `lst[2*i+1]`，否则在原有值上累加。B 选项逻辑正确。A 的分支判断反了，C、D 操作的是计数值 1 而非实际时间值。
