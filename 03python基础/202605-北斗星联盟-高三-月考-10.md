# 题目 10

10. 有如下 Python 程序段：

```python
s = "Dat15Eb2"
t = k = 0
i = 0
flag = True
while i < len(s):
    if flag and "A" <= s[i] <= "Z":
        t += ord(s[i]) - ord("A")
        k = 0
    elif "0" <= s[i] <= "9":
        k = k * 10 + int(s[i])
    flag = not flag
    i += 1
t += k
```

执行该程序段后，`t` 的值为（   ）

- A. 155
- B. 20
- C. 9
- D. 5

---

## 答案

**正确答案：** A

---

## 解析

下标 0 处的 `"D"` 满足条件，`t` 增加 `ord("D")-ord("A")=3`。随后数字 `"1"`、`"5"` 和 `"2"` 依次使 `k` 变为 1、15、152；下标 5 处的 `"E"` 因 `flag=False` 不处理。最后执行 `t+=k`，得到 `3+152=155`。
