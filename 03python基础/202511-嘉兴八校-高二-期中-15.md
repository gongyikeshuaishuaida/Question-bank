# 题目 15

15. 有如下 Python 程序段：

```python
f = 1  # 符号标记，1 为加，-1 为减
result = 0
s = input()  # 输入 "35728"
for i in range(0, len(s) - 1, 2):
    num1 = int(s[i])
    num2 = int(s[i + 1])
    total = num1 + f * num2
    result = total + result
    f = -f
if len(s) % 2 == 1:
    result += int(s[-1])
print(result)
```

程序运行时，若输入 `"35728"`，则输出的结果是（   ）

- A. -11
- B. 5
- C. 11
- D. 21

---

## 答案

**正确答案：** D

---

## 解析

输入 `s = "35728"`，`len(s) = 5`。

- `i=0`：`num1=3, num2=5, total=3+1×5=8, result=8, f=-1`
- `i=2`：`num1=7, num2=2, total=7+(-1)×2=5, result=5+8=13, f=1`
- `i=4`：超出 `range(0, 4, 2)` 范围（0、2），循环结束。
- `len(s) % 2 == 1` 成立，`result += int("8")` → `result = 13 + 8 = 21`。

输出 `21`，选 D。
