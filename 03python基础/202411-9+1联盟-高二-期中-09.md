# 题目 09

9. 按照国家电网现行标准，居民用户每月用电量划分为三档，电价实行分档递增。第一档：电量每户每月 210 度及以下；第二档：电量每户每月 210（不含）—400（含）度之间；第三档：电量每户每月 400 度以上。已知某户某月用电量为 `X`，将判断结果保存在变量 `Y` 中，则下列程序段不能实现该功能的是（   ）

- A.

```python
if 210 < X <= 400:
    Y = "第二档"
else:
    Y = "第三档"
if X <= 210:
    Y = "第一档"
```

- B.

```python
Y = "第三档"
if X <= 210:
    Y = "第一档"
elif X <= 400:
    Y = "第二档"
```

- C.

```python
if X <= 210:
    Y = "第一档"
elif X <= 400:
    Y = "第二档"
else:
    Y = "第三档"
```

- D.

```python
Y = "第一档"
if X > 210:
    Y = "第二档"
elif X > 400:
    Y = "第三档"
```

---

## 答案

**正确答案：** D

---

## 解析

D 中 `elif X>400` 依附于前面的 `if X>210`。当 `X>400` 时，前一个条件 `X>210` 已经成立，程序会直接把 `Y` 设为“第二档”，不会再执行 `elif` 分支，因此第三档无法被正确判断。A、B、C 都能覆盖三个区间。
