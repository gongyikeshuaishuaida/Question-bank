# 题目 08

8. 该连锁药店岁末推出积分兑换活动，单笔消费满 30 元，每 100 积分抵扣 2 元；满 50 元，每 100 积分抵扣 3 元；满 100 元，每 100 积分抵扣 4 元。根据活动政策，下列程序段中，能实现该功能的是（   ）

注：`pay` 表示消费金额；`jf` 表示用户积分数；`res` 表示实付金额。

- A.

```python
if pay >= 30:
    res = pay - (jf % 100) * 2
elif pay >= 50:
    res = pay - (jf % 100) * 3
else:
    res = pay - (jf % 100) * 4
```

- B.

```python
if pay >= 100:
    res = pay - (jf // 100) * 4
elif pay >= 50:
    res = pay - (jf // 100) * 3
elif pay >= 30:
    res = pay - (jf // 100) * 2
```

- C.

```python
if pay >= 100:
    res = pay - (jf // 100) * 4
elif pay >= 50:
    res = pay - (jf // 100) * 3
else:
    res = pay - (jf // 100) * 2
```

- D.

```python
if pay >= 100:
    res = pay - (jf % 100) * 4
elif pay >= 50:
    res = pay - (jf % 100) * 3
elif pay >= 30:
    res = pay - (jf % 100) * 2
```

---

## 答案

**正确答案：** B

---

## 解析

每 100 积分抵扣一次，应使用 `jf // 100` 计算可抵扣的积分组数，而不是使用余数 `jf % 100`。消费金额的判断应从高档位到低档位依次进行，否则 `pay>=100` 也会先满足 `pay>=30`。B 同时满足这两点。
