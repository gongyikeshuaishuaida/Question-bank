# 题目 09

某土壤的湿度用 `t` 变量存储，湿度的适宜范围为 `w1～w2`（不含 `w1`、`w2` 且 `w1<w2`），用 `f` 存储湿度状态。若湿度在适宜范围内，则 `f` 的值为 1，否则为 0。下列 Python 选项中不符合要求的是（   ）

- A.

  ```python
  f = 0
  if t > w1 and not t >= w2:
      f = 1
  ```

- B.

  ```python
  f = 0
  if w1 < t <= w2:
      f = 1
  ```

- C.

  ```python
  f = 1
  if t >= w2:
      f = 0
  if t <= w1:
      f = 0
  ```

- D.

  ```python
  if not (t <= w1 or t >= w2):
      f = 1
  else:
      f = 0
  ```

---

## 答案

**正确答案：** B

---

## 解析

适宜范围应满足 `w1<t<w2`。A 中 `not t>=w2` 等价于 `t<w2`；C 在两个端点及区间外把 `f` 置 0；D 是开区间条件的等价写法。B 使用 `w1<t<=w2`，错误地包含了右端点 `w2`，因此不符合要求。
