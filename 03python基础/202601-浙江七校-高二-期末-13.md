# 题目 13

小张设计了一个股票价格模拟分析算法来监测并提醒买入信号。给定股票价格序列，首先识别该序列的所有波峰（局部最大值）和波谷（局部最小值）。例如：当 `a[i]` 分别大于 `a[i-1]` 和 `a[i+1]`，则 `a[i]` 为波峰。反之当 `a[i]` 分别小于 `a[i-1]` 和 `a[i+1]`，则 `a[i]` 为波谷。如果出现以下任何一个条件，则触发提醒买入信号：

- 条件一：出现连续3个递增波峰，第3个波峰触发买入信号；
- 条件二：出现大于第一个波峰的波谷，该波谷触发买入信号。

请回答下列问题：

（1）若股票价格序列为 `[95,100,98,92,95,102,104,100,103,98]`， ▲ （填：是 / 否）会触发买入信号。

（2）实现买入信号检测功能的Python程序如下，请在划线处填入合适的代码。

```python
# 输入当前股票价格序列prices，代码略
n = len(prices)
peaks, valleys = [], []
for i in range(1, n-1):
    pre = prices[i-1]
    cur = prices[i]
    nex = prices[i+1]
    if ▲:
        peaks.append([i, cur])
    elif cur < pre and cur < nex:
        valleys.append([i, cur])

buy_signal = False
pos = 0
if len(peaks) >= 3:
    for i in range(▲):
        if peaks[i-2][1] < peaks[i-1][1] < peaks[i][1]:
            buy_signal = True
            pos = peaks[i][0]
            break

# 若条件1未触发，且波峰波谷存在
if not buy_signal and peaks and valleys:
    first_peak_price = ▲
    for i in range(len(valleys)):
        if valleys[i][1] > first_peak_price:
            buy_signal = True
            pos = i
            break

# 输出是否触发买入信号，代码略
```

（3）加框处语句有误，请改正。

---

## 答案

**正确答案：**

（1）否

（2）① `cur > pre and cur > nex`；② `2, len(peaks)`；③ `peaks[0][1]`

（3）`first_peak_price = peaks[0][1]`

---

## 解析

（1）序列波峰：100（位置1）、95（位置4）、104（位置6）、103（位置8）。波峰间：100→95→104→103，不满足连续递增（100→95不是递增），条件一不满足。波谷：98、92、100。无波谷大于第一个波峰100。条件二不满足。不会触发。

（2）① 判断波峰：`cur > pre and cur > nex`（当前值同时大于前后）。② 遍历连续3个波峰：`range(2, len(peaks))`，从第3个波峰(i=2)开始比较。③ 条件二需要第一个波峰价格作为基准：`peaks[0][1]`。

（3）加框处未正确赋值 `first_peak_price`，改正为 `first_peak_price = peaks[0][1]`。
