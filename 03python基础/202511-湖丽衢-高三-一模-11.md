# 题目 11

11. `map` 和 `ker` 均为二维数组，分别存储如第 11 题图 a 和第 11 题图 b 所示的数据。

```python
def ct(x, y, m):
    s = 0
    for i in range(x, x + m):
        for j in range(y, y + m):
            s += map[i][j] * ker[i - x][j - y]
    return s

map = [[3, 247, 4], [2, 180, 3], [2, 101, 1]]
ker = [[-1, 1], [-1, 1]]
n = len(map); m = len(ker)
c = []
for i in range(n - m + 1):
    for j in range(n - m + 1):
        c.append(ct(i, j, m))
print(c)
```

执行该程序段，输出的结果是（   ）

- A. `[-420, 422, -277, 277]`
- B. `[422, -420, 277, -277]`
- C. `[422, 277, -420, -277]`
- D. `[-277, 277, -420, 422]`

---

## 答案

**正确答案：** B

---

## 解析

`ct(x, y, m)` 计算 map 中以 `(x, y)` 为左上角、大小为 `m×m` 的子矩阵与 ker 的逐元素乘积之和（类似卷积操作）。`n=3, m=2`，遍历顺序：`i=0,1; j=0,1`。

- `ct(0,0,2)`：`3×(-1) + 247×1 + 2×(-1) + 180×1 = -3 + 247 - 2 + 180 = 422`
- `ct(0,1,2)`：`247×(-1) + 4×1 + 180×(-1) + 3×1 = -247 + 4 - 180 + 3 = -420`
- `ct(1,0,2)`：`2×(-1) + 180×1 + 2×(-1) + 101×1 = -2 + 180 - 2 + 101 = 277`
- `ct(1,1,2)`：`180×(-1) + 3×1 + 101×(-1) + 1×1 = -180 + 3 - 101 + 1 = -277`

结果为 `[422, -420, 277, -277]`，选 B。
