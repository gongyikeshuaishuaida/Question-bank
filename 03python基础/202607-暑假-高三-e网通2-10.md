# 题目 10

有如下 Python 程序段：

```python
shu = ""
k = 0
qiu = ""
x = "394-5-222-60-809"
for ch in range(len(x)):
    if "0" <= x[ch] <= "9":
        k = k + 1
    else:
        shu = x[ch-k:ch]
        if qiu < shu:
            qiu = shu + qiu
        k = 0
print(qiu)
```

执行该程序段后，输出结果是（   ）

- A. 1203
- B. 605394
- C. 809605394
- D. 809394

---

## 答案

**正确答案：** B

---

## 解析

程序只在遇到连字符时处理其前面的数字串，依次得到 394、5、222、60；最后的 809 因循环结束后未再次处理而被忽略。按字符串比较后拼接得到 `605394`。
