# 题目 10

有如下Python程序段：

```python
def f(s1, s2):
    p = 0
    for i in range(len(s1)):
        if s1[i] == s2[p]:
            p += 1
        if p == len(s2):
            return True
    return False
```

s1和s2分别取下列值时，调用函数得到的结果与其他三项不同的是（   ）

- A. `"12345"`, `"135"`  
- B. `"36425"`, `"346"`  
- C. `"98765"`, `"876"`  
- D. `"24680"`, `"246"`

---

## 答案

**正确答案：** B

---

## 解析

函数`f(s1, s2)`的功能是：判断s2是否为s1的子序列（即s2的字符按顺序出现在s1中，不必连续）。

逐一验证：
- A：`"12345"` 中找子序列 `"135"` — 字符1→3→5依次出现 → 返回True
- B：`"36425"` 中找子序列 `"346"` — 匹配3(p→1)，匹配4(p→2)，接下来需要匹配6，但在 `"36425"` 中4之后只有'2','5'，没有6 → 返回False
- C：`"98765"` 中找子序列 `"876"` — 8→7→6依次出现 → 返回True
- D：`"24680"` 中找子序列 `"246"` — 2→4→6依次出现 → 返回True

因此B返回False，其他三项返回True，B与其他不同。
