# 题目 12

有如下 Python 程序段：

```python
from random import randint
a=[0]*5
flag=True
i=0
while i<5:
    x=randint(1,20)
    if flag or x>10:
        a[i]=x
        flag=not flag
    i+=1
print(a)
```

执行该程序段后，列表 a 的值不可能是（   ）

- A. `[10,12,16,5,17]`
- B. `[1,15,12,18,5]`
- C. `[18,18,18,18,18]`
- D. `[4,19,15,19,18]`

---
## 答案

**正确答案：** A

---
## 解析

第一次必写入并翻转 flag；之后只有 x>10 才写入并再次翻转。A 中第三次写入16后第四次随机数5不会写入，第四项应保持16而不是5。
