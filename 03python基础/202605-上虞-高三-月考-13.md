# 题目 13

13. 某校园机房智能用电监测系统具有“过载预警”功能，满足以下任一条件时立即触发预警：

① 连续 3 秒整机功率超过 800W（持续过载）；

② 机房温度高于 40℃（高温散热异常）；

③ 单台设备电流大于 5A（单设备过载）。

监测设备每秒钟采集一组数据，格式为 `[整机功率, 机房温度, 设备电流]`。某次采集数据如下（从第 1 秒开始）：

```python
[[805, 28, 2.5], [820, 30, 3.0], [810, 33, 2.8], [790, 42, 3.2], [800, 35, 5.2], ...]
```

请回答下列问题：

（1）监测设备从第 ______ 秒开始触发过载预警。

（2）已将数据存入列表 `data`，实现功能的部分 Python 程序如下：
请在划线处填入合适的代码。

```python
reasons = ["功率持续过载", "机房温度过高", "单设备电流过大"]
r = -1
cnt = 0  # 连续功率超标计数
for i in range(len(data)):
    if data[i][0] > 800:
        cnt += 1
    else:
        _____①_____
    if cnt == 3:
        r = 0
        break
    if data[i][1] > 40 or _____②_____:
        if data[i][1] > 40:
            r = 1
        else:
            r = 2
        break
if r != -1:
    print("设备在第", i + 1, "秒，因", _____③_____, "触发预警。")
else:
    print("本次监测未触发预警。")
```

---

## 答案

**正确答案：** （1）3；（2）① `cnt=0`；② `data[i][2]>5`；③ `reasons[r]`
