# 题目 11

有如下 Python 程序段：

```python
n = 99
count = 0
while n > 0:
    if n % 3 == 0:
        n = n // 3
        count = count + 1
    else:
        n = n - 3
print(count)
```

执行该程序段后，输出的 `count` 值是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** A

---

## 解析

`n=99` 时整除 3，变为 33，`count=1`；33 再除以 3 得 11，`count=2`。此后 `n` 依次为 11、8、5、2、-1，均执行减 3，`count` 不再增加，最终输出 2。
