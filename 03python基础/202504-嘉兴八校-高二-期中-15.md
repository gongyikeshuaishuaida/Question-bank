# 题目 15

小张想约小周周末一同去某地游玩，同时想用加密算法开个玩笑。小张先把游玩地点的拼音写在一张 n*n 个格子的纸上（每格一个小写拼音字母，所有格子填满），再给小周一张同样大小、只填有 0、1、2 三个数字的密码纸。小周逐行寻找密码纸中写有 1 的位置，把加密字符纸对应位置的字母拼成第一个字的拼音；再找写有 2 的位置拼成第二个字的拼音，两个拼音连接后再按小张生日（12 月 15 日）作为循环凯撒解密密钥，得到游玩地点的拼音。

定义函数 `Matrix(n,m)` 将输入字符串转换成矩阵：

```python
def Matrix(n, m):
    empty = [[0 for i in range(n)] for j in range(n)]
    for i in range(n):
        for j in range(n):
            empty[i][j] = m[i*n+j]
    for i in range(n):
        for j in range(n-1):
            print(empty[i][j], end=",")
        print(empty[i][n-1])
    return empty
```

## 答案

**参考答案：** （1）hangzhou；（2）int(mm[i][j]) == x；（3）① search(mw2, mm2, x)；② key[i%4]（等价写法可得分）；③ ming += s（或 ming = ming + s）。

---
## 解析

密码纸中的字符先按矩阵位置与 x=1、2 逐行匹配，必须把 mm[i][j] 转成整数后与 x 比较，故（2）为 int(mm[i][j]) == x。主程序每次取出一类数字对应的字符并连接，故①调用 search(mw2,mm2,x)。解密密钥 [1,2,1,5] 循环使用，第 i 个字符的偏移量为 key[i%4]，故②如此；每次得到的字符 s 追加到 ming，故③为 ming += s。对给定 4×4 输入逐行取出并按密钥解密，结果为 hangzhou。
