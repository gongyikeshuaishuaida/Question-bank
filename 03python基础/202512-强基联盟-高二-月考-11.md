# 题目 11

某评分系统的功能为：评委们输入选手得分（满分10分）后，系统去除一个最高分与一个最低分，然后计算剩余分数的平均分，并将计算结果实时呈现在大屏上，其中计算平均分的Python程序代码如下：

```python
# 获取各评委打分，存入列表a，代码略
n=len(a)
maxa,mina=0,10                      # ①
score=0
for i in range(n):
    if a[i]>maxa :                  # ②
        maxa=a[i]
    if a[i]<mina:                   # ③
        mina=a[i]
    score+=a[i]
avg=(score-maxa-mina)/(n-2)         # ④
print("平均分为：",avg)
```

以下关于该程序的说法正确的是（   ）

- A. 将加框处①中的10改为-1，程序一定能正确计算平均分  
- B. 将加框处②的代码改为 `a[i]>=maxa`，程序一定不能正确计算平均分  
- C. 将加框处③的代码改为 `elif`，程序一定能正确计算平均分  
- D. 将加框处④的代码与 `score+=a[i]` 对齐，程序一定能正确计算平均分

---

## 答案

**正确答案：** D

---

## 解析

A错误：将 `mina` 初值改为-1后，所有正分数都不会小于-1，`mina` 始终保持-1，无法正确找到最小值。

B错误：改为 `a[i]>=maxa` 后找到的是最后一个最大值，去除最大值时仍会去除一个最大值（只是去除了最后一个而非第一个），程序仍能正确计算平均分。

C错误：改为 `elif` 后，当 `a[i]>maxa` 为True时不执行 `a[i]<mina` 判断。若列表a数据刚好为升序排列，每次 `a[i]>maxa` 都满足条件，最小值 `mina` 从未被更新，无法正确计算。

D正确：将④与 `score+=a[i]` 对齐后，每次循环都执行一次 `avg` 计算，最后一次循环执行完时 `avg` 为正确的平均值。
