# 03 动态规划入门

## 学习目标

- 能把题目中的“当前最优”改写成明确的 `dp` 状态。
- 能区分“必须以当前位置结尾”“考虑到当前位置为止”“当前容量/当前状态”的不同含义。
- 能完成考试风格代码填空，而不是只会写简单递推式。
- 能处理一维 DP、二维路径 DP、0/1 背包、双状态 DP、二进制状态 DP 的基础变式。

## 什么是动态规划

动态规划（Dynamic Programming，简称 DP）是一种“把大问题拆成小问题，再用小问题答案推出大问题答案”的方法。它不是某一个固定公式，而是一套解题思路：

1. 先把原问题拆成若干个规模更小、结构相似的子问题。
2. 把已经算过的子问题答案保存下来，避免重复计算。
3. 按照明确的转移关系，从小规模一步步推出大规模。

适合用动态规划的题，通常有三个信号：

- 重叠子问题：同一个小问题会被反复遇到。
- 可递推结构：当前答案能由更小的答案推出。
- 无后效性：状态确定以后，后面的计算只需要这个状态值，不需要重新关心它是怎么来的。

可以把 DP 理解成一句话：**先定义清楚“我要记住什么”，再规定“怎么从已经记住的结果推出新结果”。**

### 入门案例：爬楼梯

楼梯有 `n` 级，每次可以走 `1` 级或 `2` 级，问走到第 `n` 级共有多少种走法。

先不要急着写代码，按 DP 的四个问题来分析：

1. 状态：`dp[i]` 表示走到第 `i` 级台阶的方法数。
2. 转移：要到第 `i` 级，最后一步只有两种可能：
   - 从第 `i-1` 级走 `1` 级上来；
   - 从第 `i-2` 级走 `2` 级上来。
   
   所以 `dp[i] = dp[i-1] + dp[i-2]`。
3. 初始：站在地面还没上台阶，记作 `dp[0] = 1`；走到第 1 级只有一种方法，所以 `dp[1] = 1`。
4. 答案：最终读取 `dp[n]`。

以 `n = 5` 为例：

| i | 含义 | dp[i] |
| --- | --- | --- |
| 0 | 还没上楼梯，作为起点 | 1 |
| 1 | 走到第 1 级 | 1 |
| 2 | 从 1 级上来，或从地面跨 2 级 | 2 |
| 3 | `dp[2] + dp[1]` | 3 |
| 4 | `dp[3] + dp[2]` | 5 |
| 5 | `dp[4] + dp[3]` | 8 |

代码如下：

```python
n = 5
dp = [0] * (n + 1)
dp[0] = 1
dp[1] = 1

for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n])
```

输出为 `8`。这就是动态规划比普通递归更有效的地方：普通递归会反复计算“走到第 3 级有几种方法”“走到第 2 级有几种方法”，而 DP 把每个 `dp[i]` 只算一次、存一次、用多次。

## 核心模型

动态规划不是把所有题都写成 `dp[i]=dp[i-1]+dp[i-2]`。真正要先问清楚四件事：

1. 状态：`dp[...]` 表示哪个范围、哪个位置、哪个限制下的最优值或方案数。
2. 转移：当前状态最后一步来自哪里，或者当前对象选与不选。
3. 初始：最小规模、边界行列、空集合、容量为 0 时是什么。
4. 答案：最后读 `dp[-1]`、`max(dp)`、最后一行最小值，还是某个完整状态。

常见骨架：

```python
初始化 dp
for 当前规模/当前物品/当前状态 in 范围:
    枚举可能来源
    用来源状态更新当前状态
答案 = 指定位置或指定范围的最优值
```

如果使用二进制对药瓶编号，则只需要 `ceil(log₂n)` 只老鼠即可快速找出药瓶。假设 n=100，则对药瓶用二进制编号如下表所示。从表中可知，一共需要 7 只老鼠试药，每只老鼠喂服二进制编码中纵向为 1 的药瓶，然后观察老鼠的生命状态。例如：1 小时后编号为 1,2,3,5,6 的老鼠死亡，即可知道二进制编码 `1×2⁰ + 1×2¹ + 1×2² + 1×2⁴ + 1×2⁵ = 55`，即编号为 55 的药瓶是毒药。

### 作业2：手机网格扫描

手机屏幕上图标的排列采用网格化布局，图标严格对齐网格系统。设手机屏幕网格区域大小为 W×H（W 和 H 分别表示屏幕宽度与高度，即横向与纵向网格数量），手机图标尺寸大小有 n 种，分别为 w₀×h₀、w₁×h₁、……wₙ₋₁×hₙ₋₁（w 和 h 表示图标宽度与高度），当手机屏幕大小为 4×2，手机图标的大小为 1×1、2×2、4×2，要将图标填满整个屏幕的网格区域，共 6 种放置方案，如下图所示。

![[attachments/202509嘉兴_15_图1.jpg]]

求解放置方案种数的算法规则如下：

扫描规则：从屏幕左上角开始，按从左到右、从上到下的顺序扫描每个网格位置；

放置规则：若当前扫描位置未被占用（可放置图标），则按图标索引顺序依次尝试放置所有规格的图标；若可放置，则标记该图标占用的所有网格为已占用，继续扫描下一个未占用位置并重复放置流程；

回退规则：当所有网格位置均被占用（屏幕填满）时，记为 1 种有效方案；若当前位置无法放置任何规格的图标，则回退至上一步，取消上一个图标的占用标记，尝试其他可放置的图标规格。

（1）W×H 大小的屏幕使用二维数组（嵌套列表）存储。二维数组元素值 0 表示未占用，1 表示已占用。例如：二维数组 `[[1,0,0],[1,0,0]]` 表示的屏幕，有 2 个位置已被占用，若在该屏幕中放入 1 个 2×1 大小的图标，则该二维数组的值为 ▲ 。

（2）函数 `find_pos` 用于查找能够放置图标的位置，若找到则返回行列位置 `[row, col]`，否则表示屏幕已放满，返回 `"满"`。Python 程序如下，请在划线处填入合适代码。

```python
def find_pos(scr):
    for row in range(H):                # W、H 是屏幕 scr 的宽、高
        for col in range(W):
            if ▲:
                return [row, col]
    return "满"
```

（3）函数 `can_place` 用于判断屏幕中是否能放置图标。其中 scr 为表示屏幕状态的二维数组；pos 为要放置图标的起始位置，数据结构为 `[row, col]`；icon 为图标大小，数据结构为 `[w, h]`。如下程序加框处代码存在错误，应修改为 ▲ 。

```python
def can_place(scr, pos, icon):
    row, col = pos[0], pos[1]
    iw, ih = icon[0], icon[1]
    if row + iw > H and col + ih > W:    # 加框处
        return False
    for w in range(iw):
        for h in range(ih):
            if scr[row + h][col + w] == 1:

    return True
```

参考答案：

（1）`[[1,1,1],[1,0,0]]`

（2）`scr[row][col] == 0`

（3）`row + ih > H or col + iw > W`

（4）① `head = next`（或 `head = data[head][4]`）；② `data[head][3] += 1`

解析
（1）2×1 图标（宽 2 格、高 1 格）放在 `[[1,0,0],[1,0,0]]` 中的右上角空闲区域（第 0 行第 1-2 列），占用后数组变为 `[[1,1,1],[1,0,0]]`。

（2）扫描查找第一个未被占用的位置（值为 0），即 `scr[row][col] == 0`。

（3）加框处原代码 `row + iw > H and col + ih > W` 有两个错误：① 行列判断混淆（iw 是宽度对应 col，ih 是高度对应 row）；② 应为 `or` 而非 `and`——只要任一方向越界就不能放置。正确代码：`row + ih > H or col + iw > W`。

（4）该程序使用链表结构实现回溯（DFS）：
- ① 回退时，将 head 指针移回上一节点：`head = next`。
- ② 全部放满时，当前节点方案种数加 1：`data[head][3] += 1`。最终 `data[0][3]` 汇总所有方案种数。
