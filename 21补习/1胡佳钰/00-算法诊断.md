## B组：栈、队列、链表

### B1 栈

能力点：`top`、入栈、出栈、空栈判断。

```python

top = -1
data = [2, 4, 6]
for x in data:
    top += 1
    st[top] = x

ans = []
while top != -1:
    ans.append(st[top])
    top -= 1
print(ans)
```

### B2 队列

能力点：`head/tail`、入队、出队、空队判断。

```python
q = [0] * 6
head = 0
tail = 0
for x in [5, 7, 9]:
    q[tail] = x
    tail += 1

s = 0
while head < tail:
    s += q[head]
    head += 1
print(s, head, tail)
```
