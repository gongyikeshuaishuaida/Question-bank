# 02 贪心算法

## 学习目标

- 能从题干中找到“按什么顺序处理”和“每一步选谁”的依据。
- 能读懂贪心程序中排序、扫描、状态更新、边界判断四个关键位置。
- 能完成考试风格的选择题和第 15 题风格的大题填空。
- 能结合列表、二维列表、标记数组等数据结构追踪贪心过程。

## 核心模型

贪心算法通常不是一次直接求出答案，而是每一步都做一个当前看来最合适的选择。考试中常见的问法不是直接问“这是不是贪心”，而是让你补全：

1. 排序依据。
2. 当前对象能否被安排。
3. 选中后状态如何更新。
4. 当前资源不够时剩余部分怎么处理。

常见代码骨架：

```python
data.sort(key=lambda x: 排序依据)
初始化状态
for 当前对象 in data:
    根据当前状态判断能否安排
    如果能安排:
        更新答案
        更新状态
```

本节不再练习“从 0 写程序”，只练选择题和考试大题填空。

def sort_d(data):
