## 备选题1：无人送货车的区间载重

原型：智能工厂无人送货车往返运输产品。

训练目标：把“某产品占用一段路线”转化为区间加法，再用差分还原每段路的载重。

情景题干：

简化提取后的当前题干：

```python

m = 12
goods = [
    ["C01", 1, 4, 5],
    ["G01", 2, 6, 4],
    ["E01", 3, 7, 6]
]

diff = [0] * n
for item in goods:
    s = item[1]
    t = item[2]
    w = item[3]
    diff[________] += w
    diff[________] -= w

load = [0] * (n - 1)
cur = 0
over = 0
for i in range(n - 1):
    cur += ________
    load[i] = cur
    if ________:
        over += 1

print(load, over)
```

填空：

1. 区间加法的左端点：____
2. 区间加法的右边界后一位：____
3. 还原当前路段载重：____
4. 判断当前路段是否超重：____

参考答案：

```python
s
t
diff[i]
load[i] > m
```

运行结果：

```python

```

说明：产品 `E01` 占用路段 `3,4,5,6`，因此在 `diff[3]` 加 `6`，在 `diff[7]` 减 `6`。

## 备选题4：温度超标区间快速查询

原型：高温预警系统整理连续超标时段。

训练目标：把“是否超标”转为 0/1 数组，用前缀和快速判断一个区间内超标时段数量。

情景题干：

某温控系统每 5 分钟记录一次温度。若温度超过 27 摄氏度，则该时段为超标。管理员需要多次查询某个时间区间内超标时段的数量，若整段都超标，则该区间可合并为一条连续预警记录。

温度记录如下，下标表示时段编号。请补全代码，统计区间 `[l,r)` 内超标时段个数，并判断该区间是否整段超标。

```python
temp = [26, 28, 29, 30, 27, 28, 31, 26]
l = 1
r = 4

hot = [0] * len(temp)
for i in range(len(temp)):
    if ________:
        hot[i] = 1

pre = [0] * (len(temp) + 1)
for i in range(len(temp)):
    pre[i + 1] = ________

cnt = ________
all_hot = ________
print(cnt, all_hot)
```

填空：

1. 判断当前时段是否超标：____
2. 建立超标前缀和：____
3. 查询 `[l,r)` 内超标时段数：____
4. 判断 `[l,r)` 是否整段超标：____
