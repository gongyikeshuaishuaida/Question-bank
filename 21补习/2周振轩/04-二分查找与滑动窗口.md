# 04 二分查找与滑动窗口

## 学习目标

- 能区分普通二分、边界二分、答案二分三类写法。
- 能解释 `i/j/L/R/mid` 每次变化后仍然保留的查找范围。
- 能读懂旋转数组、山脉数组、数对查找等压轴选择题中的二分变式。
- 能把滑动窗口中的左边界、右边界、窗口统计量、答案更新拆开追踪。
- 能理解单调队列维护窗口最大值时，队首、队尾和下标过期的关系。

## 核心模型

本节重点不是背模板，而是训练“边界为什么这样移动”。

### 模型一：普通二分查找

适用条件：数据有序，目标是判断 `key` 是否存在。

```python
i = 0
j = len(a) - 1
while i <= j:
    m = (i + j) // 2
    if a[m] == key:
        找到
        break
    elif a[m] < key:
        i = m + 1
    else:
        j = m - 1
```

关键判断：`m` 已经检查过，所以移动边界时通常是 `m+1` 或 `m-1`。

### 模型二：边界二分

边界二分不一定要找到等于 `key` 的元素，而是找某个分界位置。

- 第一个大于等于 `key` 的位置：循环结束后通常看 `i`。
- 最后一个小于等于 `key` 的位置：循环结束后通常看 `j`。

例如：

```python
i = 0
j = len(a) - 1
while i <= j:
    m = (i + j) // 2
    if a[m] > key:
        j = m - 1
    else:
        i = m + 1
```

循环结束后，`j` 指向最后一个 `<= key` 的位置，`i` 指向第一个 `> key` 的位置。

### 模型三：答案二分

答案二分不是在数组里找元素，而是在答案范围 `[L, R]` 中找最小可行值或最大可行值。

```python
L = 最小可能答案
R = 最大可能答案
while L <= R:
    m = (L + R) // 2
    if check(m):
        R = m - 1
    else:
        L = m + 1
print(L)
```

关键判断：

- `check(m)` 为 True，表示 `m` 已经够用，尝试更小答案。
- `check(m)` 为 False，表示 `m` 不够用，只能增大答案。

### 模型四：滑动窗口

滑动窗口适合连续区间问题。右边界不断扩张，条件不满足时移动左边界。

```python
i = 0
统计量 = 0
for j in range(len(a)):
    加入 a[j]
    while 窗口不合法:
        移出 a[i]
        i += 1
    更新答案
```

判断窗口题时要问：

1. 窗口是什么：`[i, j]` 还是 `[i, j)`。
2. 统计量是什么：和、0 的数量、不同字符数量、最大值候选。
3. 什么时候缩左边界。
4. 什么时候更新答案。

## 例题1：重复元素的左右边界

出处：改编自 [[13查找与排序/202507-金华十校-高二-期末-11|202507-金华十校-高二-期末-11]]。

有如下 Python 程序段：

```python
d = [2, 4, 5, 5, 6, 8, 8, 8, 9, 12]
def sear(d, key, f):
    left, right = 0, len(d) - 1
    while left <= right:
        mid = (left + right) // 2
        if d[mid] < key:
            left = mid + 1
        elif d[mid] == key:
            if f > 0:
                left = mid + 1
            else:
                right = mid - 1
        else:
            right = mid - 1
    return left - f

n = sear(d, 8, 1) - sear(d, 8, 0) + 1
```

这个函数用同一套二分代码处理两个边界：

- `f > 0`：找到 `key` 后继续向右找。
- `f == 0`：找到 `key` 后继续向左找。

请完成：

1. `sear(d, 8, 1)` 的返回值是 ＿＿＿＿。
2. `sear(d, 8, 0)` 的返回值是 ＿＿＿＿。
3. `n` 的值是 ＿＿＿＿。

参考答案：

1. `7`，即最后一个 `8` 的位置。
2. `5`，即第一个 `8` 的位置。
3. `3`，因为 `8` 出现于下标 `5、6、7`。

## 例题2：递归二分改成循环二分

出处：改编自 [[13查找与排序/202512-嘉兴-高三-一模-12|202512-嘉兴-高三-一模-12]]。

函数 `f1` 在非降序数组中查找 `key` 第一次出现的位置。

```python
def f1(a, key, L, R):
    if L > R:
        return -1
    M = (L + R) // 2
    if a[M] == key:
        if M == L or a[M-1] != key:
            return M
        else:
            return f1(a, key, L, M-1)
    elif key > a[M]:
        return f1(a, key, M+1, R)
    else:
        return f1(a, key, L, M-1)
```

现在改写为循环形式：

```python
def f2(a, key, L, R):
    while L < R:
        M = (L + R) // 2
        if ______①______:
            ______②______
        else:
            ______③______
    if a[L] == key:
        return L
    else:
        return -1
```

请补全代码，并说明为什么③处不能写成 `R = M - 1`。

参考答案：

```python
key > a[M]
L = M + 1
R = M
```

③处不能写成 `R = M - 1`，因为当 `a[M] >= key` 时，`M` 仍然可能是第一个 `key` 的位置，不能被排除。
