# 题目 11

降序数组二分查找程序如下：

```python
a = [75,66,48,46,31,22,15,3]
key = int(input()); n = 0; i = 0; j = len(a)-1
while i <= j:
    m = (i+j)//2
    if key > a[m]:
        j = m-1
        n = n-1
    else:
        i = m+1
        n = n+1
```

输入不同 `key`，`n` 的值可能有（   ）

- A. 5 种
- B. 6 种
- C. 7 种
- D. 8 种

---

## 答案

**正确答案：** A

---

## 解析

沿二分判定树枚举退出路径，`n` 的可能值为 -3、-1、1、2、4，共 5 种。
