# 题目 11

某二分查找算法的 Python 程序段如下：

```python
f = [0] * 9
key = int(input("key="))
i = 0; j = 8
while i <= j:
    m = (i+j) // 2
    f[m] = 1
    if a[m] == key:
        break
    elif a[m] > key:
        j = m-1
    else:
        i = m+1
```

若 `a[0]` 到 `a[8]` 为升序序列，执行后 `f[0]` 到 `f[8]` 各元素值不可能的是（   ）

- A. 1,1,0,0,1,0,0,0,0
- B. 0,0,0,0,1,0,0,0,0
- C. 0,0,0,0,1,1,1,1,0
- D. 0,1,1,1,1,0,0,0,0

---

## 答案

**正确答案：** C

---

## 解析

首次检查下标 4；向右后检查下标 6，下一步只能走向 5 或 7，不可能让 5 和 7 都被检查，因此 C 不可能。
