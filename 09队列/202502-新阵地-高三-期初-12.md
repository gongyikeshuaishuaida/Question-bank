# 题目 12

```python
s = "21027,53523,042,"
q = [0] * 100; head = tail = 0; tmp = ""; flag = True
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        q[tail] = s[i]; tail += 1
    elif s[i] == ",":
        while head < tail:
            tmp += q[head]; head += 1
            if head != tail and flag:
                head += 1
            flag = not flag
        flag = True
```

执行后 `tmp` 的值为（   ）

- A. `"20735204"`
- B. `"20255202"`
- C. `"20755302"`
- D. `"20235304"`

---
## 答案
**正确答案：** B

---
## 解析
按逗号分段入队，再按 `flag` 交替决定是否跳过下一个队列元素。逐段模拟得到 `tmp="20255202"`。
