# 题目 08

循环队列 Q 从队首到队尾的元素依次为 `"p","y","t","h","o","n"`。约定：U 操作是指元素出队，H 操作是指元素出队后再入队。经过 UHHUHHUH 系列操作后，队列 Q 中队首到队尾的元素依次为（   ）

- A. `ont`
- B. `hon`
- C. `tno`
- D. `noh`

---

## 答案

**正确答案：** A

---

## 解析

从队首到队尾依次模拟：

| 操作 | 队列 |
| --- | --- |
| 初始 | `python` |
| U | `ython` |
| H | `thony` |
| H | `honyt` |
| U | `onyt` |
| H | `nyto` |
| H | `yton` |
| U | `ton` |
| H | `ont` |

最终队列为 `ont`。
