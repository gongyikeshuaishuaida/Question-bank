# 题目 12

某 Python 程序段如下：

```python
a = [2, 5, 3, 8, 1, 4]
total = 0
pos = -1
c = 0
for i in range(len(a)):
    total = total + a[i]
    c = c + 1
    if c >= 3:
        if total >= 15:
            pos = i
        total = total - a[i-2]
print(pos)
```

执行后程序的输出结果为（   ）

- A. 3
- B. 4
- C. 5
- D. -1

---

## 答案

**正确答案：** A

---

## 解析

程序在 `c>=3` 后维护长度为 3 的滑动窗口。`i=3` 时窗口元素为 5、3、8，总和为 16，故 `pos=3`；后续窗口 3、8、1 和 8、1、4 的和均小于 15，`pos` 不再改变，最终输出 3。
