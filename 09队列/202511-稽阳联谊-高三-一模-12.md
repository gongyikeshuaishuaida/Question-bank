# 题目 12

12. 有如下 Python 程序段：

```python
a = [6, 11, 10, 13]; b = [8, 10, 9, 12]
q = [0] * 10
i = j = 0; head = tail = 0
q[tail] = 0; tail += 1
while i < len(a) and j < len(b):
    if q[tail] < a[i] < b[j]:
        q[tail] = a[i]
        i += 1
    else:
        q[tail] = b[j]
        head += 1
        j += 1
    tail += 1
```

执行该程序段后，队列 `q[head:tail]` 中的元素个数是（   ）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** B

---

## 解析

初始：`q[0]=0, head=0, tail=1`。

- `i=0,j=0`：`q[0]=0 < 6 < 8`？`0<6<8` True。`q[0]=6, i=1, tail=2`。（注意：此处 `q[tail]` 即 `q[1]` 还是初始值 0 的占位判断，实际 `q[tail-1]=q[0]=6`）
- `i=1,j=0`：判断 `q[1] < a[1] < b[0]` → `0 < 11 < 8` False。else：`q[1]=8, head=1, j=1, tail=3`。
- `i=1,j=1`：`q[2] < a[1] < b[1]` → `0 < 11 < 10` False。else：`q[2]=10, head=2, j=2, tail=4`。
- `i=1,j=2`：`q[3] < a[1] < b[2]` → `0 < 11 < 9` False。else：`q[3]=9, head=3, j=3, tail=5`。
- `i=1,j=3`：`q[4] < a[1] < b[3]` → `0 < 11 < 12` True。`q[4]=11, i=2, tail=6`。
- `i=2,j=3`：`q[5] < a[2] < b[3]` → `0 < 10 < 12` True。`q[5]=10, i=3, tail=7`。
- `i=3` 但 `len(a)=4`，继续：`q[6] < a[3] < b[3]` → `0 < 13 < 12` False。else：`q[6]=12, head=4, j=4, tail=8`。
- `j=4` = `len(b)`，退出循环。

`head=4, tail=8`，队列元素个数 = `8-4 = 4`，选 B。
