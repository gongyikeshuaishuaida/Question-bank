# 题目 12

有如下 Python 程序段：

```python
que = [6, 9, 5] + [0] * 10
head = 0
tail = 3
for i in range(2):
    t = que[head]
    head += 1
    for j in range(2):
        if t < que[head]:
            que[tail] = t
            t = que[head]
        else:
            que[tail] = que[head]
        head += 1
        tail += 1
    que[tail] = t
    tail += 1
print(que[head:tail])
```

执行该程序段后，输出的结果是（   ）

- A. `[6, 9, 5]`
- B. `[5, 6, 9]`
- C. `[9, 6, 5]`
- D. `[5, 9, 6]`

---

## 答案

**正确答案：** B

---

## 解析

第一轮取出 6，与后续的 9、5 比较后在队尾写入 `6,5,9`；第二轮再取出 5，与后续的 6、9 比较，在队尾写入 `5,6,9`。循环结束时 `que[head:tail]` 为 `[5,6,9]`。
