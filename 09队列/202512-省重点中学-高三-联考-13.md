# 题目 13

学生预约信息存储于列表 `a` 中，如 `a = [['08:35-09:45', 5]]`，表示入馆和出馆时间分别为 8:35、9:45，人数 5 人（允许给他人预约），同一时刻先出馆再入馆。获取图书馆人数阈值存于变量 `Th` 中，统计馆内人数超过阈值的总时长。

（1）为统计图书馆内人数，列表 `d` 中的数据应按：**A．按时间降序；时间相同时，按人数由小到大排序**。

（2）完善程序：

```python
n = len(a)
d = [0] * (2 * n)
for i in range(n):
    ctime = a[i][0]
    d[i] = [ctime[5:], a[i][1]]
    d[n + i] = [ctime[6:], -a[i][1]]       # ①
d.sort(reverse=True)

time = -1
rst = sum = 0
for i in range(2 * n):
    t = int(d[i][0][0:2]) * 60 + int(d[i][0][3:])
    sum += d[i][1]
    if sum > Th:
        if time == -1:
            time = t                           # ②
        elif t > -1:
            rst = rst + t - time                # ③
            time = -1
```

① `-a[i][1]`；② `t`；③ `rst + t - time`。

## 答案

（1）A；（2）① `-a[i][1]`；② `t`；③ `rst+t-time`。

## 解析

将入馆事件记为正人数、出馆事件记为负人数，并按时间降序排列；同一时间负数排在正数之前，实现先出馆再入馆。超过阈值时记录起始时间，回到阈值以内时累加 `t-time`。
