# 改编队列05

某智能终端每分钟采集一次用电功率。网络正常时，终端先按缓存顺序上传此前暂存的数据，再上传当前数据；网络异常时，终端将当前数据暂存到本地缓存队列 `buffer` 中，缓存上限为 `limit` 条。若缓存已满，则先删除最早暂存的数据，再加入当前数据。如下程序中划线处代码依次应为（   ）

```python
buffer = []
limit = 500
while True:
    power = read_power()#获取当前数据
    if network_ok():#正常工作
        while len(buffer) > 0:
            upload(______①______)#上传数据
        upload(power)
    else:
        if len(buffer) == limit:
            ______②______
        ______③______
    # 延时 60 秒，代码略
```

- A. ① `buffer.pop(0)`  ② `buffer.pop(0)`  ③ `buffer.append(power)`  
- B. ① `buffer.pop()`  ② `buffer.pop()`  ③ `buffer.insert(0, power)`  
- C. ① `buffer[0]`  ② `buffer.clear()`  ③ `buffer.append(power)`  
- D. ① `buffer.pop(0)`  ② `buffer.pop(0)`  ③ `buffer.insert(0, power)`

---

## 答案

**正确答案：** A

---

## 解析

缓存队列需要保持先进先出。网络恢复后应从队首依次取出并上传，因此用 `buffer.pop(0)`；网络异常且缓存已满时，也要先删除最早暂存的数据，即 `buffer.pop(0)`；当前采集值加入队尾，使用 `buffer.append(power)`。
