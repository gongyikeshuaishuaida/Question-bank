# 题目 11

11. 有如下 Python 程序段：

```python
s = 0
while ha != ta:
    while hb != tb and qa[ha] > qb[hb]:
        if (qa[ha] + qb[hb]) % 2 == 0:
            qa[ta] = qb[hb]
            ta += 1
        hb += 1
    if hb != tb:
        hb += 1
    s += qa[ha]
    ha += 1
```

若 `qa` 为 `[7,0,0,0,0]`，`ha` 为 0，`ta` 为 1，`qb` 为 `[5,8,3,2,4,0]`，`hb` 为 0，`tb` 为 5，执行该程序段后，`s` 的值为（   ）

- A. 7
- B. 10
- C. 12
- D. 15

---

## 答案

**正确答案：** D

---

## 解析

第一次外层循环处理 `qa[0]=7`：`qb[0]=5` 小于 7，且两数和为偶数，将 5 加入 `qa` 队尾，随后跳过 8，`s=7`。

第二次处理新加入的 5：依次检查 3、2、4，其中只有 `5+3` 为偶数，因此将 3 加入 `qa` 队尾，`s=7+5=12`。

第三次处理新加入的 3，`qb` 已遍历结束，最终 `s=12+3=15`。
