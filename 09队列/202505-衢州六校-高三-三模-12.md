# 题目 12

12. 有 Python 代码段如下：

```python
k, h, t = 10, 0, 0
n = len(nums) ; ans = n + 1
a = [0] * (n + 1) ; q = [0] * (n + 1)
for i in range(n):
    a[i + 1] = a[i] + nums[i]
for i in range(n + 1):
    while h != t and a[i] - a[q[h]] >= k:
        m = q[h]
        h += 1
        ans = min(ans, i - m)
    q[t] = i
    t += 1
print(ans)
```

执行以上代码段，输出结果为3，则 `nums` 可能为（   ）

- A. `[1,2,3,3,3,2,1]`
- B. `[3,1,4,4,5,0,8]`
- C. `[2,2,2,2,2,2,2]`
- D. `[9,7,6,3,5,5,1]`

---
## 答案

**正确答案：** B

---
## 解析

程序用前缀和与单调队列寻找和至少为10的最短连续子数组。B 中连续子数组 `[4,5,0,8]` 的和为17，且最短满足条件的长度为3（`[5,0,8]`）；其余选项的最短长度分别不是3。
