# 题目 12

有如下 Python 程序段：

```python
n = len(a)
prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + a[i]
p = [-1] * (n + 1)
head = 0
tail = 0
minlen = n + 1
beststart = -1
for k in range(n + 1):
    while head < tail and prefix[k] - prefix[p[head]] >= s:
        left = p[head]
        head = head + 1
        if k - left < minlen:
            minlen = k - left
            beststart = left
    while head < tail and prefix[k] <= prefix[p[tail - 1]]:
        tail = tail - 1
    p[tail] = k
    tail = tail + 1
```

若列表 `a` 为 `[84, -37, 62, 40, -10, 95, 24]`，执行代码后 `minlen` 为 2，`beststart` 为 5，`s` 可能的值是（   ）

- A. 100
- B. 115
- C. 120
- D. 125

---

## 答案

**正确答案：** B

---

## 解析

`beststart=5、minlen=2` 对应子数组 `[95,24]`，和为 119，所以 `s<=119`。为避免长度 1 的元素满足条件，需要 `s>95`；为避免更早的长度 2 子数组 `[62,40]` 满足条件，需要 `s>102`。因此 $102<s\leq119$，只有 115 符合。
