# 题目 15

某人工智能平台负责大模型分布式训练任务的调度。平台配备高性能计算集群 A、通用计算集群 B，以及弹性调度集群 S。训练任务到达后，按任务所需的 GPU 数量分类调度：GPU 需求数 > 8 的高负载训练任务由集群 A 执行；GPU 需求数 ≤ 8 的常规训练任务由集群 B 执行；若新任务到达时对应集群的等待队列长度已达 c 个，该任务转由调度集群 S 处理。执行规则：集群 A、B 均按任务到达时间的先后顺序依次执行；调度集群 S 则按任务所需 GPU 数量从大到小依次执行。现给出某天到达的任务编号、到达时间、GPU 需求数、训练时长，以及集群 A、B 的等候容量 c，编写程序计算各任务的训练开始时间、完成时间以及每个任务在系统中的等待时间。

（3）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
def schedule(tasks, c):
    n = len(tasks)
    curr = [0] * 3
    q = [[] for i in range(3)]
    srv = [-1] * 3
    start = [-1] * n
    wait = [-1] * n
    for i in range(n):
        for j in range(3):
            k = srv[j]
            while len(q[j]) > 0 and (k == -1 or curr[j] + tasks[k][3] <= tasks[i][1]):
                srv[j] = q[j].pop(0)
                if k == -1:
                    curr[j] = tasks[srv[j]][1]
                    start[srv[j]] = curr[j]
                    ____①____
                else:
                    curr[j] += tasks[k][3]
                    if curr[j] < tasks[srv[j]][1]:
                        curr[j] = tasks[srv[j]][1]
                        wait[srv[j]] = 0
                    else:
                        wait[srv[j]] = curr[j] - tasks[srv[j]][1]
                    start[srv[j]] = curr[j]
                    ____②____
        if tasks[i][2] > 8 and len(q[0]) < c:
            q[0].append(i)
        elif tasks[i][2] <= 8 and len(q[1]) < c:
            q[1].append(i)
        else:
            ____③____
```

## 答案

**正确答案：** （1）8:40；（2）`i >= 0 and data[q[i]][2] < data[k][2]`；（3）① `wait[srv[j]] = 0`；② `k = srv[j]`；③ `insert_task(tasks, q[2], i)`

---

## 解析

S 集群按 GPU 需求降序插入，因此向前移动所有需求数小于新任务的索引。任务刚开始执行且没有等待时等待时间为 0；处理完当前服务任务后要更新 k。无法进入 A、B 队列的任务转入 S。
