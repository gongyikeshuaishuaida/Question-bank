# 原创队列04

有如下 Python 程序段，用单调队列求列表 `a` 中每个长度为 `k` 的连续窗口最大值。划线处代码依次应为（   ）

```python
a = [4, 2, 5, 1, 6, 3]
k = 3
q = [0] * len(a)
head = tail = 0
ans = []
for i in range(len(a)):
    while head < tail and ______①______:
        tail -= 1
    q[tail] = i
    tail += 1
    if ______②______:
        head += 1
    if i >= k - 1:
        ans.append(______③______)
print(ans)
```

- A. ① `a[q[tail-1]] <= a[i]`  ② `q[head] <= i-k`  ③ `a[q[head]]`  
- B. ① `a[q[tail-1]] >= a[i]`  ② `q[head] < i-k`  ③ `q[head]`  
- C. ① `a[q[head]] <= a[i]`  ② `q[tail-1] <= i-k`  ③ `a[q[tail]]`  
- D. ① `a[q[tail-1]] < a[i]`  ② `q[head] <= i-k+1`  ③ `a[i]`

---

## 答案

**正确答案：** A

---

## 解析

这是一趟式单调队列写法，不需要把前 `k` 项单独拿出来处理。`i < k-1` 时只维护队列但不输出；`i >= k-1` 后每轮输出当前窗口最大值。队列中保存下标，且对应值从队首到队尾单调不增；新元素更大或相等时删除队尾；若 `q[head] <= i-k`，说明队首已经离开窗口；窗口最大值为 `a[q[head]]`。
