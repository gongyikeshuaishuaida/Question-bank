# 题目 12

有如下Python程序段：

```python
stks, cnt = [], [0] * 5

for i in range(len(a)):
    if a[i] % 3 != 2:
        if cnt[a[i]] == len(stks):
            stks.append([a[i]])   # 把[a[i]]作为元素新增到列表stks的末尾
        else:
            stks[cnt[a[i]]].append(a[i])
        cnt[a[i]] += 1
    else:
        val = stks[-1].pop()      # 删除列表stks[-1]的最后一个元素并返回赋值给val
        if not stks[-1]:
            stks.pop()
        cnt[val] -= 1
```

若列表a为 `[2,2,0,3,1,4,4,1,3]`，程序运行结束时 `stks[0]` 不包含（   ）

- A. 1  
- B. 2  
- C. 3  
- D. 4

---

## 答案

**正确答案：** A

---

## 解析

程序模拟了多栈结构：`stks` 中每个元素是一个子栈，`cnt` 记录各编号出现次数。

遍历a中每个元素x：
- 当 `x%3!=2`（0,1,3,4）：压入编号对应的子栈
- 当 `x%3==2`（2）：弹出最末尾子栈的栈顶

跟踪 `a=[2,2,0,3,1,4,4,1,3]`：`stks[0]`（第一个子栈）最终包含 2、3、4，不含1。
