# 题目 12

12. 以下程序段运行后，输出的结果是（   ）

```python
q = [7,1,9,3,3,8,7,5,6,5,19,7,9,9]
k = 3
head = 0
tail = 3
cnt = 0
maxs = -1
s = sum(q[head:tail])  # 对列表进行求和
while cnt <= k:
    if s > maxs:
        maxs = s
        cnt += 1
    s = s + q[tail] - q[head]
    head = head + 1
    tail = tail + 1
print(maxs)
```

- A. 20
- B. 30
- C. 31
- D. 35

---

## 答案

**正确答案：** B

---

## 解析

`head` 和 `tail` 维护长度为 3 的滑动窗口，但 `cnt` 只在出现新的最大窗口和时增加。程序依次遇到的新最大值为：

- `17`，`cnt=1`
- `18`，`cnt=2`
- `20`，`cnt=3`
- `30`，`cnt=4`

此后再次判断 `cnt<=k` 为假，循环结束，因此输出 `30`。虽然后续数据中还能形成和为 31、35 的窗口，但程序在处理它们之前已经退出。
