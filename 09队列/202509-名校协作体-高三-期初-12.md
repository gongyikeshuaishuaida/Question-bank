# 题目 12

12. 执行如下 Python 程序段后，以下说法不正确的是（　）

```python
import random

a = ["信", "-", "息", "+", "技", "术", "+"]
que = [0] * len(a)
head = tail = 0
for i in range(len(a)):
    pos = random.choice(["m", "n"])
    if pos == "m" and a[i] != "-":
        que[tail] = a[i]
        a[i] = "-"
        tail += 1
    elif pos == "n" and head != tail and a[i] != "+":
        a[i] = que[head]
        head += 1
        tail += 1
```

- A. `que`可能为`['信','息','技','术',0,0,0]`
- B. `que`不可能为`['信',0,'息','技','术','+',0]`
- C. `a`可能为`['信','-','息','+','-','技','+']`
- D. `a`不可能全部为`'+'`

---

## 答案

**正确答案：** B

---

## 解析

逐位置分析两种随机分支及队列头尾变化，B所列队列状态可以由合法分支序列产生，因此“不可能”的判断错误。
