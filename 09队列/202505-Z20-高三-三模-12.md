# 题目 12

12．有如下 Python 程序段：

```python
st1 = [0] * 10; top1 = -1
st2 = [0] * 10; top2 = -1
for num in a:
    if num % 2 == 0:
        temp = num * 2
    else:
        temp = num * 3
    while top1 != -1 and st1[top1] > temp:
        popped = st1[top1]
        top1 -= 1
        while top2 != -1 and st2[top2] > popped:
            top2 -= 1
        top2 += 1
        st2[top2] = popped
    top1 += 1
    st1[top1] = temp
```

当列表 `a` 为 `[3, 2, 5, 4, 1, 6]` 时，运行该程序段，则列表 `st2` 所有数据之和为

- A. 51
- B. 15
- C. 4
- D. 3

---
## 答案

**正确答案：** C

---
## 解析

将奇数乘3、偶数乘2后依次维护 `st1`，从 `st1` 弹出的较大元素按顺序压入 `st2`。给定数据运行后，`st2` 中有效数据之和为4，选择 C。
