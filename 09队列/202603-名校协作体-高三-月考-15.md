# 题目 15

15. 某市火车站周围有 `m` 个人口较为密集的城区。火车站在出站口设置“出租车拼车点”，并通过“出租车拼车系统”为所有前往同一城区的乘客提供“拼车”服务。系统接收乘客的出行请求，每个请求包含乘客编号、请求上车时间、目的地城区，根据乘客的请求上车时间先后依次为乘客安排车辆。假设每辆出租车最多载客 `w` 人，乘客在请求上车时间一定可以上车，且上车后最多等待 `t` 分钟，期间一旦满载或超时，则立即发车。编写程序实现，输入出行请求，输出每辆车发车时刻及发车时车内的乘客编号。

例如：若 `m=2`，`w=4`，`t=5`，8 位乘客出行请求如下表所示，编号 `1,2,3,4` 乘客的发车时间是 `08:15`，编号 `5,6` 乘客的发车时间是 `08:21`，编号 `7,8` 乘客的发车时间是 `08:23`。

| 乘客编号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 请求上车时间 | 08:10 | 08:11 | 08:11 | 08:15 | 08:16 | 08:17 | 08:18 | 08:22 |
| 目的地城区 | 0 | 0 | 0 | 0 | 1 | 1 | 0 | 0 |

（1）若将编号为 4 的乘客的请求上车时间更改为 `08:16`，则编号为 8 的乘客的发车时间是 ______。

（2）定义 `sort(data)` 函数，参数 `data` 中每个元素包含 3 个数据项：乘客编号、请求上车时间、目的地城区。函数功能为按请求上车时间对 `data` 做升序排序。

```python
def sort(data):
    i = 0
    n = len(data)
    flag = True
    while i < n - 1 and flag:
        flag = False
        k = i
        for j in range(n-1, i, -1):
            if data[j][1] < data[j-1][1]:    # A处
                data[j], data[j-1] = data[j-1], data[j]
                flag = True
                k = j
        i = k
```

① 实现上述功能的代码如上，若 `data=[[1,550,0],[2,580,0],[3,560,1],[4,590,1],[5,570,2]]`，则 A 处代码执行次数为 ______。

② 若 `data=[[1,490,0],[2,491,0],[3,491,0],[4,496,0],[5,496,1],[6,497,1],[7,498,0],[8,502,0]]`，删除加框处代码 `k=i`，对程序运行是否有影响 ______。（单选，填字母 A. 有影响 / B. 无影响）

（3）程序运行界面如下图所示。

```text

发车时刻: 501  乘客: [4, 7]
发车时刻: 501  乘客: [5, 6]
发车时刻: 507  乘客: [8]
```

## 答案

（1）`08:27`

（2）① 7；② A

（3）① `head = que[k][0]`；② `pa = que[k][head:tail]`；③ `ct += 1`

---

## 解析

第（1）小题中，4 号乘客改为 `08:16` 后，城区 0 的第一辆车在 `08:15` 只带走 1、2、3；4、7、8 进入下一辆车，最早上车的 4 号在 `08:16`，等待 5 分钟到 `08:21` 时未满载会发车，8 号请求时间 `08:22`，只能再等到 `08:27` 发车。第（2）小题冒泡优化中 A 处比较次数按各轮扫描累计为 4+3=7；删除 `k=i` 会影响无交换时 `i` 的更新。第（3）小题 `que[k][0]` 保存当前队首位置，发车乘客索引切片为 `que[k][head:tail]`，若当前时刻未发车但仍有等待队列，则时间 `ct` 递增推进。
