# 题目 12

12. 有如下 Python 程序段，执行后输出的结果是（   ）

```python
text = "abcdeabcdeabcdeabecde"
window = [''] * 5
freq = [0] * 5
h, t = 0, 4
pre = 0
for i in range(len(text)):
    window[t] = text[i]
    add = 0
    if window[t] == 'e':
        add = 1
    sub = 0
    if window[h] == 'e':
        sub = 1
    freq[t] = pre + add - sub
    pre = freq[t]
    t = (t + 1) % 5
    h = (h + 1) % 5
print(freq[h], freq[t])
```

- A. `2 1`
- B. `2 2`
- C. `1 2`
- D. `1 0`

---

## 答案

**正确答案：** A

---

## 解析

`window` 是长度为 5 的循环窗口，`freq[t]` 记录本次窗口中字符 `e` 的个数。每轮用 `add` 加入新字符的贡献，再用 `sub` 减去被挤出字符的贡献，并同步推进首尾指针。逐轮模拟结束后，`freq[h]=2`、`freq[t]=1`。
