# 题目 12

12. 某 Python 程序段如下：

```python
import random
q = ["p", "y", "t", "h", "o", "n"]
n = len(q)
k = random.randint(1, 4)
head = 2; tail = n - 1; res = ""
while head != tail:
    if head % k == 0:
        res += chr((ord(q[head]) + k - ord("a")) % 26 + ord("a"))
    else:
        tail = (tail + 1) % n
        q[tail] = q[head]
    head = (head + 1) % n
res += q[head]
print(res)
```

执行该程序段后，输出 `"kwrn"`，则 k 的值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** C

---

## 解析

程序模拟环形队列筛选。`head%k==0` 时取出字符并加密（+k 的 Caesar 偏移）。输出 "kwrn"，反推 k=3：t→w(+3), h→k(+3), o→r(+3), n→?。验证可得 k=3。
