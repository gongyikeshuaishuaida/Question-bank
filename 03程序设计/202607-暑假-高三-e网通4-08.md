# 题目 08

有如下 Python 程序段：

```python
s = "1996/07-2021/04"
ans = ""; Max = ""; ch = ""; f = True
for i in range(0, len(s)):
    ch = s[i]
    if ch >= "0" and ch <= "9":
        ans = ans + ch
    else:
        f = False
    if not f and ans > Max:
        Max = ans
        ans = ""
        f = True
print(Max)
```

输出 `Max` 的值为（   ）

- A. 199607
- B. 202104
- C. 1996
- D. 2021

---

## 答案

**正确答案：** D

---

## 解析

程序在分隔符处比较此前连续数字串，依次处理 `1996`、`07`、`2021`；按字符串比较得到最大值 `2021`。末尾的 `04` 没有随后分隔符触发比较。
