# 题目 13

亲和数是一对互为对方真因数之和的整数。补全查找程序：

```python
def divisors(n):
    sum = 1
    for i in range(2, int(n**0.5)+1):
        if n % i == 0:
            sum += i
            if ______①______:
                sum += n//i
    return sum

def find(start, end):
    pairs = []
    for i in range(start, end+1):
        dsum = divisors(i)
        if dsum > i and dsum != i and ______②______:
            pairs.append(______③______)
    return pairs
```

若删除条件中的 `dsum>i`，在 1～2000 中会输出多少对？

---

## 答案

**正确答案：** ① `i != n//i`；② `divisors(dsum) == i`；③ `[i, dsum]`；删除后输出 4 对

---

## 解析

平方根因数不能重复累加；若 `dsum` 的真因数和回到 `i`，两者亲和。`dsum>i` 用于避免正反重复，删除后两组会各输出两次。
