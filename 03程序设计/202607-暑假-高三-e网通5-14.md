# 题目 14

字符串分段：把仅含小写字母的字符串划分为尽可能多的片段，同一字母只出现在一个片段中。补全：

```python
p = [-1] * 52
for i in range(len(s)):
    a = ______①______
...
if p[2*(j-1)] > p[2*j] or ______②______:
    ...
if p[2*i] < t2 and p[2*i+1] > t2:
    ______③______
```

若输入 `hshjhqueeqabaa`，输出共有多少行？第二行是什么？

---

## 答案

**正确答案：** ① `ord(s[i])-97`（或 `ord(s[i])-ord('a')`）；② `p[2*(j-1)] == -1`；③ `t2=p[2*i+1]`；输出 3 行，第二行为 `queeq`

---

## 解析

字符编码映射到 0～25；未出现字符需排到尾部；片段相交时扩展右端点。该字符串分为 `hshjh`、`queeq`、`abaa`。
