# 题目 10

程序把字符串中的连续升序段缩写为“首字符-尾字符”：

```python
s = input("请输入字符串:")
k = len(s); flag = False; result = ""
for i in range(0, k-1):
    if ______①______:
        result = result+s[i]+"-"
        flag = True
    elif ord(s[i]) != ord(s[i+1])-1:
        result = result+s[i]
        flag = False
______②______
print("缩写后的字符串为", result)
```

- A. ①相邻连续且 `flag`；②连接 `s[i]`
- B. ①相邻连续且 `not flag`；②连接 `s[i]`
- C. ①相邻连续且 `flag`；②连接 `s[i+1]`
- D. ①相邻连续且 `not flag`；②连接 `s[i+1]`

---

## 答案

**正确答案：** D

---

## 解析

连续段开始时标志尚为假，应连接首字符和连字符；循环未处理最后一个字符，结束后应连接 `s[i+1]`。
