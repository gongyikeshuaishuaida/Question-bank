# 题目 12

随机数与双指针程序：

```python
import random
b = [1,1,1,1,1,1]
i, j = 0, len(b)-1
while i < len(b) and j >= i:
    if random.randint(0,1) == 0:
        b[i] += j; i += 1
    else:
        b[j] += i; j -= 1
print(b)
```

输出不可能为（   ）

- A. `[1,1,1,1,1,1]`
- B. `[6,6,4,3,3,3]`
- C. `[5,5,3,3,3,1]`
- D. `[5,4,3,3,2,1]`

---

## 答案

**正确答案：** B

---

## 解析

逐轮枚举随机分支可知，形成 B 所需的中间状态无法继续到该结果；其余三个结果均存在相应分支序列。
