# 题目 09

有如下 Python 程序段：

```python
def search(x):
    ans = ""
    if a[2*x] != "":
        ans += search(2*x)
    if a[2*x+1] != "":
        ans += search(2*x+1)
    ans += a[x]
    return ans

a = [""] * 32
a[1] = "A"; a[2] = "B"; a[3] = "C"
a[4] = "D"; a[7] = "E"; a[9] = "F"
print(search(1))
```

输出结果是（   ）

- A. FDBECA
- B. ACEBDF
- C. ABCDEF
- D. FEDCBA

---

## 答案

**正确答案：** A

---

## 解析

函数按左子树、右子树、根结点的次序递归，即后序遍历，结果为 `FDBECA`。
