# 题目 13

Luhn（模 10）算法用于号码校验。程序如下：

```python
def checkLuhn(a):
    sum = 0
    parity = len(a) % 2
    for i, digit in enumerate([int(x) for x in a]):
        # 遍历 a，变量 i 枚举索引，变量 digit 枚举值（已转换为整型）
        if i % 2 == parity:
            digit *= 2
            if digit > 9:
                digit -= 9
        sum += digit
    return ______①______

def getLuhn(a):  # 计算校验码
    s = 0
    for i in range(2, len(a)+2):
        t = int(a[len(a)-i+1])
        if i % 2 != 0:
            t *= 2
            if t < 10:
                s += t
            else:
                ______②______
        else:
            s += t
    t = 10-s%10
    if t == 10:
        result = "0"
    else:
        ______③______
    return result
```

请填入代码：______①______；______②______；______③______。

---

## 答案

**正确答案：** ① `sum % 10 == 0`；② `s += t % 10 + t // 10`（或 `s += t-9`）；③ `result = str(t)`

---

## 解析

校验和能被 10 整除时号码有效；两位数的个位与十位相加可写成取模加整除；主程序拼接字符串输出校验码，因此需把 `t` 转成字符串。
