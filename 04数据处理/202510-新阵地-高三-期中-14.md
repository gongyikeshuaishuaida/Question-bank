# 题目 14

14. 对展厅环境监测数据进行分析。

![[attachments/202510新阵地_14_图1.png]]

(1) 先去除噪音大于130的无效数据，再按“时”求平均并绘图。①②③依次从下列代码选取：

- A. `df[df["噪音"]<=130]`
- B. `df[df."噪音"<=130]`
- C. `df1.groupby("时",as_index=False)["噪音"].mean()`
- D. `df1.groupby("时").噪音.count()`
- E. `df2.噪音,df2.时`
- F. `df2["时"],df2["噪音"]`

(2) 程序统计持续最长的非正常光照时段（光照小于`minx`或大于`maxx`）。关键片段：
```python
maxn = -1
n = 0
for i in range(len(data)):
    if data[i] < minx or data[i] > maxx:
        n += 1
        if n > maxn:
            ①
            tmp = []
        tmp.append(i)
    elif n == maxn:
        tmp.append(i)
    else:
        ②
for x in tmp:
    ③
    timeB = proc(x)
```
补全①②③。

---

## 答案

(1) ①A；②C；③F

(2) ①`maxn=n`；②`n=0`；③`timeA=proc(x-maxn+1)`

---

## 解析

先筛选有效记录，再分组求噪音均值，横轴为时、纵轴为噪音。连续异常时累计n，更新最长值并记录结束位置；恢复正常时清零，起点索引为`x-maxn+1`。
