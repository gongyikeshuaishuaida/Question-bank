# 题目 09

9. 某商场去年部分销售情况存储在文件 `"sale.xlsx"` 中。编写 Python 程序，先填充第 2 行"▲"处数据为"8"，再统计并输出电视类销售数量最大的 3 种型号信息。

![[attachments/202506嘉兴_09_图1.jpg]]

```python
import pandas as pd
df = pd.read_excel('sale.xlsx')
①
df1 = df[df.类别 == '电视']
df2 = df1.groupby('型号', as_index=False).②
df2 = df2.sort_values('销售数量', ascending=False).head(3)
print(df2)
```

要实现上述功能，划线 ① ② 代码正确的是（   ）

- A. `df.at[1,'销售数量']=8` / `count()`
- B. `df.at[0,'销售数量']=8` / `count()`
- C. `df.at[1,'销售数量']=8` / `sum()`
- D. `df.at[0,'销售数量']=8` / `sum()`

---

## 答案

**正确答案：** D

---

## 解析

① 第 2 行索引为 1（0-based），`df.at[1,'销售数量']=8`。② 按型号分组后需对销售数量求和统计，用 `sum()`。故答案为 D... wait, let me re-check. The answer is D but ① uses `df.at[0,'销售数量']` (row 0, which is the header row). Actually, looking at the image reference, the "▲" should be at row index 1 (second data row). But the answer key says D which has `df.at[0,'销售数量']=8`. 

Hmm, pandas DataFrame with header - row 0 is the first data row. So `df.at[0,'销售数量']` modifies the first data row. If the excel has a header row, then df row index 0 IS the first data row (header is not counted in the index). So D is correct.
