# 题目 15

某市模拟考试采用“一分一赋”规则对各科成绩赋分。根据各分数段人数比例动态划分原始分区间，同分考生按就高原则统一赋分。赋分公式为线性插值，s2、s1 为所在等级原始分区间上、下限，t2、t1 为对应赋分区间上、下限；例如原始分80分对应的等级索引可记为 `s_gra[80]`。

等级及赋分区间如下：等级1—10的赋分依次为100—97、96—94、93—91、90—88、87—85、84—82、81—79、78—76、75—73、72—70；等级11—20的赋分依次为69—67、66—64、63—61、60—58、57—55、54—52、51—49、48—46、45—43、42—40。

（1）若原始成绩为80分，排名处于等级3，等级3原始成绩区间为78—81分，则四舍五入后的赋分成绩为____分。

（2）函数 grade_sco 如下，请填空：

```python
def grade_sco(s):
    g = s_gra[s]
    if s1[g] == s2[g]:
        return ____
    return round(t1[g] + (t2[g]-t1[g])*(s-s1[g])/(s2[g]-s1[g]))
```

（3）根据学生原始成绩计算赋分：

```python
m = 20
s_num = [0] * 101
for i in range(len(sco)):
    s_num[sco[i]] = ____①
s1 = [0] * m
s2 = [0] * m
s_gra = [-1] * 101
k = 0

    while k < m - 1 and stu[k] <= 0:

# 输出每个卷面分及其对应的赋分
for score in range(100, -1, -1):

```

---
## 答案

**参考答案：** （1）92；（2）t2[g]；（3）① s_num[sco[i]] + 1；② score；③ stu[k] + stu[k-1]。

---
## 解析

（1）等级3的赋分区间为93—91，原始区间为78—81。80分的线性赋分为 91+2×(80-78)/(81-78)=92.33，四舍五入为92。  
（2）当一个等级的原始分上下限相等时，直接取该等级的赋分上限 t2[g]。  
（3）统计每个原始分人数时需在原计数上加1；第一次遇到某等级的最高原始分即记录 score 为上限；当前等级人数超出比例后，下一等级要承接剩余人数，因此用 stu[k]+stu[k-1]。
