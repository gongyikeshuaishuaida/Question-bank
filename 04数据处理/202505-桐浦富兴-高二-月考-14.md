# 题目 14

为促进学校文明建设，某高中每月评选文明年级：本月考核中达标班级最多的年级为文明年级。每周考核分满分 100 分；某班级有 3 次及以上考核分值超过 70 分，则该班级本月文明考核达标。3 月数据存于 `score.xlsx`。

第 14 题图 b 为高二年级考核达标班级图。

![[attachments/202505桐浦富兴高二_14_柱形图.png]]

（1）下列说法不正确的是____。（单选）

- A. 高一 1 班第 2 周考核分缺失不影响最终结果的计算
- B. 高一 2 班的考核记录中存在格式不一致问题
- C. 根据考核规则可知，高三 20 班本月考核达标

（2）导入整理后的数据，插入“标记”列；若周考核分值超过 70 分，在“标记”列置 1，否则置 0。补全代码。

```python
df.insert(4,"标记",0)  #插入“标记”列，值为0
for i in df.index:
    if df.at[i,"考核"]>70:
        ____  # 此处是方框处
```

（3）统计高二年级达标班级并绘图，方框语句应依次为____（选 2 项，填数字序列）。

```python
df=df[df.年级=="高二"]
```

④ `df=df.groupby("班级",as_index=False).标记.count()`

（4）`data` 形如 `[["高一",7],["高二",3],["高三",8]]`，补全程序以输出 3 月文明年级。

```python
#计算各年级的达标班级数量，存储在列表data中
n=len(data)
____①____
for i in range(n-1):
    if ____②____:
        k=i

```

---
## 答案

（1）A

（2）`df.at[i,"标记"]=1`

（3）③②

（4）① `k=n-1`；② `data[k][1]<data[i][1]`

---
## 解析

缺失一周分数会影响是否达到 3 次，故 A 错。统计时先按班级汇总超过 70 分的次数，再筛选次数不少于 3 的班级。第（4）问以当前最大值索引 `k` 比较各年级达标班级数。
