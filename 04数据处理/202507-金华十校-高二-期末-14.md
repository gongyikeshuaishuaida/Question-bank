# 题目 14

某校为方便管理学生就餐情况推出了一个订餐系统，小华收集了该校高二年级某周一的订餐情况，数据保存在 `"order.xls"` 中，部分数据如第 14 题图 a 所示，其中 F2 单元格的 `"?"` 表示"未订餐"，请回答下列问题：

![[attachments/202507金华十校_14_图a.jpg]]

(1) 根据第 14 题图 a 所示的数据，下列关于数据处理的说法，正确的是 ▲ （单选，填字母）

- A. "日期"列中存在数据逻辑错误
- B. 存在数据重复问题，应直接删除其中一行
- C. 若表格数据缺失，可以直接用 `"?"` 代替

(2) 该校高二年级共有 10 个班级，编写 Python 程序统计周一各班未订餐情况，绘制柱形图（如第 14 题图 b 所示），并输出未订餐次数最多的班级，有多个班级符合的一起输出。请按要求完善代码。

![[attachments/202507金华十校_14_图b.jpg]]

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_excel("order.xls")

for i in df.index:
    for j in df.columns[3:6]:     # 统计"早、中、晚"3列
        if ①:
            df.at[i, j] = 1
        else:
            df.at[i, j] = 0

df["合计"] = df["早"] + df["中"] + df["晚"]

df_g = ②

k = 0
for i in range(1, len(df_g)):
    if df_g.at[i, "合计"] > df_g.at[k, "合计"]:
        ③

result = ""
for i in range(0, len(df_g)):
    if df_g.at[i, "合计"] == df_g.at[k, "合计"]:

print("未订餐次数最多的班级为：" + result)
```

- B. `df.groupby("班级", as_index=False).count()`

## 答案

**正确答案：**

(1) B

(2) ① `df.at[i, j] == "?"`；② A；③ `k = i`；④ `df_g.at[i, "班级"]`

---

## 解析

(1) 第 14 题图 a 中第 3、4 行数据（陈\*静）完全重复，应删除其中一行，B 正确。A：日期"2024-10-32"是数据输入错误而非逻辑错误。C：数据缺失不能用 `"?"` 直接代替，`"?"` 本身表示"未订餐"，与缺失含义不同。

(2) 程序逻辑：
- ① 遍历"早、中、晚"三列，将 `"?"`（未订餐）转为 `1`，其余转为 `0`。
- ② 按"班级"分组并求和，`sum()` 统计每班未订餐总次数。`count()` 只会统计非空值的个数，不符合需求。
- ③ 若当前行的合计值更大，更新最大索引 `k = i`。
- ④ 将未订餐次数最多的班级名称拼接到 `result` 中。
