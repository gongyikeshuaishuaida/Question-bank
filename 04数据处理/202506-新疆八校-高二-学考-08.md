# 题目 08

某高中图书馆管理员整理出了 2024 年学校图书借阅情况的数据，保存在 `book.xlsx` 文件中，部分数据如下图所示。编写 Python 程序，统计并输出全年最受学生欢迎的 3 类图书。

![[attachments/202506新疆八校高二_08_借阅数据表.png]]

```python
import pandas as pd
df = pd.read_excel("book.xlsx")  # 读文件中的数据
df = df[df.身份类型 == "学生"]    # 筛选学生数据
df = df.rename(columns={"借阅起止日期": "借阅次数"})

# 此处是方框处的代码由下列语句中的部分语句组成
____________________________  # 此处是方框处
print(dfr)
```

① `dfg = df.groupby("图书类别", as_index=False).count()`  
② `dfg = df.groupby("图书类别", as_index=False).sum()`  
③ `dfs = dfg.sort_values("借阅次数", ascending=False)`  
④ `dfs = dfg.sort_values("借阅次数")`  
⑤ `dfr = dfs.head(3)`  
⑥ `dfr = dfs.tail(3)`

要实现上述功能，下列选项正确的是（   ）

- A．①③⑥
- B．②③⑤
- C．①④⑥
- D．②④⑤

## 答案

**正确答案：** C

## 解析

按图书类别统计学生借阅记录数，应使用 `count()`。`sort_values` 默认升序，取末尾 3 条即可得到借阅次数最多的类别，因此依次使用 ①④⑥。
