# 题目 13

某城市 2024 年前 13 周新能源汽车销量数据按日期、销量、厂商属性和品牌记录。第 13 题图 b 为某品牌周销量折线图：

![[attachments/202502名校协作体_13_图1.jpg]]

## （1）按品牌计算每周销量

```python
def week_sale(brand):
    import pandas as pd
    df = pd.read_excel("sale.xlsx")
    df1 = df[df["品牌"] == brand]
    df1 = df1.sort_values("①")
    df1.reset_index(drop=True)
    sale = [0] * 13
    s = 0
    for i in df1.index:
        day = df1.at[i,"销量"]
        ②
        if i % 7 == 6:
            sale[i//7] = s
            ③
    return sale
```

填空：

- ① `日期`
- ② `s += day`
- ③ `s = 0`

## （2）绘制折线图

```python
weeks = [i for i in range(1,14)]
plt.plot(____)
```

选项：

- A. `df["周次"], df["销量"]`
- B. `df1["weeks"], df1["sales"]`
- C. `weeks, sales`

答案为 C。

---
## 答案
**正确答案：** （1）①日期；②`s += day`；③`s = 0`　（2）C

---
## 解析
先按日期排序并依次累加每天销量，每处理完一周（索引余数为 6）就写入该周结果并清零；折线图的横、纵坐标分别应使用已经构造的 `weeks` 和 `sales` 列表。
