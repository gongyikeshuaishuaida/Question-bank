# 题目 14

14. 学校科技小组成员收集了该校校史展厅某一天的环境监测数据。将监测数据导出，存于 `data.xlsx` 文件中，部分数据如图 a 所示。现要对数据进行分析，请回答下列问题。

![[attachments/202601宁波三锋高二期末_14_题图1.png]]

(1) 将 `data.xlsx` 中的数据保存在 DataFrame 对象 `df` 中，若要编写 Python 程序找出声音高于 80 分贝的记录数，下列方法中，不正确的是   ▲   （单选，填字母）。

- B. 根据 `df` 中的“噪音”列筛选出噪音高于 80 分贝的数据存入 `dff`，对 `dff` 使用 `count()` 函数  
- C. 根据 `df` 中的“噪音”列筛选出噪音高于 80 分贝的数据存入 `dff`，对 `dff` 中的“时”数据列使用 `count()` 函数

(2) 在 (1) 的分析过程中发现记录中存在无效数据（>130 分贝），首先需要去除无效数据，并结果存入 `df1` 中，实现该功能的部分 Python 程序如下，在划线处填入合适的语句。

## 答案

**正确答案：** (1) B；(2) `df[df["噪音"] <= 130]`；(3) ① B，② D；(4) `"噪音", ascending=False`

---

## 解析

`dff["噪音"].count()` 或 `dff["时"].count()` 都能统计筛选后记录数；直接对整个 `dff` 使用 `count()` 会得到各列非空值计数的 Series，不是单个记录数，故 (1) 选 B。无效噪音数据为大于 130 的记录，应筛选保留 `<=130`。为了绘制图 b，应按“时”分组并保留“时”列作为横坐标，所以 ① 用 B，② 用 D。要让平均噪音最大时段排在第 0 行，应按“噪音”降序排序。
