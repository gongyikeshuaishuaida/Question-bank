# 题目 14

某社区有两个超市，分别为超市 A 和超市 B，现要分析 2 月份超市收入情况和商品消费情况，部分数据如第 14 题图 a 所示。请回答下列问题：

![[attachments/202504台州山海_14_图a.jpg]]

![[attachments/202504台州山海_14_图b.jpg]]

(1) 在对表格进行数据整理时发现，关于"汤达人方便面"的记录可能存在的数据问题是 ▲ （单选，填字母：A. 数据缺失 / B. 数据异常 / C. 逻辑错误 / D. 数据格式不一致）

(2) 统计两个超市 2 月份收入总额并绘制如第 14 题图 b 所示的柱形图，部分 Python 程序如下：

```python
# 读取如第 14 题图 a 所示数据，保存到 DataFrame 对象 df 中，代码略
df.insert(0, "超市名称", "")
for i in range(len(df)):
    df.at[i, "超市名称"] = df.at[i, "数据来源"][0:3]
df1 = df.groupby("超市名称", as_index=False).实付价格.sum()
plt.bar( ▲ , df1.实付价格)
plt.show()
```

(3) 现要在对象 `df` 中筛选出超市 B 的数据，以便进一步分析，请在划线处填入合适的代码。

```python
df2 = df[ ▲ ]
```

(4) 为统计分析 2 月份超市 B 商品类别平均消费水平，筛选出平均消费金额最低的 3 种商品类别数据，请在划线处填入合适的代码。

```python
dfg = df2.groupby("商品类别", as_index=False).实付价格. ①
```

方框中应填入的语句为 ▲ （多选，填字母）。

- A. `dfg.sort_values("平均消费金额", ascending=False).head(3)`
- B. `dfg.sort_values("平均消费金额", ascending=False).tail(3)`
- C. `dfg.sort_values("平均消费金额", ascending=True)[0:3]`
- D. `dfg.sort_values("平均消费金额", ascending=True)[0:4]`

---

## 答案

**正确答案：**

(1) D

(2) `df1.超市名称`（或 `df1["超市名称"]`）

(3) `df.超市名称 == "超市B"`（或 `df["超市名称"] == "超市B"`）

(4) ① `mean()`；② B、C

---

## 解析

(1) "汤达人方便面"的"数据来源"格式与其他记录不一致。

(2) 柱形图横坐标为超市名称。分组求和后 x 轴为 `df1.超市名称`。

(3) 布尔索引筛选超市 B。

(4) ① 分组后求平均用 `mean()`。② 取平均消费最低的 3 种：B（降序后取尾 3）和 C（升序取前 3）均可。
