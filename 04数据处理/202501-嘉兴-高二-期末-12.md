# 题目 12
小姜从在线电影数据库爬取电影信息保存到“电影数据集.xlsx”，如下图 a，并用 Python 分析和可视化。

![[attachments/202501嘉兴_12_图1.jpg]]

（1）C3 单元格的数据存在______问题。（单选：A. 数据缺失 / B. 数据重复 / C. 逻辑错误）

（2）用公式“（好评数×10+中评数×6+差评数）/（好评数+中评数+差评数）”计算评分：
```python
df["评分"]=(df["好评数"]*10+df["中评数"]*6+df["差评数"])/(______)
```
可填入的代码有______（多选）。

- A. `df[["好评数"]+["中评数"]+["差评数"]]`
- B. `df["好评数"]+df["中评数"]+df["差评数"]`
- C. `df[["好评数","中评数","差评数"]].count(axis=1)`
- D. `df[["好评数","中评数","差评数"]].sum(axis=1)`

（3）统计评分最高的 250 部电影：
```python
df2=df.sort_values("评分", ascending=False)
df2=______
```
选项：A. `df.head(250)` / B. `df2.head(250)` / C. `df.tail(250)` / D. `df2.tail(250)`。

（4）绘制评分最高 250 部电影中制片地区为“亚洲”的各国家电影数量柱形图（图 b）：

![[attachments/202501嘉兴_12_图2.jpg]]

```python
df3=df2[①=="亚洲"]
df4=df3.groupby("制片国家",as_index=False).片名.count()
plt.bar(df4.制片国家, ②, label="数量")
```
---
## 答案
（1）C

（2）B、D

（3）B

（4）① `df2["制片地区"]`；② `df4["片名"]`
---
## 解析
C3 本应为电影类型却出现导演姓名，属于逻辑错误。分母可逐列相加或按行求和；降序排序后取前 250 行；筛选“亚洲”后，以片名计数列作为柱高。
