（1）统计各品牌销售总金额，筛选销售额最高的5个品牌并绘制柱形图。补全程序：

```python
import matplotlib.pyplot as plt
import pandas as pd

plt.rcParams["font.sans-serif"] = ["simhei"]
df = pd.read_excel("手机门店销售数据.xlsx")
grp = df.groupby("①", as_index=False)["销售价格（元）"].sum()
grp = grp.sort_values("销售价格（元）", ascending=False).②
x = grp["品牌"]
y = grp["销售价格（元）"]
plt.bar(x, y)
plt.title("门店销售额TOP5品牌统计图")
plt.show()
```

（2）统计各店员销售业绩，并找出4月销售冠军和亚军。题给输出示例如下：

```text
张雨晴4月份销售额:229416
李浩宇4月份销售额:209674
王佳琪4月份销售额:193617
陈俊泽4月份销售额:196918
4月份销售冠军:张雨晴 4月份销售亚军:李浩宇
```

补全程序：

```python
dic = {}
for i in df.index:
    sta = df.at[i, "销售店员"]
    if sta in dic:
        dic[sta] = ①
    else:
        dic[sta] = df.at[i, "销售价格（元）"]

m1 = m2 = 0
sta1 = sta2 = ""
for j in dic:
    ②
    print(j + "4月份销售额:" + str(count))
    if count > m1:
        m2 = m1
        sta2 = sta1
        m1 = count
        sta1 = j
    elif ③:
        m2 = count
        sta2 = j
print("4月份销售冠军:" + sta1, "4月份销售亚军:" + sta2)
```

## 答案

（1）① `品牌`　② `head(5)`（或`head()`）

（2）

- ① `dic[sta] + df.at[i,"销售价格（元）"]`
- ② `count = dic[j]`
- ③ `count > m2`（`>=`也可）

---

## 解析

第（1）问先按“品牌”分组求和，再按销售金额降序排列并取前5行。第（2）问用字典把同一店员的每笔销售额累加；遍历字典时同时维护当前第一名和第二名，若新成绩超过第一名，原第一名顺延为第二名，否则只在超过当前第二名时更新亚军。
