# 题目 14

“三位一体”学考等级折算。原始数据、考生等级、折算表及统计图如下。

（1）该考生折算分是多少？  
（2）程序中 `m=______①______` 可多选（A.`df.at[i,j]` / B.`df[i][j]` / C.`df[j][i]` / D.`df[i,j]`），字典累加语句为______②______。  
（3）按班级平均总分降序后，`score=df2.at[2,"总分"]`，补全：

```python
df3 = ______③______
plt.bar(______④______, ______⑤______)
```

## 答案

**正确答案：** （1）96；（2）① A、C，② `s += cj[m]`；（3）③ `df2[df2.总分 >= score]`，④ `df3.班级`，⑤ `df3.总分`

---

## 解析

8 个 A、1 个 B、1 个 C 折算为 96。可用 `at` 或先列后行访问单元格；筛选不低于第三名分数可保留并列，柱形图横轴为班级、纵轴为平均总分。
