# 题目 10

某研究小组开发“智能门禁系统”。系统使用智能摄像头采集并识别人脸图像，也可以采用 RFID 读卡器读取校园卡数据。若人脸识别成功或校园卡识别成功，则开启闸机，否则通过电子屏与扬声器示警。系统会记录每一条识别信息至服务器，失败信息添加时，姓名统一为“***”，卡号为“FFFFFF”。

（1）服务器端程序采用 Flask Web 框架编写，若终端设备某次上传识别结果的部分 URL 为 `http://192.168.1.50:8080/upload`，则服务器 IP 地址是 **192.168.1.50**。

（2）请从题干所提及的设备中，分别列举一种输入、输出设备：

| 设备分类 | 设备名称 |
|---|---|
| 输入设备 | 智能摄像头（或 RFID 读卡器） |
| 输出设备 | 电子屏（或扬声器、闸机） |

（3）该系统卡号采用十六进制编码，下列选项中不能作为该系统卡号的是（单选）：

- A．`3D5F29`
- B．`7E8A93`
- C．`2G5B34`

答案为 **C**，因为十六进制数字只能使用 0—9 和 A—F，不能出现 G。

## 答案

（1）`192.168.1.50`；（2）输入设备为智能摄像头或 RFID 读卡器，输出设备为电子屏、扬声器或闸机；（3）C；（4）①B ②A ③C；（5）加装补光灯等合理措施。

## 解析

服务器 IP 是 URL 中端口号前的地址。成功率统计需先按日期对成功记录计数，再利用成功数除以成功数与失败数之和，最后以日期为横轴绘图；暗光问题可通过改善照明或提升摄像头、算法的暗光能力解决。
