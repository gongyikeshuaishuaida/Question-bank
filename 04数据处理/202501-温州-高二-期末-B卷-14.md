# 题目 14

小华收集 2024 年 11 月 4 日 12 时国家地表水质数据，分析浙江省水质类别 I、II 在各流域的分布：

![[attachments/202501温州B_14_图1.png]]

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_excel("data.xlsx")
# 筛选出 I 类或 II 类水质的数据存于变量 df，代码略
df = df[df.站点情况 == "正常"]

# 此处是方框处依次填入下列语句中的 3 条，代码略：
# ① df = df[df.省份 == "浙江省"]       # 筛选
# ② df = df.sort_values("水质类别", ascending=True)  # 升序排序
# ③ df = df.sort_values("流域", ascending=True)    # 升序排序
# ④ df = df.groupby("流域", as_index=False).水质类别.count()  # 分组计数

plt.bar(x, height)
# 设置绘图参数，绘制柱形图，代码略
```

（1）站点情况为“维护”的记录存在缺失，以下不可行的方法为：

- A. 忽略
- B. 采用平均值填充
- C. 采用随机值填充

答案：C。

（2）程序中应依次执行的语句为 `①④②`（即 `142`）：筛选浙江省、按流域分组计数、按水质类别升序排序。

（3）`plt.bar(x,height)` 的正确赋值为 A：`x=df.流域`，`height=df.水质类别`。

（4）获取太湖流域溶解氧平均值，答案可为 `BA`、`CAB` 或 `BCA`（筛选太湖记录并计算平均值；按流域分组后再筛选、平均也可）。

（5）在监测点分布均匀且数量相同的前提下，图 b 显示浙闽片河流水质相对较好，选 C。

---
## 答案
**正确答案：** （1）C　（2）142　（3）A　（4）BA 或 CAB 或 BCA　（5）C

---
## 解析
缺失值不能用随机值无依据地填充；筛选、分组计数、排序的顺序对应 `①④②`。柱形图横轴为流域、柱高为计数结果。图 b 中 I、II 类水质数量占比最高的流域为浙闽片河流，因此相对水质较好。
