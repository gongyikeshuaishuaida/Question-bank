# 题目 08

某高中图书馆管理员整理出了 2024 年学校图书借阅情况的数据，保存在 `book.xlsx` 文件中，部分数据如图所示。编写 Python 程序，统计并输出全年最受学生欢迎的 3 类图书。

![[attachments/202506名校联盟高二_08_数据表.png]]

```python
import pandas as pd
df=pd.read_excel("book.xlsx")  # 读文件中的数据
df=df[df.身份类型=="学生"]   # 筛选学生数据
df=df.rename(columns={"借阅起止日期":"借阅次数"})  # 修改列名
①/②/③/④/⑤/⑥  # 此处是方框处
print(dfr)
```

方框中的代码由下列语句中的部分语句组成：

① `dfg=df.groupby("图书类别",as_index=False).count()`

② `dfg=df.groupby("图书类别",as_index=False).sum()`

③ `dfs=dfg.sort_values("借阅次数",ascending=False)`

④ `dfs=dfg.sort_values("借阅次数")`

⑤ `dfr=dfs.head(3)`

⑥ `dfr=dfs.tail(3)`

要实现上述功能，下列选项正确的是（   ）

- A. ①③⑥
- B. ②③⑤
- C. ①④⑥
- D. ②④⑤

---
## 答案

**正确答案：** C

---
## 解析

每条借阅记录代表一次借阅，按图书类别计数后，按借阅次数升序排列并取末尾 3 类，即 ①④⑥。
