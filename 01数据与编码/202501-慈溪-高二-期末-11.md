# 题目 11

某 Python 程序如下：

```python
from random import randint

k = randint(0, 2)
for i in range(len(n)):
    s = ""
    x = int(n[i]) // 2**k + int(n[i]) % 2**k * 2**(4-k)
    while len(s) < 4:
        r = x % 2
        s = str(r) + s
        x = x // 2
    print(s, end="")
```

若 `n="36"`，则执行上述程序段后，输出结果不可能是（　　）

- A. `"11001001"`
- B. `"00110110"`
- C. `"01101100"`
- D. `"10010011"`

---

## 答案

**正确答案：** C

---

## 解析

`k` 分别取 0、1、2 时，程序相当于对每个 4 位二进制数循环右移相应位数。`3、6` 的输出分别为 `00110110`、`10010011`、`11001001`，因此 `01101100` 不可能出现。
