# 题目 09

阅读下列材料，回答第9至11题：

某台无人售货机某月的销售数据整理后存入列表 `a` 中，列表 `a` 的每个元素由订单号、设备ID、商品名称、支付时间、支付金额五项构成，例如 `["749375954","EA07631","可口可乐","2024/12/3 9:41:00",3.0]` 表示列表 `a` 中的某个元素。

9. 若某区域计划投放1000台无人售货机。现对每台机器的“设备ID”采用数字0-9及字母A-F进行编码，最少需要的位数是（   ）

- A. 2
- B. 3
- C. 5
- D. 7

10. 下列程序段与流程图（第10题图）描述的算法一致的是（   ）

11. 对数据中的“设备ID”进行加密，部分程序如下：

```python
a = ""; j = int(input())      #j为移动位数
for i in range(len(s)):
    if "A" <= s[i] <= "Z":
        a += chr((ord(s[i])+3-ord("A"))%26+ord("A"))
    elif "a" <= s[i] <= "z":
        a += chr((ord(s[i])-100)%26+97)
    else:
        a += s[i]
a = a[j:] + a[:j]
```

若 `s` 为 `"EA07631"`，`j` 为2，则 `a` 的值为（   ）

- A. BX07631
- B. 07631BX
- C. 07631HD
- D. 31HD076

---

## 答案

**正确答案：** B

---

## 解析

数字0-9和字母A-F共16个编码符号。2位最多表示 `16^2=256` 台，不足1000；3位可表示 `16^3=4096` 台，所以最少3位。
