# 题目 10

10. 有如下 Python 程序段：

```python
def d2b(x):
    t = ""
    for i in range(4):
        t = str(x % 2) + t
        x = x // 2
    return t

k = int(input("输入一个十进制数:"))
BCD = ""
while k > 0:
    r = k % 10
    BCD = d2b(r) + BCD
    k = k // 10
print(BCD)
```

执行该程序段后，输入 `18`，则输出的内容为（   ）

- A. `00011000`
- B. `10000001`
- C. `10010`
- D. `11000`

---

## 答案

**正确答案：** A

---

## 解析

程序将十进制数的每一位转为 4 位二进制（BCD 编码）。输入 18：个位 `r=8`，`d2b(8)="1000"`；十位 `r=1`，`d2b(1)="0001"`。拼接：`"0001"+"1000"="00011000"`。
