# 题目 11
ASCII 码在计算机内部用 8 位二进制存储。例如字符 `"A"` 的十进制 ASCII 码值为 65，存储为 `"01000001"`。

（1）字符 `"C"` 的十进制 ASCII 码值为 67，则其 8 位二进制编码是______（单选：A. `01000010` / B. `01000011`）。

（2）补全程序：
```python
def func(c):
    list = [64,32,16,8,4,2,1]
    ans = "0"
    for i in range(len(list)):
        if c >= list[i]:
            ans += "1"
            ①
        else:
            ②
    return ans
```
---
## 答案
（1）B

（2）① `c=c-list[i]`；② `ans=ans+"0"`
---
## 解析
67 等于 `64+2+1`，8 位二进制为 `01000011`。每确定一个权值位为 1 后扣除该权值，否则补 0。
