# 题目 15

15. 某大学规定学生每天完成一次跑步任务，整个跑步路线分 6 个打卡点依次编号为 1~6，学生在当天自由选择不同连续打卡点之间跑步进行打卡，系统不记录连续打卡的最后一次打卡记录。例如某学生依次跑至 1、2、3 号打卡点并打卡，系统只记录 `[1,2]`。系统自动统计学生当天是否跑完全部路线。例如：某学生的跑步打卡记录为 `[1,4,5]`，该生实际完成了跑步路线的 1-2 与 4-6 路段，还有 2-4 路段未完成。现通过给定的学生跑步打卡记录，编写 Python 程序统计学生跑步任务的完成情况。请回答下列问题：

(1) 若给定的学生跑步打卡记录如第 15 题图所示，请写出完成跑步任务的学生编号为 ______（编号之间用逗号间隔）。

(2) 定义如下 `orga(t)` 函数，参数 t 是某位学生的跑步记录，例如 `[1,4,5]`，函数功能是补充完整学生完整打卡点并对连续打卡点进行压缩处理。

```python
def orga(t):
    res = t[0] * 10
    p = 1
    j = 1
    while j < len(t):
        if t[j] - t[j-1] == p:
            res = res // 10 * 10 + t[j]  # 表示一个完成的区段
            t.pop(j)  # t.pop(j) 表示删除列表 t 中索引为 j 的元素
            j -= 1
            p += 1
        else:
            if p == 1:
                t[j-1] = res + res // 10 + 1
            else:
                t[j-1] = res + 1
            res = t[j] * 10
            p = 1
        j += 1
    if p == 1:
        t[j-1] = res + res // 10 + 1
    else:
        t[j-1] = res + 1
    return t
```

## 答案

**正确答案：** (1) 4，6；(2) 2；(3) ① `a[p]%10 < a[p+1]//10`；② `p += 1`；③ `rsu = sortv(stu[i])`

---

## 解析

系统只记录连续打卡的最后一次打卡前的记录，需要先补全并压缩连续路段。根据表中记录推得只有 4 号和 6 号学生覆盖了完整路线。`orga([3,4,4,5,1])` 中连续条件成立两次，所以加框处 `p+=1` 执行 2 次。`sortv` 先排序再合并可连接或重叠的区间；当两个区间不能连接时需要移动 p，主程序需把排序合并结果赋给 rsu。
