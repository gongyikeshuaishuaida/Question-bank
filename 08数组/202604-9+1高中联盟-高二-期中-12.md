# 题目 12

12. 有如下 Python 程序段：

```python
from random import randint
n = 6
a = [randint(0, 4) * 2 + 1 for i in range(n)]
# randint(a,b),随机生成一个[a,b]范围内的整数
for i in range(2):
    j = i + 1
    while j < n - 1:
        if i % 2 == 0:
            if a[j-1] < a[j] and a[j] > a[j+1]:
                j += 2
            else:
                a[j] += 1
        else:
            if a[j-1] > a[j] and a[j] < a[j+1]:
                j += 2
            else:
                a[j] -= 2
```

运行后，数组 `a` 中的值可能的是（   ）

- A. `[2, 4, 3, 5, 1, 3]`
- B. `[1, 4, 3, 10, 0, 3]`
- C. `[9, 10, 3, 5, 7, 5]`
- D. `[3, 10, 9, 10, 5, 7]`

---

## 答案

**正确答案：** D

---

## 解析

数组初始值均为 1 到 9 的奇数。第一轮处理奇数下标位置，若不满足峰值条件则加 1 变为偶数；第二轮处理偶数下标位置，若不满足谷值条件则减 2，仍保持奇数。A 的第 0 个元素不可能为偶数；B 中 0 不可能出现；C 中对应位置违反第二轮处理后的约束；D 可能出现。
