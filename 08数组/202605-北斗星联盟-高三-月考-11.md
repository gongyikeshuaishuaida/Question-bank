# 题目 11

11. 有如下 Python 程序段：

```python
a = [1, 2, 5, 5, 6, 7, 8, 11]
n = len(a)
c = [0] * (n+1)
for i in range(n):
    k = a[i]
    if k > n:
        k = n
    c[k] += 1
k = n
while c[k] < k and k > 0:
    k -= 1
    c[k] += c[k+1]
```

执行该程序段后，`k` 的值为（   ）

- A. 4
- B. 5
- C. 6
- D. 8

---

## 答案

**正确答案：** B

---

## 解析

数组 `c` 先统计各数值出现次数，大于 `n` 的值计入 `c[n]`。随后从 `k=8` 向下做后缀累计，使 `c[k]` 表示大于等于 `k` 的元素个数。当 `k=5` 时，`c[5]=6≥5`，循环停止，因此结果为 5。
