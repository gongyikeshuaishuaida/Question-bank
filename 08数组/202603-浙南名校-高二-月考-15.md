# 题目 15

学校艺术节的文艺汇演在报告厅举行，舞台的使用需要演出班级申请后使用。小明开发了一个简单的舞台预约管理系统，用于模拟班级的预约和取消操作。系统输入格式如下：若输入以“预约”开头，后面两个数字为预约开始时间和持续时长；若能找到符合班级预约要求的空闲时间段则预约成功，系统按照预约顺序分配舞台使用编号，起始编号为 1；若输入“取消”加编号，系统会查找指定编号并释放相应的预约时间段。

假设舞台可预约的时间范围为 0 到 280，第 15 题图 a 为舞台申请情况，图 b 为时间段分配情况。

（1）若舞台的可预约时间为 0～60，在执行图 a 的前 2 行输入后，系统分配的时间段为：`0-9：空闲`，________，`30-39：空闲`，`40-54：110班 2`，`55-60：空闲`。

（2）定义如下 `fp(sch, req, fid)` 函数，将预约班级分配到指定的时间段。参数 `sch` 存储每个时间段的预约情况，参数 `req` 为单次预约信息，参数 `fid` 为下一个可分配的编号。

```python
def fp(sch, req, fid):
    st, time = int(req[2]), int(req[3])
    ed = st + time - 1
    i = 0
    while i < len(sch):
        block = sch[i]
        if ________① and block[2] <= st and block[3] >= ed:
            sch[i] = [fid, True, st, ed]
            if block[2] < st:
                sch = sch[:i] + [[0, False, block[2], st-1]] + sch[i:]
            i += 1  # 加框处
            if ed < block[3]:
                sch = sch[:i+1] + [[0, False, ed+1, block[3]]] + sch[i+1:]
            return sch, fid
        i += 1
    return sch, -1
```

（4）测试时发现，连续的空闲时间段没有整理到一起，导致部分持续时长较长的预约失败。现编写 `zl(sch)`，将连续的空闲时间段合并并返回整理后的 `sch` 列表。

- B. B 加框处

## 答案

（1）`10-29：105班 1`

（2）

- ① `not block[1]`（或 `block[1] == False`）
- ② A

（3）

- ① `block[0] == fid`
- ② `fp(sch, req, fid)`

（4）B、C

---

## 解析

（1）第一个预约从 10 开始、持续 20，故占用 10～29，编号为 1。

（2）只有空闲时间段才能分配，因此应判断 `not block[1]`。当预约前还有空闲区间时，代码会在当前位置前插入一个元素，原预约元素的下标随之右移，所以 `i += 1` 必须与插入语句一起放入 `if block[2] < st` 内。

（3）取消时按预约编号查找已预约区间；预约时调用 `fp` 并接收其返回的列表和结果编号。

（4）取消操作会产生可能与相邻空闲段连续的新空闲段，应在取消后立即整理（B），或在每次操作结束时统一整理（C）。A 位于预约分支内，不能保证取消后、下一次预约前已经完成合并。
