# 题目 13

自习室噪声提醒装置每秒采集一次噪声，若 1 分钟内超过 50 分贝的噪声大于 30 次则提醒。

```python
d = [0] * 60
count = 0
①
while True:
    # 接收一次数据存入 val
    if d[i] > 50 and val <= 50:
        ②
    elif d[i] <= 50 and val > 50:
        count += 1
    ③
    i = (i + 1) % 60
    if count > 30:
        print("噪声过大")
```

（1）填空：① `i = -60`（`-60` 到 `59` 均可）；② `count -= 1`；③ `d[i] = val`。

（2）改善方法示例：提高采集频率；将噪声阈值由 50 分贝调整为 40 分贝；将提醒阈值由 30 次调低；更换灵敏度更高的声音传感器；提高传输速率或增加传感器提高采集精度。

---
## 答案
**正确答案：** （1）①`i` 取 -60～59 均可；②`count-=1`；③`d[i]=val`　（2）合理的数据采集或处理改进均可

---
## 解析
`d` 是长度为 60 的循环窗口。首次从负索引开始可将窗口视作已填满；新旧数据跨越 50 分贝阈值时只需增减一次计数，最后用新值覆盖窗口当前位置。
