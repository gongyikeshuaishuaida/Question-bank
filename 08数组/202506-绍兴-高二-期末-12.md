# 题目 12

12. 有如下 Python 程序段：

```python
# 生成 5 个随机整数，保存在列表 a 元素 a[0]~a[4]中，代码略
maxs = tmp = 0
left = right = 0
while right < 5:
    tmp += a[right]
    while left <= right and tmp > 0:
        tmp -= a[left]
        left += 1
    if right - left + 1 > maxs:
        maxs = right - left + 1
    right += 1
print(maxs)
```

执行该程序段后，输出结果为 3，则 `a[0]~a[4]` 的值可能为（   ）

- A. `[4, 0, 0, -2, -3]`
- B. `[-2, -3, -4, 6, 7]`
- C. `[-7, 7, 1, 2, 3]`
- D. `[-6, 2, -1, 6, 0]`

---

## 答案

**正确答案：** D

---

## 解析

算法找最长的子数组使得其和≤0。D：[-6,2]和=-4≤0,len=2；[-6,2,-1]和=-5≤0,len=3（maxs=3）。其他选项的最长满足条件的子数组长度不等于3。
