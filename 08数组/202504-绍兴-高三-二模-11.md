# 题目 11

11. 数组元素 `s[0]~s[5]` 为随机正整数，执行如下 Python 程序段后，`s[0]~s[5]` 的值可能为（　　）

```python
for i in range(5):
    for j in range(5, i, -1):
        if s[j] % 2 < s[j - 1] % 2:
            s[j], s[j - 1] = s[j - 1], s[j]
```

- A. 6, 2, 1, 3, 7, 7
- B. 1, 3, 5, 7, 9, 2
- C. 10, 8, 6, 3, 2, 1
- D. 1, 2, 5, 5, 6, 7

---
## 答案

**正确答案：** A

---
## 解析

程序按相邻元素的奇偶性进行交换，将偶数逐步移到奇数之前，但同一奇偶组内的相对次序还受初始随机值影响。选项A可以由某组随机正整数经过该程序得到。
