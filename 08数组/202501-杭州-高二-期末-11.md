# 题目 11

有如下 Python 程序段：

```python
# 读取 n 个数据，存入列表 a，代码略
tmp = 1
ans = 0
for i in range(1, len(a)):
    if a[i] >= a[i - 1]:
        tmp = tmp + 1
    else:
        if tmp > ans:
            ans = tmp
        tmp = 1
```

若列表 `a` 有 6 个元素，运行该程序段后 `ans` 的值为 3，则列表 `a` 的值可能是（　　）

- A. `[2,4,4,6,3,1]`
- B. `[5,9,8,2,4,6]`
- C. `[6,5,5,9,2,1]`
- D. `[1,3,2,2,1,6]`

---

## 答案

**正确答案：** C

---

## 解析

程序只在出现下降时把刚结束的非递减连续子段长度写入 `ans`，最后一个子段不会在循环结束后补记。C 中子段 `[5,5,9]` 长度为 3，随后遇到 `2` 时被写入 `ans`；其余选项得到的 `ans` 分别为 4、2、2。
