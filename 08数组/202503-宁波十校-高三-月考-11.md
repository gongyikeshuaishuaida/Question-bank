# 题目 11

11. 有如下 Python 程序段：

```python
b = []
n = len(a)
for i in range(n):
    for j in range(len(a[i])):
        if i < j and a[i][j] not in b:
            b.append(a[i][j])
```

执行该程序段后，若数组 `b` 的值为 `[3,6,7,9]`，那么数组 `a` 的值不可能的是（   ）

- A. `[[1,3,6,7],[2,4,7,9],[5,2,3,7]]`
- B. `[[1,3,6,7],[1,3,6,7],[1,3,6,9]]`
- C. `[[1,3,6,7],[2,4,9,7],[5,2,3,8]]`
- D. `[[1,3,6,7],[2,6,9,7],[5,2,3,3]]`

---

## 答案

**正确答案：** C

---

## 解析

程序按行扫描二维数组中满足 `i<j` 的元素，并按首次出现顺序去重加入 `b`。C 中前两行会得到 `[3,6,7,9]`，第三行的 `a[2][3]=8` 还会被加入，最终多出 8，因此不可能得到题设的 `b`。
