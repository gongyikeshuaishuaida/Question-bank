# 题目 15

某图书馆对图书位置进行了编号，依次为 `0~n-1`。借阅规则如下：

① 借书期限：7 天内免费（含 7 天）；
② 超过 7 天后，每逾期 1 天收费 2 元（不满 1 天按 1 天算），封顶 30 元。

例如某书的借出时间为第 3 天，归还时间为第 14 天，则该书的逾期费用为 10 元。

现编写程序，根据已有的借还书记录，输出已还图书的逾期费用及图书馆内剩余图书数。某时段的借阅信息如下表：

| 时间（天） | 书号 | 类型（1=借出，-1=归还） |
| --- | --- | --- |
| 10 | B001 | 1 |
| 12 | B002 | 1 |
| 15 | B001 | -1 |
| 18 | B003 | 1 |
| 20 | B002 | -1 |
| 25 | B004 | 1 |

（1）若某书的借出时间为第 5 天，归还时间为第 15 天，则该书的逾期费用为 ________ 元。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码：

```python
# 读取图书馆图书数量 m，代码略
# 读取借还书记录数量 n，书号、时间（天）、类型分别存入数组 sh、sj、lx
# 类型 1=借出，-1=归还，代码略
a = [""] * m  # 存储借出的书号
b = [0] * m   # 存储借出时间
cnt = m       # 剩余图书数（初始为 m，借出时-1，归还时+1）
for i in range(n):
    if lx[i] == 1:  # 借出操作
        k = 0
        while k < m and a[k] != "":
            k += 1
        a[k] = sh[i]
        b[k] = sj[i]
        cnt -= 1  # 借出后剩余图书数-1
    else:  # 归还操作
        cnt += 1  # 归还后剩余图书数+1
        k = 0
        while k < m and ________①________:
            k += 1
        time = sj[i] - b[k]  # 计算借阅天数
        overdue = ________②________  # 逾期天数
        if overdue > 0:
            fee = overdue * 2
            if fee > 30:
                fee = 30
        else:
            fee = 0
        if ________③________:
            fee = 0
        print("书号", sh[i], "的逾期费用为", fee, "元")
print("图书馆内还有", cnt, "本书")
```

（3）程序中计算借阅天数的加框处代码有误，请改正。

---

## 答案

（1）8

（2）

① `a[k] != sh[i]`
② `time - 7`
③ `overdue < 0`

（3）将 `time = sj[i] - b[k]` 改为：

```python
time = sj[i] - b[k] + 1
```

---

## 解析

（1）借阅天数包含借出当天和归还当天，共 `15-5+1=11` 天；逾期 `11-7=4` 天，费用为 `4×2=8` 元。

（2）归还时要在数组 `a` 中寻找与当前书号 `sh[i]` 相同的位置，因此循环继续条件为 `a[k] != sh[i]`。逾期天数等于借阅天数减去免费期限 7 天，即 `time-7`；当 `overdue<0` 时费用应为 0。

（3）借阅天数需同时计入借出日和归还日，所以应在日期差上加 1。以题干示例为例，`14-3+1=12` 天，逾期 5 天，费用为 10 元，与题意一致。
