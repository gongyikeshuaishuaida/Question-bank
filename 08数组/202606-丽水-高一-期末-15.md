# 题目 15

15. 有如下 Python 程序段：

```python
t = [0, 0, 0, 0, 0]
num = [3, 8, 5, 2, 7]
for i in range(4):
    for j in range(i + 1, 5):
        if num[i] % 2 == num[j] % 2:
            t[i] = t[i] + 1
        else:
            t[j] = t[j] + 1
print(t[2] + t[4])
```

执行该程序段后，输出结果为（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C

---

## 解析

两数奇偶性相同时给较小下标 `i` 对应的 `t[i]` 加 1，不同时给较大下标 `j` 对应的 `t[j]` 加 1。遍历所有数对后，`t=[2,2,2,2,2]`，所以 `t[2]+t[4]=2+2=4`。
