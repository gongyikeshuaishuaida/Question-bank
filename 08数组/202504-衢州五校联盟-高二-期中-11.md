# 题目 11

11.有如下 python 程序段：

```python
import random
a=[0]*6;b=[0]*6;c=[1,0,0,0,0,0]
for i in range(6):
    a[i]=random.randint(0,5)
    # 随机产生一个[0,5]区间的整数
for i in range(6):
    b[a[i]]=b[a[i]]+1
for i in range(1,6):
    c[i]=c[i-1]+b[i-1]
```

执行该程序后，则 c 列表中各元素的值不可能的是（   ）

- A. `[1,1,2,4,5,6]`
- B. `[1,1,2,2,2,6]`
- C. `[1,2,2,3,6,6]`
- D. `[1,1,1,4,5,8]`

---
## 答案

**正确答案：** D

---
## 解析

`b` 统计 6 次随机取数在 0—5 各值上的出现次数，`c` 是这些计数的前缀和，因此最终 `c[5]` 必须为 6，且各项不能超过 6。D 的最后一项为 8，不可能出现。
