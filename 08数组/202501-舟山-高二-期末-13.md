# 题目 13

n 个选手参加跳水比赛，选手的最终得分 = 基础分 × 难度分。基础分的计算规则为：在 7 个裁判的打分（1~10）中去掉一个最高分和一个最低分，剩余 5 个分数相加即为基础分。

```python
# 输入选手数据，存储在列表 data 中
# data[i] 存储编号为 i(0~n-1) 的选手数据
# data[i][0] 存储姓名，data[i][1]~data[i][7] 存储 7 个裁判的打分，data[i][8] 存储难度系数，代码略

for i in range(n):
    tot = 0
    minv = 10
    maxv = ①
    for j in range(1, 8):
        tot += data[i][j]
        if data[i][j] > maxv:
            maxv = data[i][j]
        if data[i][j] < minv:
            minv = data[i][j]
    tot -= maxv + minv
    score = ②
    data[i].append(score)  # 在 data[i] 最后面追加数据

k = 0
for i in range(1, n):
    if data[i][9] > data[k][9]:
        ③

print(data[k][0], data[k][9])
```

(1) 某选手数据为 `['gm', 9, 9, 9, 8, 10, 6, 10, 3.0]`，则 `'gm'` 的得分为 ▲ 。

(2) 在划线处填入合适代码。

---

## 答案

**正确答案：**

(1) 135（或 135.0）

(2) ① `1`（或 `data[i][1]`）；② `tot * data[i][8]`；③ `k = i`

---

## 解析

(1) 7 个裁判分：9,9,9,8,10,6,10。去掉最高 10 和最低 6，剩余 9+9+9+8+10=45。得分 = 45 × 3.0 = 135。

(2) ① `maxv` 初始值应为可能的最小值（1）或取第一个裁判分。② 最终得分 = 基础分 × 难度系数。③ 打擂台记录最高分选手下标。
