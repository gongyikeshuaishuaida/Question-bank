# 题目 15

15. 某云计算平台有 `n` 台服务器（编号 0 到 `n-1`），可用于处理若干项目的计算任务。服务器设有负载量上限，表示能同时承载的最大计算总量。每个项目包含若干具有计算量的任务，如第 15 题图 a 所示。平台需将同一项目的任务合并后，合理分配给一台或多台服务器处理。分配时，优先分配给负载量最小的服务器（若负载量相同则选择编号最小的）；若分配后该服务器的负载量超出上限，则将超出部分继续分配给下一台负载量最小的服务器，直至计算量被完全分配或提示“服务器资源不足”。编写程序，根据上述方法进行计算任务分配。请回答下列问题：

![[attachments/202601湖州高二期末_15_题图1.png]]

(1) 若平台有 5 台服务器，服务器负载量上限为 90，初始负载量均为 0，分配完第 15 题图 a 中项目 A01、A02、B01 的计算任务后，各服务器的负载量如第 15 题图 b 所示。则分配完所有计算任务后，服务器 4 的负载量为   ▲   。

(2) 定义 `merge(task)` 函数，参数 `task` 列表每个元素表示一项计算任务，同一项目的任务连续存储。函数的功能是合并同一项目的计算任务，返回合并后计算任务的数量。

```python
def merge(task):
    m, j = len(task), 0
    for i in range(m):
        if i == 0 or task[i][0] != task[i - 1][0]:
            task[j] = task[i]
            j += 1
        else:
            task[i - 1][1] += task[i][1]  #加框处
    return j
```

## 答案

**正确答案：** (1) 15；(2) ① 4；② C；(3) ① `d = task[i][1]`；② `b[ma] += d` 或等价代码；③ `d = d - (mload - b[ma])` 或等价代码

---

## 解析

合并后项目计算量为 A01=70、A02=30、B01=80、B02=105。前三项分配后负载如图 b，B02 的 105 先把编号 3 的服务器从 0 填到 90，剩余 15 分配给编号 4，因此服务器 4 的负载为 15。`merge` 中每遇到一个新项目执行一次 `task[j] = task[i]`，共有 A01、A02、B01、B02 四个项目；合并同项目任务时应累加到当前合并项 `task[j-1]`。分配时 `d` 为当前项目计算量，若可直接放入最小负载服务器则累加；否则先填满该服务器，再把未分配的剩余量继续循环分配。
