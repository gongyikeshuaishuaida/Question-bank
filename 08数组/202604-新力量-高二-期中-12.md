# 题目 12

12. 某数牛小游戏的棋盘为 8 行 8 列。格子按行优先编号：

$$
\text{序号}=(\text{行号}-1)\times8+\text{列号}
$$

放置小牛的位置必须同时满足：

1. 序号为 1～64 的正整数；
2. 行号与列号之和为偶数；
3. 与每头已放置的小牛不同行、不同列；
4. 与每头已放置的小牛不构成八邻域相邻。

![[attachments/202604新力量_12_图1.png]]

玩家每次选择合法位置，合法放置次数加 1；若位置非法（含重复）则不放置且计数不变。

（1）玩家依次选择序号 `1、10、19、37`，合法放置次数为______。

（2）请在划线处填入合适代码。

```python
def getrowcol(num):
    row = (num - 1) // 8 + 1
    col = ①
    return row, col

def islegal(num, row, col, placed):
    if num < 1 or num > 64:
        return False
    elif (row + col) % 2 != 0:
        return False
    for (prow, pcol) in placed:
        if prow == row or pcol == col:
            return False
        if ②:
            return False
    return True

def countlegal(inputstr):
    legalcount = 0
    i = 0
    ③
    numstr = ""
    placed = []
    while i < n:
        ch = inputstr[i]
        if ch != ",":
            numstr += ch
            i += 1
        else:
            num = int(numstr)
            row, col = getrowcol(num)
            if islegal(num, row, col, placed):
                legalcount += 1
                placed.append([row, col])
            numstr = ""
            i += 1

    num = int(numstr)
    row, col = getrowcol(num)
    if islegal(num, row, col, placed):
        legalcount += 1
        placed.append((row, col))
    ④

s = input("请输入玩家选择的格子序号，序号之间用逗号分隔：")
print("合法放置次数：", countlegal(s))
```

---

## 答案

（1）3

（2）

① `(num - 1) % 8 + 1`（或 `num - (row - 1) * 8`）

② `abs(prow - row) <= 1 and abs(pcol - col) <= 1`

③ `n = len(inputstr)`

④ `return legalcount`

---

## 解析

序号 1 对应 `(1,1)`，合法；10 对应 `(2,2)`，与 `(1,1)` 斜向相邻，不合法；19 对应 `(3,3)`，合法；37 对应 `(5,5)`，合法，因此共 3 次。

列号可由序号对 8 取模换算。八邻域相邻意味着行差、列差的绝对值都不超过 1；同行、同列已在前一个判断中排除。主函数按字符串长度扫描逗号分隔的序号，最后返回累计合法次数。
