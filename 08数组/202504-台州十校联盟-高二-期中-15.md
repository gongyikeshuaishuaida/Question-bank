# 题目 15

某停车场对停车位置进行了编号，依次为0～n-1。停车场收费规则：半小时内免费（包括半小时）；半小时以上每小时4元（不满1小时的部分按1小时算），封顶40元。现编写程序，根据已有的出入车辆信息，输出已经出场车辆的停车费用及停车场内剩余的车辆数。某一时段的停车信息如下：

| 时间 | 车牌 | 类型 |
|---|---|---:|
| 07:10 | 浙A.1USRX | 1 |
| 07:18 | 浙A.UZ4PJ | 1 |
| 07:37 | 浙A.UZ4PJ | -1 |
| 08:07 | 浙A.8F6DZ | 1 |
| 08:35 | 浙A.1USRX | -1 |
| 09:29 | 浙A.431IW | 1 |

程序运行结果：

- 车辆浙A.UZ4PJ停车费用为0元
- 车辆浙A.1USRX停车费用为8元
- 停车场内还有2辆车

请回答下列问题：

（1）若一辆车的入场时间为06:15，出场时间为10:50，则该车辆的停车费为 ______ 元。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码：

```python
# 读取停车场车位的数量，存入 m，代码略
# 读取停车场入场出场记录数量 n，车牌、时间（转换为分钟）、出入场类型分别存入数组 cp、sj、lx 中，
# 出入场类型为 1 表示入场，代码略

a=[""]*m; b=[0]*m; cnt=0
for i in range(n):
    if lx[i]==1:
        k=0
        while k<m and a[k]!="":
            k+=1
        a[k]=cp[i]; b[k]=sj[i]
        ①
    else:
        cnt-=1; k=0
        while k<m and ②:
            k+=1
        a[k]=""
        time=sj[i]-b[k]
        fee=(time//60)*4  # 此处是方框处
        if fee>40:
            fee=40
        if ③:
            fee=0
        print("车辆"+cp[i]+"停车费用为"+str(fee)+"元")
print("停车场内还有"+str(cnt)+"辆车")
```

（3）程序加框处的代码有误，请改正。

---
## 答案

**参考答案：** （1）20；（2）① cnt+=1；② a[k]!=cp[i]；③ time<=30；（3）可改为 fee=((time-1)//60+1)*4，也可写为 fee=(time+59)//60*4（再保留40元封顶）。

---
## 解析

06:15到10:50共275分钟，超过30分钟后按5个计费小时收费，得到20元。入场时将车牌和时间写入首个空车位并将占用数加1；出场时按车牌查找对应车位，先减去占用数，计算停车时长，30分钟以内费用为0。原公式对31～59分钟会算成0元，应用向上取整的计费小时公式；40元封顶逻辑继续保留。
