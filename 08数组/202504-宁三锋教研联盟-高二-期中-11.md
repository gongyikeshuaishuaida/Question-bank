# 题目 11

11．给定列表 `a=[4,7,3,10,9,6]`，执行以下 Python 程序段后，列表 `a` 的值是（   ）

```python
for i in range(0, len(a) - 1, 2):
    if i > 0 and a[i] < a[i - 1]:
        a[i], a[i - 1] = a[i - 1], a[i]
    if i < len(a) - 1 and a[i] < a[i + 1]:
        a[i], a[i + 1] = a[i + 1], a[i]
```

- A. `[4,7,10,3,9,6]`
- B. `[7,4,3,10,9,6]`
- C. `[7,3,10,4,9,6]`
- D. `[4,7,10,9,3,6]`

---
## 答案

**正确答案：** C

---
## 解析

`i=0` 时先比较 `a[0]` 与 `a[1]`，再比较当前的 `a[0]` 与 `a[1]`，列表变为 `[7,4,3,10,9,6]`；`i=2` 时先将 3 与 4 交换，再将 4 与 10 交换，得到 `[7,3,10,4,9,6]`；`i=4` 时两个条件均不成立，最终选 C。
