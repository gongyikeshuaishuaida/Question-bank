# 题目 13

某十字路口红绿灯采用四相位（东西直行、东西左转、南北直行、南北左转）依次动态控制。每个相位的绿灯时长根据两个方向中较大的车辆数动态调整，调整范围为 10~30 秒。黄灯亮 3 秒后开始调整下一个相位。每辆车通过路口的平均时长为 2 秒。

![[attachments/202506衢州_13_图a.jpg]]

![[attachments/202506衢州_13_图b.jpg]]

(1) 若从 0 开始计时，东西直行相位最大车辆数为 20，下一个相位（东西左转）最大车辆数为 6，则南北直行相位的绿灯从第 ▲ 秒开始。

(2) 请在划线处填入合适的代码。

```python
base = 2; short = 10; long = 30
cur = 0
while True:  # 依次判定四相位的绿灯时长
    car = get_data()
    ①
    if car[cur + 1] > t:
        t = car[cur + 1]
    green = long
    if short <= t * base <= long:
        ②
    elif t * base < short:
        green = short
    # 调整该相位的绿灯时长并亮起，之后绿灯结束亮黄灯3秒
    cur = ③
```

---

## 答案

**正确答案：**

(1) 48

(2) ① `t = car[cur]`；② `green = t * base`；③ `(cur + 2) % 8`

---

## 解析

(1) 东西直行：20×2=40秒，限制为30秒+黄灯3秒=33秒结束。东西左转：6×2=12秒+黄灯3秒=15秒。南北直行从第33+15=48秒开始。

(2) ① 取当前方向车辆数。② 绿灯时长=2×车辆数。③ cur每次跳2（直行+左转配对），模8循环。
