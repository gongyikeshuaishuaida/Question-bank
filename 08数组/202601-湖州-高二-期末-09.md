# 题目 09

9. 数组 `d` 中存储 `n` 位同学的学号和身高数据，`d[0]` 为第 1 位同学的学号，`d[1]` 为第 1 位同学的身高，……以此类推。现要删除第 `x` 位同学的学号和身高数据。实现该功能的程序段如下，方框中应填入的正确代码为（   ）

```python
i = (x - 1) * 2
while i < len(d) - 2:
    __________
print(d[:i])
```

- A.
```python
d[i] = d[i + 1]
i = i + 1
```

- B.
```python
d[i] = d[i + 2]
i = i + 1
```

- C.
```python
d[i + 1] = d[i]
i = i + 2
```

- D.
```python
d[i] = d[i + 2]
i = i + 2
```

---

## 答案

**正确答案：** B

---

## 解析

每位同学占连续两个数据项。删除第 `x` 位后，要从删除位置开始把后面的数据整体前移 2 个位置。循环中每次令 `d[i] = d[i+2]`，并让 `i` 逐项加 1，最后输出到新长度位置。
