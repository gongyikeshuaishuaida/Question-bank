# 题目 11

11. 有如下 Python 程序段：

```python
a=[7,3,2,4,6,9]
n=len(a)
i=n-1
while i>=1:
    k=0
    for j in range(i):
        if a[j]<a[j+1]:
            a[j],a[j+1]=a[j+1],a[j]
            k=j
    ____________
```

若运行程序后，列表 `a=[9, 7, 6, 4, 3, 2]`，则划线处的语句可以为

- ① `i-=1`
- ② `i=k-1`
- ③ `i=k`
- ④ `i=k+1`

- A. ①③
- B. ②③
- C. ①④
- D. ②④

---
## 答案

**正确答案：** A

---
## 解析

这是对数组进行降序冒泡排序，`i-=1` 是标准地缩小下一轮边界，`i=k` 也可利用最后一次交换位置优化边界。`i=k-1` 会过早缩小范围，`i=k+1` 不能保证继续缩小并可能重复处理，因此可选 ①③。
