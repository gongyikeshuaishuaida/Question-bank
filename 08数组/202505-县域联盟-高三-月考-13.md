# 题目 13

某港口安排摆渡车将旅客从码头送往游轮。摆渡车满载或最早到达的乘客等待超过 120 秒时发车。摆渡车往返一次需要 10 分钟（600 秒），荷载 10 人。编写程序计算所需摆渡车总数。

(1) 某时间段内旅客到达数据为 `[[0,2],[120,8],[150,5],[200,22],[500,8]]`，需安排的摆渡车数量是 ▲ 。

(2) 请在划线处填入合适的代码。

```python
# 获取旅客的到达数据，按到达时刻升序存入列表 d
goback, waitlim = 600, 120  # 摆渡车往返时长, 旅客最大等待时长
bus = []  # 摆渡车返回时刻
①
w = 0
p = 0
for i in range(len(d)):
    t = d[i][0]
    if ②:
        if len(bus) > 0 and bus[0] <= d[p][0] + waitlim:
            bus.pop(0)
        else:
            s += 1
            bus.append(d[p][0] + waitlim + goback)
        w = 0
        p = i
    w += d[i][1]
    if w >= 10:  # 满载发车
        for j in range(w // 10):
            bus.append(t + goback)
        while len(bus) > 0 and bus[0] <= t and w >= 10:
            bus.pop(0)
            ③
        s += w // 10
        w = w % 10
        if w == 0:
            p = i + 1
        else:
            p = i

# 剩余的乘客安排摆渡车，代码略
# 输出所需的摆渡车数量 s，代码略
```

---

## 答案

**正确答案：**

(1) 5

(2) ① `s = 0`；② `t - d[p][0] > waitlim`；③ `w = w - 10`

---

## 解析

(1) 模拟调度过程：等待超时或满载发车，共需 5 辆摆渡车。

(2) ① 初始化摆渡车计数。② 检查最早等待乘客是否超过等待时限。③ 安排一辆已返回的摆渡车后，减少等待人数。
