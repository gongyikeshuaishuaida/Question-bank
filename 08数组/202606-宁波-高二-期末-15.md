# 题目 15

15. 某学校开展“书香班级”评选活动，每月统计各班学生的总阅读时长（单位：分钟），并根据阅读时长计算学生的月度阅读总分，用于评选“阅读之星”。学生的月度阅读总分由时长分和排位分相加得到。

①时长分根据学生的阅读时长通过分段函数计算，规则如第 15 题图 a 所示。阅读时长 120 分钟及以上的学生为活跃学生，参加评选。

![[attachments/202606宁波高二_15_图1.png]]

②排位分根据该学生时长分在所有参与评比的活跃学生中的相对位置计算：

$$
\text{排位分}=\left\lfloor\frac{f1+0.5\times f2}{n}\times 100\right\rfloor
$$

其中，`f1` 为时长分低于该学生的人数，`f2` 为时长分等于该学生的人数，`n` 为活跃学生总人数，结果向下取整。

(1) 假设学生小华的 3 月阅读时长为 560 分钟，若全校活跃学生总人数为 200 人，低于小华时长分的人数为 120 人，等于小华时长分的人数为 8 人，则他的排位分是 ______。

(2) 定义如下函数 `getTimeScore(t)`，功能为根据第 15 题图 a 计算时长分。

```python
def getTimeScore(t):
    if t < 240:
        return t // 6
    elif t < 480:
        return 40 + (t - 240) // 12
    elif t < 720:
        return 60 + (t - 480) // 16
    else:
        s = 75 + (t - 720) // 20
        if s > 100:
            return 100
        return s
```

以下表达式与加框处功能相同的是 ______（多选，填字母）。

- A. `return min(s, 100)`
- B. `return (s + 100 + abs(s - 100)) // 2`
- C.

```python
return s
if s > 100:
    return 100
```

- D.

```python
if s // 100 < 1:
    return s
else:
    return 100
```

## 答案

**正确答案：** (1) 62；(2) A、D；(3) ① `getTimeScore(t)`；② `ts=stu[2]`；③ `pre+=cnt[i]`

③也可写为 `pre=f1[i]+cnt[i]`。

---

## 解析

(1)

$$
\left\lfloor\frac{120+0.5\times 8}{200}\times100\right\rfloor
=\left\lfloor62\right\rfloor=62
$$

(2) 加框代码把 `s` 的上限限制为 100。A 直接取 `s` 与 100 的较小值；D 在 `s<100` 时返回 `s`，否则返回 100，功能相同。B 实际求的是两者中的较大值；C 在执行后续判断前已经返回 `s`，不能封顶。

(3) `getActive(data)` 先筛选阅读总时长不少于 120 分钟的活跃学生。`getRankScore` 中先调用 `getTimeScore(t)` 得到每位学生的时长分；遍历 `stuList` 时取出 `stu[2]` 并用 `cnt` 统计各分值人数；`pre` 保存低于当前分值的累计人数，处理完分值 `i` 后增加 `cnt[i]`，即可得到下一分值对应的 `f1`。主程序依次调用 `getActive(stuData)` 和 `getRankScore(stuData, act)` 得到排位分字典。
