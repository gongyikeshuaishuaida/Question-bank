# 题目 17

某医院某体检项目由于设备有限，体检中心对患者实行预约制度。该设备只在每天上午 7 点到 8 点开放（若 8 点有患者在体检等结束再关闭）。患者需提前一天在系统填写预约时间（预约时间为 7-8 点）。此项目每人用时相同，预约系统根据预约信息尽可能为多的患者完成体检。处理过程分两步：

① 按预约时间顺序体检。若出现预约时间在前一患者体检结束前，则修改此患者预约时间至前一患者结束时。

② 剩余未成功预约的患者按预约时间顺序插入空闲时间段。若空闲时长不足则无法插入。

程序运行界面如第 17 题图所示。

![[attachments/202501金华十校_17_图1.jpg]]

(1) 某天的患者预约时间为 `hz = ['07:20','07:30','07:35','07:50','07:55','07:55']`，该体检项目每人需要 15 分钟，则最多成功预约体检的患者数量为 ▲ 。

(2) 有函数 `trans(s, f)` 的代码如下：

```python
def trans(s, f):
    if f == 0:
        return int(s[:2]) * 60 + int(s[-2:])
    else:
        h = str(s // 60); m = str(s % 60)
        if len(h) == 1:
            h = '0' + h
        if len(m) == 1:
            m = '0' + m
        return h + ':' + m
```

若 `s = 465, f = 1`，调用 `trans(s, f)` 后，返回的结果是 ▲ 。

(3) 实现预约处理的 Python 程序如下，请在划线处填入合适的代码。

```python
# 导入预约时间列表 hz 并升序排列，代码略
# 步骤一，按时间顺序预约体检
m = int(input('请输入项目时长:'))
k = 0; kx = []
curtime, endtime = trans('07:00', 0), trans('08:00', 0)
while k < len(hz) and curtime < endtime:
    ①
    if t1 < curtime:
        print(k + 1, '号修改预约时间', trans(curtime, 1))
    else:
        print(k + 1, '号预约时间', trans(t1, 1), '成功')
        kx.append(curtime)
        kx.append(t1 - curtime)
        ②
    curtime += m
    k += 1

# 步骤二，剩余患者插入空闲时间
c = 0
while ③:
    t2 = kx[c + 1]
    if t2 < m:
        c += 2
        continue
    else:
        print(k + 1, '号修改预约时间', trans(kx[c], 1))
        if t2 > m:
            ④
            kx[c + 1] -= m
        else:
            c += 2
        k += 1

# 输出最多预约人数、未预约成功人员等信息，代码略
```

## 答案

**正确答案：**

(1) 4

(2) `07:45`

(3) ① `t1 = trans(hz[k], 0)`；② `curtime = t1`；③ `k < len(hz) and c < len(kx)`；④ `kx[c] += m`

---

## 解析

(1) 每人 15 分钟：07:20 成功；07:30 在前一人 07:35 结束前，改到 07:35；07:35 在前一人 07:50 结束前，改到 07:50；此时 `curtime` 加 15 分钟后为 08:05，不再满足步骤一的循环条件。剩余 07:50、07:55、07:55 三名患者按顺序插入空闲时段，07:00-07:20 的空闲段只能再插入 1 人。共 4 人。

(2) `f=1` 时是分转时间格式：465//60=7h, 465%60=45m → `"07:45"`。

(3) ① 将预约时间字符串转为分钟数。② 更新 curtime 为 t1。③ 循环条件：还有未处理预约且还有空闲时间段。④ 空闲时间起始点向后移动一个单位时长。
