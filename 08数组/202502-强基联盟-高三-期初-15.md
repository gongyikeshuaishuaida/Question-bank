# 题目 15

某游戏的地图可用 6 行 61 列的二维表表示，怪物从地图右侧（第 61 列）出现，每秒以一定速度向左移动，且不会跨行。玩家可以在地图上放置炸弹道具消灭怪物；若怪物走到第 1 列仍未被消灭，再向左走就会失败。

要消灭所有怪物，至少需要______个炸弹。

（2）定义 `b_sort()` 函数对怪物数据预处理：将到达第一列时间写入第三项，并按所在行、出现时间排序。

```python
def b_sort(mt):
    n = len(mt)
    f = list(range(n))
    for m in mt:
        m[2] = m[1] + int(60 / m[2])
    for i in range(n - 1):
        for j in range(0, n - i - 1):
            if mt[f[j]][0] > mt[f[j + 1]][0]:
                f[j], f[j + 1] = f[j + 1], f[j]
            elif mt[f[j]][0] == mt[f[j + 1]][0] and mt[f[j]][1] > mt[f[j + 1]][1]:
                f[j], f[j + 1] = f[j + 1], f[j]
    return f
```

若 `mt` 中数据为 `[[1,3,6], [1,20,5], [6,30,2], [3,15,5], [1,7,1], [2,15,4], [3,3,5], [3,9,10], [3,3,10], [1,8,20]]`，调用 `b_sort(mt)` 所得返回序列 `f` 的最后一个元素为______。

（3）实现炸弹区间计算的部分 Python 代码如下：

```python
def min_bombs(mt):
    f = b_sort(mt)                         # ①
    bombs = []
    cnt = 0
    current_row = -1
    R_time, L_time = 0, 0
    for i in range(len(mt)):
        m = mt[f[i]]
        if m[0] != current_row:
            current_row = m[0]              # ②
            L_time = m[1]
            R_time = m[2]
            cnt += 1
            bombs.append([m[0], L_time, R_time])
        elif R_time < m[1]:
            L_time = m[1]
            R_time = m[2]
            cnt += 1
            bombs.append([m[0], L_time, R_time])
        else:
            L_time = m[1]
            if R_time > m[2]:
                R_time = m[2]
            bombs[cnt - 1][1] = L_time              # ③
            bombs[cnt - 1][2] = R_time
    return bombs
'''
依次读取怪物数据存入列表 mt，mt[i] 包含 3 个数据项，mt[i][0]、mt[i][1]、mt[i][2]
分别存放怪物所在行数、出现时间和行进速度，代码略
'''
bombs = min_bombs(mt)
'''
输出 bombs 序列的长度以及 bombs 中的炸弹投放区间数据，代码略
'''
```

运行结果为：

```text
最少需要 6 颗炸弹
第 1 行，可以在第 8 - 11 秒投放炸弹
第 1 行，可以在第 20 - 32 秒投放炸弹
第 2 行，可以在第 15 - 30 秒投放炸弹
第 3 行，可以在第 9 - 9 秒投放炸弹
第 3 行，可以在第 15 - 27 秒投放炸弹
第 6 行，可以在第 30 - 60 秒投放炸弹
```

---
## 答案

**正确答案：**（1）4；（2）2；（3）① `f = b_sort(mt)`；② `current_row = m[0]`；③ `bombs[cnt-1][1] = L_time`（题面随后已给出 `bombs[cnt-1][2] = R_time`）。

---
## 解析

每只怪物的存在区间是“出现时间—到达第一列时间”。同一行中，区间有交集的怪物可由同一颗炸弹覆盖，按行排序后维护当前炸弹区间即可。第（1）问中 1 行需要 2 颗、2 行需要 1 颗、6 行需要 1 颗，共 4 颗。`b_sort` 按行和出现时间排序，给定数据的返回序列最后一个元素为 2；区间合并程序在重叠时先更新当前区间的左端点（第③空），再由题面下一行更新右端点，共形成 6 个炸弹区间并得到图 e 的输出。
