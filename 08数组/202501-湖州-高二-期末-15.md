# 题目 15

铁路 CR400 系列动车组第 2 至第 7 共计 6 个车厢为普通二等座车厢，每个车厢设有 18 排座位，每排设 A、B、C 与 D、F 共计 5 个座位，如第 15 题图 a 所示。旅行社根据旅客乘坐意向向铁路部门提交二等座购票申请。旅客乘坐意向存储在文本文件中，如第 15 题图 b 所示。编写程序：读取购票申请，根据余票信息，判断是否能够达成旅客意向。请回答下列问题：

![[attachments/202501湖州_15_图b.jpg]]

(1) 若余票中三人座与两人座分别为 3 与 4，旅客需求三人一起与两人一起分别为 2 与 5，则 ▲ （选填：能/不能）达成旅客的乘坐意向。

(2) 定义如下 `count1(fname)` 函数，函数功能为统计旅客对三人一起与两人一起的需求意向。

```python
def count1(fname):
    f = open(fname, encoding="utf-8")
    line = f.readline()  # 从文件中读取一行
    n3, n2 = 0, 0
    while line:
        x = len(line.split(", "))  # "a, b, c".split(", ") 的结果为 ["a", "b", "c"]
        if x == 3:
            n3 += 1
        if x == 2:
            n2 += 1
        line = f.readline()
    f.close()
    return n3, n2
```

加框处语句 ▲ （选填：能/不能）用下列代码段来替换。

```python
x = 1
for c in line:
    if c == ",":
        x += 1
```

(3) 定义如下 `count2(tickets)` 函数，请在划线处填入合适的代码。

```python
def count2(tickets):

        cars = int(ticket[0:2])
        rows = int(ticket[2:4])
        x = (cars - 2) * 18 + (rows - 1)

        data[x][y] = 1
```

(4) 主程序的判断条件有误，请改正。

```python
# 收集整理可购车票信息存入 tickets 列表，代码略
# 形如 tickets = ["0507A", "0601A", "0502C"……"0502D"]
n3, n2 = count1("ideal.txt")
t3, t2 = count2(tickets)
if t3 + t2 >= n3 + n2:     # 有误，请改正
    print("能达成旅客的乘坐意向")
else:
    print("不能达成旅客的乘坐意向")
```

## 答案

**正确答案：**

(1) 能

(2) 能

(3) ① `y = dic[ticket[4]]`（或 `y = dic[ticket[-1]]`）；② `t2 += 1`

(4) `t3 >= n3 and t3 - n3 + t2 >= n2`（或 `t3 >= n3 and t3 + t2 >= n3 + n2`）

---

## 解析

(1) 三人座余 3 ≥ 需求 2，两人座余 4 < 需求 5，但多余的三人座可降级为两人座用（3-2=1 个多余三人座），总可满足两人座的需求。

(2) 等价替换：统计逗号数即可知人数（1 个逗号 = 2 人，2 个逗号 = 3 人）。

(3) ① `ticket[4]` 为座位字母，通过 `dic` 映射为列索引 0-4。② ABC 列中恰好 B 列被占（即 k[0]+k[1]+k[2]==2 且 k[1]==1），说明 A、C 空而 B 被占，无法构成两人连座，不计数。只有 ABC 全空(seats==3)或 AB/BC 连空才构成有效座位。

(4) 原判断 `t3+t2 >= n3+n2` 忽略了三人座不能降级满足三人需求的问题。改正：需确保三人座够用（`t3 >= n3`），且剩余座位够两人用。
