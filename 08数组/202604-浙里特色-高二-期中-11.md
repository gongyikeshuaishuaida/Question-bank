# 题目 11

数组 `a` 中存放着无重复的正整数，现需要从数组 `a` 中找出最大值 `max1` 和次大值 `max2`。实现该功能的程序如下：

```python
max1 = max2 = 0
a = [88, 95, 82, 99, 91, 78, 85]
for i in range(len(a)):
    if a[i] > max1:
        ________①________
        ________②________
    elif a[i] > max2:
        ________③________
print("最大值为：" + str(max1) + "，次大值为：" + str(max2))
```

上述程序段中划线处可选的语句为：

① `max1 = a[i]`
② `max2 = max1`
③ `max2 = a[i]`

则划线处语句依次为（　）

- A. ①②③
- B. ①③②
- C. ②①③
- D. ②③①

---

## 答案

**正确答案：** C

---

## 解析

发现比当前最大值更大的元素时，应先把原最大值保存为次大值，即执行②，再把新元素赋给最大值，即执行①；元素只大于次大值时执行③。因此顺序为②①③，选 C。
