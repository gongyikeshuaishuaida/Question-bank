# 题目 15

将糖果打包成礼盒出售。用数组 `price` 来存储不同糖果的价格（1～100 之间的整数），其中 `price[i]` 表示第 `i` 种糖果的价格。礼盒的甜蜜度是礼盒中任意两种糖果价格绝对差的最小值，求从中挑选 `k` 种不同糖果打包成礼盒的最大甜蜜度。例如：不同糖果的价格为 `[13, 5, 1, 8, 21]`，挑选 3 种不同糖果，挑选结果可以为 `[13, 5, 21]` 或 `[13, 1, 21]`，最大甜蜜度为 8。请回答下列问题：

（1）不同糖果的价格为 `[3, 7, 5, 5, 5, 10, 8]`，挑选 3 种不同糖果，最大甜蜜度为______。

（2）定义如下 `psort(p)` 函数，参数 `p` 为不同种类糖果的价格。函数功能实现对 `price` 升序排序。

```python
def psort(p):
    d = [0] * 100
    for i in p:
        d[i] += 1
    k = 0
    for i in range(100):
        if d[i] > 0:  # 此处是方框处
            d[i] -= 1
            p[k] = i
            k += 1
    return p
```

若加框处代码 `if d[i] > 0:` 有误，应修改为______。

（3）实现程序功能的 Python 程序如下，请在划线处填入正确的代码。

```python
def check(sw):

    return cnt
```

---

## 答案

（1）3

（2）`while d[i] > 0:`

（3）① `price[0]`；② `prev = price[i]`；③ `check(mid) >= k`

---

## 解析

价格去重排序后为 `[3, 5, 7, 8, 10]`，选择 3、7、10 时相邻最小差为 3，且无法达到 4。计数排序需要把出现多次的价格全部写回，因此应使用 `while`。`check(sw)` 用贪心方式从小到大选取与上一个已选价格至少相差 `sw` 的糖果；若能选到不少于 `k` 种，说明该甜蜜度可行，二分时继续增大下界。
