# 题目 11

有如下 Python 程序段：

```python
import random

flag = [False] * 10
a = [0] * 6
i = 0
while i <= 5:
    k = random.randint(1, 9)
    if flag[k] == False:
        flag[k] = True
        a[i] = k
        i += 1
```

该程序执行后，列表 `a` 的值可能是（   ）

- A. `[1, 2, 3, 0, 5, 10]`
- B. `[0, 4, 7, 9, 0, 7]`
- C. `[5, 7, 3, 3, 0, 2]`
- D. `[1, 4, 9, 6, 8, 2]`

---

## 答案

**正确答案：** D

---

## 解析

程序只会把 1～9 中尚未出现过的整数写入 `a`，循环结束时 `a` 应包含 6 个互不相同的非零整数。A 含 0 和 10，B、C 含 0 和重复值；D 中 6 个数均在 1～9 范围内且互不相同，因此可能出现。
