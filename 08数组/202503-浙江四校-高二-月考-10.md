# 题目 10

10. 数组元素 `a[0]` 至 `a[n-1]` 依次存放着 n 个数据，现需将数据小于或等于 x 的元素删除。例如：n 为 5，数组 a 为 `[3, 14, 12, 9, 11]`，x 为 10，删除后数组为 `[14, 12, 11]`。实现该功能的程序段如下，方框内应填入的正确代码是

```python
k = 0
for i in range(n):
    if a[i] <= x:
        k += 1
    else:
        ______  # 此处是方框处
n -= k
# 按顺序输出剩余的 n 个元素，代码略。
```

- A. `a[i-k] = a[i]`
- B. `a[i-1] = a[k]`
- C. `a[i] = a[i+k]`
- D. `a[k] = a[i]`

---
## 答案

**正确答案：** A

---
## 解析

扫描到一个保留元素时，前面已经发现 k 个待删除元素，因此应把当前元素前移 k 个位置，即 a[i-k] = a[i]。扫描结束后再令 n -= k，保留下来的元素就在数组前 n 个位置。
