# 题目 12

12. 现有一个 m 行、n 列的数字矩阵，如 `a=[[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]`，矩阵中的元素每行每列都是按照非升序排列，如第 12 题图所示。实现统计该矩阵中小于 0 的数字个数的 Python 程序段如下，划线处应填入的正确代码是（   ）

![[attachments/202604宁波高三_12_图1.png]]

```python
def f(a):
    m = len(a)
    n = len(a[0])
    i, j = 0, n - 1
    cnt = 0
    while i < m and j >= 0:
        if a[i][j] < 0:
            ______①______
            ______②______
        else:
            ______③______
    return cnt
```

- A. ① `cnt += m-i`；② `j -= 1`；③ `i += 1`  
- B. ① `cnt += n-j`；② `j -= 1`；③ `i += 1`  
- C. ① `cnt += 1`；② `i += 1`；③ `j -= 1`  
- D. ① `cnt += m-i-1`；② `i += 1`；③ `j -= 1`

---

## 答案

**正确答案：** A

---

## 解析

矩阵每行每列均非升序。从右上角开始，若当前位置为负数，则该列从当前行到最后一行均为负数，累计 `m-i` 并左移；否则下移。因此三处代码为 `cnt += m-i`、`j -= 1`、`i += 1`。
