# 题目 10

10. 有如下 Python 程序段：

```python
a = [2, 5, 7, 9, 11]; b = [3, 6, 8, 10, 12]
i = j = 0
c = []
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        c.append(a[i])
        i += 1
    else:
        c.append(b[j])
        j += 1
c += a[i:]
c += b[j:]
```

执行该程序段后，`c[5]` 的值是（　）

- A. 8
- B. 9
- C. 10
- D. 11


---

## 答案

**正确答案：** A

---

## 解析

合并结果为 `[2,3,5,6,7,8,9,10,11,12]`，下标 5 对应 8。
