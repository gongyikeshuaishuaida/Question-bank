# 题目 13

某快递存放点有一排智能识别连续货位，编号为0～n-1，能自主识别投放 a、b 两类快递（其他类型不能识别投放），a 类快递需占相邻3个货位，b 类快递占用相邻2个货位。现编写程序，根据已完成的投放或取件操作，输出余位数量及还能投放 a 类快递的最多数量（不移动已占位的快递）。请回答下列问题。

（1）若 n 为12，初始货位全空，经过下表所示的投放或取件操作后，在不移动已占位的快递前提下，还能投放 a 类快递最多的数量为 ______ 个。

| 快递类型 | 操作类型 | 货位编号 |
|---|---|---|
| b | 投放 | 5, 6 |
| a | 投放 | 1, 2, 3 |
| b | 投放 | 9, 10 |
| a | 取件 | 1, 2, 3 |
| a | 投放 | 0, 1, 2 |

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
cnt1=n
lst=[0]*n
while True:
    if t=="a":
        w=3
    ____①____:
        w=2
    else:
        break
    if d=="P":
        cnt1-=w
    else:
        cnt1+=w
    ____②____
    if t=="a":
        lst[s+1]=1-lst[s+1]
        lst[s+2]=1-lst[s+2]
    elif t=="b":
        lst[s+1]=1-lst[s+1]
    i,cnt2=0,0
    while i<n-1:
        if lst[i]==0 and lst[i+1]==0 and lst[i+2]==0:
            ____③____
            cnt2+=1
        i+=1
```

---
## 答案

**参考答案：** （1）0；（2）① elif t=="b"；② lst[s]=1-lst[s]；③ i+=2。

---
## 解析

操作后占用0、1、2，5、6和9、10，剩余空位没有连续三个，所以最多放置0个 a。②翻转起始货位状态，③跳过已计数的位置。
