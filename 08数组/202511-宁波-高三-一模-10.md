# 题目 10

10. a数组中有n个元素（n为偶数），现要将所有索引为奇数的元素循环右移两位，索引为偶数的元素不变，如 `[1,2,3,4,5,6]` 处理后得到 `[1,6,3,2,5,4]`。实现该功能的Python程序段如下：

```python
n = len(a)
last = a[n - 1]
for i in range(①):
    ②
a[i] = last
```

则划线处应填入的正确代码为（   ）

- A. ① `n-3, 0, -2`　② `a[i+2] = a[i]`
- B. ① `n-1, 1, -2`　② `a[i-2] = a[i]`
- C. ① `1, n-1, 2`　② `a[i+2] = a[i]`
- D. ① `0, n-2, 2`　② `a[i-2] = a[i]`

---

## 答案

**正确答案：** A

---

## 解析

数组长度为偶数n，奇数索引元素（索引1,3,5,…,n-1）循环右移两位，偶数索引不变。

以 `n=6, a=[1,2,3,4,5,6]` 为例，期望结果 `[1,6,3,2,5,4]`。
奇数索引元素共3个（索引1→2, 3→4, 5→6），循环右移2位后：原索引5→索引1、原索引1→索引3、原索引3→索引5。

算法：先保存 `last = a[n-1]`，再从后往前将奇数索引的元素向后移动两位，最后将last填入第一个奇数位置。

验证选项A：`range(n-3, 0, -2) → i=3,1`
- i=3: `a[5] = a[3] = 4` → `[1,2,3,4,5,4]`
- i=1: `a[3] = a[1] = 2` → `[1,2,3,2,5,4]`
- 循环结束后 i=1（最后一个值未进入下一轮），`a[1] = last = 6` → `[1,6,3,2,5,4]` ✓

其他选项均无法正确实现。
