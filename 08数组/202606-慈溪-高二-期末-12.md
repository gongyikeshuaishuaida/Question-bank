# 题目 12

12. 有如下 Python 程序段：

```python
a = [1, 2, 3, 4]
k = 3
i = 0
n = len(a)
# 给列表 b 赋值，代码略                         ①处
while n > 1:
    i = (i + k - 1) % n
    if b[i] != 0:
        b[i] = 0
    else:
        for j in range(i + 1, n):
            a[j - 1] = a[j]
            b[j - 1] = b[j]
        n = n - 1
```

执行该程序段后，`a[0]` 的值为 1，则①处列表 `b` 不可能赋值为（   ）

- A. `[0, 0, 0, 0]`
- B. `[1, 0, 0, 0]`
- C. `[0, 0, 1, 0]`
- D. `[0, 0, 0, 1]`

---

## 答案

**正确答案：** C

---

## 解析

每轮先按当前长度计算位置 `i`。若 `b[i]` 非 0，只把它改为 0；否则删除 `a[i]` 和 `b[i]`。当 `b=[0,0,1,0]` 时，第一次定位到下标 2，只将 `b[2]` 置 0；下一次定位到下标 0，元素 1 被删除，所以最终 `a[0]` 不可能为 1。其余三种赋值均可使元素 1 保留。
