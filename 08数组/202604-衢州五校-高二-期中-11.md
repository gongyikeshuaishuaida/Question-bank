# 题目 11

有如下 Python 程序段：

```python
ka = [9, 5, 2, 0, 0, 0, 0]
pa = 2
kb = [4, 8, 1, 6]
pb = 3
s = 0
while pb >= 0:
    cur = kb[pb]
    pb -= 1
    while pa >= 0 and ka[pa] < cur:
        pa -= 1
    pa += 1
    ka[pa] = cur
print(ka)
```

执行上述程序段后，变量 `ka[1]` 的值为（   ）

- A. `4`
- B. `6`
- C. `8`
- D. `9`

---

## 答案

**正确答案：** C

---

## 解析

程序依次从 `kb` 尾部取出 `6、1、8、4`。每次先让 `pa` 向前越过 `ka` 中所有小于 `cur` 的元素，再把 `cur` 写入相应位置。

执行结束后 `ka` 的前部为 `[9, 8, 4]`，因此 `ka[1]=8`，选 C。
