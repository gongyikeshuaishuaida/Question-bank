# 题目 11

有如下 Python 程序段：

```python
from random import randint

a = [0] * 6
i = 0
j = 5
while i <= j:
    k = randint(0, 10)  # 随机生成0-10之间的整数
    if k % 2 == i % 2:
        a[i] = k
        i += 1
    else:
        a[j] = k
        j = j - 1
print(a)
```

执行该程序段后，输出的结果不可能是（   ）

- A. `[4, 7, 0, 2, 6, 8]`
- B. `[8, 1, 2, 6, 8, 1]`
- C. `[6, 1, 4, 3, 6, 1]`
- D. `[0, 9, 10, 1, 9, 3]`

---

## 答案

**正确答案：** B

---

## 解析

当随机数 `k` 与当前下标 `i` 同奇偶时，`k` 被放入左端的 `a[i]`，随后 `i` 右移；不同奇偶时，`k` 被放入右端的 `a[j]`，随后 `j` 左移。因此从左端依次确定的位置必须与其下标同奇偶。

B 中 `a[0]=8`、`a[1]=1`、`a[2]=2` 均符合要求，但下一待填左端位置为 `i=3`，该位置只能由奇数填入，而 `a[3]=6` 为偶数，不可能出现。
