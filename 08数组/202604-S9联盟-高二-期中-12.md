# 题目 12

给定一个非降序数组 `a`，删除重复元素，使每个元素只出现一次，输出去重后的数组。实现该功能的程序段如下，方框中应填入的正确代码为（   ）

```python
p1, p2 = 0, 1
while p2 < len(a):
    while p2 < len(a) and a[p2] == a[p1]:
        p2 += 1
    # 方框处
print(a[:p1+1])
```

- A.

```python
if p2 < len(a):
    a[p1] = a[p2]
p1 += 1
p2 += 1
```

- B.

```python
if p2 < len(a):
    a[p1+1] = a[p2]
    p1 += 1
p2 += 1
```

- C.

```python
a[p1+1] = a[p2]
p1 += 1
p2 += 1
```

- D.

```python
if p2 < len(a):
    a[p1] = a[p2]
    p1 += 1
p2 += 1
```

---

## 答案

**正确答案：** B

---

## 解析

`p2` 跳过与 `a[p1]` 相同的重复元素后，若仍未越界，就应把新的不同元素复制到 `a[p1+1]`，再让 `p1` 前移。无论是否越界，`p2` 都继续后移，B 项符合该逻辑并避免越界访问。
