# 题目 13

某停车场是一个矩形区域，共有 `m` 排，每排有 `n` 个连续的停车位，编号依次为 `1～m*n`，可用于停放小型车和大型车，如第 13 题图 a 所示。小型车（A 型）占 1 个停车位，大型车（B 型）需占 2 个相邻的停车位。编写 Python 程序，根据停车场的当前状态以及已完成的停车或离开操作，输出当前空闲的总停车位数量和还可以停放的大型车最大数量。

![[attachments/202501杭州_13_图1.jpg]]

![[attachments/202501杭州_13_图2.jpg]]

（1）若 `m=2，n=10`，开始时停车场全空，经过第 13 题图 b 所示的操作后，还可停放大型车的数量最多为______辆。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
m = 5
n = 10
sta = [[False for i in range(n)] for j in range(m)]

'''
读取当前停车场车位状态数据，存入二维数组 sta，代码略。
若 sta[i][j] 的值为 True 表示该车位已停车，
值为 False 表示该车位未停车。
统计当前总空位数，存入变量 cnt1，代码略。
'''

while True:
    '''
    读取车位感应装置采集的数据：汽车类型（A 或 B）、
    停车或离开状态（True 或 False）、车位编号起始值，
    存入 car、stop 和 num，代码略。
    '''
    if car == "A":
        w = 1
    else:
        w = 2
    if stop == True:
        cnt1 -= w
    else:
        ①

    i = (num - 1) // n
    ②
    sta[i][j] = not sta[i][j]
    if car == "B":
        sta[i][j + 1] = not sta[i][j + 1]

cnt2 = 0
for i in range(m):
    j = 0
    while ③:
        if not sta[i][j] and not sta[i][j + 1]:
            j += 1
            cnt2 += 1
        j += 1

print("当前总空余车位数：", cnt1, "，还可停放大型车的最大数量：", cnt2)
```

---

## 答案

（1）5

（2）① `cnt1 += w`；② `j = (num - 1) % n`；③ `j < n - 1`

---

## 解析

（1）操作完成后，第 1 排占用 3、4、6、7 号位，可再安排 2 辆大型车；第 2 排占用 12、15、16 号位，可再安排 3 辆，共 5 辆。

（2）离开车辆会增加空位数，所以执行 `cnt1 += w`。车位编号减 1 后，整除 `n` 得到行号，模 `n` 得到列号。检查相邻两个位置时必须保证 `j+1` 不越界，因此循环条件为 `j < n-1`。
