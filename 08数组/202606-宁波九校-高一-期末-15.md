# 题目 15

15. 对一组取值在0～127之间的整数采用混合加密算法。设分段长度为`m`，每`m`个数据分为一段，最后不足`m`个的数据自成一段。加密流程如下：

1. 数值加密：数值密钥为长度`m`的列表`a`，分段内下标`i`处的加密值为`(原数据+a[i]) % 128`。
2. 位置加密：位置密钥为长度`m`的列表`b`，其元素为1～m的不重复整数；原分段下标`i`处的数据放到新分段下标`b[i]-1`处。
3. 满`m`个数据的分段同时执行数值加密和位置加密；不足`m`个的末段只执行数值加密。各段完成后按原顺序拼接。

例如：`m=3`，`a=[2,5,7]`，`b=[2,3,1]`，分段数据为`[10,20,30]`，加密后为`[37,12,25]`。

（1）已知`m=4`，`a=[5,12,8,3]`，`b=[2,4,1,3]`，分段数据为`[20,66,90,15]`，加密结果为______。

（2）补全程序：

```python
def new(c, t, a):
    lst = []
    for i in range(t):
        newd = (c[i] + a[i]) % 128
        lst += [newd]
    return lst

# 原始数据存入data；读取数值密钥a、位置密钥b、分段长度m，代码略
n = len(data)
encode = []

for i in range(0, n, m):
    ①
    length = len(seg)
    ②
    if length == m:
        form = [0] * m
        for k in range(m):
            ③
            form[pos] = trans[k]
        encode += form
    else:
        ④

print("原始数据：", data)
print("加密后数据：", encode)
```

---

## 答案

（1）`[98,25,18,78]`

（2）

- ① `seg = data[i:i+m]`
- ② `trans = new(seg, length, a)`
- ③ `pos = b[k] - 1`
- ④ `encode += trans`

---

## 解析

数值加密后为`[25,78,98,18]`。位置密钥`[2,4,1,3]`表示四个值分别放到下标1、3、0、2，因此得到`[98,25,18,78]`。循环中先切出当前分段，再按实际段长做数值加密；只有满段才按位置密钥重排。
