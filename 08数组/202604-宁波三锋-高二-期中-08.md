# 题目 08

8. 程序求相邻元素差的绝对值的最大值：

```python
a = [4,8,3,6,2,7,8,1]
n = abs(a[0]-a[1])
for i in range(2, len(a)):
    if abs(a[i]-a[i-1]) > n:
        n = abs(a[i]-a[i-1])
```

执行后 `n` 为（　）

- A. 5　B. 8　C. 7　D. 1

---

## 答案

**正确答案：** C

---

## 解析

相邻差绝对值依次比较，最大值来自 `|1-8|=7`。
