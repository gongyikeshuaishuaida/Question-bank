# 题目 13

照明设备控制 `n` 盏编号 0～`n-1` 的霓虹灯，状态列表 `light` 中 0 表示灭、1 表示亮。每轮先从第 3 盏灯开始按前两盏状态之和的奇偶更新；若亮灯数量超过总数 50%，则所有灯取反，否则只取反第一盏灯。

（1）`light` 初始为 `[1,0,0,0,0]`，经过规则 A 后编号为 3 的灯状态值为 **1**。

（2）程序填空：

```python
light = [0] * n
while True:
    for i in range(2, n):
        ①
        if m % 2 == 0:
            light[i] = 0
        else:
            light[i] = 1
    count = sum(light)
    if ②:
        j = 0
        while j < n:
            ③
            j += 1
    else:
        light[0] = 1 - light[0]
```

填空：① `m = light[i-1] + light[i-2]`；② `count/n > 0.5`（或等价写法）；③ `light[j] = 1 - light[j]`（或 `abs(light[j]-1)`）。

---
## 答案
**正确答案：** （1）1　（2）①`m=light[i-1]+light[i-2]`；②`count/n>0.5`；③`light[j]=1-light[j]`（等价答案均可）

---
## 解析
规则 A 中编号 2 的状态为 `light[1]+light[0]=1`，编号 3 的状态再由编号 2、1 相加得到奇数，因此为 1。规则 B 用亮灯数量与总数比较，超过一半时遍历列表逐个取反。
