# 题目 09

已知一维数组长度为100，数组元素 `a[0]` 到 `a[n-1]` 依次存放着 n 个数据（n<100），要求在索引 k 的位置插入元素 x，实现上述功能的部分 Python 代码如下：

```python
for i in range(____):
    __________
    a[k]=x
```

划线处可供选择的语句有：① `k,n`；② `n-1,k-1,-1`；③ `a[i+1]=a[i]`；④ `a[i]=a[i-1]`。则程序中两处划线处的代码依次为（   ）

- A. ①③
- B. ①④
- C. ②③
- D. ②④

---
## 答案

**正确答案：** C

---
## 解析

插入前要把 a[k] 到 a[n-1] 的元素整体向右移动一位，必须从后向前遍历下标 n-1 到 k，循环步长为-1；每次执行 a[i+1]=a[i]。因此选择②③。
