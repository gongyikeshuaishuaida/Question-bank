# 题目 12

12. 有如下 Python 程序，执行该程序后，`a` 的值可能是（   ）

```python
import random

a = []
for i in range(8):
    a.append(random.randint(1, 9))  # 在列表后添加一个值
for i in range(len(a)):
    if i % 2 == a[i] % 2:
        a[i] += 1
```

- A. `[8, 9, 4, 5, 4, 7, 2, 5]`
- B. `[5, 8, 8, 7, 1, 9, 1, 2]`
- C. `[3, 6, 1, 10, 9, 4, 5, 8]`
- D. `[5, 6, 9, 0, 5, 8, 3, 4]`

---

## 答案

**正确答案：** C

---

## 解析

偶数下标处若元素为偶数就加 1，因此处理后偶数下标处一定是奇数；奇数下标处若元素为奇数就加 1，因此处理后奇数下标处一定是偶数。C 中偶数下标元素均为奇数、奇数下标元素均为偶数，并且所有值都可能由 1～9 的初始值产生。
