# 题目 12

列表 `a` 有 `n（n>=2）` 个正整数，相邻两数的差值为 1、0 或 -1。求满足相邻两数具有相同差值的连续子序列中，子序列元素和的最大值。实现该功能的程序段如下，加框处应填写的正确代码是（   ）

```python
state = a[1] - a[0]
maxv = t = a[1] + a[0]
for i in range(2, n):
    f = a[i] - a[i-1]
    ________
print(maxv)
```

- A.

  ```python
  if state == f:
      t += a[i]
  else:
      state = f
      t = a[i-1] + a[i]
      if t > maxv:
          maxv = t
  ```

- B.

  ```python
  if state == f:
      t += a[i]
  else:
      state = f
      t = a[i-1] + a[i]
  if t > maxv:
      maxv = t
  ```

- C.

  ```python
  if state == f:
      t += a[i]
  if state != f:
      state = f
      t = a[i-1] + a[i]
  elif t > maxv:
      maxv = t
  ```

- D.

  ```python
  if state == f:
      t += a[i]
  elif state != f:
      state = f
      t = a[i-1] + a[i]
  elif t > maxv:
      maxv = t
  ```

---

## 答案

**正确答案：** B

---

## 解析

当相邻差值不变时，应把 `a[i]` 累加到当前连续子序列；差值改变时，从 `a[i-1]、a[i]` 重新开始统计。无论差值是否改变，每轮都要用当前和 `t` 更新全局最大值 `maxv`，只有 B 的缩进和分支结构符合要求。
