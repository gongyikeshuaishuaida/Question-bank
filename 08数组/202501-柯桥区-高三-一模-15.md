# 题目 15

在大宗商品交易中，有两个核心参与者：买方和卖方。市场中的订单分为买单（buy）和卖单（sell）。买单是指买方提出购买意向，包括指定购买的数量和价格，并记录下订单的提交时间。卖单是指卖方提出出售意向，包括提供的数量和价格，同样记录提交时间。为了实现公平有效的交易，订单撮合遵循以下规则：

1. 价格优先：买单按价格降序排列（即出价高的优先匹配）；卖单按价格升序排列（即报价低的优先匹配）。
2. 时间优先：如果价格相同，则优先匹配时间更早的订单。
3. 成交价以卖方价格为准（订单类型：1 代表买入单子，0 代表卖出单子）。

| 编号 | 订单类型 | 订单数量 | 订单价格 | 订单时间 |
|---:|---:|---:|---:|---:|
| 1 | 1 | 10 | 5 | 1 |
| 2 | 0 | 5 | 4 | 2 |
| 3 | 0 | 10 | 5 | 2 |
| 4 | 1 | 7 | 4 | 4 |

编写程序：给定订单数据，根据上述方法进行处理，输出成交记录、未完成的买单和卖单。请回答下列问题：

（1）由题意可知，对表中数据进行订单撮合，最终未完成的订单数量为______。

（2）定义如下 `bubble_sort(lst)` 函数，对 `lst` 进行按规则排序。参数 `lst` 的每个元素由编号、订单类型、订单数量、订单价格、订单时间 5 个数据项组成。

```python
def compare(a, b):                 # 自定义比较函数
    if a[1] != b[1]:
        return a[1] > b[1]
    elif a[3] != b[3]:
        return a[3] > b[3]
    else:
        if a[1] == 1:
            return a[4] < b[4]
        else:
            return a[4] > b[4]

def bubble_sort(lst):
    n = len(lst)
    for i in range(n):
        for j in range(0, n - i - 1):
            if not compare(lst[j], lst[j + 1]):
                lst[j], lst[j + 1] = lst[j + 1], lst[j]
    return lst
```

调用该函数，若 `lst` 为 `[[1,1,10,5,1], [2,0,5,4,2], [3,0,10,5,3], [4,1,7,4,4], [5,1,8,6,2]]`，请回答：

①代码 `return a[4] > b[4]` 对应的撮合原则是______。

- A. 时间优先原则：买入按降序排列
- B. 时间优先原则：买入按升序排列
- C. 时间优先原则：卖出按降序排列
- D. 时间优先原则：卖出按升序排列

②`lst` 数据处理完毕，交换的次数为______。

（3）实现订单撮合功能的部分 Python 程序如下，请在程序中划线处填入合适的代码：

```python
def match_orders(orders):

orders = [
```

## 答案

（1）2

（2）① C；② 7

（3）① `0`；② `orders[i][1] != 0 and orders[j][1] != 1`；③ `j -= 1`

---

## 解析

（1）订单 1 先与订单 2 成交 5，再与订单 3 成交 5；最终订单 3 和订单 4 未完成，共 2 个。

（2）卖单位于买单之后，程序把同价卖单按时间降序排列，使更早的订单更靠近列表末端，故选 C。按程序逐轮跟踪共有 7 次交换。

（3）排序后买单从列表左端开始、卖单从右端开始，因此 `i=0`；循环要求 `i` 仍指向买单且 `j` 仍指向卖单。当前买价不足以成交时，令 `j` 左移继续处理。
