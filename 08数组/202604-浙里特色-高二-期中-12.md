# 题目 12

有如下程序段：

```python
from random import randint
i, n = 0, 4
a = [0] * 5
while i <= n:
    x = randint(1, 9)  # 生成指定范围内的随机整数
    if i % 2 == 1:
        a[i] = x
    elif x % 2 == 1:
        a[n] = x
        n = n - 1
    i = i + 1
```

运行程序后，`a` 的值可能是（　）

- A. `[3, 0, 5, 7, 8]`
- B. `[0, 7, 4, 0, 5]`
- C. `[2, 0, 4, 8, 5]`
- D. `[0, 8, 0, 9, 1]`

---

## 答案

**正确答案：** D

---

## 解析

`i=0` 时若随机数为奇数，只会把该数写入 `a[n]`，不会写入 `a[0]`，所以 `a[0]` 保持为 0，排除 A、C。

D 可以由如下随机数序列得到：`i=0` 时取 `1`，写入 `a[4]` 并令 `n=3`；`i=1` 时取 `8`，写入 `a[1]`；`i=2` 时取偶数，不赋值；`i=3` 时取 `9`，写入 `a[3]`。此后 `i=4>n=3`，循环结束，结果为 `[0, 8, 0, 9, 1]`。
