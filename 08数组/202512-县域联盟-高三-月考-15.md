# 题目 15

15. 某选课冲突检测系统用于检测每个学生选课过程中可能存在的选课冲突。选课冲突包括时间冲突和先修课程冲突。部分课程有先修课程要求，该要求是指在选该课程前必须已完成或在本学期同时选修这些先修课程。

- 时间冲突：同一时间段的课程之间存在时间冲突；
- 先修课程冲突：如果没有先修课程要求，则该课程不存在先修课程冲突。如果有先修课程要求，需要逐个检查这些先修课程：
①此先修课程涉及的先修课程是否存在先修课程冲突；
②若此先修课程未完成，且本学期未选修，则存在先修课程冲突。

请回答下列问题：

图 a 为某学生的选课信息，包含课程 id、时间段和先修课程，输出如图 b 所示。

![[attachments/202512县域联盟高三月考_15_图1.png]]

（1）若某同学在图 a 所示的选课基础之上新选了一门课程 id 为 104、时间段为 D、先修课程无要求的课程，则检测结果中共有 ▲ 条冲突。

（2）函数 `check_time` 的作用是遍历课程列表数据 `nodes`，找出其中存在的时间冲突。请在划线处填写正确的代码。

```python
def check_time():  # 检测时间冲突
    tgroup = {}
    for node in nodes:
        if ▲:
            tgroup[node[1]] = []
        tgroup[node[1]].append(node[0])
    return tgroup
```

（3）实现其余功能的部分 Python 程序如下，请在划线处填入合适的代码。

def find(cid):
    # 查找课程在 nodes 中的索引
    i = 0
    while i < len(nodes):
        if nodes[i][0] == cid:
            break
        i += 1
    return i

def check_pre(cid):

def check_course():

## 答案

**正确答案：** （1）4；（2）`node[1] not in tgroup`；（3）① `st[top]`；② `i >= len(nodes)`；③ `check_pre(cid)` 或 `check_pre(node[0])`

---

## 解析

新增课程 104 后，原有 3 条 A 时间段冲突仍存在，104 与 105 的先修课程关系补齐，105 的先修冲突消失，但 108 仍因 107 和 104 两条路径产生先修冲突，因此共 4 条冲突。`check_time` 用时间段作键建分组；`check_pre` 使用栈保存待检查课程和路径，若先修课程在 `nodes` 中找不到，则记录缺失路径。
