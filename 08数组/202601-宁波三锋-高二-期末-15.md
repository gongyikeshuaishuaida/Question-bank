# 题目 15

15. 接上题，将校史展厅的光照数据存储于列表 `data` 中，要求统计出持续最长的非正常光照时段，若光照值小于 `minx` 或者大于 `maxx`，则表示非正常。若这样的时段有多个，则依次全部输出（保证至少存在一个有效解）。请回答下列问题：

(1) 已知一段时间的光线值为 `"433,501,480,380,381,390,399,555,520,410,442"`，若光照值小于 400 或者大于 500，表示非正常，则持续最长的非正常光照时段长度为   ▲   （填数字，例如 8）。

(2) 定义如下 `proc(x)` 函数，功能为根据正整数 `x` 值返回相应时间，如 `x` 为 0，则返回 `"08:00"`；如 `x` 为 150，则返回 `"10:30"`。

```python
def proc(x):
    x = __________________
    h = str(x // 60)
    f = str(x % 60)
    if len(h) < 2:
        h = "0" + str(x // 60)
    if len(f) < 2:
        f = "0" + str(x % 60)
    sj = h + ":" + f
    return sj
```

(3) 实现上述功能的 Python 程序如下，请在划线处填入合适代码。

---

## 答案

**正确答案：** (1) 6；(2) `x + 480`；(3) ① `data[i][1] < minx or data[i][1] > maxx`；② `n > maxn`；③ `proc(data[x - maxn + 1][0])`

---

## 解析

序列中从 380、381、390、399、555、520 连续 6 个光照值都小于 400 或大于 500，是最长非正常时段。`proc` 要把从 08:00 起经过的分钟数转换为当天时间，因此要先加上 8 小时即 480 分钟。主程序中 ① 判断当前光照是否非正常；当当前连续长度严格大于历史最大值时，② 清空旧答案并更新 `maxn`；`tmp` 中保存最长区间的结束下标，起点下标为 `x - maxn + 1`，所以 ③ 应取该位置的采集时间并调用 `proc`。
