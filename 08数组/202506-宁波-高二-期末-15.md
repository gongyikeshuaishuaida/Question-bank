# 题目 15

15.某社区共有n个小区，现打算在这n个小区里设置k个快递驿站（0<k<n），为了使驿站的设置尽可能合理，从以下两个方面进行考虑：（a）人口多的小区可能需要更多的快递服务，因此驿站更倾向于设置在人口多的小区；（b）快递驿站尽量靠近其他小区，以减少派送的总距离成本。

示例：如有A、B、C、D四个小区，人口数分别为10、20、30、40，小区之间的距离用矩阵表示如第15题图a表格所示：

|   | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 2 | 5 | 7 |
| B | 2 | 0 | 3 | 5 |
| C | 5 | 3 | 0 | 2 |
| D | 7 | 5 | 2 | 0 |

第15题图a

若4个小区设置1个快递驿站，则选择A小区设置驿站的派送成本为：10×0+20×2+30×5+40×7=470；选B小区的成本为：10×2+20×0+30×3+40×5=310；同理算出选C和D小区的成本分别为190和230。因此可以把驿站设置在成本最低的C小区。请回答以下问题：

（1）示例中若A小区的人口是60，则把驿站设置在（填字母）小区的成本最低。

（2）若示例中4个小区要设置2个快递驿站，则根据成本计算先选出C小区设置快递驿站，然后在剩下的3个小区中再选出成本最低的小区设置驿站（计算成本时，其他小区可就近选择C小区）：选A的成本为10×0+20×2+30×0+40×2=120，选B的成本为10×2+20×0+30×0+40×2=100，选D的成本为10×5+20×3+30×0+40×0=110，因此选B，也即四个小区选择C和B设置2个快递驿站。为实现程序功能，设计如下算法：n个小区，编号0至n-1，通过成本计算，在所有小区里挑选出成本最低的小区设置为驿站，然后在剩下的小区里再挑选成本最低的小区设置为驿站，重复这个步骤，直到挑出k个小区。在计算成本的时候，所有小区选择最近的驿站。主程序代码如下，运行界面如图第15题图b所示，请补充程序划线处：

（3）以下自定义函数计算成本，请补充程序划线处：

```python
def cost(x, dis, p, f):
    s=0
    for i in range(len(dis)):
        min_i=p[i]*dis[x][i]*f[i]
        for j in range(len(dis)):
            if j!=i and f[j]==0:
                k=p[i]*dis[i][j]*f[i]
                if k<min_i:
                    min_i=k
        ____③____
    return s
```

（4）该算法是否一定能得到总派送成本最小的驿站设置方案？（填：是 / 否）

---

## 答案

**正确答案：**

① B
② ① `not found` 或 `found==False`；② `f[minpos]=0`
③ `s += min_i` 或 `s = s + min_i`
④ 否

---

## 解析

（1）A人口改为60后重新计算各小区成本：选A=60×0+20×2+30×5+40×7=470, B=60×2+20×0+30×3+40×5=410, C=60×5+20×3+30×0+40×2=440, D=60×7+20×5+30×2+40×0=580。B成本最低410。

（2）①首次找到可用小区时found为False，应进入分支设置mincost初始值，故填`not found`；②选出驿站后标记该小区已被选中：`f[minpos]=0`。

（3）对每个小区i计算到最近驿站的派送成本min_i，累加到总成本s中：`s += min_i`。

（4）该算法为贪心算法，每次选当前成本最低的小区，但贪心不保证全局最优解，故填"否"。
