# 题目 12

有如下 Python 程序段：

```python
import random
b = [0] * 6
i = 0
while i < 6:
    m = random.randint(1, 10) + 3
    n = m * 2 + 1
    if m % 2 == i % 2:
        i -= 1
    elif m % 3 == 0:
        b[i] = n
    else:
        b[i] = m + b[i-1]
    i += 1
print(b)
```

以上程序运行后，列表 `b` 的值不可能是（   ）

- A. `[13, 17, 22, 26, 37, 47]`
- B. `[19, 27, 32, 13, 18, 25]`
- C. `[5, 25, 30, 25, 32, 36]`
- D. `[7, 25, 38, 13, 19, 26]`

---

## 答案

**正确答案：** D

---

## 解析

当 `m` 与下标 `i` 同奇偶时，本轮不会给 `b[i]` 赋值，所以下标为偶数时实际接受奇数 `m`，下标为奇数时接受偶数 `m`。D 的前五项可分别由 `m=7、12、13、6、9` 得到；到 `i=5` 时，允许的 `m` 为偶数。若 `m` 能被 3 整除，`b[5]` 只能为 13 或 25；否则只能为 `19+4=23`、`19+8=27` 或 `19+10=29`，不可能得到 26，因此 D 不可能。
