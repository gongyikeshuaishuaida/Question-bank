# 题目 10

有如下 Python 程序段：

```python
a = [9, 7, 10, 21, 16, 9, 7, 25]
n = len(a)
k = a[n-1]
p = 0
for i in range(n-2, -1, -1):
    if a[i] <= k:
        p = i
        k = a[p]
print(p, k)
```

该程序段执行后，运行结果是（   ）

- A. `1 7`
- B. `6 7`
- C. `0 9`
- D. `7 0`

---

## 答案

**正确答案：** A

---

## 解析

程序从索引 6 向索引 0 逆序扫描。`k` 初值为 25，在索引 6 处更新为 7；之后遇到的元素均大于 7，直到索引 1 的元素也是 7，因为条件为 `<=`，再次更新为 `p=1、k=7`。最终输出 `1 7`。
