# 题目 12

定义如下函数：
```python
def judge(a):
    i = j = 0
    t = 1

    f = [-1] * 100
    while j < len(a):
        k = a[j]
        if f[k] >= i:
            t = max(t, j - i)  # max(a, b)返回a和b中的较大值
            i = f[k] + 1
        f[k] = j
        j += 1
    t = max(t, j - i)
    if t >= len(a) // 2:
        return True
    return False
```
如果调用函数后返回的结果为 True，则 a 的值可能为（   ）

- A. [6, 1, 9, 6, 6, 9, 2, 9]
- B. [7, 7, 5, 3, 2, 2, 7, 3]
- C. [2, 6, 6, 2, 8, 8, 2, 4]
- D. [5, 2, 4, 2, 7, 2, 2, 3] ## 二、综合题（本大题共3题，其中第13题7分，第14题10分，第15题9分，共26分）
