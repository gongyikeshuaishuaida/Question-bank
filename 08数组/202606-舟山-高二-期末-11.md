# 题目 11

11. 有如下 Python 程序段：

```python
a = [2, 3, 1, 2, 4, 4, 3, 2, 5, 4]
n = len(a)
i = 0
while i < n:
    r = i + 1
    for j in range(i + 1, n):
        if a[j] != a[i]:
            a[r] = a[j]
            r += 1
    n = r
    i += 1
print(a[:r])
```

执行该程序段后，输出的结果是（   ）

- A. `[2, 3, 1, 4]`
- B. `[2, 3, 1, 2, 3, 2, 5, 4]`
- C. `[3, 1, 2, 4, 5]`
- D. `[2, 3, 1, 4, 5]`

---

## 答案

**正确答案：** D
