# 题目 13

快递根据体积分为 A、B、C 三种类型，快递柜有大、中、小三种格口。A 只能投大格口，B 可投大、中格口，C 三类均可投。

(1) 若大、中、小格口剩余 1、2、3，未投放快递 `["B","B","C","B","C"]`，则 ▲ （选填：能/不能）完成投放。

(2) 请在划线处填入合适代码：

```python
cab = [3, 4, 8]  # cab[0]、cab[1]、cab[2] 分别表示大、中、小格口剩余数量
pac = ["A","C","C","B","C","C","B","C","C","B","B","C","B","A","C"]
num = [0, 0, 0]
for i in range(len(pac)):
    d = ①
    num[d] += 1
    ②
    rest = 0
for i in range(3):
    if cab[i] + rest >= num[i]:
        ③
    else:
        flag = False
        break
if flag == True:
    print("能完成投放")
else:
    print("不能完成投放")
```

---

## 答案

**正确答案：**

(1) 能

(2) ① `ord(pac[i]) - ord("A")`；② `flag = True`；③ `rest = cab[i] + rest - num[i]`

---

## 解析

(1) B投大/中，C投中/小。1大+2中+3小可满足 3B+2C。

(2) ① 将字母 A/B/C 转为索引 0/1/2。② 初始化标志。③ 大格口多余容量可降级给 B/C，`rest` 累计剩余容量。
