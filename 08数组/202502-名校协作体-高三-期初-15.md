# 题目 15

每条流水线用由 `0、1、-1` 组成的需求串表示原材料要求：`1` 为必须使用，`0` 为可有可无，`-1` 为不需要。程序从少到多枚举原材料生产方案 `b`，判断是否满足所有流水线。

## （1）最少生产方案

4 条流水线的需求为：`1,0,1`；`1,-1,0`；`0,0,1`；`1,-1,1`。最少方案为 **101**。

## （2）字符串分组

调用 `chan("110-10101-1-1-11", 6, 2)` 时，语句 `i += 1` 的执行次数为 **2**。

## （3）补全程序

```python
# 读取原材料种类 n、流水线数量 k 及需求串 s，代码略
b = [0] * (n + 1)
a = chan(s, n, k)
p = True
while p == True and b[0] == 0:       # ①
    j = n
    while b[j] == 1:
        j -= 1
    b[j] = 1
    for i in range(j + 1, n + 1):
        b[i] = 0                      # ②
    p = False
    for i in range(len(a)):
        for j in range(len(a[i])):
            if a[i][j] == 1 and b[j+1] == 0 or a[i][j] == -1 and b[j+1] == 1:  # ③
                p = True

if p == True:
    print("无最佳原材料生产方案！")
else:
    for i in range(1, n + 1):
        if b[i] == 1:
            print("原材料", i, "必须生产")
        else:
            print("原材料", i, "无需生产")
```

填空：① `p==True and b[0]==0`；② `b[i]=0`；③ `a[i][j]==-1 and b[j+1]==1`。

---
## 答案
**正确答案：** （1）101　（2）2　（3）①`p==True and b[0]==0`；②`b[i]=0`；③`a[i][j]==-1 and b[j+1]==1`

---
## 解析
方案 `101` 同时满足四条流水线的必需材料且没有生产被明确禁止的材料。`chan` 按 `-` 分隔的负值项和普通数字项分组，恰好形成两个长度为 6 的元素。枚举时每次把当前方案之后的位清零；若某条流水线出现“必须但未生产”或“不需要但生产”的冲突，就将 `p` 置为真继续枚举。
