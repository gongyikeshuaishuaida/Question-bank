# 题目 12

12. 有如下 Python 程序：

```python
n = len(info)
last = [-1] * n
next = [n] * n
for i in range(n):
    k = info[i]
    if last[k] != -1:
        next[last[k]] = i
    last[k] = i
```

若 `info` 为 `[1, 2, 3, 2, 3, 1]`，执行程序后，`next` 的值为（   ）

- A. `[5, 3, 4, 6, 6, 6]`  
- B. `[5, 3, 4, -1, -1, -1]`  
- C. `[0, 5, 1, 3, 2, 4]`  
- D. `[0, 5, 1, 6, 6, 6]`

---

## 答案

**正确答案：** A

---

## 解析

`last[k]` 记录值 k 上一次出现的位置，`next[last[k]] = i` 把上一次位置指向当前同值位置。对 `[1,2,3,2,3,1]` 跟踪可得 `next` 为 `[5,3,4,6,6,6]`。
