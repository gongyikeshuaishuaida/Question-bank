# 题目 15

某学校 n 名学生参加 1 分钟跳绳比赛，每位学生有两次成绩。两次成绩按跳绳个数从高到低分别存储。编写程序：更正第一次比赛中的错误数据，取两次成绩较高值为最终成绩，输出排名。

![[attachments/202506绍兴_15_图c.jpg]]

(1) 结合图 a 和图 b，若仅更正图 a 中编号为 5 的学生跳绳个数为 199，则最终成绩第 6 名的学生编号为 ▲ （填数字）。

(2) 定义 `correct(res, s1)` 函数，`res[0]` 为需更正的学生编号，`res[1]` 为更正后的个数。函数根据 res 更正 s1 中对应学生的成绩并保持降序。

```python
def correct(res, s1):
    i = 0
    while s1[i][0] != res[0]:
        i = i + 1
    if s1[i][1] < res[1]:      # 更正后数据更大，需前移
        s1[i][1] = res[1]
        while i >= 1:
            if s1[i][1] > s1[i-1][1]:
                s1[i], s1[i-1] = s1[i-1], s1[i]  # A
            else:
                break
            i -= 1
    else:
        s1[i][1] = res[1]
        while i < len(s1) - 1:
            if s1[i][1] < s1[i+1][1]:
                s1[i], s1[i+1] = s1[i+1], s1[i]  # B
            else:
                break
            i += 1
```

① 若 `s1 = [[3,215],[2,204],[4,190],[5,185],[11,174],[8,173]]`，`res = [2,184]`，调用 `correct(res, s1)`，则语句 A 执行次数为 ▲ ，语句 B 执行次数为 ▲ 。

② 删除加框处语句 `s1[i][1] = res[1]`（else 分支中的第一句），对运行结果 ▲ （选填：有/无）影响？

(3) 主程序如下，请在划线处填入合适代码：


## 答案

**正确答案：**

(1) 7

(2) ① 0、2；② 无

(3) ① `pa < n and a[pa][1] > a[pb][1]`（或 `>=`）；② `a[tail][2] = cur`；③ `mc = i`

---

## 解析

(1) 更正后按最终成绩排名，第 6 名为编号 7。

(2) ① res[1]=184 < s1[1][1]=204，走 else 分支，A 执行 0 次；B 向后交换 2 次。② else 分支中已有 `s1[i][1] = res[1]`，加框处重复。

(3) ① 归并选择成绩高者。② 链表连接。③ 成绩不同时更新排名序号。
