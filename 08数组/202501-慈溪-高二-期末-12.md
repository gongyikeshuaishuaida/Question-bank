# 题目 12

某 Python 程序如下：

```python
s = [0] * len(a)
s[0], maxa = a[0], a[0]
for i in range(1, len(a)):
    s[i] = s[i-1] + a[i]              # ①；此处是方框处
    for j in range(i-1, -1, -1):
        if s[i] - s[j] > maxa:         # ②；此处是方框处
            maxa = s[i] - s[j]
```

若 `a=[9,-6,8,7,-4,2,3,-2,1,9]`，则执行该程序段后，下列说法中不正确的是（　　）

- A. 列表 `s` 的值变为 `[9,3,11,18,14,16,19,17,18,27]`
- B. 加框处①语句执行后，`s[i]` 的值不一定大于 `s[i-1]`
- C. 加框处②语句一共执行了 45 次
- D. 该程序段的功能为统计列表 `a` 中任意两个元素的最大差值

---

## 答案

**正确答案：** D

---

## 解析

`s` 是前缀和数组；当 `a[i]` 为负数时，`s[i]` 可能小于 `s[i-1]`。内层循环执行次数为 `1+2+...+9=45`。`s[i]-s[j]` 表示一段连续元素之和，程序比较的是前缀和之差，并不是任意两个原始元素的差值，因此 D 错误。
