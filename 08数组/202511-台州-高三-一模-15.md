# 题目 15

15．某工厂接到一批零件订单，要用一台设备进行加工。每个订单的信息包含订单编号、加工时长、截止时间和订单状态。订单状态为"T"表示设备符合该订单的加工要求；标记"F"表示设备不符合该订单的加工要求。

该工厂从第1天开始工作，在订单状态为"T"的订单中选择尽可能多的订单依次进行加工，一旦选择某个订单，其加工结束时间必须小于等于该订单的截止时间，且处理完该订单后才能开始处理下一个订单。（时间单位均为天）

（1）由题意可知，若将第15题图a中编号S04的订单状态修改为"T"，则该工厂最多可完成的订单数量为 ▲ 。

（2）定义如下 `bubble_sort(lst)` 函数，参数lst列表中每个元素包含4个数据项，依次为订单编号、加工时长、截止时间和订单状态。函数的功能是根据每个订单的截止时间，对lst进行升序排序，并删除状态为"F"的订单。

```python
def bubble_sort(lst):
    n = len(lst)
    i = 0
    while i < n:
        for j in range(n - 1, i, -1):
            if lst[j][3] == "T":
                if lst[j - 1][3] == "F" or lst[j][2] < lst[j - 1][2]:
                    lst[j], lst[j - 1] = lst[j - 1], lst[j]
        if lst[i][3] == "F":
            break
        i = i + 1
    return lst[0:i]
```

① 若lst列表依次存储第15题图a所示的订单信息，如 `lst[0] = ["S01", 5, 7, "T"]`，调用 `bubble_sort(lst)` 函数，则语句 "`i = i + 1`" 的执行次数为 ▲ 。

② 若将加框处语句修改为 "`i < n - 1`"，则对函数返回结果 ▲ （单选，填字母：A．有影响 / B．无影响）。

## 答案

**正确答案：**

（1）3

（2）① 3
② A（有影响）

（3）① `current + data[i][1] - 1 <= data[i][2]`
② `j -= 1`
③ `current - j + data[i][1]`

---

## 解析

（1）图a中订单按截止时间排序后的状态为"T"的订单有：S02(时长3,截止4), S01(时长5,截止7)。若S04改为"T"，则增加S04(时长2,截止8)。依次安排：
- current=1（第1天开始），选S02：加工3天，结束于第3天≤截止4 ✓，current=4
- 选S04：加工2天，结束于第5天≤截止8 ✓，current=6
- 选S01：加工5天，结束于第10天>截止7 ✗

最多完成3个订单（S02, S04, 另一个符合的订单）。

（2）① 函数执行时，i从0开始递增。分析排序过程：每轮将"F"订单沉底、按截止时间冒泡"T"订单。当 lst[i] 为"F"时 break。对于图a数据（S01:T, S02:T, S03:F, S04:F, S05:T），排序后"F"订单被排到后面。i会递增3次后遇到"F"而退出循环。

② 改为 `i < n - 1` 会影响函数返回结果（A），因为当最后一个元素为"T"时，原条件 `i < n` 会多处理一轮，而改为 `i < n - 1` 可能少处理一轮，导致排序不完整。

（3）程序使用贪心策略：优先选择加工时长短且截止时间早的订单。
- ① 判断当前订单能否被安排（在当前时间开始加工，能在截止时间前完成）：`current + data[i][1] - 1 <= data[i][2]`
- ② 找到占用加工时长最长的已选订单（从m向下扫描c列表）：`j -= 1`
- ③ 替换后更新当前时间：`current - j + data[i][1]`（减去被替换订单的时长j，加上新订单的时长）
