# 题目 12

有如下 Python 程序段:
```python
import random
a=[0]*6
for i in range(6):
    a[i]=random.randint(4,9)
i,n=0,len(a)
while i<n:
    p=i+1
    for j in range(i+1,n):
	    if a[i]!=a[j]:
		    a[p]=a[j]
		    p+=1
    n=p; i+=1
```
运行该程序后，a 的值可能是（   ）

- A. [4,5,7,3,4,5]
- B. [5,6,4,4,6,5]
- C. [8,7,9,7,4,9]
- D. [7,8,5,5,6,8] 

---

## 答案

**正确答案：** B
