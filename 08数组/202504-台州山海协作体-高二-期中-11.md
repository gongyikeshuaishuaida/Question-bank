# 题目 11

11. 数组 `a` 中存放着无重复的正整数，现需要从数组 `a` 找出最大值 `max1` 和次大值 `max2`。实现该功能的程序如下：

```python
max1 = max2 = 0
a = [100, 101, 98, 85, 60, 55, 43]
for i in range(len(a)):
    if a[i] > max1:
        ____
        ____
    elif a[i] > max2:
        ____
print("最大值为:" + str(max1) + ",次大值为:" + str(max2))
```

上述程序段中划线处可选的语句为：① `max1 = a[i]`　② `max2 = max1`　③ `max2 = a[i]`

则划线处语句依次为（   ）

- A. ③①②
- B. ②①③
- C. ②③①
- D. ①②③

---

## 答案

**正确答案：** B

---

## 解析

当 `a[i] > max1` 时，原最大值变为次大值（② `max2 = max1`），再更新最大值（① `max1 = a[i]`）。当 `a[i]` 介于两者之间时，仅更新次大值（③ `max2 = a[i]`）。故顺序为 ②①③。
