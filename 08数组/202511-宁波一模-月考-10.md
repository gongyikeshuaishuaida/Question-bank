# 题目 10

10. `a` 数组中有 `n` 个元素（`n` 为偶数），现要将所有索引为奇数的元素循环右移两位，索引为偶数的元素不变，如 `[1, 2, 3, 4, 5, 6]` 处理后得到 `[1, 6, 3, 2, 5, 4]`。实现该功能的 Python 程序段如下：

```python
n = len(a)
last = a[n-1]
for i in range(______①______):
    ______②______
a[i] = last
```

则划线处应填入的正确代码为（   ）

- A. ① `n-3, 0, -2`  ② `a[i + 2] = a[i]`
- B. ① `n-1, 1, -2`  ② `a[i - 2] = a[i]`
- C. ① `1, n-1, 2`  ② `a[i + 2] = a[i]`
- D. ① `0, n-2, 2`  ② `a[i - 2] = a[i]`

---

## 答案

**正确答案：** A

---

## 解析

奇数索引元素循环右移两位，即每个奇数位元素移到后面相隔 2 的奇数位。需先保存最后一个奇数位 `a[n-1]`，再从 `n-3` 倒序到 1，把 `a[i]` 赋给 `a[i+2]`，最后把保存的 `last` 放到 `a[1]`。选项 A 的循环和赋值方向正确。
