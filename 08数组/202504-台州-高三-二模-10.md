# 题目 10

某 Python 程序段如下所示：

```python
import random
lst = [2, 1, 7, 5, 5, 9, 8, 9, 3, 8]
b = [0] * 10
for i in range(10):
    b[lst[i]] += 1
j = 0
k = random.randint(3, 6)
while k > b[j]:
    k -= b[j]
    j += 1
```

运行该程序，j 的值不可能为（   ）

- A. 8
- B. 7
- C. 5
- D. 3

---
## 答案

**正确答案：** A

---
## 解析

统计数组为 b=[0,1,1,1,0,2,0,1,2,2]。当 k 取3、4、5、6时，循环结束的 j 分别为3、5、5、7，可能值只有3、5、7，故 j=8 不可能。
