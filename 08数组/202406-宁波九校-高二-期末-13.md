# 题目 13

13. 给定一个数字三角形，找出自顶向下的最小路径和。每一步只能移动到下一行中相邻的结点上。相邻的结点指的是下标与上一层结点下标相同或者等于上一层结点下标 +1 的两个结点。若某一步位于当前行的下标为 `i` 的结点，则下一步可以移动到下一行的下标 `i` 或 `i+1` 的结点。如第 13 题图 a 所示的数组三角形，自顶向下的最小路径和为 11（2 + 3 + 5 + 1 = 11）。

![[attachments/202406宁波九校高二_13_图1.png]]

编写 Python 程序，输入数字三角形，输出自顶向下的最小路径和。

（1）若将图 a 中第四行第二列的数字“1”改为“7”，则新的最小路径和为 ______。

（2）计算最小路径和的程序实现如下，请在程序划线处填入合适的代码。

```python
a = [[2],[3,4],[6,5,7],[4,1,8,3]]
n = len(a)
f = [[0] * n for i in range(n)]
f[0][0] = a[0][0]
for i in range(1,n):
    f[i][0] = f[i-1][0] + a[i][0]

        else:
            f[i][j] = f[i-1][j] + a[i][j]

for i in range(1,n):
    if f[n-1][i] < ans:
        ans = f[n-1][i]
print('最小路径和为：',ans)
```

---

## 答案

**正确答案：** （1）15；（2）① `f[i-1][j-1]<f[i-1][j]` 或 `f[i-1][j-1]<=f[i-1][j]`；② `f[i-1][i-1]+a[i][i]`；③ `ans=f[n-1][0]`

---

## 解析

第（1）小题把第四行第二列改为 7 后，底层路径和最小值为 `2+3+6+4=15`。程序中 `f[i][j]` 表示到达第 `i` 行第 `j` 个位置的最小路径和，中间位置应在上一行相邻的两个位置中取较小者，所以①比较 `f[i-1][j-1]` 和 `f[i-1][j]`。每行最右端只能由上一行最右端转移，故②为 `f[i-1][i-1]+a[i][i]`。最后先把答案初始化为最后一行第一个路径和，再遍历最后一行求最小值。
