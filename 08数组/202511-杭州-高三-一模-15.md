# 题目 15

15. 某团购平台提供生鲜下单与配送服务，用户下单时选择期望配送的时段（用从 1 开始的整数表示），平台会按此时段安排配送，也可能依据实际情况延迟配送。平台每个时段最多可完成 n 个订单的配送，同一时段内配送顺序遵循如下规则：根据延迟时长从大到小安排配送；若延迟时长相同或均无延迟，则按订单号从小到大安排配送。当前时段未配送的订单延至下一时段，若某订单延迟超过 m 个时段，就转派至第三方配送。

平台提供订单修改功能，同一个订单号可能对应多条记录，保留最后提交的记录并予以配送。现给定所有订单的数据表，每条记录包含提交时间、订单号和期望配送时段，并按提交时间的顺序排列，订单号按照提交时间从 1 开始编号。

在第 15 题图所示的样例中，n、m 分别为 2、1，根据图中前三行数据计算出需要保留的记录、订单的实际配送时段和转派情况。

![[attachments/202511-杭州-_06_图1.jpg]]

请回答下列问题：

（1）若在第 15 题图所示的样例中增加一条提交时间为 12:00、订单号为 5、期望配送时段为 3 的记录，那么需要转派的订单数量应为 ▲ 。

（2）定义如下 `filter(tasks)` 函数，tasks 列表中每个元素包含 3 个数据项，依次为提交时间、订单号和期望配送时段，列表已按提交时间的顺序排列。函数功能是保留每个订单最后提交的一条记录，并根据订单号对保留的订单进行升序排列。

```python
def filter(tasks):
    lst = [-1] * 1000    # 订单号范围是 1~999
    mx = 0
    for i in range(len(tasks)):
        sid = tasks[i][1]
        ①
        if mx < sid:
            mx = sid
    res = []    # 语句 A
    for k in range(1, mx+1):
        if lst[k] != -1:
            res.append(tasks[lst[k]])
    return res
```

① 请选择合适的语句填入程序中划线处： ▲ （单选，填字母）。
- A. `lst[sid] = i`
- B. `lst[i] = sid`
- C. `lst[i] = mx`

② 若 tasks 为 `[["08:00", 1, 1], ["08:10", 2, 2], ["08:34", 1, 2], ["08:44", 3, 1], ["09:05", 2, 1], ["09:20", 4, 3], ["09:30", 3, 2]]`，调用 filter(tasks) 函数，则执行到语句 A 时，变量 mx 的值为 ▲ 。

（3）实现按照规则输出转派订单的数量，以及其余订单实际配送时段的 Python 程序如下，请在划线处填入合适的代码。

```python
def solve(tasks, n, m):
    last = 0
    for s in tasks:
        if s[2] > last:
            last = s[2]
    info = [[-1, -1, 0] for i in range(last + 1)]
    nxt = [-1] * len(tasks)
    for i in range(len(tasks)):
        stime = tasks[i][2]
        if info[stime][0] == -1:
            ①
        else:
            nxt[info[stime][1]] = i
        info[stime][1] = i
        info[stime][2] += 1
    curtime = 1
    t = 1
    num = 0
    ans = []
    while num < len(tasks):
        count = 0
        for p in range(t, curtime + 1):
            if count >= n or p > last:
                break
            while ②:
                ans.append([tasks[info[p][0]][1], curtime])
                count += 1
                info[p][2] -= 1
                info[p][0] = nxt[info[p][0]]
                if info[p][0] == -1:
                    info[p][1] = -1
        num += count
        curtime += 1
        while t + m < curtime:
            ③
            t += 1
    return num - len(ans), ans
```

## 答案

**正确答案：**

（1）0

（2）① A；② 4

（3）① `info[stime][0] = i`；② `info[p][0] != -1 and count < n`（或 `info[p][2] > 0 and count < n`）；③ `num += info[t][2]`

---

## 解析

（1）原始样例中 3 条记录经 filter 后保留 2 条（订单 1 最后提交为时段 2，订单 2 最后提交为时段 2）。增加订单 5 后，时段 1-3 各分配合理，无需转派，故转派数量为 0。

（2）① `lst[sid] = i` 记录订单号 sid 最后一次出现的索引 i，选 A。
② 遍历后 mx 记录最大订单号，task 中出现的订单号为 1,2,3,4，故 mx=4。

（3）该算法模拟按时段配送的调度过程：
- ① 初始化时段 stime 的链表头指针：`info[stime][0] = i`。
- ② 在当前时段 p 中，还有未配送订单且未超过容量限制时继续配送：`info[p][0] != -1 and count < n`。
- ③ 超过 m 个时段延迟的订单转派，将时段 t 的所有剩余订单计入转派：`num += info[t][2]`。
