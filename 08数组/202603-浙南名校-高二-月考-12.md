# 题目 12

有如下 Python 程序段：

```python
# 生成 5 个随机整数，保存在列表 a 的元素 a[0]～a[4] 中，代码略
maxs = 4
tmp = minl = L = R = 0
while R < 5:
    tmp += a[R]
    while L <= R and tmp >= maxs:
        tmp -= a[L]
        L += 1
    if R - L + 1 > minl:
        minl = R - L + 1
    R += 1
print(minl)
```

> 原卷内层循环印作 `L <= r`，结合变量定义和程序语义应按 `L <= R` 理解。

执行该程序段后，输出结果为 3，则 `a[0]～a[4]` 的值可能为（   ）

- A. `[4, 0, 0, -2, -3]`
- B. `[2, -3, 6, 1, 7]`
- C. `[-7, 7, 1, 2, 3]`
- D. `[-3, 2, -1, 6, 0]`

---

## 答案

**正确答案：** D

---

## 解析

程序用窗口 `[L,R]` 累加元素；当窗口和达到 4 时不断右移 `L`，直到窗口和小于 4。`minl` 实际记录收缩后出现过的最大窗口长度。

对 D 模拟：前三轮窗口长度依次为 `1、2、3`；加入 `6` 后窗口和达到阈值，内层循环连续右移 `L`，后续窗口长度不再超过 3；最后加入 `0` 时窗口长度为 1。因此输出 3，选择 D。
