# 题目 12

12.有如下程序段：

```python
import random
a=[0]*5
for i in range(5):
    a[i]=random.randint(-5,5) #randint(a,b)产生[a,b]区间的随机整数
max=-25
for i in range(5):
    s=a[i]
    for j in range(i+1,5):
        s+=a[j]
        if s>max:
            max=s
print(max)
```

运行该程序段后，输出结果为2，则列表a可能为（   ）

- A. `[4, -2, -1, 1, -1]`
- B. `[-3, 2, 1, -2, -1]`
- C. `[2, -3, -1, 5, -2]`
- D. `[5, -6, 1, -2, 2]`

---

## 答案

**正确答案：** A

---

## 解析

程序求所有长度≥2的连续子段的最大和。分别计算四个选项的子段和最大值：A选项长度≥2子段最大和为2（如4+(-2)=2，-2+(-1)+1+(-1)≤2），符合题意。B、C两项可得更大子段和，D项最大连续子段和小于2。
