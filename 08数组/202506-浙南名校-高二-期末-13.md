# 题目 13

某车间有编号 1~n 段机械轨道，出现多处故障需维修。若任意连续 3 段轨道中仅有一段发生故障，则不影响运行。编写程序，根据故障轨道编号，输出最少需要维修的轨道编号。例如故障轨道 [1,2,3,6,7,9]，最少需维修 [2,3,7] 这 3 段。

(1) 若故障轨道编号为 [1,2,3,4,5,7,8,9,13]，则最少需要维修的轨道数量为 ▲ 段。

(2) 请将程序补充完整。

```python
# 输入故障轨道序列 faults，代码略
result = []
n = len(faults)
repair = [False] * n
i = 0
while i < n:
    j = i + 1
    while j < n and faults[j] - faults[i] < 3:
        ①
        j += 1
    ②
for i in range(n):
    if repair[i]:
        result.append(③)
print(result)
```

---

## 答案

**正确答案：**

(1) 5

(2) ① `repair[j] = True`；② `i = j`；③ `faults[i]`

---

## 解析

(1) 贪心策略：在连续故障段中选择维修最少的关键轨道，使得任意连续 3 段中不超过 1 段故障。9 段故障需修 5 段。

(2) ① 将与 faults[i] 距离小于 3 的故障轨道标记为需维修。② 跳过已处理区间。③ 输出需维修的轨道编号。
