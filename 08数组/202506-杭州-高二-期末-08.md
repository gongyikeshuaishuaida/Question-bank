# 题目 08

8. 数组 a 的长度为 n，现需要删除下标 x（x≥0）开始的 L（x+L-1<n）个数据，例如：n 为 7，数组 a 为 `[3,2,1,4,0,5,6]`，x 为 1，L 为 2，删除操作后的结果为 `[3,4,0,5,6]`。实现该功能的 Python 程序段如下，方框中应填入的正确代码为（   ）

```python
i = x
while i < ____:
    a[i] = a[i+L]
    i += 1
print(a[0:i])    # 输出删除操作后的结果
```

- A. `x+L`
- B. `x+L+1`
- C. `n-L`
- D. `n-L+1`

---

## 答案

**正确答案：** C

---

## 解析

删除长度为 `L` 的连续数据后，原数组中下标 `x+L` 到 `n-1` 的元素要依次前移到下标 `x` 到 `n-L-1`。循环最后一次应执行到 `i=n-L-1`，因此条件为 `i < n-L`。
