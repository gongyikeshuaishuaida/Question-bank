# 题目 11

11. 医院用蓝牙信标为视障患者导航。每个时刻选择信号强度值最大的信标，只有编号变化时
才追加到患者路径；再与预设路径`B01→B02→B03→B04`逐项比较，统计首次偏离位置。

![[attachments/202606温州学考_11_图1.jpg]]

（1）根据图中数据记录，09:30:02 时选出的信标编号为①______；09:35:18 时，患者行走路径与预设路径②______（选填“有”或“无”）偏离。

（2）为实现从日志数据中提取患者行走路径的功能，定义函数 `trace(data)`。列表 `data` 存储某患者的导航日志，每个元素格式如 `["09:30:00", "B01", -42]`。请在划线处填入合适的代码。

```python
def trace(data):
    path = []
    pre = ""
    i = 0
    while i < len(data):
        best = i
        i += 1
        while i < len(data) and data[i][0] == data[best][0]:
            if data[i][2] > data[best][2]:
                best = i
            i += 1
        b = data[best][1]
        if b != pre:
            path.append(b)
            ①
    return path
```

（3）定义 `check(path, route)` 函数，比对患者行走路径与预设路径中的信标编号，一旦编号不一致，标注为“患者偏离”。请在划线处填入合适的代码。

```python
def check(path, route):
    result = [""] * len(route)
    i = 0
    while i < len(path) and i < len(route):
        if ②:
            result[i] = "患者偏离"
            break
        i += 1
    return result
```

（4）主程序如下，请在划线处填入合适的代码。

```python
route = ["B01", "B02", "B03", "B04"]
# 读取所有患者的导航日志，存入列表 logs，代码略
maxi = 0
err = [0] * len(route)
for log in logs:
    path = trace(log)
    result = check(path, route)
    for i in range(len(result)):
        if result[i] == "患者偏离":
            ③
            if err[i] > err[maxi]:
                maxi = i
if err[maxi] > 0:
    print("偏离最多的位置:" + route[maxi] + ", 共" + str(err[maxi]) + "次")
```

---

## 答案

（1）① B01　② 有

（2）① `pre = b`

（3）② `path[i] != route[i]`

（4）③ `err[i] += 1`

---

## 解析

同一时刻信号值越大（越接近0）越强，因此09:30:02选择B01。路径发生变化时更新`pre`；比对首次不一致处并累加该预设信标的偏离次数。
