# 题目 14

14. 有如下 Python 程序段：

```python
def f(x, y):
    while x < y:
        if ①:
            a[x], a[y] = a[y], a[x]
            x += 1; y -= 1
        elif a[x] % 3 == 0:
            ②
        else:
            ③

a = [6, 9, 8, 6, 5, 15]
f(0, len(a) - 1)
```

执行该程序后，a 的值为 `[6, 9, 15, 6, 5, 8]`，则划线处合适的语句是（   ）

- A. ① `a[x] % 3 == 0 and a[y] % 3 == 0` / ② `y -= 1` / ③ `x += 1`
- B. ① `a[x] % 3 != 0 and a[y] % 3 == 0` / ② `x += 1` / ③ `y -= 1`
- C. ① `a[x] % 3 != 0 and a[y] % 3 == 0` / ② `y -= 1` / ③ `x += 1`
- D. ① `a[x] % 3 == 0 and a[y] % 3 != 0` / ② `x += 1` / ③ `y -= 1`

---

## 答案

**正确答案：** B

---

## 解析

算法目标：将能被 3 整除的数移到前面。双指针 x（前）和 y（后）：当 x 位置不能被 3 整除且 y 位置能被 3 整除时交换。初始 a=[6,9,8,6,5,15]，x=0, y=5：a[0]=6%3==0 → elif 分支 ②→x+=1。x=1, y=5：a[1]=9%3==0 → x+=1。x=2, y=5：a[2]=8%3!=0 且 a[5]=15%3==0 → 交换得 [6,9,15,6,5,8]，x=3, y=4。此后循环结束。B 逻辑正确。
