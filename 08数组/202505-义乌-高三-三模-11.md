# 题目 11

11. 阅读以下程序：

```python
a = [2,3,1,2,4,4,3,2,5,4]
m = 0;tmp = 0
for i in range(len(a)):
    if i % 4 != 0:
        tmp += a[i]
    elif m < tmp:
        m = tmp
        tmp = 0
print(m)
```

程序运行结束后，输出的结果是（   ）

- A. 7
- B. 8
- C. 9
- D. 10

---
## 答案

**正确答案：** C

---
## 解析

在下标1—3处累加得到 `3+1+2=6`，下标4处更新 `m`；下标5—7处累加得到 `4+3+2=9`，下标8处更新 `m=9`。最后一个不完整区间不会再次触发更新，输出为9。
