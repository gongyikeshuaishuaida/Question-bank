# 题目 15

15. 有一组正整数序列存储在列表 `a` 中，要求对其中的奇偶数进行调整。调整后奇数在前偶数在后，并保持相对顺序不变。实现上述算法的 Python 程序如下：

```python
a = [93, 32, 15, 80, 50, 13, 90, 19, 57, 83]
b = []
n = len(a)
k, i = 0, 0
while i < n:
    if ①:
        k += 1
        b.append(a[i])
    else:
        ②
    i += 1
for j in range(③):
    a[j] = b[j - n + k]
print(a)
```

下列选项中，划线 ① ② ③ 处的正确顺序是（   ）

- A. ① `a[i] % 2 == 1` / ② `b[i-k] = a[i]` / ③ `n-k+1, n`
- B. ① `a[i] % 2 == 0` / ② `a[i-k] = a[i]` / ③ `n-k, n`
- C. ① `a[i] % 2 == 1` / ② `a[i-k] = a[i]` / ③ `n-k, n`
- D. ① `a[i] % 2 == 0` / ② `b[i-k] = a[i]` / ③ `n-k+1, n`

---

## 答案

**正确答案：** B

---

## 解析

算法：遍历 `a`，偶数存入 `b`（① `a[i] % 2 == 0`），奇数前移 `a[i-k] = a[i]`（②，k 为已移出的偶数个数）。遍历结束后，`a` 的前 `n-k` 位为奇数（保持原序），再将 `b` 中 `k` 个偶数复制到 `a` 的末尾 `range(n-k, n)`（③）。
