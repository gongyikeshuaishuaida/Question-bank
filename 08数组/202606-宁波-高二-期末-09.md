# 题目 09

9. 有如下 Python 程序段：

```python
a = [7, -1, -3, -8, 10, 0, -3, 7]
k1, k2 = 0, 0
for i in range(len(a)):
    if a[i] < a[k1]:
        k2 = k1
        k1 = i
    elif a[i] <= a[k2]:
        k2 = i
```

该程序段运行后，变量 `k1`、`k2` 的值分别为（   ）

- A. 3，2
- B. 3，6
- C. 4，7
- D. 4，0

---

## 答案

**正确答案：** B

---

## 解析

`k1` 记录当前最小值的位置，遇到更小值时原来的 `k1` 转给 `k2`。遍历结束后最小值 `-8` 的下标为 3，因此 `k1=3`；其余元素中的次小值为 `-3`，条件使用 `<=`，后出现的下标 6 会覆盖原下标 2，因此 `k2=6`。
