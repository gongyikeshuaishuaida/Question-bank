# 题目 12

12. 有如下Python程序段：

```python
import random
n = 6
a = [random.randint(1, 9) for i in range(n)]
for i in range(1, n - 1):
    if i % 2 == 1:
        while a[i] <= a[i - 1] or a[i] <= a[i + 1]:
            a[i] += random.randint(1, 5)
    else:
        while a[i] >= a[i - 1] or a[i] >= a[i + 1]:
            a[i] -= random.randint(1, 5)
print(a)
```

执行该程序段后，输出结果可能是（   ）

- A. `[3, 7, 2, 8, 1, 10]`
- B. `[0, 8, 3, 7, 2, 5]`
- C. `[2, 6, 5, 15, 8, 9]`
- D. `[5, 9, 4, 10, 3, 8]`

---

## 答案

**正确答案：** D

---

## 解析

下标0和5不参与循环，值必须保持在1～9，因此A中的`a[5]=10`和B中的`a[0]=0`不可能。C若最终`a[2]=5`，处理下标2时要停止必须已有`a[3]>5`；随后处理下标3时，若要继续增加又需`a[3]<=a[4]`，而初始`a[4]`至多为9，一次增加至多5，无法得到15。D满足奇数下标为局部高点、偶数下标为局部低点，并可由初始1～9的取值经程序产生。
