# 题目 15

为提升交通信号灯的巡查管理效率，某交通管理局制定了一套智能信号灯巡查优先级编排方案。每个信号灯有坐标位置和权重值。

编排方案：
1. 选取权重最大的 n 个作为主信号灯
2. 在每个主信号灯左右距离 k 范围内，寻找权重最大的且未被选中的 m 个作为辅助信号灯
3. 按分区输出编排结果

(1) 信号灯数据 `[[1,10],[3,20],[5,15],[7,30],[9,25],[11,5],[13,35],[15,40],[17,22]]`，n=2, k=4, m=3 时，被选入巡查列表的信号灯总数是 ▲ 。

(2) ① 调用 `findn(data, n, usedlst)` 函数，若 data 为 `[[1,10],[3,20],[5,15],[7,30],[9,25],[11,5],[13,35],[15,40],[17,42]]`，n=4，usedlst 为 `[3,4,5]`，则返回值是 ▲ 。

② 程序中加框处代码 `for j in range(len(ls)-i)` 有错，请改正为： ▲ 。

(3) 请在划线处填入合适的代码：

```python
def findmax(data, usedlst):
    maxi = -1
    for i in range(len(data)):
        if i not in usedlst:
            if ①:
                maxi = i
    return maxi

def traverse_signals(data, usedlst, n, k, m):
    main_ls = findn(data, n, usedlst)
    usedlst += main_ls
    for i in range(len(data)):
        data[i].append(-1)
    f_i = []
    for i in range(len(main_ls)):
        f_i.append([main_ls[i], 0])
    for i in range(len(data)):
        maxi = findmax(data, usedlst)
        if maxi == -1:
            break
        for j in range(len(main_ls)):
            if ② and f_i[j][1] < m:
                f_i[j][1] += 1
                data[f_i[j][0]][2] = maxi
                ③
                break
        usedlst.append(maxi)
```

---

## 答案

**正确答案：**

(1) 5

(2) ① `[1, 6, 7, 8]`；② `len(ls)-1, i, -1`

(3) ① `maxi == -1 or data[i][1] > data[maxi][1]`；② `abs(data[maxi][0] - data[main_ls[j]][0]) <= k`；③ `f_i[j][0] = maxi`

---

## 解析

(1) 主信号灯：权重最大 2 个（40、35）。在 k=4 范围内各选 m=3 个辅助灯，去重后共 5 个。

(2) ① 排除已使用的 [3,4,5]，从剩余中选权值最大的 4 个索引。② 冒泡排序范围应为 `range(len(ls)-1, i, -1)`。

(3) ① `findmax` 找权值最大的未使用信号灯。② 判断信号灯坐标是否在主信号灯的 k 范围内。③ 更新分区链表头指针。
