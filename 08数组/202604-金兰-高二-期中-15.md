# 题目 15

15. 某学校有若干项活动，每项活动对各种材料的要求分别用 1、0、-1 表示：1 表示必须准备，0 表示不需要，-1 表示不能准备。现要选择尽量少的材料，使其满足所有活动的要求。

| 活动 | 材料1 | 材料2 | 材料3 | 材料4 |
| --- | ---: | ---: | ---: | ---: |
| 活动1 | 1 | 0 | 1 | -1 |
| 活动2 | 1 | 0 | 0 | 0 |
| 活动3 | 0 | 0 | 1 | -1 |

（1）用长度为 4 的 01 字符串表示材料准备方案，则满足上表要求的方案为______。

（2）函数 `ch(s,n,k)` 将字符串 `s` 中连续存储的要求转换为二维列表，其中 `n` 为材料种数，`k` 为活动数。若 `s="101-11000001-1"`，执行 `ch(s,4,3)` 时，语句 `i += 1` 共执行______次。

```python
def ch(s, n, k):
    a = [[] for i in range(k)]
    p = 0
    i = 0
    while p < len(s) and i < k:
        if s[p] == "-":
            a[i].append(int(s[p:p+2]))
            p += 2
        else:
            a[i].append(int(s[p]))
            p += 1
        if len(a[i]) == n:
            i += 1
    return a
```

（3）以下程序枚举材料准备方案并寻找满足要求的方案，请在划线处填入合适代码。

```python
b = [0] * (n + 1)
a = ch(s, n, k)
flag = True
t = 0
while ①:
    b[n] += 1
    j = n
    while b[j] == 2:
        b[j-1] += 1
        ②
        j -= 1
    flag = False
    for i in range(k):
        for j in range(n):
            if ③ or a[i][j] == -1 and b[j+1] == 1:
                flag = True
    t += 1
print("材料准备方案为：", b[1:])
```

---

## 答案

（1）1010

（2）3

（3）

① `flag and b[0] == 0`

② `b[j] = 0`

③ `a[i][j] == 1 and b[j+1] == 0`

---

## 解析

（1）材料1、材料3必须准备，材料2不需要，材料4不能准备，所以方案为 `1010`。

（2）每读取完一项活动的 4 个要求，`i` 增加 1；字符串中共有 3 项活动，因此执行 3 次。

（3）列表 `b[1:]` 作为 n 位二进制数，从小到大枚举方案，`b[0]` 是最高位溢出的进位。某活动要求必须准备但方案位为 0，或要求不能准备但方案位为 1，均产生冲突并令 `flag=True`。当方案无冲突时循环结束；若所有方案都冲突，则 `b[0]` 变为 1 后停止。
