# 题目 11

11. 有如下Python程序：

```python
from random import randint
a = [9, 4, 7, 5, 6, 3, 8, 2]
n = len(a)
x = randint(1, 3) * 2 + 1
for i in range(n - 1):
    for j in range(x, i, -1):
        if a[j] < a[j - 1]:
            a[j], a[j - 1] = a[j - 1], a[j]
```

执行该程序段后，数组`a`的值不可能为（   ）

- A. [2,3,4,5,6,7,8,9]
- B. [3,4,5,6,7,9,8,2]
- C. [4,5,7,9,6,3,8,2]
- D. [4,5,6,7,9,3,8,2]

---

## 答案

**正确答案：** D

---

## 解析

x只能为3、5、7。分别执行得到C、B、A三个结果，因此D不可能出现。
