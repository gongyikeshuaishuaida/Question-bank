# 题目 10

10. 以下函数的功能是对列表 a 中元素升序排序：

```python
def sort(a):
    n = len(a)
    for i in range(1, n):
        key = a[i]
        j = i - 1
        while ____:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a
```

划线处应填入的正确代码为（   ）

- A. `j >= 0 and a[j] > a[j + 1]`
- B. `j >= 0 or a[j] < key`
- C. `j > 0 or a[j] > a[j + 1]`
- D. `j >= 0 and a[j] > key`

---

## 答案

**正确答案：** D

---

## 解析

插入排序：当 `j >= 0` 且 `a[j] > key` 时，将较大的 `a[j]` 后移一位。D 正确。A 比较的是相邻元素而非与 key 比较。B 使用 or 导致无限循环。C 条件错误。
