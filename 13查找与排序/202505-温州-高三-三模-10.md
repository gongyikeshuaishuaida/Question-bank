# 题目 10

10. 有如下 Python 程序段：

```python
#随机生成数组d，代码略
for i in range(len(d)-1):
    for j in range(__________):  # 此处是方框处
        if d[j] > d[j+1]:
            d[j], d[j+1] = d[j+1], d[j]
```

加框处可以选填的代码有：

```python
① 0, len(d)-i-1
② i, len(d)-2
③ len(d)-1, i, -1
④ len(d)-2, i-1, -1
```

以下能正确实现排序的是

- A. ①③
- B. ①④
- C. ②③
- D. ②④

---
## 答案

**正确答案：** B

---
## 解析

①是从左到右的冒泡排序边界，④是从右到左的等价边界，两者组合可正确排序；②、③的边界不能与当前比较式正确配合。
