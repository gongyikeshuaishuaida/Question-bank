# 题目 11

11. 如下 Python 程序段实现了数组 `a` 的降序排序：

```python
i = 1
n = len(a)
while i < n:
    k = 0
    for j in range(n-i):
        if a[j] < a[j+1]:       # 语句①
            a[j], a[j+1] = a[j+1], a[j]  # 语句②
            k = j
    i = n - k
```

若 `a` 的值为 `[9,8,3,2,6,5,1]`，执行该程序段后，下列说法不正确的是（   ）

- A. 语句①共执行了 12 次
- B. 语句②共执行了 4 次
- C. 加框处语句共执行 3 次
- D. 加框处语句修改成 `k=n-1`，程序会陷入死循环

---

## 答案

**正确答案：** A

---

## 解析

三轮循环的比较次数分别为 6、4、3，共 13 次，因此 A 不正确。交换次数为 2+2+0=4 次；`k=0` 在每轮开始时执行，共 3 次。若把初值改成 `k=n-1`，在没有交换的轮次中会令 `i=n-(n-1)=1`，循环无法结束。
