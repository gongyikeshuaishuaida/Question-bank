# 题目 10

某二分查找算法的 Python 程序段如下：

```python
d = [1, 2, 3, 4, 4, 4, 4, 5, 6]
key = int(input())
c = 0
i = 0
j = len(d) - 1
while i <= j:
    m = (i + j) // 2
    if key >= d[m]:
        i = m + 1
    else:
        j = m - 1
    c += 1
print(c)
```

运行该程序段，输入以下 `key` 值，其中有一组输出结果 `c` 与另外三组不相同，则输出结果不同的输入 `key` 值为（   ）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** B

---

## 解析

程序统计循环次数。输入 3、5、6 时循环均执行 4 次，输入 4 时依次检查下标 4、6、7，只执行 3 次，因此不同的是 4。
