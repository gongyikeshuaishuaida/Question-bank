# 题目 11

11. 有如下 Python 程序：

```python
res = ''
k = 1
for i in range(len(a) - 2):
    if ord(a[i]) * k < ord(a[i + 2]) * k:
        a[i], a[i + 2] = a[i + 2], a[i]
    k = -k
for s in a:
    res += s
print(res)
```

已知数组 `a` 共 8 个元素，每个元素都为单个字符，运行该程序后输出结果可能是（   ）

- A. computer
- B. repomcut
- C. nesesicc
- D. sciences

---

## 答案

**正确答案：** D

---

## 解析

程序每次比较相隔 2 个位置的字符，并交替改变比较方向。`k=1` 时若前者较小就交换，`k=-1` 时若前者较大就交换。因此偶数位置序列的一趟处理中较小字符会向后移动，奇数位置序列中较大字符会向后移动。逐项检查，A、B、C 都违反相应末位特征，只有 D 可能成为输出。
