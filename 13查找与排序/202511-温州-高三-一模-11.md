# 题目 11

11. 列表a中每连续3个元素依次存储同一考生的考号、笔试成绩和面试成绩，即 `a[0]` 为某考生考号，`a[1]` 为该考生笔试成绩，`a[2]` 为该考生面试成绩，后续元素以此类推。原始数据已按考生考号升序。输入考生考号key，查找该考生的笔试、面试成绩。

实现该功能的Python程序如下：

```python
i = 0; j = __(1)__
while i <= j:
    m = __(2)__
    if a[m] == key:
        print("考号", key, "笔试成绩为", a[m + 1], "面试成绩为", a[m + 2]); break
    elif a[m] < key:
        i = __(3)__
    else:
        j = __(4)__
```

(1)(2)(3)(4)划线处可选填的有

① `len(a) // 3 - 1`
② `len(a) - 3`
③ `(i + j) // 2`
④ `(i + j) // 2 * 3`
⑤ `m // 3 + 1`
⑥ `m // 3 - 1`
⑦ `m + 3`
⑧ `m - 3`

则划线处应依次填入的是（   ）

- A. ①③⑤⑥
- B. ①④⑤⑥
- C. ②③⑦⑧
- D. ②④⑦⑧

---

## 答案

**正确答案：** B

---

## 解析

该程序使用二分查找在按考号升序的列表中查找指定考生。由于每个考生占3个连续元素，二分查找的索引需要区分"考生索引"和"数组索引"。

分析：
- `i`、`j` 为考生索引（第几个考生），范围 0 ~ 考生总数-1
- 考生总数 = `len(a) // 3`，所以 `j = len(a) // 3 - 1` → 选 ①
- `m` 是数组索引（直接访问 `a[m]` 比较考号），`m = (i + j) // 2 * 3` → 选 ④
- 当 `a[m] < key` 时，目标在右半部分，`i = m // 3 + 1`（将数组索引转回考生索引再加1） → 选 ⑤
- 当 `a[m] > key` 时，目标在左半部分，`j = m // 3 - 1` → 选 ⑥

填入顺序为 ①④⑤⑥，对应选项 B。
