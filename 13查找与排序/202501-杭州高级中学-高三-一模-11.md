# 题目 11

有如下 Python 程序段：

```python
# 在列表 a 中存储若干个整数类型的数据
n = len(a)
t = random.randint(0, n - 1)
for i in range(n):
    for j in range(n - 1, i, -1):
        x = (j - t) % n
        y = (x - 1) % n
        if a[x] % 3 < a[y] % 3:
            a[x], a[y] = a[y], a[x]
print(a)
```

以下运行结果不可能的是（   ）

- A. `[5, 8, 4, 1, 6]`
- B. `[20, 50, 30, 40, 10]`
- C. `[18, 12, 16, 4, 17]`
- D. `[11, 8, 15, 7, 13]`

---

## 答案

**正确答案：** A

---

## 解析

程序按由随机起点 `t` 决定的循环顺序，对各元素除以 3 的余数进行冒泡排序。因此把最终列表视为首尾相接后，余数序列至多出现一次由大到小的回绕。A 的余数依次为 2、2、1、1、0，存在两次下降，无法由任一循环起点形成非递减序列；其余选项均可选择合适的 `t` 得到。
