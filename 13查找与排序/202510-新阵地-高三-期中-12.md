# 题目 12

12. 有如下程序：
```python
import random
x = random.randint(2, 9)
i, j, res = 0, x, []
while i <= j:
    m = (i + j) // 2
    res.append(m)
    if m ** 2 > x:
        j = m - 1
    else:
        i = m + 1
```
执行后`res`的值不可能是（   ）

- A. `[1,2]`
- B. `[2,3]`
- C. `[3,2,1]`
- D. `[4,1,2,3]`

---

## 答案

**正确答案：** C

---

## 解析

枚举`x=2～9`跟踪二分区间，A、B、D分别可由某些x产生；`[3,2,1]`不符合区间更新轨迹。
