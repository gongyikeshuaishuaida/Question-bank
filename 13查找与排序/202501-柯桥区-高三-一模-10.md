# 题目 10

某二分查找算法的 Python 程序段如下：

```python
a = [1, 3, 3, 5, 5, 7, 8, 9, 9, 10]
i, j = 0, len(a) - 1
while i <= j:
    m = (i + j) // 2
    if key < a[m]:
        j = m - 1       # 语句①
    else:
        i = m + 1       # 语句②
```

运行该程序段，语句①执行 2 次，语句②执行 1 次，则 `key` 的值可能是（   ）

- A. 5 或 7
- B. 1 或 3
- C. 5 或 1
- D. 3 或 7

---

## 答案

**正确答案：** C

---

## 解析

逐步跟踪二分区间可得：`key=1` 和 `key=5` 时，语句①各执行 2 次、语句②各执行 1 次，因此选 C。
