# 题目 12

12. 执行如下程序段，下列说法正确的是（   ）

```python
from random import randint
nums = [0 for i in range(10)]
nums[0] = randint(0,20)
for i in range(1,10):
    nums[i] = nums[i-1] + randint(0,6)
target = 20
count = 0
left, right = 0, len(nums) - 1
while left <= right:
    mid = (left + right) // 2
    if nums[mid] == target:
        break
    elif nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
    count += 1
print(count)
```

A. 数组 `nums` 中不可能存在重复元素  
B. 程序结束后，变量 `left` 的值可能会小于 0  
C. 程序结束后，输出结果可能为 0  
D. 若 `target` 等于 `nums[5]`，程序运行后 `count` 一定等于 2

---

## 答案

**正确答案：** C

---

## 解析

`randint(0,6)` 可能取 0，所以 `nums` 中可能有重复元素。`left` 初值为 0，且只会增大，不会小于 0。若第一次循环时 `mid` 对应元素就是 `target`，会直接 `break`，此时 `count` 仍为 0，因此 C 正确。即使 `target==nums[5]`，由于可能存在重复值和区间调整路径不同，`count` 不一定等于 2。
