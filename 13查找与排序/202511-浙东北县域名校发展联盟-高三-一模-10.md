# 题目 10

**10．** 已知非降序列表 `a` 由若干个整型元素构成。现要查找并输出整数 `key` 出现的次数。实现该功能的程序段如下：

```python
def search(k):
    i, j = 0, len(a) - 1
    while i <= j:
        m = (i + j) // 2
        if           :
            i = m + 1
        else:
            j = m - 1
    return i

a = [1, 3, 6, 6, 6, 8, 9, 9, 9, 9, 10]
key = int(input("输入查找键: "))
x = search(key)
y = search(key - 1)
print("出现的次数: " + str(x - y))
```

加框处应填入的正确代码为（   ）

- A. `k <= a[m]`
- B. `k < a[m]`
- C. `k >= a[m]`
- D. `k > a[m]`

---

## 答案

**正确答案：** C

---

## 解析

`search(k)` 函数返回第一个**大于** `k` 的索引。`x = search(key)` 返回第一个大于 `key` 的位置，`y = search(key-1)` 返回第一个大于 `key-1` 的位置，`x - y` 即为 `key` 出现的次数。

要使 `search(k)` 返回第一个大于 `k` 的索引：当 `a[m] <= k` 时向右搜索 (`i = m + 1`)；当 `a[m] > k` 时向左搜索。即条件为 `k < a[m]` → `j = m - 1`，else → `i = m + 1`。

等价写法：`if a[m] <= k: i = m + 1 else: j = m - 1`。加框处应填 `k <= a[m]`，选 C。
