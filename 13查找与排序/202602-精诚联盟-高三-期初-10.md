# 题目 10

对于数组 `a=["6","8","1","2","1"]`，分别执行以下两个程序段，说法正确的是（   ）

甲程序段：

```python
def quick(a):
    if len(a) <= 1:
        return a
    L = ""
    M = ""
    R = ""
    p = a[0]
    for x in a:
        if x < p:
            L += x
        elif x == p:
            M += x
        else:
            R += x
    return quick(L) + M + quick(R)
```

乙程序段：

```python
n = len(a)
flag = True
i = 0
while i < n - 1 and flag:
    flag = False
    for j in range(n - i - 1):
        if a[j] < a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
            flag = True
    i += 1
```

- A. 两个程序段都采用了递归算法
- B. 两个程序段都将数组 `a` 降序排序
- C. 甲程序段中加框处代码可以修改为 `p=a[-1]`
- D. 乙程序段中加框处代码可以修改为 `(n-i,i,-1)`

---

## 答案

**正确答案：** C

---

## 解析

甲程序段通过递归实现快速排序，按照“小于基准、等于基准、大于基准”的顺序拼接，结果为升序；快速排序的基准可以选择当前序列中的其他元素，因此 `p=a[-1]` 也可以作为基准。

乙程序段没有递归调用，是带提前结束标记的冒泡排序；当 `a[j]<a[j+1]` 时交换，使较大值向前移动，结果为降序。把循环范围改为 `(n-i,i,-1)` 会改变遍历下标范围，不能直接替代原范围。故 C 正确。
