# 题目 10

数组 L 长度为 `n`，要实现数组元素 `L[a]` 至 `L[b]` 升序排列（`0≤a<b≤n-1`），其余元素的位置不变，实现相应功能的 Python 程序段如下：

```python
for i in range(0, b-a):
    for j in ______:
        if L[j] < L[j-1]:
            L[j], L[j-1] = L[j-1], L[j]
```

划线处代码可以填写为（   ）

- A. `range(a,b-1)`
- B. `range(b,a-i,-1)`
- C. `range(b,a+i,-1)`
- D. `range(a-i+1,b)`

---

## 答案

**正确答案：** C

---

## 解析

从右向左进行冒泡，每趟把当前区间较小元素向左移动；第 `i` 趟的左边界为 `a+i+1`，因此循环应写为 `range(b, a+i, -1)`。
