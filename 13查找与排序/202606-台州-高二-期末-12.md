# 题目 12

12. 数组 `d` 存放着 `n` 个整型数据，且 `d[0]≤d[1]≤…≤d[n-1]`，现要统计并输出 `key` 值的数据个数，实现该功能的程序段如下，方框（1）、（2）处分别应填入的正确代码为（   ）

```python
def find(key, d, i, j):
    if i > j:
        return i
    m = (i+j) // 2
    if (1):
        return find(key, d, i+1, j)
    else:
        return find(key, d, i, j-1)

# 获取 d、key 的值，代码略
i, j = 0, len(d)-1
total = find((2), d, i, j) - find(key-1, d, i, j)
print(total)
```

- A. (1) `key>d[m]`；(2) `key+1`
- B. (1) `key>=d[m]`；(2) `key+1`
- C. (1) `key>d[m]`；(2) `key`
- D. (1) `key>=d[m]`；(2) `key`

---

## 答案

**正确答案：** D

---

## 解析

函数最终返回数组中小于等于参数 `key` 的元素个数：当 `key>=d[m]` 时应从左端排除一个元素，否则从右端排除一个元素。于是 `find(key)-find(key-1)` 恰好等于值为 `key` 的元素个数，因此两处应分别填 `key>=d[m]` 和 `key`。
