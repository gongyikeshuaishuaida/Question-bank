# 题目 11

11. 有如下 Python 程序段：

```python
# 输入列表 a，共 n 个元素，各元素递增排列，代码略
a = a[x:] + a[:x]    # (x 为 0~n-1 的正整数)
L = 0; R = len(a) - 1
while L < R:
    m = ①
    if a[m] <= a[R] and a[m] < a[L]:
        R = m - 1
    else:
        L = m
print("数组中的最大值位置为:", ②)
```

为使程序实现所需功能，划线处应填入的代码是（   ）

- A. ① `(L+R+1)//2` ② `m`
- B. ① `(L+R)//2` ② `m`
- C. ① `(L+R+1)//2` ② `L`
- D. ① `(L+R)//2` ② `R`

---

## 答案

**正确答案：** C

---

## 解析

`a = a[x:] + a[:x]` 将递增数组循环左移 x 位，形成一个"旋转有序数组"。程序目的是找到旋转数组中的最大值位置。

旋转数组中，二分查找需要上取整（`(L+R+1)//2`）以避免死循环。当 `a[m]` 在右侧递增段（`a[m] <= a[R]` 且 `a[m] < a[L]`）时，最大值在 m 左侧，收缩右边界；否则最大值在 m 或 m 右侧，收缩左边界。

最终 `L == R` 时，最大值位置为 L。因此 ① 填 `(L+R+1)//2`，② 填 `L`，选 C。
