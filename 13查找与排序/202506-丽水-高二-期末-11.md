# 题目 11

某次学生测试成绩从高到低存储在 `a` 数组中。输入 `key` 值，查找其值以上人数的 Python 算法程序段如下：

```python
a=[98,……,85,85,85,85,……,50]
key=int(input("请输入要查找的数据:"))
i=0;j=len(a)-1
while i <= j:
    m=(i+j)//2
    if     (1)     :
       i=m+1
    else:
       j=m-1
print("大于等于key值的人数为:",      (2)      )
```

划线（1）（2）处可供选择的语句有：

① `key <= a[m]`　　② `key < a[m]`　　③ `j+1`　　④ `i+1`

则正确的代码应为（   ）

- A. ①③
- B. ①④
- C. ②③
- D. ②④

---
## 答案

**正确答案：** A

---
## 解析

数组按降序排列，寻找第一个小于 `key` 的位置时应使用 `key <= a[m]` 的判断；循环结束时 `j+1` 即为大于等于 `key` 的人数。
