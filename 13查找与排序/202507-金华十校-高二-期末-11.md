# 题目 11

11. 有如下 Python 程序段：

```python
d = [2, 4, 5, 5, 6, 8, 8, 8, 9, 12]
def sear(d, key, f):
    left, right = 0, len(d) - 1
    while left <= right:
        mid = (left + right) // 2
        if d[mid] < key:
            left = mid + 1
        elif d[mid] == key:
            if f > 0:
                left = mid + 1
            else:
                right = mid - 1
        else:
            right = mid - 1
    return left - f

n = sear(d, 8, 1) - sear(d, 8, 0) + 1
```

执行该程序后，变量 `n` 的值是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** B

---

## 解析

`sear(d, key, f)` 是变种二分查找：当 `f > 0` 时查找等于 `key` 的最右位置，当 `f == 0` 时查找等于 `key` 的最左位置的前一个位置。

`d = [2, 4, 5, 5, 6, 8, 8, 8, 9, 12]`，查找 `key = 8`（索引 5、6、7）：

- `sear(d, 8, 1)`：找到 8 后继续向右 → 最终 `left = 8`，返回 `8 - 1 = 7`（最后一个 8 的位置）
- `sear(d, 8, 0)`：找到 8 后继续向左 → 最终 `left = 5`，返回 `5 - 0 = 5`（第一个 8 之前的位置）

`n = 7 - 5 + 1 = 3`，即 8 在数组中出现了 3 次。
