# 题目 12

有如下 Python 程序段：

```python
L = 0
R = len(a) - 1
while L < R:
    m = (L + R) // 2
    if a[m] > a[m + 1]:
        L = m + 1
    else:
        R = m
print(L)
```

运行该程序段后，输出结果为 `2`。则列表 `a` 不可能是（   ）

- A. `[9, 5, 3, 4, 6]`
- B. `[8, 6, 2, 3, 5]`
- C. `[7, 4, 1, 2, 3]`
- D. `[5, 3, 3, 2, 4]`

---

## 答案

**正确答案：** D

---

## 解析

该二分过程利用相邻元素的大小关系收缩区间。分别代入四个列表，A、B、C 最终都收敛到下标 2；D 第一次取 `m=2` 时有 `a[2]=3>a[3]=2`，令 `L=3`，最终输出 3，不可能输出 2。

因此选 D。
