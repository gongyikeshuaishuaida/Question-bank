# 题目 11

11. 列表元素 `d[0]～d[n-1]` 已升序排列，现将元素 `d[pos]` 减 2，仍保持列表有序排列，实现上述功能的 python 程序如下，加框处应填入的语句是（   ）

```python
j = pos - 1
while j >= 0:
    if ______:
        break
    d[j], d[j+1] = d[j+1], d[j]
    j -= 1
```

- A. `d[j] > d[pos]`  
- B. `d[j] > d[j+1]`  
- C. `d[j] < d[pos]`  
- D. `d[j] < d[j+1]`

---

## 答案

**正确答案：** D

---

## 解析

`d[pos]` 减小后需要向左移动，当前待插入元素会随着交换位于 `d[j+1]`。若左侧元素 `d[j] < d[j+1]`，说明相邻顺序已正确，应停止；否则继续交换。
