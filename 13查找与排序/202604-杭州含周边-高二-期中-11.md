# 题目 11

有如下 Python 程序段：

```python
from random import randint
x = randint(2, 4) * 2 - 1
a = [3, 8, 4, 6, 2, 5, 1, 7]
n = len(a)
for i in range(0, n-1):
    for j in range(0, n-x-1):
        if a[j] > a[j+1]:
            a[j], a[j+1] = a[j+1], a[j]
print(a)
```

执行该程序段后，输出结果不可能的是（   ）

- A. `[3, 8, 4, 6, 2, 5, 1, 7]`
- B. `[3, 4, 8, 6, 2, 5, 1, 7]`
- C. `[3, 4, 6, 8, 2, 5, 1, 7]`
- D. `[2, 3, 4, 6, 8, 5, 1, 7]`

---

## 答案

**正确答案：** C

---

## 解析

`x` 的可能值为 3、5、7。`x=7` 时内层循环不执行，输出 A；`x=5` 时反复比较前 3 个元素，输出 B；`x=3` 时反复比较前 5 个元素，使其有序，输出 D。因此 C 不可能出现。
