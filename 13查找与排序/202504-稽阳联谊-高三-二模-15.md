# 题目 15

15. 波浪理论可以分析金融市场上的价格波动，小鱼同学设计了简化的波浪理论模型，并用算法描述其一部分理论。在一次上涨中，浪1为上涨（以阶段最高点为终点），浪2为下跌（以阶段最低点为终点）但不能跌破浪1起点。另外规定：

规则一：浪1、浪2的时间长度（终点-起点）均需要满足在10~30个交易日之间。

规则二：浪1顶点后10个交易日内没有新高，浪2终点后10个交易日内没有新低。

根据上述算法，小鱼编写程序，研究某市场指数的历史交易记录，找出符合条件的全部记录。

例：浪1起点1000点，经过15个交易日后到该段最高1200点，浪2从浪1最高点下跌，经过20个交易日后到最低点1020。

找到有效图形时输出形式如：“有效图形`[[20140428, 2003, 2085], [20140616, 2085, 2020]]`”。

（1）如下表所示为3月某指数，若每浪的时间长度改为5~10日之间，其他不变，则该段时间的一个完整1~2浪是（答案填日期，如3-10-19）？

![[attachments/202504稽阳_15_图.jpg]]

（2）函数 `judge` 的功能是寻找列表 `a` 中相对 `a[0]` 的极值，若有返回其下标，没有返回-1，方框处代码有误，请改正。

```python
def judge(a,n):#参数n=1 寻找最大值，n=-1 寻找最小值
    i=1 ; p=-1
    t=a[0][1]
    while i<len(a):
        if a[i][1]<t:  # 此处是方框处
            p=i
            t=a[i][1]
        i+=1
    if p>0:
        return p
    else:
        return -1
```

## 答案

**参考答案：** （1）4-13-20（或等价日期写法）；（2）`a[i][1]*n>t*n`（或等价写法）；（3）① `d[i][1]`；② `j=j+t`或`j+=t`；③ `d[k][1]<d[i][1]`。

---
## 解析

（1）按5~10个交易日的限制，4日为浪1起点，13日为浪1顶点，20日为浪2底部终点。（2）`n=1`时寻找最大值，`n=-1`时寻找最小值，应将比较式统一为 `a[i][1]*n>t*n`。（3）`maxtmp`从浪1起点价格开始；后10日出现新高时将 `j` 前移 `t` 个位置；浪2底部低于浪1起点时当前图形无效。
