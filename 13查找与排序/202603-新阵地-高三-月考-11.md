# 题目 11

11. 编写程序，实现将 `tmp` 值插入到升序列表 `a` 中，并保持升序，程序段如下：

```python
if tmp >= a[-1]:
    a.append(tmp)
else:
    j = len(a) - 1
    while j >= 0 and tmp < a[j]:
        if ___(1)___:
            a.append(a[j])
        else:
            ___(2)___
        j -= 1
    ___(3)___
```

划线 (1)(2)(3) 处可供选择的语句有：

① `j==len(a)-1`  ② `j==0`  ③ `a[j+1]=a[j]`  ④ `a[j]=a[j-1]`  ⑤ `a[j]=tmp`  ⑥ `a[j+1]=tmp`

下列选项中，填入划线处能使程序正确运行的顺序是（   ）

- A. ①③⑥
- B. ①④⑤
- C. ②④⑤
- D. ②③⑥

---

## 答案

**正确答案：** A

---

## 解析

从末尾向前移动比 `tmp` 大的元素。第一次移动末尾元素时需用 `append(a[j])` 扩容，所以 (1) 为 ①；之后用 `a[j+1]=a[j]` 后移元素；循环结束后把 `tmp` 放到 `a[j+1]`。
