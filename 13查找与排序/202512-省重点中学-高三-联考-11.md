# 题目 11

列表 `data` 存放了 `n` 个不重叠的整数区间，每个区间包含起始值和结束值，且已按起始值从低到高排序。例如 `data = [[1,3], [5,9]]`。函数返回 `key` 在列表 `data` 中所在的区间位置：

```python
def bsearch(data, key):
    L = 0
    R = len(data) - 1
    while L <= R:
        m = (L + R) // 2
        if ______________________________:  # ①
            R = m - 1
        else:
            L = m + 1
    pos = R
    if pos >= 0 and ______________________________:  # ②
        return pos
    return -1
```

则①②处应填入的正确代码依次为（   ）

- A．① `data[m][1] > key`；② `data[pos][1] >= key`
- B．① `data[m][0] > key`；② `data[pos][0] <= key`
- C．① `data[m][0] > key`；② `data[pos][1] >= key`
- D．① `data[m][1] > key`；② `data[pos][0] >= key`

## 答案

**正确答案：** C

## 解析

二分查找应根据区间起始值 `data[m][0]` 与 `key` 比较，找到最后一个起始值不大于 `key` 的区间后，再判断该区间结束值 `data[pos][1]` 是否覆盖 `key`，因此选择 C。
