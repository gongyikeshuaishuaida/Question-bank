# 题目 11

11. 根据列表中元素大小关系，升序排列各元素的索引，并将排序后的索引保存在列表 y 中。如列表 `s=[1,5,6,8,1,2]`，程序运行后得到列表 `y=[0,4,5,1,2,3]`。则划线处的代码应该是（   ）

```python
def sort_in(x):
    n = len(x)
    y = [i for i in range(n)]
    for i in range(_____①_____):
        for j in range(_____②_____):
            if _____③_____:
                y[j], y[j+1] = y[j+1], y[j]
    return y

x = [1, 5, 6, 8, 1, 2]
y = sort_in(x)
print("各元素升序排列的序号：", y)
```

- A. ① `n`；② `n-i`；③ `y[j] >= y[j+1]`
- B. ① `n`；② `n-i`；③ `x[y[j]] >= x[y[j+1]]`
- C. ① `n-1`；② `n-i-1`；③ `y[j] >= y[j+1]`
- D. ① `n-1`；② `n-i-1`；③ `x[y[j]] >= x[y[j+1]]`

---

## 答案

**正确答案：** D

---

## 解析

y 保存的是索引，比较大小时必须比较 `x[y[j]]` 和 `x[y[j+1]]`；相邻比较到 `j+1`，内层范围应避免越界，冒泡排序外层和内层分别为 `n-1`、`n-i-1`。
