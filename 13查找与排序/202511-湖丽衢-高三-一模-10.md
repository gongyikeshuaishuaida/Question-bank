# 题目 10

10. 某 Python 程序段如下：

```python
i = 0; j = len(a) - 1; key = int(input())
while a[i] <= key <= a[j]:
    m = (i + j) // 2
    if a[m] == key:
        break
    elif a[m] > key:
        j = m - 1
    else:
        i = m + 1
```

若 `a` 为 `[1, 3, 5, 7]`，运行该程序段后，`i` 和 `j` 的值不可能是（   ）

- A. `3, 2`
- B. `2, 3`
- C. `0, 3`
- D. `0, 0`

---

## 答案

**正确答案：** A

---

## 解析

`a = [1, 3, 5, 7]`，初始 `i=0, j=3`。while 循环条件为 `a[i] <= key <= a[j]`。

- 若 key=4：`a[0]=1 <= 4 <= a[3]=7`，进入循环。`m=1, a[1]=3 < 4`，`i=2`。再次检查 `a[2]=5 <= 4 <= a[3]=7`？`5 <= 4` 为 False，退出。此时 `i=2, j=3` → B 可能。
- 若 key=1：`a[0]=1 <= 1 <= a[3]=7`，进入。`m=1, a[1]=3 > 1`，`j=0`。`a[0]=1 <= 1 <= a[0]=1`，进入。`m=0, a[0]=1 == 1`，break。`i=0, j=0` → D 可能。
- 若 key=10：`a[0]=1 <= 10 <= a[3]=7` 为 False（`10 <= 7` 不成立），不进入循环。`i=0, j=3` → C 可能。
- `3, 2`（`i>j` 交叉）不可能出现，因为 while 条件 `a[i] <= key <= a[j]` 要求 `a[i] <= a[j]`，对于升序数组需要 `i <= j`，循环退出时不会出现 `i=3, j=2` 的交叉情况（若 `a[m]>key` 设 `j=m-1` 或 `a[m]<key` 设 `i=m+1`，均不会导致 `i=3,j=2`）。故选 A。
