# 题目 12

12. 有如下 Python 程序，实现在数组 `a` 中查找关键字 `key`：

```python
a = [10, 15, 18, 25, 25, 26, 30, 33]
key = int(input("key="))
L, R = 0, len(a) - 1
m = (L + R) // 2
while L <= R and a[m] != key:
    if a[m] > key:
        R = m - 1
    else:
        L = m + 1
    m = (L + R) // 2
    # 注释①
if L > R:
    print(-1)
else:
    print(m)
```

运行程序，以下说法正确的是（   ）
- A. 输入 `key` 的值为 25，程序输出 4
- B. 输入 `key` 的值为 2025，程序报错：下标越界
- C. 注释①语句改为 `m = (L + R + 1) // 2`，输出结果不变
- D. 输入 `key` 值为任意整数，注释①语句至多执行 3 次

---

## 答案

**正确答案：** C

---

## 解析

本程序在有序数组中进行二分查找。对中点使用向下取整或向上取整，只要配合边界更新正确，查找结果不变。输入 25 时首次中点下标为 3，输出 3；查找 2025 会使 `L > R` 后输出 -1，不会越界。
