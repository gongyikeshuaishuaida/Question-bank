# 题目 11

11. 有如下 Python 程序段，该程序利用二分法求 $\sqrt{10}$ 的近似值：

```python
x = 10
L = 0.0
R = x
while R - L > 0.001:
    mid = (L + R) / 2
    if mid * mid > x:
        R = mid
    else:
        L = mid
print(round(L, 3))
```

下列说法正确的是（   ）

- A. 输出结果为 3.000
- B. 加框处改为 `mid=(L+R)//2`，程序仍能正常运行
- C. 若把 `R` 的初值由 `x` 改为 `x/2`，程序运行结果不变
- D. 循环终止条件改为 `R-L>1`，结果精度更高

---

## 答案

**正确答案：** C

---

## 解析

$\sqrt{10}\approx3.162$，而 `x/2=5`，区间 `[0,5]` 仍包含目标值，因此将 `R` 的初值改为 `x/2` 不会改变最终结果。使用整除会使区间可能无法继续缩小；原输出不是 3.000；把误差阈值改为 1 会降低精度，因此选 C。
