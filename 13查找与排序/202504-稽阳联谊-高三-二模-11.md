# 题目 11

11. 有如下 Python 程序：

```python
a=[1,3,5,7,9,8,6,4,2,0]
n=len(a)
for i in range(n-1):
    for j in range(_______):
        if a[j-1]>a[j]:
            a[j],a[j-1]=a[j-1],a[j]
```

在横线上填入如下代码：

```python
① n-1,i,-1
② 1,n-i
③ n-i-1,n
④ n
```

可以实现对 `a` 数组升序排序的个数为

- A. 1
- B. 2
- C. 3
- D. 4

---
## 答案

**正确答案：** C

---
## 解析

①从右到左、②从左到右是标准冒泡排序的两种写法；③本质上是插入排序；④会造成列表下标越界。因此共有3种。
