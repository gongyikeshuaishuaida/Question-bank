# 题目 11

11. 以下程序段运行后，数组 `c` 不可能是（   ）

```python
import random

def f(arr, p):
    for j in range(0, 5-p):
        if arr[j] < arr[j+1]:
            arr[j], arr[j+1] = arr[j+1], arr[j]

x = random.randint(1, 3)  # 生成1到3的随机整数
c = [4, 7, 2, 9, 5]
for i in range(1, x):
    f(c, i)
```

- A. `[7,9,5,4,2]`
- B. `[4,7,2,9,5]`
- C. `[9,7,5,4,2]`
- D. `[7,4,9,5,2]`

---

## 答案

**正确答案：** C

---

## 解析

`x` 可能为 1、2、3：

- `x=1` 时循环不执行，得到 B；
- `x=2` 时执行一次 `f(c,1)`，得到 D；
- `x=3` 时再执行 `f(c,2)`，得到 A。

因此 C 所示数组不可能出现。
