# 题目 12

12. 有如下 Python 程序段：

```python
import random
a = [3, 2, 5, 1, 4, 6]
n = len(a)
i = -1
k = random.randint(0, n - 1)
a[k], a[n - 1] = a[n - 1], a[k]
for j in range(n - 1):
    if a[j] <= a[n - 1]:
        i += 1
        a[i], a[j] = a[j], a[i]
a[i + 1], a[n - 1] = a[n - 1], a[i + 1]
print(a)
```

执行该程序段后，输出 `a` 的值不可能为（   ）

- A. `[3, 2, 5, 1, 4, 6]`
- B. `[2, 1, 3, 6, 4, 5]`
- C. `[1, 2, 3, 6, 5, 4]`
- D. `[3, 2, 1, 4, 6, 5]`

---

## 答案

**正确答案：** C

---

## 解析

程序执行的是快速排序的一次 Lomuto 分区：随机选择的基准值先交换到末尾，分区完成后，基准值左侧的元素均不大于它，右侧元素均大于它。

逐一考虑可能的基准位置可得到 A、B、D。选项 C 若把 6 看作已归位的基准，其右侧却仍有 5、4；若把其他元素看作基准，也不符合分区后两侧的大小关系，因此不可能出现。
