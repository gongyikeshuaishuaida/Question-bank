# 题目 12

12. 有如下 Python 程序段：

```python
a = [2, 4, 7, 10, 11, 12, 14]
cnt = 0
ch = int(input())
for key in a:
    i, j = 0, len(a) - 1
    while key % 2 == 0 and i <= j:
        m = (i + j) // 2
        if a[m] == ch:
            cnt += 1
            break
        elif a[m] == key:
            break
        elif a[m] < key:
            i = m + 1
        else:
            j = m - 1
```

若输入 `ch` 的值为 4，执行该程序段后，变量 `cnt` 的值是（　）

- A. 0
- B. 2
- C. 3
- D. 6


---

## 答案

**正确答案：** B

---

## 解析

逐个跟踪偶数对应的二分查找过程，共有 2 次在遇到当前 `key` 之前查到 4 并执行计数。
