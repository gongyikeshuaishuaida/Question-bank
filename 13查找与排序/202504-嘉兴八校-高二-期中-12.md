# 题目 12

有如下程序段：

```python
def findmin(s):
    t = s[0]
    min = 0
    for i in range(1, len(s)):
        if s[i] < t:
            min = i
            t = s[min]
    return min

lst = ["5", "25", "2025"]
res = []
n = len(lst)
while n > 0:
    j = findmin(lst)
    res.append(lst[j])
    lst = lst[:j] + lst[j+1:]
    n -= 1
print(res)
```

执行程序后，输出的结果为（   ）

- A. `["5", "25", "2025"]`
- B. `["5", "2025", "25"]`
- C. `["2025", "25", "5"]`
- D. `["25", "2025", "5"]`

---
## 答案

**正确答案：** C

---
## 解析

列表元素是字符串，比较采用字典序。三者的顺序为 "2025"、"25"、"5"：先取 "2025"，再在剩余元素中取 "25"，最后取 "5"，得到 C。
