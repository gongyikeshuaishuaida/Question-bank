# 题目 15

15. 某软件对用户先后两次的运动状况进行评估，两次评估总分之差为其成长分数。针对某次评估，用户的总分由基础分和等级分相加得到。基础分根据用户成绩（0~100之间的整数）所处的成绩区间对应取得，如第15题图所示；等级分由公式 `(f1 + 0.5 × f2) / n × 100` 计算后向下取整得到，其中，`f1` 为该区间内低于该用户成绩的人数，`f2` 为该区间内等于该用户成绩的人数，`n` 为该区间内的总人数（不包含仅参加一次评估的用户）。请回答下列问题：

（1）某次评估中，若用户成绩为50，其中，`f1` 为10，`f2` 为4，`n` 为20，则该用户总分为▲。

（2）定义如下 `intersection (lst1, lst2)` 函数，列表 `lst1`、`lst2` 为先后两次评估的用户成绩数据表，`lst1`、`lst2` 中的每个元素依次由用户的编号和成绩2个数据项组成，列表均已按用户编号升序排列。函数的功能是筛选出参与了两次评估的用户的索引，结果存 `lst` 并返回。

```python
def intersection (lst1, lst2):
    lst = []
    i, j = 0, 0
    m1, m2 = len(lst1), len(lst2)
    while i < m1 and j < m2:
        n1, n2 = lst1[i][0], lst2[j][0]
        if n1 == n2:                 #同一用户在lst1、lst2中的编号保持不变
            lst.append([i,j])        #为列表lst追加元素[i,j]
            i += 1
            j += 1
        elif n1 < n2:
            i += 1
        else:
            j += 1
    return lst
```

① 加框处理语句执行的次数是▲。

② `lst[0]` 的值为▲。

## 答案

**参考答案：** （1）100；（2）①5；②`[1,0]`；（3）① `r = ilst[m][1]`；② `score[j][2] = heads[i]`；③ `f1 = score[q][0]`。

---
## 解析

（1）成绩50属于41—60区间，基础分为40，等级分为 `(10+0.5×4)/20×100=60`，总分为100。

（2）双指针循环比较编号，直到一方遍历结束，共执行5次；第一个同时出现的用户编号为2，对应索引为 `[1,0]`。

（3）先用 `r = ilst[m][1]` 定位成绩，再将同一区间的节点链接到 `heads[i]`；向后遍历时，`f1` 累加低于当前成绩的区间人数，填入 `f1 = score[q][0]`。
