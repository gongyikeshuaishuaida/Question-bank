# 题目 11

11. 有如下Python程序：

```python
import random
a = [2, 3, 4, 4, 4, 8, 8, 9, 10]
key = random.randint(1, 10)
i, j = 0, 8
s = ""
while i <= j:
    m = (i + j) // 2
    if a[m] >= key:
        j = m - 1
        s = s + "L"
    else:
        i = m + 1
        s = s + "R"
print(s)
```

程序运行后，输出变量`s`的结果不可能是（   ）

- A. LLL
- B. LRL
- C. RLR
- D. RRRL

---

## 答案

**正确答案：** C

---

## 解析

每次比较后按二分查找方向记录L或R。路径RLR要求`key>4`后又`key<=8`，再要求`key>8`，条件矛盾；其余路径均可由某些1～10的`key`产生。
