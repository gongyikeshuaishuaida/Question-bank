# 题目 10

有如下 Python 程序段：

```python
s1="babababa"; s2="aba"
i=0; pos=[]
while i<=len(s1)-len(s2):    # ①
    if s1[i:i+len(s2)]!=s2:
        i+=1                  # ②
    else:
        pos.append(i)
        i=i+len(s2)-1
if pos:
    print("位置：",pos)
else:
    print("找不到")
```

运行该程序段，下列描述正确的是（   ）

- A. ①所在行执行 3 次
- B. ②所在行执行 1 次
- C. `i` 的值为 8
- D. 输出结果为“位置：`[1,5]`”

---
## 答案

**正确答案：** B

---
## 解析

程序在 `i=0` 时不匹配，执行一次 ②后到 `i=1`；随后在 `i=1、3、5` 分别匹配，`i` 依次跳到 3、5、7，循环条件结束。因此 ①共执行 4 次，②只执行 1 次，最终 `i=7`，输出位置为 `[1, 3, 5]`，只有 B 正确。
