# 题目 11

有如下 Python 程序段：

```python
d=[12,45,24,63,2,3,60,50]
cnt=0
step=int(input("输入1~4之间的整数:"))
for i in range(step,len(d)):
    j=i-step
    t=d[i]
    while j>=0 and t>d[j]:
        d[j+step]=d[j]
        j=j-step
    d[j+step]=t
print(d)
```

运行该程序段，输出结果不可能是（   ）

- A. `[63,60,50,45,24,12,3,2]`
- B. `[63,50,24,60,45,2,12,3]`
- C. `[12,45,60,63,2,3,24,50]`
- D. `[60,63,24,50,12,45,2,3]`

---
## 答案

**正确答案：** B

---
## 解析

这是按步长 `step` 的希尔排序式插入过程。逐一运行 `step=1、2、3、4`：分别得到 A、D、`[63,50,24,60,45,3,12,2]` 和 C。选项 B 与任何允许的步长结果都不相同，因此不可能。
