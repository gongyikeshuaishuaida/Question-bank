# 题目 10

10. 已知非降序列表 a 由若干个整型元素构成，现要查找并输出 a 中整数 key 出现的次数。实现该功能的程序段如下：

```python
def search(a, key):
    L, R = 0, len(a)-1
    while L <= R:
        m = (L + R) // 2
        if ______:  # 此处是方框处
            R = m - 1
        else:
            L = m + 1
    return L

# 列表 a 和 key 初始化，代码略
print(search(a, key+1) - search(a, key))
```

加框处应填入的正确代码为

- A. `a[m] >= key`
- B. `a[m] > key`
- C. `a[m] < key`
- D. `a[m] <= key`

---
## 答案

**正确答案：** A

---
## 解析

search 要返回列表中第一个大于或等于 key 的位置。若 a[m] >= key，应收缩右边界继续寻找更早位置；否则向右移动左边界。于是两次下界之差就是 key 出现次数，选 A。
