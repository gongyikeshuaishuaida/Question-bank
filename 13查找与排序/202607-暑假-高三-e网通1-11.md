# 题目 11

某二分查找算法的程序如下：

```python
i = c = 0
j = 9
key = int(input())
while i <= j:
    m = (i+j) // 2
    if a[m] == key:
        break
    if a[m] > key:
        j = m-1
    else:
        i = m+1
        c += 1
```

已知 `a=[2,13,14,19,23,26,29,31,32,38]`，运行该程序后，`c` 的值为 2，则 `key` 的值不可能是（   ）

- A. 19
- B. 29
- C. 30
- D. 32

---

## 答案

**正确答案：** C

---

## 解析

变量 `c` 只在向右缩小区间时加 1。分别跟踪查找路径，19、29、32 都恰好向右查找 2 次；查找 30 时会向右查找 3 次，因此 30 不可能。
