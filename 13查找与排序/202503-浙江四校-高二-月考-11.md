# 题目 11

11. 将某班级 n 位同学信息、作业的完成时间存储在二维列表 d 中，格式如：`d = [["zhang", 35], ["li", 40], ["wang", 38], ["zhao", 30], ……]`，按照完成时间升序排序，部分 Python 程序段如下：

```python
for i in range(①):
    for j in range(n-1, i, -1):
        if ②:
            d[j], d[j-1] = d[j-1], d[j]
```

划线处的语句依次是

- A. ① 1,n；② `d[j][1] < d[j-1][1]`
- B. ① 1,n；② `d[j] < d[j-1]`
- C. ① 0,n-1；② `d[j][1] < d[j-1][1]`
- D. ① 0,n-1；② `d[j] < d[j-1]`

---
## 答案

**正确答案：** C

---
## 解析

外层循环需从 i=0 到 n-2，因此是 range(0,n-1)；内层比较二维列表中表示完成时间的第 2 个元素，条件为 d[j][1] < d[j-1][1]。满足时交换相邻元素，得到升序结果。
