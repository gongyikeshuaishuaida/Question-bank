# 题目 11

有如下 Python 程序段：

```python
a = [27, 7, 9, 8, 34]
for i in range(1, 5):
    j = i
    key = a[j]
    while j > 0 and a[j-1] < key:
        a[j] = a[j-1]
        j = j-1
    a[j] = key
print(a)
```

执行该程序段后，列表 `a` 的值是（   ）

- A. `[34,27,9,8,7]`
- B. `[27,34,7,9,8]`
- C. `[34,7,9,8,27]`
- D. `[27,8,9,7,34]`

---

## 答案

**正确答案：** A

---

## 解析

程序执行降序插入排序，最终列表为 `[34,27,9,8,7]`。
