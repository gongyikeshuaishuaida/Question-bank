# 题目 12
有如下 Python 程序段：

```python
a=[5,2,6,4,9,8]
n=len(a); c=0
for i in range(1,n):
    flag=True
    c=c+1
    for j in range(n-i):
        if a[j]>a[j+1]:
            a[j],a[j+1]=a[j+1],a[j]  # ①
            flag=False
    if flag==True:
        break
print(c)
```

关于该程序段，下列说法正确的是（　　）

- A. 该排序算法的时间复杂度是 `O(1)`
- B. 该算法的第1趟冒泡后数组 `a` 为 `[2,5,6,4,9,8]`
- C. 执行该程序段后，输出 `c` 的值为 2
- D. 该程序段执行过程中，①处语句共执行了4次

---
## 答案
**正确答案：** D（答案表标注为 C，与程序逐步运行结果不一致）

---
## 解析
第一趟交换3次，数组变为 `[2,5,4,6,8,9]`；第二趟交换1次，数组变为 `[2,4,5,6,8,9]`；第三趟没有交换，触发提前结束。因此交换语句①共执行4次，D正确。按题面代码 `c` 在每一趟外层循环开始时加1，第三趟仍会加1后才发现有序，所以最终 `c=3`，C的“输出2”与代码不符；参考答案表将本题记为C，属于答案表与代码的冲突，已按可复现的程序结果录入并保留差异说明。
