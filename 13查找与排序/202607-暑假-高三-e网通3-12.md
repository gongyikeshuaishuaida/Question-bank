# 题目 12

如下 Python 程序段，在无序的序列中利用对分查找算法求第 `k` 个大的数：

```python
k = 3
a = [8,4,6,7,5,6,2,4]
low, high = min(a), max(a)
while low <= high:
    m = (low+high) // 2
    cnt = 0
    for i in a:
        if i > m:
            cnt += 1
    if cnt < k:
        high = m-1
    else:
        low = m+1
```

执行程序后，下列说法不正确的是（   ）

- A. 第 `k` 大数是 `low`
- B. `low > high`
- C. `m` 的值为 6
- D. `cnt` 的值为 3

---

## 答案

**正确答案：** D

---

## 解析

循环结束时 `low=6`、`high=5`、`m=6`，最后一次统计大于 6 的数只有 8 和 7，`cnt=2`，所以 D 不正确。
