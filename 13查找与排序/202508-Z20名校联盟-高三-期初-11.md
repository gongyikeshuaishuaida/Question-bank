# 题目 11

11. 定义如下函数：

```python
def bbsort(data):
    blk = []
    st = 0
    for i in range(1, len(data)):
        if data[i] != data[i - 1]:
            ed = i - 1
            blk.append([st, ed])
            st = i
    n = len(blk)
    for i in range(n):
        for j in range(0, n - i - 1):
            if data[blk[j][0]] > data[blk[j + 1][0]]:
                blk[j], blk[j + 1] = blk[j + 1], blk[j]
```

调用该函数，若参数`data`为`[2, 2, 2, 1, 1, 3, 3, 3, 3, 7, 7, 7, 4]`，运行该程序段后，`blk[x][1]`（`0≤x≤len(blk)-1`）的值不可能为（   ）

- A. 2
- B. 4
- C. 11
- D. 12

---

## 答案

**正确答案：** D

---

## 解析

程序遇到相邻值变化时记录上一段，得到`[0,2]`、`[3,4]`、`[5,8]`、`[9,11]`；最后的单个元素4没有在循环后追加为一段。冒泡排序只调整这些块的顺序，因此各块结束下标只能是2、4、8、11，不可能为12。
