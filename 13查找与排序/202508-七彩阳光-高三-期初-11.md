# 题目 11

11. 若数组`a=[1,2,1,5,1,8,2,6,9,4]`，以下Python程序运行后，输出不可能是（   ）

```python
import random

i, j = 0, len(a) - 1
while i <= j:
    mid = random.randint(i, j)  # 随机生成范围在i～j之间的整数
    if mid >= len(a) - 1:
        continue                # 跳过本次循环，直接进入下一次
    if a[mid] > a[mid + 1]:
        j = mid - 1
    else:
        i = mid + 1
print(i)
```

- A. 1
- B. 8
- C. 3
- D. 7

---

## 答案

**正确答案：** D

---

## 解析

程序根据相邻元素大小随机缩小区间，最终可能定位到局部峰值相关位置。数组中的候选输出可为索引1、3、5、8，对应选项中的1、3、8均可能出现；索引7不满足形成终止位置的条件，因此不可能输出7。
