# 题目 12

12. 取升序数列中某一个数为分割点，将其前面所有数轮转到数列的末尾可以得到一个轮转后有序数列，如`[7,11,13,17,2,3,5]`，其中最小元素2为该数列的拐点。已知数组`a`中存储着一个由升序数列轮转后的有序数列，编写Python程序寻找该数列的拐点所在位置，代码如下：

```python
L = 0
R = len(a) - 1
while L < R:
    m = (L + R) // 2
    if a[m] > a[R]:
        ①
    else:
        ②
print("拐点元素索引为:", L)
```

①②划线处的代码分别为（   ）

- A. ①`L=m`　②`R=m`
- B. ①`L=m`　②`R=m-1`
- C. ①`L=m+1`　②`R=m-1`
- D. ①`L=m+1`　②`R=m`

---

## 答案

**正确答案：** D

---

## 解析

若`a[m]>a[R]`，最小值必在`m`右侧，令`L=m+1`；否则最小值可能就是`m`，应保留`m`并令`R=m`。循环结束时`L`即拐点索引。
