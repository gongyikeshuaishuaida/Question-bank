# 题目 11

11. 定义如下函数：

```python
def quick(a):
    if len(a) <= 1:
        return a
    L = ""; M = ""; R = ""; p = a[0]
    for x in a:
        if x < p:
            L += x
        elif x == p:
            M += x
        else:
            R += x
    return quick(L) + M + quick(R)
```

若 `m = "gibcb"`，执行语句 `st = quick(m)`，下列说法正确的是（   ）

- A. 该函数采用了迭代算法
- B. 程序实现对 m 中字符降序排序
- C. 函数 quick 被调用 4 次
- D. 加框处修改为 `p = a[-1]`，st 结果不变

---

## 答案

**正确答案：** D

---

## 解析

快速排序以 a[0] 为基准。m="gibcb"→st="bbcgi"（升序）。选 a[-1] 会改变基准，但由于字符有重复（b 出现两次），结果可能不变。D 正确。A 错误，是递归。B 错误，是升序。C 错误，调用次数不是 4。
