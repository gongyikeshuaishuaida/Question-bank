# 题目 10

有如下 Python 程序段：

```python
import random
a = [12, 18, 23, 23, 25, 29, 29, 30, 31, 33]
i, j = 0, len(a) - 1
key = random.randint(6, 15) * 2 + 1
f = [0] * len(a)
while i <= j:
    m = (i + j) // 2
    f[m] = 1
    if key >= a[m]:
        i = m + 1
    else:
        j = m - 1
```

执行程序段后，若 `f` 值为 `[0, 1, 1, 0, 1, 0, 0, 0, 0, 0]`，则 `key` 的值可能为（   ）

- A．18
- B．21
- C．23
- D．25

---
## 答案

**正确答案：** B

---
## 解析

`key` 的生成结果一定是 13～31 之间的奇数。取 `key=21` 时，二分查找访问下标 4、1、2，正好得到 `f=[0,1,1,0,1,0,0,0,0,0]`；其他选项不满足随机表达式或访问路径。
