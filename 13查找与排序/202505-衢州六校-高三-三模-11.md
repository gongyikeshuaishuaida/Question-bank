# 题目 11

11. 某二分查找算法的 Python 程序段如下：

```python
c = 0
i, j = 0, len(a) - 1
while i <= j:
    m = (i + j) // 2
    if key <= a[m]:
        j = m - 1
    else:
        i = m + 1
    c += 1
```

若非降序数组 `a` 包含 8 个元素，`key` 为 `a` 中一个元素，运行该程序段后 `c` 的值为 3。若将加框处代码修改为 `key<a[m]`，重新运行该程序段，`c` 的值依然为 3，则数组 `a` 中值为 `key` 的元素个数最多为（   ）

- A. 5
- B. 6
- C. 7
- D. 8

---
## 答案

**正确答案：** B

---
## 解析

两次二分查找分别使用小于等于和小于的边界条件，且比较次数都为3，说明 `key` 的连续等值区间受到左右边界位置的共同限制。在8个元素中同时满足两次查找路径时，等值元素最多可占6个，故选 B。
