# 题目 11

11. 列表`a`含`n`个整数，程序实现非降序排序：
```python
i = n
while i > 0:
    if i == n or ____①:
        ____②
    else:
        a[i], a[i-1] = a[i-1], a[i]
        ____③
```
可选语句：①`i+=1`；②`i-=1`；③`a[i-1]>=a[i]`；④`a[i-1]<=a[i]`。依次应填（   ）

- A. ③②①
- B. ③①②
- C. ④①②
- D. ④②①

---

## 答案

**正确答案：** D

---

## 解析

相邻元素已有序或到达右端时向左移动，即条件④后执行②；若逆序则交换并向右回退检查，即执行①。
