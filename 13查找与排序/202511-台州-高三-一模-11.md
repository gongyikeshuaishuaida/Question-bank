# 题目 11

11. 有如下Python程序段：

```python
L = 0; R = len(a) - 1
while L < R:
    m = (L + R) // 2
    if a[m] < a[m + 1]:
        L = m + 1
    else:
        R = m
print(L)
```

运行该程序段后，输出结果为4，则列表a不可能是（   ）

- A. `[1,3,5,6,8,4,2]`
- B. `[3,5,6,8,9]`
- C. `[1,8,7,4,8,6,5]`
- D. `[1,3,5,8,8,7,4]`

---

## 答案

**正确答案：** D

---

## 解析

该程序使用二分法查找**峰值元素**（局部最大值）的索引——即 `a[m] ≥ a[m+1]` 时向左收缩，否则向右收缩。

逐项验证：

**A.** `[1,3,5,6,8,4,2]`
L=0,R=6,m=3→a[3]=6<a[4]=8→L=4; L=4,R=6,m=5→a[5]=4>a[6]=2→R=5; L=4,R=5,m=4→a[4]=8>a[5]=4→R=4; 输出 4 ✓

**B.** `[3,5,6,8,9]`
L=0,R=4,m=2→a[2]=6<a[3]=8→L=3; L=3,R=4,m=3→a[3]=8<a[4]=9→L=4; 输出 4 ✓

**C.** `[1,8,7,4,8,6,5]`
L=0,R=6,m=3→a[3]=4<a[4]=8→L=4; L=4,R=6,m=5→a[5]=6>a[6]=5→R=5; L=4,R=5,m=4→a[4]=8>a[5]=6→R=4; 输出 4 ✓

**D.** `[1,3,5,8,8,7,4]`
L=0,R=6,m=3→a[3]=8≥a[4]=8→R=3; L=0,R=3,m=1→a[1]=3<a[2]=5→L=2; L=2,R=3,m=2→a[2]=5<a[3]=8→L=3; 输出 3 ≠ 4 ✗

D 输出 3 而非 4，因此不可能。
