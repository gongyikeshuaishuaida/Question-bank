# 题目 11

11. 执行如下 Python 程序段后，`a` 的值为（　）

```python
a = [1, 2, 5, 5, 6, 7]
for i in range(5):
    for j in range(5, i, -1):
        if a[j] % 2 <= a[j - 1] % 2:
            a[j], a[j - 1] = a[j - 1], a[j]
```

- A. `[6,2,5,5,7,1]`
- B. `[2,6,1,5,5,7]`
- C. `[6,2,5,5,1,7]`
- D. `[2,6,1,7,5,5]`

---

## 答案

**正确答案：** A

---

## 解析

比较键为`x%2`，且相等时也交换。偶数被移到前部，奇数内部顺序因等键交换而反转，得到A。
