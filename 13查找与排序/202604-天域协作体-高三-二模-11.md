# 题目 11

有如下 Python 程序段：

```python
n = len(a)
for i in range(n-2, -1, -1):
    k = a[i]
    j = i + 1
    while j <= n-1 and a[j] % 5 > k % 5:
        a[j-1] = a[j]
        j += 1
    a[j-1] = k
```

列表 `a` 有 6 个元素，运行该程序段后，`a` 可能的值是（   ）

- A. `[10, 6, 7, 22, 28, 4]`
- B. `[18, 8, 7, 22, 6, 30]`
- C. `[4, 24, 3, 2, 22, 24]`
- D. `[9, 13, 1, 11, 2, 5]`

---

## 答案

**正确答案：** B

---

## 解析

程序从右向左执行插入排序，使元素按除以 5 的余数降序排列。各选项的余数序列中，只有 B 为 `3、3、2、2、1、0`，满足非递增顺序。
