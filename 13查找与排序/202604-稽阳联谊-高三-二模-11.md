# 题目 11

有如下 Python 程序段：

```python
x = int(input())
a = [5,4,9,0,2,3]
for i in range(len(a)-1-x):
    if a[i] > a[i+1]:
        a[i], a[i+1] = a[i+1], a[i]
for i in range(len(a)-2, x, -1):
    if a[i] < a[i-1]:
        a[i], a[i-1] = a[i-1], a[i]
```

执行该程序段，分别输入 0、1、2，列表 `a` 的结果不可能的是（  ）

- A. [0, 4, 5, 2, 3, 9]  
- B. [4, 0, 5, 2, 9, 3]  
- C. [4, 5, 0, 2, 3, 9]  
- D. [4, 5, 0, 2, 9, 3]

---

## 答案

**正确答案：** C

---

## 解析

分别代入 `x=0、1、2` 执行，结果为 A、B、D；不会得到 C。该程序相当于根据 `x` 控制左右两段相邻交换的范围。
