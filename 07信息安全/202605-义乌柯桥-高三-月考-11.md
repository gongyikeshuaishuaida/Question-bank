# 题目 11

11. 下列 Python 程序段功能是对列表 `lst` 进行加密处理。

```python
n, m = len(lst), len(key)
t = [""] * m
for i in range(n):
    k = i % m
    t[k] = chr((ord(lst[i]) - 97 + key[k]) % 26 + 97)  # 字符 "a" 的 ASCII 码是 97
    if k == m - 1:
        for j in range(m):
            lst[i - m + 1 + key[j]] = t[j]
r = n % m
for j in range(r):
    lst[n - r + j] = t[j]
print(lst)
```

当 `key = [2, 0, 1]`，`lst = ['a', 'p', 'p', 'l', 'e']` 时，执行该程序段，输出结果是

- A. `['c', 'p', 'q', 'n', 'e']`
- B. `['c', 'q', 'p', 'e', 'l']`
- C. `['p', 'q', 'c', 'n', 'e']`
- D. `['p', 'p', 'c', 'm', 'f']`

---

## 答案

**正确答案：** C
