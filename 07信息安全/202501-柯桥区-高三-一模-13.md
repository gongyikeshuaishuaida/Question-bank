# 题目 13

凯撒密码是应用替代方法进行加密的经典算法。这种加密算法提供一个明文字母表，如：

`ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz1234567890 !?.`

加密时，对明文字母表中的每个明文字符右移 `key` 个字母，替代得到密文字母表。例如，`key = 3`，则 `"A"` 加密后得到 `"D"`，`"?"` 加密后得到 `"B"`。现要编写程序，对密文进行解密。请回答下列问题：

（1）某英文单词经凯撒加密后得到密文 `"Ejkpc"`，则该英文单词是______。（`key` 未知）

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
message = input("输入密文:")

# 明文字母表 SYM
SYM = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz1234567890 !?."

# 从英文词典文件 words.txt 中读取英文单词，
# 每个单词作为一个元素存入列表 dic，单词中的大写字母均转换为小写，代码略
for key in range(1, len(SYM)):       # 枚举密钥可能的值
    text = ""
    for sym in message:
        index = SYM.find(sym)         # 找出 sym 在 SYM 中的索引位置
        index = ①
        text += SYM[index]

    text1 = text.lower() + ". "
    word = ""
    n1 = n2 = 0
    for ch in text1:
        if "a" <= ch <= "z" or "0" <= ch <= "9":
            ②
        elif word != "":
            n1 += 1
            if word in dic:
                n2 += 1
            word = ""
    if ③:
        # 解密单词中有 60% 以上存在于英文词典，则可能解密成功
        print("密钥:", key, "明文:", text)
```

---

## 答案

（1）`China`

（2）① `(index - key) % len(SYM)`；② `word += ch`；③ `n2 / n1 >= 0.6`

---

## 解析

枚举 `key` 后，密文字符应在字母表中循环左移 `key` 位；`key=2` 时 `"Ejkpc"` 解密为 `"China"`。程序把连续字母或数字拼成单词，用 `n1` 统计单词总数、`n2` 统计词典中存在的单词数，再判断比例是否达到 60%。
