# 题目 10

有如下 Python 程序：

```python
a = [11, 2, 12, 11, 12, 1, 18]
n = len(a)
i = 0
while i < n-1:
    k = i
    i = n-1
    for j in range(n-1, k, -1):
        if a[j] < a[j-1]:
            a[j], a[j-1] = a[j-1], a[j]
            i = j
print("排序后：", a)
```

以下说法不正确的是（   ）

- A. 该算法采用冒泡排序算法思想
- B. 该算法能实现数组的升序排序
- C. 该算法的时间复杂度是 $O(n^2)$
- D. 为使数组完全有序，`while` 循环只需执行 2 次

---

## 答案

**正确答案：** D

---

## 解析

程序是记录最后交换位置的冒泡排序，可完成升序排序，最坏时间复杂度为 $O(n^2)$；给定数据需要 3 趟，D 错误。
