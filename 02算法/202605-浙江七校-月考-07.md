# 题目 07

某算法流程图如第 7 题图所示，以下说法不正确的是（   ）

![[attachments/202605浙江七校_07_图1.png]]

- A. 该流程图表达的是枚举算法
- B. 输入 n 的值为 50，输出 cnt 为 2
- C. 输入 n 的值为 50，判断框 `i<n?` 执行 8 次
- D. 该算法求 n 的因子中同时是 3 和 7 的倍数的个数


---

## 答案

**正确答案：** D

---

## 解析

流程从 i=7 开始每次加 7，只枚举 7 的倍数，再判断 `j%3==0`，即统计小于 n 的 21 的倍数个数，不是统计 n 的因子。
