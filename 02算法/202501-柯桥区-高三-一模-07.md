# 题目 07

某同学根据第 7 题图所示流程图编写 Python 程序如下：

![[attachments/202501柯桥区_07_图1.jpg]]

```python
n = int(input())
s = 1
while n <= 10:
    s = s * n
    n = n + 1
print(s)
```

用下列输入数据测试程序段与流程图，两者得到的 `s` 值不同的是（   ）

- A. 8
- B. 9
- C. 10
- D. 11

---

## 答案

**正确答案：** D

---

## 解析

流程图先执行一次循环体再判断条件，程序则先判断 `n <= 10`。输入 11 时，程序不执行循环体而输出 1，流程图会先计算 `s = 1 * 11` 再退出，结果不同。
