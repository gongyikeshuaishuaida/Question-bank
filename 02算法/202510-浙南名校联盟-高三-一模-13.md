# 题目 13

13. 配送记录中0表示上门配送、1表示驿站自提，求0和1数量相等的最长连续记录。

(1) 对`[0,1,0,1,1,0,0,1,0,1,0]`，最长长度为______。

(2) 补全：
```python
①
for i in range(n):
    if nums[i] == 0:
        nums[i] = -1
d = {}
cur = ans = 0
for i in range(n):
    cur += nums[i]
    if ②:
        ans = i + 1
    if cur not in d:
        d[cur] = i
    else:
        tmp = ③
        ans = max(ans, tmp)
```

---

## 答案

(1) 10

(2) ①`n=len(nums)`；②`cur==0`；③`i-d[cur]`

---

## 解析

把0变为-1后，和为0表示两类数量相等；相同前缀和两次出现之间的区间和为0，用首次位置计算最长长度。
