# 题目 13

13. 图书馆预约记录含进馆时间、出馆时间和人数，同一时刻先出馆再入馆，统计人数超过阈值的总时长。

(1) 事件列表应______（A按时间升序，同时间按人数从小到大；B按时间降序，同时间按人数从大到小）。

(2) 补全：
```python
d[i]=[ctime[:5],a[i][1]]
d[n+i]=[ctime[6:],①]
...
if sum>Th:
    if time==-1: time=②
elif time>-1:
    rst=③
    time=-1
```

---

## 答案

(1) A

(2) ①`-a[i][1]`；②`t`；③`rst+t-time`

---

## 解析

出馆事件用负人数；升序且同时间负值在前满足先出后入。首次超阈值记开始，回落时累加区间时长。
