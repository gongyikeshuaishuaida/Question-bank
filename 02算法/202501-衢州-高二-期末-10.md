# 题目 10


阅读下列材料，回答第 10 题。

某台无人售货机某月的销售数据整理后存入列表 `a` 中，列表 `a` 的每个元素由订单号、设备ID、商品名称、支付时间、支付金额五项构成，例如 `["749375954","EA07631","可口可乐","2024/12/3 9:41:00",3.0]` 表示列表 `a` 中的某个元素。

10. 下列程序段与流程图（第10题图）描述的算法一致的是（   ）

![[attachments/202501衢州_10_图1.png]]

- A.

```python
sum = 0
for i in range(1,len(a)):
    sum += a[i][-1]
print(sum)
```

- B.

```python
sum = 0
for i in a:
    sum += i[-1]
print(sum)
```

- C.

```python
i = 0; sum = 0
while i < len(a):
    sum += a[i][-1]
    i += 2
print(sum)
```

- D.

```python
i = len(a); sum = 0
while i >= 0:
    sum += a[i][-1]
    i = i - 1
print(sum)
```


---

## 答案

**正确答案：** B

---

## 解析

流程图从 `i=0` 开始，在 `i<len(a)` 时累加 `a[i][-1]`，再令 `i=i+1`，即遍历列表全部元素并累加最后一项。B中的 `for i in a` 正是逐个取元素累加 `i[-1]`。
