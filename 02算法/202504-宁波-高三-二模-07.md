# 题目 07

7. 某算法流程图如图所示，若输出 t 为 3，则输入 s 的值可能是

![[attachments/202504宁波高三_07_图1.png]]

- A. "bbbaa"
- B. "aabba"
- C. "bbaaa"
- D. "abbab"

---
## 答案

**正确答案：** C

---
## 解析

流程图从 i=1 开始比较相邻字符 s[i-1] 与 s[i]。相同则 t 加 1，不同则把 t 重置为 1，循环结束时 t 表示字符串末尾连续相同字符的长度。四个选项中只有 "bbaaa" 的末尾有连续 3 个 a，因此 C 正确。
