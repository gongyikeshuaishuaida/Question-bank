# 题目 07

7. 某中学生一分钟内跳绳计数为 `n`，跳绳体测判定标准如第 7 题图所示，下列程序段功能与流程图所示一致的是

![[attachments/202605强基联盟高三月考_07_图1.png]]

- A.

```python
if n >= 180:
    g = "优秀"
elif n >= 140:
    g = "良好"
else:
    g = "合格"
```

- B.

```python
if n >= 140:
    if n >= 180:
        g = "优秀"
    else:
        g = "良好"
elif n >= 64:
    g = "合格"
```

- C.

```python
g = "合格"
if n >= 180:
    g = "优秀"
elif n >= 140:
    g = "良好"
```

- D.

```python
g = "良好"
if n >= 180:
    g = "优秀"
if 64 <= n < 140:
    g = "合格"
```

---

## 答案

**正确答案：** B

---

## 解析

流程图先判断 `n>=180` 为优秀，否则判断 `n>=140` 为良好，再判断 `n>=64` 为合格。B 中嵌套分支能覆盖这三个区间且不会给低于 64 的情况赋值。
