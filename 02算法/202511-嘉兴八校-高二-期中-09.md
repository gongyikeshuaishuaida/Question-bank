# 题目 09

9. 某算法的部分流程图如图所示，执行该流程时，依次输入 `x` 的值为 3、2、4、-1，下列说法正确的是（   ）

![[attachments/202511嘉兴八校_09_图1.jpg]]

- A. 执行该流程图后，输出的结果是 1
- B. 执行该流程图之后，变量 `s` 的值是 9
- C. 依次输入 `x` 的值为 3、2、4、-1 与依次输入 `x` 的值为 4、3、2、-1，最终 `s` 的值相同
- D. 表达式 `x % 2 == 0` 用于判断 `x` 是否为奇数

---

## 答案

**正确答案：** C

---

## 解析

流程图逻辑：输入 x，当 `x != -1` 时循环。若 `x % 2 == 0`（x 为偶数），则 `s += x`；否则继续下一次输入。输入 3、2、4、-1：

- x=3：奇数，不加。输入 2。
- x=2：偶数，s=2。输入 4。
- x=4：偶数，s=6。输入 -1。
- x=-1：退出循环。输出 s=6。A、B 错。

若输入 4、3、2、-1：
- x=4：偶数，s=4。输入 3。
- x=3：奇数，不加。输入 2。
- x=2：偶数，s=6。

最终 s 值相同（6），C 正确。`x % 2 == 0` 判断 x 是否为偶数，D 错。
