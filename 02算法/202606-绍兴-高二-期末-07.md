# 题目 07

下列程序段中输入值 x 为 1 到 10 之间的整数（包括 1 和 10），其功能与如图所示流程图不一致的是（   ）

![[attachments/202606绍兴高二_07_图1.png]]

- A.

```python
x = int(input())
if x > 5:
    if x >= 10:
        s = x
    else:
        s = x + 1
else:
    s = x - 1
print(s)
```

- B.

```python
x = int(input())
if x <= 5:
    s = x - 1
elif x < 10:
    s = x + 1
else:
    s = x
print(s)
```

- C.

```python
x = int(input())
s = x
if x > 5 and x <= 10:
    s = x + 1
elif x <= 5:
    s = x - 1
print(s)
```

- D.

```python
x = int(input())
s = x - 1
if x >= 10:
    s = x
elif x > 5:
    s = x + 1
print(s)
```

---

## 答案

**正确答案：** C
