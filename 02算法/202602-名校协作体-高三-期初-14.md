# 题目 14

14. 图书馆座位系统连续采集5次人数，排序取中位数，筛选与中位数差不超过3的数据后取平均。

![[attachments/202602名校协作体_14_流程图整行.png]]

(1) 缺失流程为______；数据42、43、46、50、55的有效人数为______。
(2) 拥挤区使用率>80%，闲置区<20%。补全：①闲置条件；②选需引导最多且编号最小的拥挤区；③得到闲置区可接收人数。
```python
if r>0.8: stat[i]=[int(cur[i]-total[i]*0.8),1]
elif ①: stat[i]=[ceil(total[i]*0.2-cur[i]),0]
...
if ②:
    src=i;maxm=stat[i][0]
...
③
```

---

## 答案

(1) B；44

(2) ①`r<0.2`；②`stat[i][1]==1 and stat[i][0]>maxm`；③`dnum=stat[dst][0]`

---

## 解析

中位数46，与其差不超过3的是43和46（含题目流程相应筛选结果），平均取整为44。拥挤标志为1并更新最大引导数，闲置区容量直接取统计值。
