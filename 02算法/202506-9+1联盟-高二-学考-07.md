# 题目 07

下列程序段中输入 `x` 为 1 到 10 之间的整数（包括 1 和 10），其功能与第 7 题图所示流程图不一致的是（   ）

![[attachments/2025069加1联盟高二_07_流程图.png]]

- A．

  ```python
  x = int(input())
  if x > 5:
      if x >= 10:
          s = x
      else:
          s = x + 1
  else:
      s = x - 1
  print(s)
  ```

- B．

  ```python
  x = int(input())
  if x <= 5:
      s = x - 1
  elif x < 10:
      s = x + 1
  else:
      s = x
  print(s)
  ```

- C．

  ```python
  x = int(input())
  s = x
  if x > 5 and x <= 10:
      s = x + 1
  elif x <= 5:
      s = x - 1
  print(s)
  ```

- D．

  ```python
  x = int(input())
  s = x - 1
  if x >= 10:
      s = s + 1
  elif x > 5:
      s = s + 2
  print(s)
  ```

## 答案

**正确答案：** C

## 解析

流程图在 (x>5) 且 (x<10) 时输出 (x+1)，在 (x\geq10) 时输出 (x)。C 选项的条件 `x > 5 and x <= 10` 使 (x=10) 时输出 11，与流程图不一致；其余程序与流程图等价。
