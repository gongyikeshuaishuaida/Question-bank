# 题目 07

7. 甲乙二人石头剪刀布游戏：数字 0 代表石头，数字 1 代表剪刀，数字 2 代表布。如图所示，一共玩 5 局，输出 `num` 的值为甲胜出的局数。例如输入 `s1` 和 `s2` 的值分别为 `"01200"` 和 `"12121"`，分别模拟甲乙两人的出拳顺序，此时输出的 `num` 的值为 3。则流程图①处的代码为（   ）

![[attachments/202606温州十校_07_图1.png]]

- A. `b == a + 1`
- B. `a == b + 1`
- C. `b == (a + 1) % 3`
- D. `a == (b + 1) % 3`

---

## 答案

**正确答案：** C

---

## 解析

甲获胜的编码组合为 `(a,b)=(0,1)、(1,2)、(2,0)`，都满足 `b==(a+1)%3`，因此①处应填选项 C。
