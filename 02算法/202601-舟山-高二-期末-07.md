# 题目 07

7. 某算法的部分流程图如图所示，执行这部分流程，若输入 `x` 的值依次为 153、371、508，则输出 `flag` 的值依次是（   ）

![[attachments/202601舟山高二期末_07_题图1.png]]

- A. True False True  
- B. True True True  
- C. True False False  
- D. True True False

---

## 答案

**正确答案：** D

---

## 解析

流程图计算输入数各位数字立方和 `sum`，并判断 `x == sum`。`153 = 1^3 + 5^3 + 3^3`，输出 True；`371 = 3^3 + 7^3 + 1^3`，输出 True；`508` 的各位立方和为 `5^3 + 0^3 + 8^3 = 637`，不等于 508，输出 False。
