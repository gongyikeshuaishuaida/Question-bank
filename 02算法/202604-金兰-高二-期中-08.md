# 题目 08

8. 观察下列程序段，和流程图功能不一致的是（   ）

![[attachments/202604金兰_08_图1.png]]

- A.

```python
s = 0
i = 99
while i > 0:
    if i % 5 == 0:
        s = s + i
    i = i - 2
print(s)
```

- B.

```python
s = 0
for i in range(1, 101):
    if i % 5 == 0:
        s = s + i
    i = i + 2
print(s)
```

- C.

```python
s = 0
i = 1
while i <= 100:
    if i % 5 == 0 and i % 2 == 1:
        s = s + i
    i = i + 1
print(s)
```

- D.

```python
s = 0
for i in range(1, 101, 2):
    if i % 5 == 0:
        s = s + i
print(s)
```

---

## 答案

**正确答案：** B

---

## 解析

流程图从 `i=1` 开始，每轮令 `i=i+2`，因此只遍历 1～100 中的奇数并累加其中 5 的倍数。A 反向遍历同一组数，C 额外判断奇数，D 直接以步长 2 遍历，功能均一致。B 的 `for` 循环仍按步长 1 遍历，循环体内修改 `i` 不影响下一轮取值，会把偶数的 5 的倍数也累加。
