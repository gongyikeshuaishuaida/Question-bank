# 题目 11

小明学习某导航软件“通过车辆起步数据推算交通信号灯周期”的算法，研究某路口信号灯固定周期时长（20 秒≤固定周期≤300 秒）的推算，编写程序模拟推算过程。算法步骤如下：

1. 对该路口某条直行车道的原始车辆起步数据进行预处理；
2. 通过“离停止线距离小于 3 米”的条件筛选出所有首车，计算所有相邻首车的起步时间差，将其中符合固定周期范围的数据组成差值序列；
3. 对差值序列进行处理，计算最终周期。

## （1）筛选首车

原始数据预处理后存入列表 `data` 中，每个元素包含起步时间、离停止线距离（单位：米）两个数据项，并按起步时间先后顺序排列。示例数据为：

```python
[["08:00:01", 2.3], ["08:01:31", 1.2], ["08:01:35", 7.3], ["08:03:03", 1.1]]
```

根据“离停止线距离小于 3 米”的条件，共有 **3** 辆首车。

## （2）编写 `getdt()` 函数

```python
def getsec(t):
    # 本函数将形如 "hh:mm:ss" 的参数 t 转化为当日累计秒数并返回，代码略
    pass

def getdt(data):
    dt = []
    tmp = -1
    for i in range(len(data)):
        ts = getsec(data[i][0])
        if data[i][1] < 3:
            if tmp == -1:
                tmp = ts
            else:
                if 20 <= ts - tmp <= 300:
                    dt.append(ts - tmp)
                tmp = ts
    return dt
```

填空：`tmp = ts`。

## （3）编写 `getlt()` 函数

将差值序列从小到大排列；相邻两数差值大于阈值时切分序列，保留长度最长的子序列（并列取首个），计算其平均值并取整：

```python
def getlt(dt, thr):
    dt = sorted(dt)
    p = 0
    c = 0
    f = []
    for i in range(len(dt) - 1):
        if dt[i + 1] - dt[i] > thr:
            g = dt[p:i + 1]
            if c < len(g):
                c = len(g)
                f = g
            p = i + 1
    if len(f) < len(dt[p:]):
        f = dt[p:]
    return int(sum(f) / len(f))
```

填空：`g = dt[p:i+1]`。

## （4）主程序

```python
# 读取原始数据，完成预处理，返回 data 列表，代码略
k = 2                         # 分界阈值
dt = getdt(data)
# 注：处理后，dt 中的元素不少于 100 个
T = getlt(dt, k)
print("经推算，当前路口周期为：", T, "秒")
```

填空：`getlt(dt, k)`。

## 答案

（1）3；（2）`tmp = ts`；（3）`g = dt[p:i+1]`；（4）`getlt(dt, k)`。

## 解析

距离小于 3 米的三条记录是首车。每得到一辆新的首车，都要把它的时间更新为下一次相邻差值的起点；切分时取当前子序列 `dt[p:i+1]`，主程序使用分界阈值 `k` 调用 `getlt`。
