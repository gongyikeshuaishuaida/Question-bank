# 题目 13

某校的"悦跑"系统能实时记录学生在跑道上的跑步里程数，并将里程数转换成积分，转换规则如下：里程数≤10千米：每千米得1分；10千米<里程数≤30千米：每千米得2分；里程数>30千米：每千米得3分。根据用算法解决问题的过程，请回答下列问题：

（1）若某同学跑步里程数为18千米，根据转换规则，所得积分为 ▲ 。

（2）计算所得积分时，需提炼的核心要素有 ▲ （多选，填字母）。

（注：全部选对的得2分，选对但不全的得1分，不选或有错的得0分）

- A. 跑道  
- B. 里程数  
- C. 积分  
- D. 每千米

（3）根据转换规则，计算所得积分，请在▲处填入合适的表达式。

```python
lcs=18
if lcs<=10:
    score=lcs*1
elif lcs<=30:
    score=10*1+(lcs-10)*2
else:
    score= ▲
```

（4）计算积分所采用的算法是 ▲ （单选，填字母：A. 解析算法 / B. 枚举算法）。

---

## 答案

**正确答案：** 

（1）26 或 26分

（2）B、C

（3）`10*1+20*2+(lcs-30)*3` 或 `50+(lcs-30)*3` 或 `50+(lcs-30)//1*3` 或 `50+int(lcs-30)*3`

（4）A

---

## 解析

（1）18千米属于11-30千米之间，前10千米得10×1=10分，后续8千米得8×2=16分，总计10+16=26分。

（2）计算所得积分时涉及的核心要素是里程数和积分数据（输入和输出）。跑道是场地信息，每千米是换算比例的组成部分而非独立要素。

（3）当里程数>30千米时，前10千米10分，中间20千米20×2=40分，超出30千米的部分按每千米3分计算，即 `(lcs-30)*3`。总积分为 `10+40+(lcs-30)*3 = 50+(lcs-30)*3`。

（4）该问题根据不同里程数范围使用不同公式进行计算，每个公式直接给出结果，属于解析算法。
