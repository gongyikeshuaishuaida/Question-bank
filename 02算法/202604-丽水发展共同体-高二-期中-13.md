# 题目 13

13. 输入用小写字母表示的非遗品类陈列序列，输出最长连续不重复品类序列的区间；
若有多段长度相同，输出最前一段。

（1）输入 `"abccba"`，最长连续不重复品类序列的区间是______。

（2）补全程序：

```python

mx = i = start = 0
n = len(s)
for j in range(n):
    c = s[j]

    index[t] = j

```


---

## 答案

（1）`[0, 2]`

（2）

- ① `t = ord(c) - ord("a")`
- ② `index[t] + 1`
- ③ `length = j - i + 1`


---

## 解析

用 `i` 表示当前无重复窗口左端。字符若在当前窗口中出现过，就把左端移到其上次出现位置的后一位；窗口长度为 `j-i+1`。
