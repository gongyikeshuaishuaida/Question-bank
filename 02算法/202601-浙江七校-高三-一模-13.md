# 题目 13

13. 股票序列中，局部最大值为波峰、局部最小值为波谷。连续3个递增波峰时，或出现大于
第一个波峰的波谷时，触发买入信号。

（1）若股票价格序列为 `[95,100,98,92,95,102,104,100,103,98]`，______（填“是”或“否”）会触发买入信号。

（2）实现买入信号检测功能的 Python 程序如下，请在划线处填入合适的代码。

```python
# 输入当前股票价格序列 prices，代码略
n = len(prices)
peaks, valleys = [], []
for i in range(1, n - 1):
    pre = prices[i - 1]
    cur = prices[i]
    nex = prices[i + 1]
    if ①:
        peaks.append([i, cur])
    elif cur < pre and cur < nex:
        valleys.append([i, cur])

buy_signal = False
pos = 0
if len(peaks) >= 3:
    for i in range(②):
        if peaks[i - 2][1] < peaks[i - 1][1] < peaks[i][1]:
            buy_signal = True
            pos = i
            break

if not buy_signal and peaks and valleys:
    first_peak_price = peaks[0]
    for i in range(len(valleys)):
        if valleys[i][1] > first_peak_price:
            buy_signal = True
            pos = i
            break
# 输出是否触发买入信号，代码略
```

（3）程序中 `first_peak_price = peaks[0]` 语句有误，请改正。

---

## 答案

（1）否

（2）① `cur > pre and cur > nex`　② `2, len(peaks)`

（3）`first_peak_price = peaks[0][1]`

---

## 解析

波峰存为`[位置,价格]`，比较价格必须取下标1。循环从第3个波峰开始，检查连续三个峰值是否递增。
