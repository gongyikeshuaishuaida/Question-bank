# 题目 07

7. 某算法的部分流程图如第7题图所示，若 `n` 值为 5，数组 `a` 为：`[7, 2, 6, 5, 3]`，数组 `b` 为：`[0, 1, 2, 3, 4]`，执行这部分流程图后，输出的结果为（   ）

![[attachments/202505义乌_07_流程图.jpg]]

- A. `[1, 0, 4, 2, 3]`
- B. `[0, 2, 3, 4, 1]`
- C. `[0, 2, 1, 3, 4]`
- D. `[1, 2, 3, 4, 0]`

---
## 答案

**正确答案：** A

---
## 解析

流程图从 `j=n-1=4` 开始向前比较相邻索引对应的 `a` 值，若前一个值较大就交换 `b` 中的两个索引。依次处理 `j=4,3,2,1` 后，`b` 为 `[1, 0, 4, 2, 3]`。
