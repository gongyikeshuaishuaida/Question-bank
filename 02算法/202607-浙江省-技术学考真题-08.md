# 题目 08

算法的部分流程图如下：

![[attachments/202607浙江技术学考_08_流程图.png]]

执行该流程时，若输入 `a,b,c` 的值分别为 6、8、3，则输出 `a,b,c` 的值分别为（   ）

- A．3、6、8
- B．3、8、6
- C．6、8、3
- D．8、6、3

## 答案

**正确答案：** D

## 解析

流程依次比较并交换 `a` 与 `b`、`a` 与 `c`、`b` 与 `c`。输入 6、8、3 时，第一次交换后为 8、6、3，后两次判断均不满足交换条件，最终输出 8、6、3。
