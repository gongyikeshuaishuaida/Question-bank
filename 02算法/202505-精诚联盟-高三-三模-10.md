# 题目 10

10. 给定一个正整数数组 `a` 和目标值 `target`，找出数组中一个和等于目标值的连续区间，输出其起始和结束下标。方框中应填入的正确代码是（   ）

```python
a = [1, 3, 2, 5, 1, 1, 2, 3]
target = 8
i = j = s = 0
while j < len(a):
    s += a[j]
    while 【方框】:
        s -= a[i]
        i += 1
    if s == target:
        print("找到目标区间：", i, j)
        break
    j += 1
```

- A. `s < target and i < j`
- B. `s > target and j < len(a)`
- C. `s > target and i < j`
- D. `s == target and i < j`

---

## 答案

**正确答案：** C

---

## 解析

数组元素均为正数。加入右端元素后，只有窗口和 `s>target` 时才需要右移左端点来减小窗口和；同时用 `i<j` 保证窗口仍有可收缩空间，所以选 C。
