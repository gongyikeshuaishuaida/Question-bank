# 题目 15

在海岸线（x 轴）安装最少雷达覆盖全部岛屿。每个岛屿 `(x,y)` 对应可安装雷达横坐标区间。示例如图。补全：

```python
qj[i][0] = ______①______
qj[i][1] = x + sqrt(d*d-y*y)
...
if ______②______:
    k = j
...
elif ______③______:
    num += 1
    cur = qj[i][1]
```

（1）示例中覆盖距离改为 3，最少雷达数是多少？  
（3）若修改不可覆盖判断，不影响正确性的选项是 A.`i==n-1` / B.`i==n` / C.`i<n` / D.`y>d`。  
（4）选择排序最多交换多少次？

![[attachments/202607暑假高三e网通5_15_图1.png]]

---

## 答案

**正确答案：** （1）1；（2）① `x-sqrt(d*d-y*y)`；② `qj[k][0]>qj[j][0] or (qj[k][0]==qj[j][0] and qj[k][1]>qj[j][1])`；③ `cur<qj[i][0]`；（3）D；（4）`n-1`

---

## 解析

勾股定理给出每个岛屿对应的雷达位置区间；先按左端点、再按右端点排序，贪心维护当前公共右端点。新区间左端点超过它时需新增雷达。
