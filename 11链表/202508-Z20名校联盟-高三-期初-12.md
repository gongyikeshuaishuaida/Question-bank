# 题目 12

12. 有如下Python程序段：

```python
lnk = [[1, -1]]
head = 0
for i in range(len(a)):
    p = head
    while p != -1:
        if a[i][0] == lnk[p][0]:
            break
        q = p
        p = lnk[p][1]
    if (1):
        lnk.append((2))
        if p == head:
            head = len(lnk) - 1
        else:
            lnk[q][1] = len(lnk) - 1
    else:
        lnk.append((3))
        lnk[p][1] = len(lnk) - 1
```

若`a`为`[[1, 0], [2, 1], [1, 0], [1, 1]]`，运行程序段后，`lnk`为`[[1, 4], [2, 2], [3, 3], [4, 0], [5, -1]]`。程序段中（1）～（3）处可选语句为：

① `a[i][1] == 0`  
② `a[i][1] == 1`  
③ `[i+1, lnk[p][1]]`  
④ `[i+2, lnk[p][1]]`  
⑤ `[i+1, p]`  
⑥ `[i+2, p]`

则（1）～（3）处语句序号依次为（   ）

- A. ②④⑤
- B. ①⑤③
- C. ①⑥④
- D. ②③⑥

---

## 答案

**正确答案：** C

---

## 解析

新结点的数据依次为2、3、4、5，因此结点值使用`i+2`。当`a[i][1] == 0`时把新结点插到匹配结点前，新结点后继应为`p`，即⑥；否则插到匹配结点后，新结点后继为原`lnk[p][1]`，即④。因此依次为①⑥④。
