# 题目 15

考点有 `n` 名考生，每个试场 `m` 个座位，按准考证号升序将考生编排进试场和座位，并用链表保存。分段索引中每段结束位置的下标存入列表 `b`。

![[attachments/202502新阵地_15_图1.jpg]]

![[attachments/202502新阵地_15_图2.jpg]]

（1）当 `n=80`、`m=30` 时，`k=n//m=2`，列表 `b` 中有 **2** 个元素。

（2）链表插入排序：

```python
def linksort(data, mark):
    head = 0
    for i in range(1, len(data)):
        p = head
        if data[p] >= data[i]:
            mark[i] = p
            head = i
        else:
            while p != -1 and data[i] > data[p]:
                pre = p
                p = mark[p]
            mark[i] = p
            ②
    return head
```

给定 `data=[2501067,2501078,2501046,2501059,2501044]`、`mark=[-1,-1,-1,-1,-1]`，返回 `head=4`，`mark` 为 `[1,-1,3,0,2]`；②填 `mark[pre] = i`。

（3）分段索引查找：

```python
def search(key, data, mark):
    i = 0; j = k - 1
    while i <= j:
        mid = (i + j) // 2
        if ①:
            j = mid - 1
        else:
            i = mid + 1
    if i == 0:
        p = head
        q = b[i]
    elif i == k:
        p = mark[b[k-1]]
        q = -1
    else:
        ②
        q = b[i]
    while p != q and key > data[p]:
        p = mark[p]
    if key == data[p]:
        return p
    return -1
```

①填 `key <= data[b[mid]]`；②填 `p = mark[b[i-1]]`（或 `p = mark[b[j]]`）；在生成索引前还需执行 ③ `head = linksort(data, mark)`。

---
## 答案
**正确答案：** （1）2　（2）①`[1,-1,3,0,2]`；②`mark[pre]=i`　（3）①`key<=data[b[mid]]`；②`p=mark[b[i-1]]`或`p=mark[b[j]]`；③`head=linksort(data,mark)`

---
## 解析
`n//m` 给出完整试场数，最后不足一个整场时不记录索引。`linksort` 通过调整 `mark` 指针把新节点插入有序链表；二分查找先在每段结束节点上定位区间，再沿链表顺序扫描该段。
