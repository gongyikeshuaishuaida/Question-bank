# 题目 12

用列表模拟链表结构，每个节点包含数据区域和指针区域，`h` 为头指针。现在修改链表各节点关系，使链表中小于 `x` 的在前，大于等于 `x` 的在后排列，且节点相对关系不变（保证链表头节点小于 `x`）。当 `x=4` 时，链表图如下：

![[attachments/202512省重点中学高三_12_链表图.png]]

```python
x = 4
p = h = 1
pre = r = -1
while p != -1 and data[p][0] < x:
    r = p
    p = data[p][1]
while p != -1:
    if data[p][0] >= x:
        pre = p
    else:
        data[pre][1] = data[p][1]
        ______________________________  # ①；此处是方框处
        r = p
        p = pre
    p = data[p][1]
```

方框中应填入的正确代码为（   ）

- A．`data[r][1] = p`；`data[p][1] = r`
- B．`data[p][1] = r`；`data[r][1] = data[p][1]`
- C．`data[r][1] = data[p][1]`；`data[p][1] = r`
- D．`data[p][1] = data[r][1]`；`data[r][1] = p`

## 答案

**正确答案：** D

## 解析

把当前小于 `x` 的节点从原位置摘下后，应先让它指向当前大于等于 `x` 段的首节点，再让前一个小于 `x` 的节点指向该节点，即 `data[p][1]=data[r][1]`、`data[r][1]=p`。
