# 题目 12

12. 有如下 Python 程序段：

```python
a = [[8, 1], [15, 2], [16, 3], [12, 4], [6, -1]]
head = p = q = 0
np = nq = head
while p != -1:
    if a[p][0] < a[np][0]:
        np = p
        nq = q
    q = p
    p = a[p][1]
if np != head:
    a[nq][1] = a[np][1]
    a[np][1] = head
    head = np
```

运行该程序段后，a 的值为（   ）

- A. `[[8, 1], [15, 2], [16, 3], [12, -1], [6, 0]]`
- B. `[[8, 3], [15, 2], [16, -1], [12, 1], [6, 0]]`
- C. `[[8, 1], [15, 3], [16, 0], [12, 4], [6, -1]]`
- D. `[[8, 4], [15, 3], [16, 1], [12, 0], [6, -1]]`

---

## 答案

**正确答案：** A
