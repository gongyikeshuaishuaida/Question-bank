# 题目 12

12. 有如下 Python 程序：

```python
data = [[22, 2], [11, 0], [33, -1], [55, 1], [44, 3]]
g = [0] * len(data)
p = i = 0
while i < len(data):
    if    ①   and g[p] == 0:
        g[i] += 1
        p = data[p][1]
    else:
        if p != -1:
            g[i] += g[p]
        i += 1
           ②
```

执行该程序段后，`g` 的值为 `[2, 3, 1, 4, 5]`，则划线处的代码依次为（   ）

- A. ① `data[p][1] != -1`；② `p = i`  
- B. ① `data[p][1] != -1`；② `p = data[p][1]`  
- C. ① `p != -1`；② `p = i`  
- D. ① `p != -1`；② `p = data[p][1]`

---

## 答案

**正确答案：** C

---

## 解析

列表 `data` 的第 2 项可看作后继指针，`-1` 表示链尾。程序应沿着 `p` 指向的链表继续统计，直到 `p == -1` 或已计算过 `g[p]`，因此 ① 应判断 `p != -1`。处理完当前 `i` 后，应从新的结点 `i` 开始继续遍历，故 ② 为 `p = i`。
