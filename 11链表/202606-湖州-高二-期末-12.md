# 题目 12

有如下Python 程序段：
```python
h = 0
for i in range(1, len(d)):
    q = -1
    p = h
    while p != -1 and d[p][0] <= d[i][0]:
        q = p
        p = d[p][1]
    if q != -1:
        d[q][1] = i
    else:
        h = i
```
若d 为[[3,-1],[1,-1],[5,-1],[2,-1],[6,-1]]，运行该程序段后，d[h][1]的值为（   ）

- A. -1
- B. 2
- C. 3
- D. 4 二、非选择题（本大题共3 小题，其中第13 小题7 分，第14 小题10 分，第15 小题9 分， 共26 分）

## 答案

**正确答案：** C
