# 题目 12

使用列表 `d` 模拟链表结构（节点数大于 0），每个节点包含数据区域和指针区域，`head` 指向链表的头节点。现要删除链表中倒数第 `k` 个节点，示例输出结果如下图所示。

![[attachments/202502强基联盟_12_图1.png]]

实现该功能的部分 Python 程序段如下：

```python
def delend(head, k):
    if head == -1 or k <= 0:
        return head

    p = q = head
    t = 0
    while t < k and p != -1:
        p = d[p][1]
        t += 1
    if t < k:
        return head
    if p == -1:
        return d[head][1]
    while ____:
        p = d[p][1]
    m = d[q][1]
    d[q][1] = d[m][1]
    return head

d = [[1, 3], [5, 2], [8, 4], [3, 1], [9, 5], [6, -1]]
head = 0
```

则划线中应填入的正确代码依次为（   ）

① `p != -1`　② `d[p][1] != -1`　③ `q = p`　④ `q = d[q][1]`

- A. ①③
- B. ①④
- C. ②③
- D. ②④

---
## 答案

**正确答案：** D

---
## 解析

快指针 `p` 先领先 `k` 个节点。之后要让 `q` 停在待删除节点的前一个节点，因此循环条件应为 `d[p][1] != -1`，循环体中每次让 `q` 后移，即 `q = d[q][1]`。所以选择 ②④（D）。
