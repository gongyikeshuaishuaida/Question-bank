# 题目 15

15. 某视频监控平台接收了 `n` 个视频片段，每个片段包含起始时间和结束时间（单位：秒）。由于网络传输延迟，接收到的数据是乱序的。系统使用链表管理这些片段，先按起始时间升序排列，再将时间重叠的片段合并。

链表采用列表 `lst` 模拟，每个节点为 `[起始时间, 结束时间, next]`，`next` 为后继节点索引，-1 表示结尾。

例如：片段数据 `datas = [[1,5], [3,4], [2,6], [8,10]]`。构造有序链表后，`lst` 的值为：`[[1,5,2], [3,4,3], [2,6,1], [8,10,-1]]`，`head` 为 0。合并后，`lst` 的值变为：`[[1,6,3], [3,4,3], [2,6,1], [8,10,-1]]`，`head` 仍为 0，对应 `[1,6] -> [8,10]`。请回答下列问题：

（1）若片段数据为 `[[5,8], [1,3], [2,4]]`，则构造有序链表后，第 2 个节点起始时间为 ______。

（2）函数 `build_sorted_list(datas)` 遍历数据列表，逐个将节点插入到链表的有序位置。请在划线处填入合适代码。

```python
def build_sorted_list(datas):
    lst = []  # 模拟链表
    head = -1  # 头指针
    for data in datas:
        lst.append([data[0], data[1], -1])
        new_idx = len(lst) - 1
        if head == -1 or data[0] < lst[head][0]:
            lst[new_idx][2] = head
            head = new_idx
        else:
            pre = head
            cur = lst[pre][2]
            while _____①_____:
                pre = cur
                cur = lst[cur][2]
            lst[new_idx][2] = cur
            _____②_____
    return lst, head
```

（3）函数 `merge(lst, head)` 合并重叠片段。请在划线处填入合适代码。

```python
def merge(lst, head):
    p = head
    while lst[p][2] != -1:
        q = lst[p][2]
        if lst[p][1] >= lst[q][0]:
            lst[p][1] = max(lst[p][1], lst[q][1])  # 记录最大值
            _____③_____
        else:
            p = lst[p][2]
    return head

# 读取视频片段数量 n 和数据 datas，每个片段包含两个数据项[起始时间, 结束时间]。代码略。
lst, head = build_sorted_list(datas)  # 构造有序链表
head = merge(lst, head)  # 合并重叠片段
# 输出结果，代码略。
```

（4）若片段数据为 `[[1,3], [2,5], [4,7], [8,10]]`，则合并后链表中剩余节点个数为 ______ 个。

---

## 答案

**正确答案：** （1）2；（2）① `cur != -1 and lst[cur][0] < data[0]`；② `lst[pre][2] = new_idx`；（3）`lst[p][2] = lst[q][2]`；（4）2
