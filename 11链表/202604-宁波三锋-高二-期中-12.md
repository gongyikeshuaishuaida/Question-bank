# 题目 12

12. 列表 `a` 存储了升序链表节点（节点数大于 0），每个节点包含数据区域和指针区域。`head` 指向头节点，现要删除链表中数据值在 `[st, ed]` 范围之外的所有节点。实现该功能的部分程序段如下：

```python
p = q = head
while p != -1:
    if a[p][0] >= st and a[p][0] <= ed:
        q = p
        p = a[p][1]
    else:
        # 方框处
```

方框内应填入的代码是（　）

- A.

  ```python
  if head != p:
      head = a[p][1]
  else:
      a[q][1] = -1
  p = a[p][1]
  ```

- B.

  ```python
  if a[p][0] < st:
      head = a[p][1]
  else:
      a[p][1] = -1
  p = a[p][1]
  ```

- C.

  ```python
  if a[p][0] < st:
      head = a[p][1]
  else:
      a[q][1] = -1
  p = a[p][1]
  ```

- D.

  ```python
  if a[p][0] > ed:
      head = a[p][1]
  else:
      a[p][1] = -1
  p = a[p][1]
  ```

---

## 答案

**正确答案：** C

---

## 解析

链表升序：小于下界的节点只会出现在头部，应不断右移头指针；一旦大于上界，后续也都超界，应把最后一个保留节点的后继置为 -1。
