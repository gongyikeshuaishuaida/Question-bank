# 题目 11

**11．** 有如下 Python 程序段：

```python
n = len(data)
mark = [False] * n; res = [0] * n
for i in range(n):
    if not mark[i]:
        count = 0; p = i
        while p != -1 and not mark[p]:
            mark[p] = True
            count += 1
            p = data[p][1]
        q = i
        while q != -1 and res[q] == 0:
            res[q] = count
            q = data[q][1]
```

若 `data` 为 `[[36,1], [72,3], [15,-1], [90,2], [28,0]]`，程序运行后，下列说法正确的是（   ）

- A. `res[1] + res[3] = 4`
- B. `mark` 中存在某个元素的值为 `False`
- C. 列表 `res` 中，`res[4]` 的值最大
- D. 存在某个索引 `i`，使得 `res[i]` 的值等于从 `i` 出发（含 `i`）沿链表到尾节点的节点总数

---

## 答案

**正确答案：** D

---

## 解析

`data` 格式 `[值, 后继下标]`，链表结构：
- 0 → 1 → 3 → 2 → -1（一条链有 4 个节点：36,72,90,15）
- 4 → 0 → ...（4 指向 0，属于同一链的子部分）

程序逻辑：遍历每个未标记节点，沿链表走到底统计节点数 `count`，然后将链上所有节点的 `res` 设为 `count`。

- 从 i=0 开始（未标记）：沿 0→1→3→2→-1，count=4。res[0]=res[1]=res[3]=res[2]=4。全部标记。
- i=4：mark[4] 未标记。沿 4→0→...但 mark[0] 已标记，只计 count=1。然后 res[4]=1。

- A：res[1]+res[3] = 4+4 = 8 ≠ 4。错误。
- B：所有节点都会被标记为 True。错误。
- C：res[4]=1，不是最大（多个为 4）。错误。
- D：res[0]=4 恰好等于从 0 出发到尾节点的节点总数（0→1→3→2 共 4 个），正确。
