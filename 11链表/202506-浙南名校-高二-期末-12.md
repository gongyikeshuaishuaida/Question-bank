# 题目 12

12. 使用列表 d 模拟链表结构，每个节点包含数据区域和指针区域，h 为头指针。现要实现根据链表的数据区域进行升序排序。实现该功能的部分程序段如下，方框内应填入的正确代码为（   ）

![[attachments/202506浙南名校_12_图a.jpg]]

![[attachments/202506浙南名校_12_图b.jpg]]

```python
h = 4; flag = True
while flag:
    flag = False
    r = h; q = r; p = d[q][1]
    while p != -1:
        if d[q][0] > d[p][0]:
            d[r][1] = p
            ①
            d[p][1] = q
            flag = True
            if q == r:
                h = p
            r = p
        r = q; q = d[r][1]; ②
```

- A. ① `d[q][1] = d[p][1]`　② `p = d[q][1]`
- B. ① `d[q][1] = p`　② `p = d[q][1]`
- C. ① `d[q][1] = p`　② `p = q`
- D. ① `d[q][1] = d[p][1]`　② `p = q`

---

## 答案

**正确答案：** A

---

## 解析

链表冒泡排序：交换相邻节点时，① 将 q 的指针指向 p 的后继（跳过 p），② p 移动到 q 的下一节点继续比较。A 正确。
