# 题目 12

有如下 Python 程序段：

```python
m, n = 0, data[p][0]
cur = p; tag = [p, p]
while p != -1:
    num = data[p][0]
    if m <= 0:
        m = num
        cur = p
    else:
        m += num
    if n < m:
        n = m
        tag[0], tag[1] = cur, p
    p = data[p][1]
```

若 `p` 为 2，`data` 为 `[[-4,3],[-9,-1],[3,0],[4,5],[5,1],[-3,4]]`，执行该程序段后，`tag` 的值为（   ）

- A. [3,3]
- B. [3,4]
- C. [3,5]
- D. [4,5]

---

## 答案

**正确答案：** B

---

## 解析

从 `p=2` 开始按后继下标遍历，节点序列为 2 -> 0 -> 3 -> 5 -> 4 -> 1，对应数据值为 3、-4、4、-3、5、-9。程序维护当前连续和 `m` 及最大连续和区间 `tag`，最大和出现在从节点 3 到节点 4 的区间，因此 `tag` 为 `[3,4]`。
