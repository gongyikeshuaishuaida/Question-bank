# 题目 15

15. 程序每分钟从帖子中提取以`#`开头、空格结尾的话题，统计热度和最后更新时间。
榜单按热度降序；热度相同时，最后更新时间越新越靠前，并用链表维护榜单。

（1）数据为：4秒 `#比赛`、12秒 `#滑翔伞`、23秒 `#杨梅`、33秒 `#滑翔伞`、44秒 `#预赛`、58秒 `#杨梅`。当前榜首话题是______。

（2）定义如下 `read_posts()` 函数，函数功能是读取 `post.txt` 中的帖子内容，返回字典类型，其形式如 `{"#宁波暴雨": [热度值, 最后更新的时间], ...}`。

```python
def read_posts():
    f = open('post.txt', 'r', encoding='utf-8')
    lines = f.readlines()
    # 清空文件，代码略
    dic = {}
    for line in lines:
        # 提取时间并转换为当日秒数，保存在变量 curtime 中，代码略
        i = 0
        f = False
        while i < len(line):
            j = i
            if line[i] == '#':
                f = True
                while j < len(line) and line[j] != ' ':
                    j += 1

                if topic in dic:
                    dic[topic][0] += 1
                    dic[topic][1] = curtime
                else:
                    dic[topic] = [1, curtime]
            i += 1
            if f:
                i = j
                f = False
    return dic
```

## 答案

（1）`#杨梅`

（2）① `topic = line[i:j]`　② B（否）

（3）③ `insert_node(cur)`　④ `node[1] == cur[1] and node[2] > cur[2]`

---

## 解析

`#杨梅`与`#滑翔伞`热度同为2，但杨梅最后更新时间更晚。更新已有节点后要按新排序键重新插入；比较函数先比热度，再比最后更新时间。
