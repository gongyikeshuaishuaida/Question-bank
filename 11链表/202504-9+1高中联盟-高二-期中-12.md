# 题目 12

使用列表 `a` 模拟链表结构（节点数 `n>0` 且 `n` 为偶数），每个节点包含数据区域和指针区域，`head` 为头指针，结构如第 12 题图所示。若要计算该链表中两个中点位置节点的数据区域的平均值。实现上述功能的 Python 程序段如下所示，方框中应填入的正确代码为（   ）

```python
s=f=head
num=0
while f!=-1:
    # 方框处填入代码
num=(num+a[s][0])/2
print("平均值为",num)
```

![[attachments/2025049+1高中联盟_12_图2.jpg]]

- A.
```python
if a[f][1]==-1:
    num+=a[s][0]
s=a[s][1]
f=a[a[f][1]][1]
```

- B.
```python
s=a[s][1]
f=a[a[f][1]][1]
if a[f][1]==-1:
    num+=a[s][0]
```

- C.
```python
if a[a[f][1]][1]==-1:
    num+=a[s][0]
s=a[s][1]
f=a[a[f][1]][1]
```

- D.
```python
s=a[s][1]
f=a[a[f][1]][1]
if a[a[f][1]][1]==-1:
    num+=a[s][0]
```

---

## 答案

**正确答案：** C

---

## 解析

链表有偶数个节点，需要同时取得两个中点。若判断 `a[f][1]==-1` 或先移动再判断，会漏掉前一个中点；应在快指针再走两步将到尾部前先累计慢指针数据，选 C。
