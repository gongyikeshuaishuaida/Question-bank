# 题目 12

12. 有如下 Python 程序段：

```python
n = len(d)
q = p = h
while p != -1:
    if d[p][0] <= x:
        x -= d[p][0]
        if p == h:
            h = d[h][1]; q = h
        else:
            d[q][1] = d[p][1]
        n = n - 1
    else:
        q = p
    p = d[p][1]
```

若 `d` 为 `[[1,1], [5,2], [3,3], [1,4], [2,-1]]`，`h=0`，`x=5`，运行该程序段后，`n` 的值为（   ）

- A. 1  
- B. 2  
- C. 3  
- D. 4

---

## 答案

**正确答案：** B

---

## 解析

按链表顺序访问。结点 0 的值 1 不超过 5，被删除，`x` 变为 4，`n` 变为 4；结点 1 的值 5 超过 4，保留；结点 2 的值 3 不超过 4，被删除，`x` 变为 1，`n` 变为 3；结点 3 的值 1 不超过 1，被删除，`x` 变为 0，`n` 变为 2；结点 4 保留。
