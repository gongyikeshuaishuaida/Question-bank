# 题目 15

接单平台每项任务含截止日期和报酬，每天最多完成一单。按报酬降序、同报酬按截止日期降序、再按编号升序处理，并尽量安排在截止日之前的最晚空闲日。

（1）修改示例后，第 1～4 天接单编号依次为何？  
（2）有序链表插入时：

```python
while p != -1 and task[i][1] <= task[p][1]:
    if task[i][1] == task[p][1] and ______①______:
        break
```

（3）补全：

```python
def find(x):
    for i in range(x, 0, -1):
        if ______②______:
            f[i] = -1
            return i
...
while p != -1:
    ______③______
    t = find(day)
    if t != -1:
        ______④______
```

![[attachments/202607暑假高三e网通6_15_图1.png]]

---

## 答案

**正确答案：** （1）4、8、3、6；（2）① `task[i][0] > task[p][0]`；（3）② `f[i] == i`（或 `f[i] != -1`），③ `day=task[p][0]`，④ `lst[t]=p+1`

---

## 解析

排序规则决定链表插入位置；`find` 从截止日逆向寻找未占用日期。找到后以任务下标加 1 记录接单编号。
