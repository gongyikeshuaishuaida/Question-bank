# 题目 15

15. 某校运动会设有 `m` 个比赛项目（编号 `0~m-1`），每个项目有人数上限。学生在线报名，系统按报名记录的提交顺序逐条处理，对于每条报名记录，若该选手尚未成功报名该项目且该项目当前已成功报名人数未达上限，则报名成功；否则报名失败。

请回答下列问题：

(1) 若报名记录如第 15 题图所示，项目 0 和项目 1 的上限人数分别为 3 和 2，则报名成功的记录数共 ______ 条。

![[attachments/202606台州高二_15_图1.png]]

(2) 定义如下函数 `bubble_sort(lst)`，其功能是对成功报名的记录按项目编号升序排列，相同项目编号按选手编号升序排列。列表 `lst` 中的每个元素包含三个数据项，依次为提交顺序、项目编号和选手编号。

```python
def bubble_sort(lst):
    n = len(lst)
    for i in range(n-1):
        flag = False
        for j in range(n-i-1):
            a = lst[j]
            b = lst[j+1]
            if a[1] > b[1] or a[1] == b[1] and a[2] > b[2]:
                lst[j], lst[j+1] = lst[j+1], lst[j]
                flag = True
        if flag == False:
            break
    return lst
```

① 若 `lst` 为 `[[1,0,103],[2,1,102],[3,1,104],[4,0,101],[5,0,104],[6,2,103]]`，则函数中冒泡排序算法的排序遍数为 ______。

② 程序中方框处的代码 `range(n-i-1)` 可以替换为 ______（单选）。

- A. `range(n-2,i-1,-1)`
- B. `range(n-2-i,0,-1)`
- C. `range(i,n-1,1)`

(3) 实现报名处理功能的 Python 程序如下，请在划线处填入合适的代码。

```python
def proc(data, cap):
    m = len(cap)
    info = [[-1, -1] for i in range(m)]
    nodes = []
    success = []
    cnt = [0] * m
    for item in data:
        t, proj, pid = item[0], item[1], item[2]
        if ①:  # 项目已满员
            continue
        check = False
        p = info[proj][0]
        while p != -1:
            if nodes[p][0] == pid:
                check = True
                break
            ②
        if check == True:  # 选手已成功报名该项目
            continue
        # 报名成功的数据处理
        nodes.append([pid, -1])  # 为 nodes 末尾追加一个元素 [pid,-1]
        if info[proj][0] == -1:
            info[proj][0] = len(nodes)-1
        else:
            ③
        info[proj][1] = len(nodes)-1
        success.append([t, proj, pid])
        cnt[proj] += 1
    return success

# 将报名记录信息存入 data 列表，每个元素包含三个数据项，
# 依次为提交顺序、项目编号和选手编号；
# 将每个项目的上限人数信息存入 cap 列表，代码略
lst = proc(data, cap)
print(bubble_sort(lst))
```

## 答案

**正确答案：** (1) 4；(2) ① 4；② A；(3) ① `cnt[proj]>=cap[proj]`；② `p=nodes[p][1]`；③ `nodes[info[proj][1]][1]=len(nodes)-1`

---

## 解析

(1) 提交顺序 1、2、3 均成功；第 4 条与第 1 条为同一选手重复报名项目 0，失败；第 5 条提交时项目 1 已满员，失败；第 6 条成功，因此共 4 条。

(2) 前三遍仍发生交换，第 4 遍没有交换并触发提前结束，所以排序遍数为 4。选项 A 从右向左比较相邻元素，将较小元素逐步移到前端，与外层循环配合可以完成同一排序目标。

(3) 先通过 `cnt[proj]>=cap[proj]` 判断项目是否满员；查重时用 `p=nodes[p][1]` 沿该项目的链表向后遍历；新增节点时，将原尾节点的后继指针改为新节点下标。
