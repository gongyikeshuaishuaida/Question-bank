# 题目 12

使用列表 `d` 模拟链表结构（节点数大于 1），每个节点包含数据区域和指针区域，`head` 为头指针。现要删除链表中数据值在 `[begin, end]` 范围的节点，实现该功能的部分程序段如下，方框中应填入的正确代码为（   ）

```python
q = p = head
while p != -1:
    if d[p][0] < begin or d[p][0] > end:
        q = p
        p = d[p][1]
    else:
        # 此处是方框处
```

- A.

```python
if head == p:
    head = d[p][1]
else:
    p = d[q][1]
    d[q][1] = d[p][1]
```

- B.

```python
if head != p:
    d[q][1] = d[p][1]
else:
    head = d[head][1]
p = d[p][1]
```

- C.

```python
if head == q:
    head = d[q][1]
else:
    d[q][1] = d[p][1]
p = d[q][1]
```

- D.

```python
if head != q:
    head = d[q][1]
else:
    d[q][1] = d[d[q][1]][1]
p = d[q][1]
```

---

## 答案

**正确答案：** B

---

## 解析

删除非头节点时，应令前驱节点 `q` 的后继直接指向当前节点 `p` 的后继；删除头节点时，应更新 `head`。无论哪种情况，最后都要让 `p` 移到原当前节点的后继继续检查，因此 B 正确。
