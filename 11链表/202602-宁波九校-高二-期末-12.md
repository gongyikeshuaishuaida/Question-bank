# 题目 12

12. 有如下 Python 程序：

```python
data = [[22,2], [11,0], [33,-1], [55,1], [44,3]]
g = [0] * len(data)
p = i = 0
while i < len(data):
    if    ①   and g[p] == 0:
        g[i] += 1
        p = data[p][1]
    else:
        if p != -1:
            g[i] += g[p]
        i += 1
           ②
```

执行该程序段后，`g` 的值为 `[2, 3, 1, 4, 5]`，则划线处的代码依次为（   ）

- A. ① `data[p][1] != -1`   ② `p = i`  
- B. ① `data[p][1] != -1`   ② `p = data[p][1]`  
- C. ① `p != -1`            ② `p = i`  
- D. ① `p != -1`            ② `p = data[p][1]`

---

## 答案

**正确答案：** C

---

## 解析

`data[p][1]` 表示后继下标，`-1` 表示链尾。程序应在 `p != -1` 且当前节点未计算时继续沿链统计；当一条链统计结束并转到下一个起点 `i` 时，应令 `p = i`。这样可依次求出从各下标出发到链尾的节点数，得到 `[2, 3, 1, 4, 5]`。
