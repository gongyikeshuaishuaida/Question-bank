# 题目 11

如下 Python 程序段实现删除链表倒数第 n 个节点的功能（n 小于链表节点总数），请为划线处选择合适的代码：

```python
head=0
s=[["A",1], ["B",2], ["C",3], ["D",4], ["E",5], ["F",-1]]
n=int(input()); p1=p2=head
for i in range(n):
    p2 = s[p2][1]
if p2 == -1:
    head = s[head][1]
else:
    while ____①____:
        p1 = s[p1][1]
        p2 = s[p2][1]
    ____②____
```

- A. ① `p2 != -1` ② `s[p1][1] = s[s[p1][1]][1]`
- B. ① `s[p2][1] != -1` ② `s[p1][1] = s[s[p1][1]][1]`
- C. ① `p2 != -1` ② `s[p2][1] = s[s[p2][1]][1]`
- D. ① `s[p2][1] != -1` ② `s[p2][1] = s[s[p2][1]][1]`

---

## 答案

**正确答案：** B

---

## 解析

先让 p2 前进 n 步，再保持间隔同步移动。应在 `p2` 到达尾结点前停止，此时 p1 指向待删节点前驱，因此修改 `s[p1][1]` 跳过后继节点。
