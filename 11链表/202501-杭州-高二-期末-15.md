# 题目 15

某工厂经常有多种不同类型的原料物资需要入库。为实现物资高效存储和管理，仓库管理员采用一种优化的物资存储方案，目标是尽量将同类物资存放在同一个货架上，以便后续清点及出库等操作。

物资入库操作方法如下：

1. 将当前数量最多的同种类物资放置到与货架剩余容量最接近且能全部放下的货架上；
2. 若不能全部放下，则选择剩余容量最大的货架放置，剩余部分等待后续放置；
3. 重复上述放置操作，直至全部放完或货架全满为止。

编写 Python 程序，模拟物资入库上架过程。程序运行时从文件中读取物资数据及各货架剩余容量数据，计算并输出各物资放置信息。

（2）编写自定义函数 `merge(Lst)`，对类型相同的物资进行合并。参数 `Lst` 为物资列表，列表每个元素分别由物资类型和数量两项组成。例如，`[["A",400],["B",500],["A",300],["C",200]]` 合并后为 `[["A",700],["B",500],["C",200]]`。Python 程序代码如下：

```python
def merge(Lst):
    i = 0
    n = len(Lst) - 1
    while i < n:
        j = i + 1
        while j <= n:
            if Lst[i][0] == Lst[j][0]:
                Lst[i][1] += Lst[j][1]
                Lst[j] = Lst[n]
                j -= 1        # 此处是方框处
                n -= 1
            j += 1
        i += 1
    return Lst[:n+1]
```

## 答案

（1）B、A（或 A、B）

（2）B

（3）① `d < 0 or shelf[i][1] - x < d`；② `shelf[k][1] -= data[head][1]`；③ `data[tmp][2] = q`

---

## 解析

（1）先按数量从大到小处理。B 的 300 件最适合放入 C3（余 100），C 的 280 件放入 C2，E 的 250 件恰好放入 C1，D 的 200 件继续放入 C2；A 的 150 件先向 C2 放 120 件，再向 C3 放 30 件，因此 C3 中有 B、A 两类物资。

（2）合并元素后用末尾元素覆盖当前位置。若不执行 `j -= 1`，覆盖进来的元素不会与当前类型再次比较。B 中最后一个 B 会被换到刚处理的位置，漏掉退回检查就不能完成全部 B 的合并。

（3）当货架容量足够时，应在尚未找到足够容量的货架或当前差值更小时更新最优货架；整批放下后扣除相应货架容量；拆分物资并重新插入链表时，新节点 `tmp` 的后继应指向原定位节点 `q`。
