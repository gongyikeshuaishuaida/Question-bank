# 题目 15

15. M个散件组装1个完整件需T分钟；等待区达到M个即启动，若“等待区数量+到达批次数量≥TH”则整批转移加工。

(1) M=5，批次在6:00到2件、6:15到2件、6:18到3件、6:29到1件，首次启动时间为______（A6:00/B6:15/C6:18/D6:29）。

(2) `m=x[1][y:]`不能正确把分钟转整数，应改为______。

(3) 补全模拟程序：①连接转移批次链表；②完成一次组装后计数；③等待下一批到达时更新时间。
```python
if head == -1:
    head = i
else:
    ①
tail = i
...
if tmp >= M:
    tmp -= M
    curtime += T
    ②
elif i < n:
    tmp += data[i][2]
    ③
    i += 1
```

---

## 答案

(1) C

(2) `m=int(x[1][y+1:])`

(3) ①`data[tail][3]=i`；②`cnt+=1`；③`curtime=data[i][1]`

---

## 解析

前三批累计在6:18达到7件，首次启动。分钟应跳过冒号再转整数。转移批次用第4项作后继指针，组装后计数，无可立即组装时把时钟推进到下一批送达。
