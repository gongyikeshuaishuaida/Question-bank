# 题目 15

15. 系统用升序链表管理空闲自习室。预约时删除头节点，归还时把节点按编号重新插入。

（1）初始编号 0～5，依次执行：预约、预约、预约、归还2、预约、归还0、预约、预约、归还1。
最终链表节点顺序是______。

（2）实现预约和归还模拟的部分 Python 程序如下，程序中下划线处有错误，请改正。

（3）请在标号划线处填入合适的代码。

```python
# 初始化自习室编号列表
rooms = [101, 102, 103, 104, 105]
n = len(rooms)
link = []
id_to_idx = {}
for i in range(n):
    if i < n - 1:
        link.append([rooms[i], i + 1])
    else:
        link.append([rooms[i], -1])

    node_id = link[node_idx][0]
    if head == -1 or node_id < link[head][0]:
        link[node_idx][1] = head
        return node_idx
    p = head
    while link[p][1] != -1 and link[p][1] < node_id:
        p = link[p][1]
    link[node_idx][1] = link[p][1]

        else:

            print("借出", link[node_idx][0])
    else:

        node_idx = id_to_idx[room_id]
        head = insert_node(link, head, node_idx)

# 输出最终链表
```

---

## 答案

（1）`1 -> 4 -> 5`

（2）`link[p][1] != -1 and link[link[p][1]][0] < node_id`

（3）

- ① `link[p][1] = node_idx`
- ② `head = link[node_idx][1]`
- ③ `p = link[p][1]`

---

## 解析

比较时必须取后继节点保存的自习室编号，而不能拿节点下标与编号比较。插入时让前驱指向新节点；预约删除头结点就是让 head 指向原头的后继；输出遍历按后继指针前进。
