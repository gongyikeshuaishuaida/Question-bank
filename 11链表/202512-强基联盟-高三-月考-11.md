# 题目 11

11. 使用二维数组 `link` 模拟链表结构，每个节点数据依次为数据域和指针域，`head` 和 `tail` 分别指向链表的头节点和尾节点，以下 Python 程序实现对各节点数据的升序排序：

```python
def sortL(head, tail):
    p = head
    st = []
    while         (1)        :
        while len(st) != 0 and link[p][0] < st[-1]:
            (2)
            link.append([val, -1])
            link[tail][1] = len(link) - 1
            (3)
        st.append(link[p][0])
        (4)
    return st

link = [[2, 2], [4, 4], [8, 3], [3, -1], [5, 0], [1, 1]]
head, tail = 5, 3
print(sortL(head, tail))
```

划线 `(1)(2)(3)(4)` 处可供选择的语句有：① `p != -1`；② `p != tail`；③ `p = link[p][1]`；④ `tail = link[tail][1]`；⑤ `val = st.pop()`；⑥ `val = link[p][0]`。其填入正确的顺序是（   ）
- A. ①⑤④③
- B. ①⑥③④
- C. ②⑥④③
- D. ②⑤③④

---

## 答案

**正确答案：** A

---

## 解析

链表遍历应以 `p != -1` 为条件。若当前节点值小于栈顶元素，需要弹出栈顶值 `val = st.pop()`，追加到链表尾部后更新尾指针 `tail = link[tail][1]`；处理完当前节点后用 `p = link[p][1]` 移到后继节点。
