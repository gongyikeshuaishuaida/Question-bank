# 题目 12

使用列表 `a` 模拟链表结构（节点数 `n > 0`），其中 `a[i][0]` 存储数据，`a[i][1]` 存储指针，尾节点的指针值为 `-1`。该链表的头指针丢失，找回头指针的程序段如下，则方框中应填入的正确代码为（   ）

```python
tail = -1
for i in range(len(a)):
    if a[i][1] == -1:
        tail = i
        break
head = tail
if tail != -1:
    found = True
    while found:
        found = False
        # 此处是方框处

# 从 head 所指头节点开始遍历链表并输出，部分代码省略
```

- A.

```python
for j in range(len(a)):
    if a[j][1] == head:
        head = j
        found = True
        break
```

- B.

```python
for j in range(len(a)):
    if a[j][1] == tail:
        tail = j
        found = True
        break
```

- C.

```python
p = 0
while a[p][1] != head and p != -1:
    p = a[p][1]
if p != -1 and a[p][1] == head:
    found = True
    head = p
```

- D.

```python
p = 0
while a[p][1] != head:
    p = a[p][1]
if p != -1 and a[p][1] == head:
    found = True
    head = p
```

---

## 答案

**正确答案：** A

---

## 解析

程序先找到尾节点，再反复扫描所有节点，寻找“后继指向当前 `head`”的前驱节点，并把 `head` 向前移动；找不到前驱时，当前节点就是链表头。A 正确地更新 `head`，B 错误更新了 `tail`，C、D 只能沿后继方向查找，不能可靠地由尾节点反向找到头节点。
