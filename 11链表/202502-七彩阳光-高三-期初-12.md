# 题目 12

12. 已知链表 `a` 存放了学生 ID 和借阅图书书名，链表 `b` 存放了学生 ID 和姓名。两链表节点都按学生 ID 升序存放，如第 12 题图 (a) 和 (b) 所示。链表 `a` 的头指针指向额外的空元素。现要将两链表中有共同学生 ID 的节点连接成一个新链表，如第 12 题图 (c) 所示。

![[attachments/202502七彩阳光_12_图1.png]]

![[attachments/202502七彩阳光_12_图2.png]]

```python
ha = q = 0
p = ha
while a[p][2] != -1:
    tp = a[p][2]
    if q == -1:
        a[p][2] = -1
        break
    if a[tp][0] == b[q][0]:
        a[tp].append(b[q][1])
        ①
    elif a[tp][0] > b[q][0]:
        q = b[q][2]
    else:
        ②

# 从 ha 的下一个位置开始输出链表 a，
# 输出结果即为两表连接结果，代码略
```

则划线部分程序应填入的正确代码为（   ）

- A. ① `q = b[q][2]`；② `p = a[p][2]`
- B. ① `p = a[p][2]`；② `a[p][2] = a[tp][2]`
- C. ① `tp = a[tp][2]`；② `p = a[tp][2]`
- D. ① `p = tp`；② `p = a[tp][2]`

---

## 答案

**正确答案：** B

---

## 解析

`p` 指向链表 `a` 当前节点的前驱，`tp=a[p][2]` 指向当前待比较节点。两个 ID 相等并补入姓名后，应令 `p` 前移到该节点，即 `p=a[p][2]`。当 `a[tp][0] < b[q][0]` 时，`a` 的当前节点无法匹配，应通过 `a[p][2]=a[tp][2]` 将其从链表中删除。因此选 B。
