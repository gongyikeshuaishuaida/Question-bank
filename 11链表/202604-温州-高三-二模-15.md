15. 某车间有多类设备，设备用于承接并完成订单对应的各类生产任务。为减少设备启停带来的损耗，若某订单的完成时刻与后续订单的开始时刻相同，且所需的设备类型一致，则合并订单，安排该设备不间断运行。车间根据合并后的订单，优先分配完成时刻最早的该类设备。每台设备一次只能处理一个订单。请回答下列问题。

（2）定义函数 `merge`，用于处理订单合并。

```python
def merge(orders):
    res = []
    for i in range(len(orders)):
        tp, st, t = orders[i][1], orders[i][2], orders[i][3]
        k = -1
        for j in range(len(res) - 1, -1, -1):
            if res[j][0] == tp:
                k = j
                break
        if k != -1 and res[k][1] + res[k][2] == st:
            res[k][2] += t
        else:
            res.append([tp, st, t])
    return res
```
