# 题目 12

列表 `d` 存储了升序链表的节点（节点数大于 0），每个节点包含数据区域和指针区域，`head` 为头指针。现要仅保留链表中数据值在 `[start,end]` 范围内的节点。实现该功能的 Python 部分程序段如下，方框内应填入的正确代码为（   ）

```python
q = p = head
while p != -1:
    if d[p][0] >= start and d[p][0] <= end:
        q = p
        p = d[p][1]
    else:
        ________
```

- A.

  ```python
  if head != p:
      head = d[p][1]
  else:
      d[q][1] = -1
  p = d[p][1]
  ```

- B.

  ```python
  if d[p][0] > end:
      head = d[p][1]
  else:
      d[p][1] = -1
  p = d[p][1]
  ```

- C.

  ```python
  if d[p][0] < start:
      head = d[p][1]
  else:
      d[q][1] = -1
  p = d[p][1]
  ```

- D.

  ```python
  if d[p][0] < start:
      head = d[p][1]
  else:
      d[p][1] = -1
      p = d[p][1]
  ```

---

## 答案

**正确答案：** C

---

## 解析

链表已按数据值升序排列。若当前节点值小于 `start`，说明它位于待删除的头部，应令 `head=d[p][1]`，把头指针向后移动；若当前节点值大于 `end`，说明它及其后续节点位于待删除的尾部，应令前驱节点 `q` 成为新尾节点，即 `d[q][1]=-1`。两种情况处理后都要令 `p=d[p][1]` 继续遍历，因此 C 正确。
