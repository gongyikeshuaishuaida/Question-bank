# 题目 12

12. 有如下Python程序：

```python
pre = [0] * (len(data) + 1)
min_pre = 0
p = head
i = 1
max_sum = data[head][0]
while p != -1:
    pre[i] = pre[i - 1] + data[p][0]
    if pre[i] - min_pre > max_sum:
        max_sum = pre[i] - min_pre
    if pre[i] < min_pre:
        min_pre = pre[i]
    p = data[p][1]
    i += 1
```

若`data`为`[[12,3], [4,4], [3,1], [-2,2], [-3,5], [1,-1]]`，`head=0`，运行该程序后`max_sum`的值为（   ）

- A. 10
- B. 15
- C. 17
- D. 19

---

## 答案

**正确答案：** C

---

## 解析

按后继下标遍历顺序为`0→3→2→1→4→5`，数值序列为`12,-2,3,4,-3,1`。维护最小前缀和计算最大连续子段和，最大值为`12-2+3+4=17`。官方答案表与计算均对应C。
