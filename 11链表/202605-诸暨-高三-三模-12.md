# 题目 12

12. 有如下 Python 程序段：

```python
import random

a = [[1, 5], [5, 2], [2, 4], [2, 0], [4, -1], [3, 1]]
p = head = 3
q = a[p][1]
x = random.randint(1, 5)
while q != -1 and a[q][0] < x:
    p, q = q, a[q][1]
t = p
while q != -1:
    if a[q][0] < x:
        a[p][1] = a[q][1]
        a[q][1] = a[t][1]
        a[t][1] = q
        t, q = a[t][1], a[p][1]
    else:
        p = q
        q = a[q][1]
# 遍历链表 a，依次输出 a[i][0]，代码略
```

执行上述程序后，下列输出结果不可能的是

- A. 2，1，3，5，2，4
- B. 2，1，2，3，5，4
- C. 2，1，3，2，5，4
- D. 2，1，2，3，4，5

---

## 答案

**正确答案：** D

---

## 解析

程序围绕随机值 `x` 调整链表中小于 `x` 的节点位置，但不会破坏原链表中部分节点可达关系到产生 D 所示全局升序序列，因此 D 不可能。
