# 题目 11

11. 有如下程序段，用于将列表 `a` 中的字符串根据长度分类，将长度为 `x` 的单词存储至链表头为 `head[x]` 的链表中，则方框中应填入的正确代码为（   ）

```python
node = []
head = [-1] * 100; tail = [-1] * 100
for i in a:
    x = len(i)
    node.append([i, -1])
    if head[x] == -1:
        head[x] = tail[x] = len(node) - 1
    else:
        ______
        tail[x] = len(node) - 1
```

- A. `node[tail[x]][1] = len(node) - 1`
- B. `node[tail[x]][1] = -1`
- C. `tail[len(node)-1] = -1`
- D. `node[x][1] = len(node) - 1`

---

## 答案

**正确答案：** A

---

## 解析

该程序用链表将同长度的字符串串联起来。`head[x]` 指向链表头部，`tail[x]` 指向链表尾部。

当链表非空时（`head[x] != -1`），需要将新节点连接到当前尾部后面。新节点的索引是 `len(node) - 1`。因此需要将当前尾节点的指针指向新节点：`node[tail[x]][1] = len(node) - 1`，然后更新尾部为新节点，选 A。
