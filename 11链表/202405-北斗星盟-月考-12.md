# 题目 12

12. 从链表 `b` 中随机取出 6 个不同节点元素存入数组 `a`，方框中填入的代码不能实现该功能的为（   ）

```python
import random
b = [["A",1],["B",2],["C",3],["D",4],["E",5],["F",6],["G",7],["H",-1]]
head = 0
a = []
for i in range(6):
    k = random.randint(0,len(b)-i-1)
    if k == 0:
        a.append(b[head][0])
        head = b[head][1]
    else:
        # 方框中填入代码
print(a)
```

- A.

```python
p = head
for j in range(k):
    pre = p
    p = b[p][1]
b[pre][1] = b[p][1]
a.append(b[p][0])
```

- B.

```python
p = head
for j in range(k+1):
    pre = p
    p = b[p][1]
a.append(b[p][0])
b[pre][1] = b[p][1]
```

- C.

```python
p = head; i = 0
while i < k:
    i = i + 1; pre = p
    p = b[p][1]
b[pre][1] = b[p][1]
a.append(b[p][0])
```

- D.

```python
p = head; i = 0
while i < k-1:
    i = i + 1
    p = b[p][1]
a.append(b[b[p][1]][0])
b[p][1] = b[b[p][1]][1]
```

---

## 答案

**正确答案：** B

---

## 解析

当 `k>0` 时，应从链表头开始移动 `k` 次找到第 `k` 个节点，并把该节点从链表中删除。A 和 C 都能找到目标节点并修改前驱指针；D 通过定位目标节点前驱后删除其后继节点，也能实现。B 中循环 `range(k+1)` 会多移动一次，取出的不是第 `k` 个节点，因此不能正确实现随机取出对应节点。
