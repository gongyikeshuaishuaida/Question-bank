# 题目 12

使用列表 `d` 模拟链表结构（节点数 `n>0`），每个节点包含数据、个数、指针三个数据项，`h` 为头指针，链表节点按“数据”非降序排序。现要对链表节点进行合并，将“数据”相同的节点合并为一个节点，并在节点中记录该数据的个数。

合并前的第12题图 a：

![[attachments/202506台州高二_12_原链表.png]]

合并后的第12题图 b：

![[attachments/202506台州高二_12_合并链表.png]]

实现上述功能的 Python 程序段如下：

```python
p = h = 1
while p != -1:
    ______
    ______
    while q != -1 and d[q][0] == d[p][0]:
        q = d[q][2]
        c += 1
    d[p][1] = c
    ______
```

可选代码：

① `q = p`　② `q = d[p][2]`　③ `c = 1`　④ `c = 0`

⑤ `d[p][2] = q`　⑥ `d[p][2] = d[q][2]`　⑦ `p = d[p][2]`　⑧ `p = q`

按划线顺序填入代码，顺序正确的是（   ）

- A．①④⑥⑦
- B．②③⑤⑧
- C．②③⑥⑦
- D．①③⑤⑧

---
## 答案

**正确答案：** B

---
## 解析

每轮从当前节点的后继开始检查相同数据节点，因此先令 `q=d[p][2]`、`c=1`。循环结束后将当前节点指针改为 `q`，跳过已合并节点，并令 `p=q` 处理下一段，故顺序为 ②③⑤⑧。
