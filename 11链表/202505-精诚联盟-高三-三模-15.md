# 题目 15

15. 某重点高中计划从 n 所初中已报名的学生中选拔 s 名“自主招生直录生”。规则如下：

- 成绩位列所在初中前 w 名的学生直接录取；
- 剩余名额按全体未录取学生的综合测评分数从高到低补录；
- 多名学生成绩相同时一并录取；
- 录取人数达到或超过 s 名时立即结束。

数据表 `stu` 的每项包含学校编号（0～n-1）、学生编号、综合测评分数。“校内名次”定义为：若同校有 m 人分数高于该生，则名次为 m+1。

（1）若：

```python
stu = [
    [0,"S1001",91], [1,"S2001",93], [2,"S3001",95],
    [0,"S1002",91], [2,"S3002",90], [1,"S2002",90],
    [0,"S1003",88], [1,"S2003",97], [2,"S3003",85],
    [2,"S3004",85], [1,"S2004",84], [0,"S1004",86]
]
```

编号 S1003 的学生“校内名次”是______。

（2）函数 `mysort` 按综合测评分数从高到低排序：

```python
def mysort(a):
    for i in range(len(a)):
        for j in range(len(a)-i-1):
            if a[j][2] < a[j+1][2]:
                a[j], a[j+1] = a[j+1], a[j]
    return a
```

---

## 答案

（1）3

（2）B、C

（3）

① `stu[i][1] == sid`

② `r[k][1] += 1`

③ `stu[tails[v]][5] = i`

④ `q != -1 and stu[q][2] == tmp`

---

## 解析

（1）初中编号 0 中分数高于 S1003（88 分）的有 S1001、S1002 两人，因此名次为 3。

（2）B、C 都执行按分数降序的冒泡排序。A 的 `range` 步长为 0，无法执行；D 的比较方向得到升序。

（3）`query` 以学生编号定位记录。`r[k][1]` 统计学校 k 已处理的人数，遇到新分数时把它作为该分数段的校内名次。`stu[*][5]` 保存下一节点下标，③把当前节点接到相应链表尾部。补录时 ④ 保证与当前分数 `tmp` 相同的学生全部一并录取。
