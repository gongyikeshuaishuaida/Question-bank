# 题目 12

12. 列表 `a` 中存放 n 个数据，正确的降序关系存储在列表 `link` 中。现发现两个相邻降序数据对应的链表数据发生了错误。如列表数据 `a = [40, 10, 35, 25, 30, 36]`，正确的链表数据 `link = [5, -1, 4, 1, 3, 2]`，`head = 0`，若 `link = [5, -1, 3, 1, 2, 4]`，`head = 0`，则数据 30、35 的降序关系发生错误。现编写 Python 程序，修改列表 `link` 中对应的数据值，使其恢复正确的降序关系。

```python
q = head = 0
p = link[head]
while p != -1 and a[q] > a[p]:
    t = q
    q = p
    p = link[p]
```

## 解析

while 循环遍历链表找到第一个降序错误的位置（`a[q] ≤ a[p]`）。此时需修正链表指针：将位置 q 的后继跳过 p，改为指向正确位置。C 选项的代码正确实现了指针调整逻辑。
