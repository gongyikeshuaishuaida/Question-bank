# 题目 11

**11．** 有如下 Python 程序段：

```python
tag = [0] * len(data)
i = 0
p = i
while i < len(data):
    if p != -1:
        tag[i] += 1
        p = data[p][1]
    else:
        i += 1
        p = i
```

若 `data` 为 `[[0,1], [1,2], [2,-1], [3,2], [4,3]]`，运行该程序段后，`tag[4]` 的值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** C

---

## 解析

`data` 格式为 `[值, 后继下标]`，模拟链表结构：
- data[0] = [0, 1] → 节点值 0，后继指向 1
- data[1] = [1, 2] → 节点值 1，后继指向 2
- data[2] = [2, -1] → 节点值 2，后继为 -1（链表尾）
- data[3] = [3, 2] → 节点值 3，后继指向 2
- data[4] = [4, 3] → 节点值 4，后继指向 3

链表结构：4→3→2→-1（一条链），1→2→-1（另一条链），0→1→2→-1。

程序逻辑：从 i=0 开始，`p` 沿链表后继一直走，每走一步 `tag[i]` 加 1。走到底（p=-1）时 i+1 继续。即统计从节点 i 出发的链表长度。

- tag[0]：沿 0→1→2→-1，3 步 → tag[0]=3
- tag[1]：沿 1→2→-1，2 步 → tag[1]=2
- tag[2]：2→-1，1 步 → tag[2]=1
- tag[3]：3→2→-1，2 步 → tag[3]=2
- tag[4]：4→3→2→-1，3 步 → tag[4]=**3**
