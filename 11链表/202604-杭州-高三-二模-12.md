# 题目 12

12. 使用列表 `d` 模拟链表结构（节点数大于 2），每个节点包含数据区域和指针区域，`h` 为头指针。现要修改该链表各节点的链接关系，将链表 `L0→L1→L2→…→Ln-1` 重排为 `L0→Ln-1→L1→Ln-2→…`，实现该功能的程序段如下，运行结果如第 12 题图所示。

![[attachments/202604杭州高三二模_12_图1.png]]

```python
# 初始化链表数据 d，并输出链表数据，代码略
s = h       # h 为头指针
# 方框处填入代码
print("重排后链表数值顺序:", end=" ")
p = h
while d[p][1] != -1:
    print(d[p][0], end="→")
    p = d[p][1]
print(d[p][0])
```

有如下代码段，在方框中填入的语句顺序应为（   ）

代码段①

```python
p = -1
cur = s
while cur != -1:
    nxt = d[cur][1]
    d[cur][1] = p
    p = cur
    cur = nxt
```

代码段②

```python
f = h
while f != -1 and d[f][1] != -1:
    p = s
    s = d[s][1]
    f = d[f][1]
    if f != -1:
        f = d[f][1]
d[p][1] = -1
```

代码段③

```python
p1 = h
p2 = q = p
while q != -1:
    q = d[p2][1]
    d[p2][1] = d[p1][1]
    d[p1][1] = p2
    p1 = d[p2][1]
    p2 = q
```

- A. ③①②  
- B. ②①③  
- C. ①③②  
- D. ①②③

---

## 答案

**正确答案：** B

---

## 解析

先用快慢指针将链表分为前后两段（②），再反转后半段（①），最后将前半段与反转后的后半段交替合并（③）。
