# 题目 15

**15．** 机器人可以上下左右移动收集四周的资源进行充电。机器人电量 `s` 为已收集资源能量之和；现要求求出机器人能获得的最大能量值。机器人初始位置为 (1,1)，获得能量 9，可以向四个方向移动。当能量 `s = 28` 时，四周已无满足条件的资源块，行程结束。因此，最大能量值为 28。

（1）若将地图中第 (3,2) 位置的资源能量值改为 7，则机器人能获得的最大能量值为 **____**。

（2）`insert` 函数功能为：在链表中插入值为 `[x, y, k]` 的资源块，并返回头指针。其中 x、y 为位置，k 为能量值。实现上述功能的 Python 代码如下，请在划线处填入合适的代码。

```python
def insert(h, x, y, k):
    if h == -1:
        que.append([x, y, k, -1])
        return len(que) - 1
    pos = len(que) - 1
    if k <= que[h][2]:
        que[pos][3] = h
        return      ①
    else:
        p = h
        q = que[p][3]
        while      ②      :
            p = q
            q = que[q][3]
        que[pos][3] = q
        que[p][3] = pos
        return h
```

（3）`walk` 函数实现机器人收集能量块过程，并返回获取的能量最大值。Python 程序如下，请在划线处填入合适的代码。

```python
# dx, dy 表示上下左右四个方向
dx = [0, 0, 1, -1]
dy = [-1, 1, 0, 0]

def walk(x, y):
    h = -1
    que = []
    que.append([x, y, data[x][y], -1])
    h = 0
    s = 0
    vis[x][y] = True
    while h != -1:
        top = que[h]
        h = que[h][3]
        if s == 0 or s / 2 > top[2]:
              ①
        elif s / 2 <= top[2]:
            return s
        for i in range(len(dx)):
            nx, ny = x + dx[i], y + dy[i]
            if nx < 0 or ny < 0 or vis[nx][ny]:
                continue
            vis[nx][ny] = True
                ②
    return s

# 主程序
data = [[14, 7, 17, 4, 15, 20], [...], ...]  # 略
vis = [[False] * 6 for _ in range(3)]
x = y = 1
ans = walk(x, y)
print("最大能量值为:", ans)
```

## 答案

**正确答案：**

（1）**13**（1 分）

（2）① **`h = pos`** 或 `return pos`（2 分）
② **`q != -1 and que[q][2] < k`**（2 分）

（3）① **`s += top[2]`**（2 分）
② **`insert(h, nx, ny, data[nx][ny])`**（2 分）

---

## 解析

（1）将 (3,2) 位置能量改为 7 后，第一次机器人获取能量值为 9+4=13，7 > 13/2，行程结束，最大能量值为 13。

（2）`insert` 函数维护按能量值升序的有序链表。① 若新节点值小于等于头节点，在头部插入后返回新头指针 `pos`。② 遍历链表找到合适的插入位置：当前节点能量值 `que[q][2]` 仍小于新值 `k` 时继续遍历。

（3）① 当可以吸收当前能量块时，将能量值累加到 `s`。② 将新位置的能量块按能量值插入有序链表。
