# 题目 15

15. 某餐厅推出了套餐优惠活动，凡用户购买一个套餐即可获得一张等额换购券，其使用规则如下：

（一）获得换购券的第二天才能开始使用，在有效期内可以换购优惠菜品（简称惠品），其他如“新品”“饮料”等无法使用换购券；

（二）一张换购券最多只允许使用一次，且只能用于不高于换购券金额的惠品；

（三）若使用时有多张换购券满足条件，则优先使用获得时间最早的换购券。

若有用户订单信息如第15题图a所示。其中“时间（天）”列是指订单完成时间，即优惠活动开始后的天数。在第1天、第5天和第6天购买“套餐”订单（编号1、2、3）分别可以获得金额为18、20、37的三张换购券。假设换购券有效期是30天。

| 订单编号 | 类型 | 金额（元） | 时间（天） |
| --- | --- | --- | --- |
| 1 | 套餐 | 18 | 1 |
| 2 | 套餐 | 20 | 5 |
| 3 | 套餐 | 37 | 6 |
| 4 | 新品 | 50 | 7 |
| 5 | 饮料 | 20 | 15 |
| 6 | 惠品 | 36 | 16 |
| 7 | 惠品 | 14 | 18 |
| 8 | 惠品 | 20 | 36 |

按照规则可知，6号订单应选择3号订单获得的换购券换购；7号订单使用最先获得的18元换购券换购；对于8号订单，在已发放的换购券中仅剩2号，但该券在第35天后已经失效，因此8号订单没有换购券可用，仍需支付20元。因此该餐厅的收入为：$18+20+37+50+20+0+0+20=165$元。据此，请回答下列问题。

（1）如第15题图a所示，若4号订单也是“套餐”订单，金额与时间不变，其他订单所有数据也不变，换购券只要未过期都能有效利用，餐厅收入 ▲ 元。

（2）将换购券信息按时间先后顺序放到数组`coupon`中，如第15题图a所示的三张换购券对应数组为`[[18,1], [20,5], [37,6]]`，每个数组元素包含2个数据项，第1个数据项表示换购券金额（元），第2个数据项表示换购券获取时间（天）。定义函数`remove()`查找可使用的换购券，并将该换购券从`coupon`数组中删除。

```python
def remove(pos, amount):
    discount = 0
    i = pos
    while i < len(coupon):
        if amount <= coupon[i][0]:
            discount = amount
            coupon.pop(i)  # 将数组coupon中下标为i的元素删除
            break
        i += 1
    return discount
```

①初始情况下若`pos=0`，`amount=36`，调用`remove`函数后，则数组还剩 ▲ 个元素。

②若删除加框处代码`break`，则 ▲（选填字母：A.能 / B.不能）保证该函数的正常功能。

（3）定义函数`sort()`实现将订单数据`data`按时间从小到大的顺序排列。订单数据放在链表`data`中，链表用Python列表模拟实现，节点各字段含义为：下标0是订单类型，下标1是金额，下标2是时间，下标3是下一个节点位置。请在划线处填入合适的代码。

```python
def sort(head, n):  # n表示链表原始节点个数
    p = data[head][3]
    tail = head
    dummy = n
    data.append([-1, 0, -1, head])
    while p != -1:
        if data[tail][2] <= data[p][2]:
            tail = data[tail][3]
        else:
            q = dummy
            while data[data[q][3]][2] < data[p][2]:
                q = data[q][3]
            data[tail][3] = data[p][3]
            ①
            data[q][3] = p
        p = data[tail][3]
    return data[dummy][3]
```

（4）主程序统计了所有未过期换购券都能有效利用时餐厅总收入，请在划线处填入合适的代码。

```python
# 输入所有订单数据存入链表data，换购券有效时长用变量expired表示，代码略
# data数据如[["套餐",20,5,2], ["套餐",18,1,0], …]
h = sort(head, len(data))  # 链表data的头指针为head
p = h
income = 0
coupon = []
pos = 0
while p != -1:
    income += data[p][1]
    if data[p][0] == "套餐":
        coupon.append([data[p][1], data[p][2]])
    elif data[p][0] == "惠品":
        while pos < len(coupon) and ①:
            pos += 1
        if pos < len(coupon) and coupon[pos][1] < data[p][2]:
            discount = ②
            income -= discount
    p = data[p][3]
print(income)
```

## 答案

**正确答案：** （1）145；（2）①2；②B；（3）①`data[p][3] = data[q][3]`；（4）①`coupon[pos][1] + expired < data[p][2]`；②`remove(pos, data[p][1])`。

---

## 解析

4号订单改为套餐后获得50元换购券，第36天的8号订单可用该券减免20元，所以收入只计前五个需付款订单，共145元。`remove(0,36)`删除37元券后还剩2张；若无`break`，循环可能继续删除多张券。链表插入时先令待插入结点`p`指向`q`原来的后继，再令`q`指向`p`。主程序先跳过已过期券，再调用`remove`按当前惠品金额查找并删除可用券。
