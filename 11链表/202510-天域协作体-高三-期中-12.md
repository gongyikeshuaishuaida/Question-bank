# 题目 12

12. 有如下Python程序段：

```python
import random
a = [[3,5], [5,2], [2,-1], [4,0], [1,3], [2,1]]
p = head = 4
q = a[p][1]
x = random.randint(1, 5)
while q != -1 and a[q][0] < x:
    p, q = q, a[q][1]
t = p
while q != -1:
    if a[q][0] < x:
        a[p][1] = a[q][1]
        a[q][1] = a[t][1]
        a[t][1] = q
        t, q = a[t][1], a[p][1]
    else:
        p = q
        q = a[q][1]
```

遍历链表`a`输出数据域，结果不可能的是（   ）

- A. `1 4 3 2 5 2`
- B. `1 2 2 3 4 5`
- C. `1 3 2 2 4 5`
- D. `1 4 3 2 2 5`

---

## 答案

**正确答案：** B

---

## 解析

分别代入随机数`x=1～5`跟踪链表后继指针，A、C、D均可由某个`x`得到；完全升序的`1 2 2 3 4 5`不会出现，因此B不可能。
