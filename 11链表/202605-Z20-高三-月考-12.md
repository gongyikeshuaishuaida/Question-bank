# 题目 12

12. 有如下 python 程序段：

```python
d = [['D',5], ['B',6], ['A',4], ['C',0], ['B',3], ['D',1], ['E',-1]]
t = h = 2
p = d[h][1]
while p != -1:
    d[t][1] = p; k = p
    q = d[p][1]
    while q != -1:
        if d[p][0] != d[q][0]:
            d[k][1] = q
            k = q
        else:
            d[t][1] = d[p][1]
        q = d[q][1]
    if d[t][1] == p:
        t = p
    p = d[p][1]
```

执行该程序段后，`d[3][1]` 的值是（   ）

- A. 6  
- B. 5  
- C. 0  
- D. -1

---

## 答案

**正确答案：** A

---

## 解析

以 `h=2` 为头节点按后继指针遍历，初始链为 `2(A)->4(B)->3(C)->0(D)->5(D)->1(B)->6(E)`。程序在内层循环中跳过与当前节点值相同的后续节点，最终会把节点 3 的后继从 0 改为 6，因此 `d[3][1]=6`。
