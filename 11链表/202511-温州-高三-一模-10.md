# 题目 10

10. 使用列表lst模拟链表结构，如第10题图a所示，每个节点包含数据区域和指针区域，h为头指针。定义如下函数：

```python
def con(p, m):
    c = lst[p][1]
    for i in range(m):
        t = lst[c][1]
        lst[c][1] = lst[t][1]
        lst[t][1] = lst[p][1]
        lst[p][1] = t
```

将链表调整后结果如第10题图b所示，则主程序调用的函数为（   ）

![[attachments/202511温州_10_图1.png]]

- A. con(3,3)
- B. con(3,2)
- C. con(2,2)
- D. con(2,3)

---

## 答案

**正确答案：** B

---

## 解析

分析函数 `con(p, m)` 的功能：从节点 p 的后继节点 c 开始，将 c 之后的 m 个节点逐个移动到节点 p 之后（头插法）。

参数含义：
- `p`：目标位置节点的索引（移动后的 m 个节点插入到 p 之后）
- `m`：要移动的节点个数

对比图a和图b：图a 中链表顺序为 h → … → 节点3 → …，图b 中将某两个连续节点移动到了节点3之后。移动了 2 个节点（m=2），目标位置为节点3之后（p=3），故调用 `con(3, 2)`。

验证：A 的 m=3 移动了过多节点，C/D 的 p=2 目标位置不对。
