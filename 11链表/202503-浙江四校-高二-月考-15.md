# 题目 15

15. 在计算机系统中，各个进程可能会不断提出对磁盘进行读写操作的请求。由于有时候进程发送请求的速度比磁盘响应的还要快，因此有必要为每个磁盘设备建立一个等待顺序。最短寻道时间优先算法在选择调度处理的磁道时，优先访问与当前磁头所在磁道距离最近的磁道，以使每次的寻找时间最短。假设磁头现在位于 100 号磁道，要访问的磁道号和访问顺序及其对应移动距离如下表所示：

| 磁道号 | 访问顺序 | 移动距离 |
|---:|---:|---:|
| 53 | 5 | 12 |
| 65 | 4 | 59 |
| 98 | 1 | 2 |
| 122 | 2 | 24 |
| 124 | 3 | 2 |
| **移动总距离** |  | **99** |

（1）假设磁头位于 70 号磁道，要访问的磁道号不变，则移动总距离为 ______。

（2）实现该访问策略的部分 Python 程序如下，请在划线处填入合适的代码。

```python
def create(data, start):
    a = []
    a.append([start, 1])
    for i in range(len(data)):
        a.append([data[i], ①])
    n = len(a)

def show(head):
    p = head

def find(current):

    min_distance = 10000
    while a[p][1] != -1:

        p = a[p][1]

            min_distance = abs(a[p][0] - a[current][0])
            pre = q
            next = p
    a[pre][1] = a[next][1]
    a[next][1] = a[current][1]
    a[current][1] = next

data = [53, 65, 98, 122, 124]

# 创建得到链表 [[100, 1], [53, 2], [65, 3], [98, 4], [122, 5], [124, -1]]

```

---
## 答案

**参考答案：** （1）88；（2）① i+2；② p = a[p][1]；③ q = p；④ current = next

---
## 解析

从 70 号磁道开始，最近的是 65（移动 5），随后依次选择 53（12）、98（45）、122（24）、124（2），总移动距离为 5+12+45+24+2=88。链表中每个节点的第二项是下一节点下标：创建时 data[i] 对应 i+2，show 中沿 next 指针移动；find 遍历候选节点时用 q 保存前驱，调度后令 current = next。
