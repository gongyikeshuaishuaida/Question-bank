# 题目 11

若字符串 s 的值为 `"abcde"`，执行如下程序段后，变量 res 的值不可能是（   ）

```python
from random import randint
res = ""
i, j = 0, len(s)-1
while i < len(s) and j >= i:
    if randint(0, 1) == 0:  # randint(0,1)随机生成0或1
        res += s[i]
        i += 1
    else:
        res += s[j]
        j -= 1
```

- A. `"abced"`
- B. `"aecbd"`
- C. `"aedbc"`
- D. `"edcba"`

---

## 答案

**正确答案：** B

---

## 解析

程序每次只能从尚未选取字符串的最左端或最右端取一个字符。若前两次得到 `a、e`，剩余字符串为 `"bcd"`，第三次只能取 b 或 d，不可能取 c，因此 `"aecbd"` 不可能出现。
