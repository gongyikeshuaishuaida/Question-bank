# 题目 10

有如下 Python 程序段：

```python
c, i = "", 0
while i < len(s) and t >= 0:
    if s[i] == "e":
        t -= 1
    else:
        c += s[i]
    i += 1
```

若 s 为 `"keeper"`，t 为 2，执行该程序段后，c 的值为（   ）

- A. `"k"`
- B. `"kp"`
- C. `"kpr"`
- D. `"kper"`

---

## 答案

**正确答案：** B

---

## 解析

扫描字符串时，非 `"e"` 字符加入 c，遇到 `"e"` 则 t 减 1。依次处理 k、e、e、p、e 后，c 为 `"kp"`，t 变为 -1，循环结束，后面的 r 不再处理。
