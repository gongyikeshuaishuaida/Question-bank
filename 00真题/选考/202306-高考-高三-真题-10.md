# 题目 10

定义如下函数：

```python
def f(a, s):
    if a >= s:
        return a
    else:
        return f(a+1, s-a)
```

执行语句 `k = f(6, 21)` 后，`k` 的值为（   ）

- A. 6
- B. 7
- C. 8
- D. 9

---

## 答案

**正确答案：** C

---

## 解析

依次递归计算：`f(6,21) → f(7,15) → f(8,8)`。此时 `8>=8`，函数返回 8，因此 `k=8`。
