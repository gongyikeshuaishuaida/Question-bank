# 题目 11

列表 `q` 长度为 20，`q[0]` 至 `q[4]` 的值依次为 `'p'`，`'r'`，`'i'`，`'n'`，`'t'`，执行如下程序段后，输出的最后一个字符为（   ）

```python
head, tail = 0, 5
while head < tail:
    if head % 3 == 0:
        print(q[head])
    else:
        q[tail] = q[head]
        tail += 1
    head += 1
```

- A. t
- B. n
- C. i
- D. r

---

## 答案

**正确答案：** D

---

## 解析

`head` 是 3 的倍数时输出当前字符，否则把当前字符追加到队尾。依次输出的位置为 0、3、6、9、12，对应字符为 p、n、i、t、r，因此最后输出 r。
