# 题目 12

定义如下函数，返回 key 在列表 data 中的下标，若 key 不存在，则返回 -1。

```python
def bsearch(data, key):
    i, j = 0, len(data) - 1
    while i <= j:
        m = (i+j) // 2
        for k in range(m-1, m+2):
            if i <= k <= j and data[k] == key:
                return k
        if data[m] < key:
            i = m + 2
        else:
            j = m - 2
    return -1
```

如果调用函数返回结果不正确，则 data 可能是（   ）

- A. `[16,19,18,22,20,29,25]`
- B. `[16,19,20,18,22,25,29]`
- C. `[18,16,19,20,22,29,25]`
- D. `[18,16,20,19,25,22,29]`

---

## 答案

**正确答案：** B

---

## 解析

程序每次检查中点及其相邻位置，然后依据 `data[m]` 与 key 的关系跨过两个位置缩小区间。因此 data 虽不要求完全有序，但每轮被排除区域与剩余区域仍须满足相应的大小关系。B 中的 19 位于首次中点左侧的被排除区域，当 key 为 19 时程序会转向右侧，最终错误地返回 -1。
