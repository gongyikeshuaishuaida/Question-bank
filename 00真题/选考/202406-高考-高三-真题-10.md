# 题目 10

某二分查找算法的 Python 程序段如下：

```python
i, j = 0, len(d)-1
while i <= j:
    m = (i+j)//2  # 语句①
    if key == d[m]:
        break
    elif key < d[m]:
        j = m-1
    else:
        i = m+1
```

当 d 为 `[6,12,15,18,22,25,28,35,46]` 时，运行该程序段查找 key，语句①的执行次数小于等于 2；若将 d 修改为 `[6,12,15,18,22,25,28,35,46,58]`，重新运行该程序段，查找同一 key 值，则语句①的执行次数不可能为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** C

---

## 解析

先根据长度为 9 的列表中查找次数不超过 2，确定 key 只能落在首次或第二次比较即可结束的分支；再将这些 key 代入长度为 10 的列表逐一模拟，可出现 1、2 或 4 次比较，但不会恰好执行 3 次。
