# 题目 12

有如下 Python 程序段：

```python
import random
a = ['A', 'B', '#', '#', 'C', 'D', '#']
stk = [0] * len(a)
top = -1
for i in range(len(a)):
    op = random.randint(0, 1)  # 随机生成0或1
    if op == 1 and a[i] != '#':
        top += 1
        stk[top] = a[i]
        a[i] = '#'
    elif op == 0 and top != -1 and a[i] == '#':
        a[i] = stk[top]
        top -= 1
```

执行该程序段后，`a` 的值不可能的是（   ）

- A. `['A', 'B', '#', '#', 'C', 'D', '#']`
- B. `['#', '#', '#', '#', '#', '#', '#']`
- C. `['#', 'B', '#', '#', 'C', 'D', 'A']`
- D. `['#', '#', 'A', 'B', 'C', 'D', '#']`

---

## 答案

**正确答案：** D

---

## 解析

字母入栈后只能按后进先出的次序出栈。若 `A`、`B` 都已入栈，则出栈时必须先得到 `B`、后得到 `A`，不可能在 `a[2]`、`a[3]` 依次出现 `A`、`B`。A 可在所有 `op` 都不触发修改时得到，B 可让所有字母入栈，C 也存在相应随机序列，因此 D 不可能。
