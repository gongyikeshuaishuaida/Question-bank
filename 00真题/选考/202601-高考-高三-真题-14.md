# 题目 14

服务器根据温度数据生成状态码，满足一定条件时发送给智能终端以控制风扇运行。生成和发送状态码的规则如下：

① 温度不超过 15℃ 时，状态码为 0；温度不低于 35℃ 时，状态码为 2；其他温度范围，状态码为 1。

② 当状态码连续 k（k>1）个相同，且与最近已发送状态码不同时，则发送该状态码。

请回答下列问题：

(1) 若 k 为 3，最近已发送状态码为 1，随后生成的状态码序列为“0、0、0、2、0、0、1、1、1、0”，则由该序列触发的状态码发送次数为 ▲ 次。

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
sent = last = -1
# 获取k值，代码略
while True:
    # 获取温度数据保存到变量t中，代码略
    ①
    if t >= 35:
        code = 2
    elif t > 15:
        code = 1
    if ②:
        if code != last:
            cnt = 1
        else:
            ③
        if cnt == k:
            # 发送状态码code，代码略
            sent = code
    last = code
    # 延时1分钟，代码略
```

---

## 答案

(1) 2

(2) ① `code=0`；② `code!=sent`；③ `cnt+=1`

---

## 解析

(1) 前三个 0 连续出现且不同于最近发送的 1，触发发送 0；随后三个连续的 1 又不同于最近发送的 0，触发发送 1，共 2 次。

(2) 先把低温状态默认设为 0；只有当前状态码不同于最近已发送状态码时才需继续计数；若当前状态码与上一次相同，则连续次数加 1。
