# 题目 10

有如下 Python 程序段：

```python
i, r = n, ""
while i < len(s):
    r += s[i]
    i += 1
    if i % 5 == 0:
        i += n
```

若 s 为 `"abcdefghi"`，n 为 2，运行该程序段后，r 的值为（   ）

- A. `"abefi"`
- B. `"abfg"`
- C. `"cdehi"`
- D. `"cdhi"`

---

## 答案

**正确答案：** C

---

## 解析

i 初值为 2，依次访问 `s[2]`、`s[3]`、`s[4]`，得到 `"cde"`。访问 `s[4]` 后 i 变为 5，满足 `i%5==0`，再增加 n 得到 7；随后访问 `s[7]`、`s[8]`，最终 r 为 `"cdehi"`。
