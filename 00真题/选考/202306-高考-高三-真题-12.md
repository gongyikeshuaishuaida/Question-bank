# 题目 12

已排序的列表 `a` 有 `n` 个整型元素，现要查找出现次数最多的值并输出。若出现次数最多的值有多个，则输出最前面的一个。实现该功能的程序段如下，方框中应填入的正确代码为（   ）

```python
c, m, v = 1, 1, 0
for i in range(1, n):
    # 方框处
print(a[v])
```

- A.

```python
if a[i] == a[i-1]:
    c += 1
    if c > m:
        m = c
        v = i
else:
    c = 1
```

- B.

```python
if a[i] == a[i-1]:
    c += 1
    if c > m:
        m = c
        v = i
    else:
        c = 1
```

- C.

```python
if a[i] == a[i-1]:
    c += 1
else:
    if c > m:
        m = c
        v = i-1
        c = 1
```

- D.

```python
if a[i] == a[i-1]:
    c += 1
else:
    if c > m:
        m = c
        v = i-1
    c = 1
```

---

## 答案

**正确答案：** A

---

## 解析

列表已排序，相同值连续出现。`c` 记录当前值连续出现的次数；只要 `c>m`，就立即更新最大次数和对应位置，因此即使出现次数最多的一组位于列表末尾也不会遗漏。使用严格大于号还可保证次数相同时保留最前面的一组，故 A 正确。
