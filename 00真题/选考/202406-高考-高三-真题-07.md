# 题目 07

某同学根据第 7 题图所示流程图编写的 Python 程序段如下：

![[attachments/202406高考_07_图1.jpg]]

```python
n = int(input())
if n <= 20:
    z = 0
if n <= 50:
    z = 1
else:
    z = 2
```

用下列输入数据测试程序段与流程图，两者得到的 z 值不同的是（   ）

- A. 60
- B. 50
- C. 30
- D. 10

---

## 答案

**正确答案：** D

---

## 解析

流程图中第二个判断只在 `n>20` 时执行；程序中的两个 `if` 相互独立。当 n=10 时，程序先令 `z=0`，随后又因 `n<=50` 将 z 改为 1，而流程图输出 0，因此两者不同。
