# 题目 11

对于任意非空字符串 s，甲、乙程序段输出结果相同，则乙程序段加框处的正确代码为（   ）

甲程序段：

```python
def f(s, t):
    if t >= len(s) - 2:
        return s[t]
    return f(s, t+2) + s[t]

print(f(s, 0))
```

乙程序段：

```python
r = ""
n = len(s)
for i in range(0, n, 2):
    ①
print(r)
```

- A. `r=s[n-i]+r`
- B. `r=r+s[n-i-1]`
- C. `r=r+s[i]`
- D. `r=s[i]+r`

---

## 答案

**正确答案：** D

---

## 解析

递归函数依次取下标 0、2、4……处的字符，但由于递归返回时再拼接当前字符，输出顺序与取字符顺序相反。循环中按 0、2、4……取字符时，应把新字符放在 r 的前面，即 `r=s[i]+r`。
