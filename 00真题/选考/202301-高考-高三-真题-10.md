# 题目 10

列表 `s` 包含 8 个互不相等的元素，即 `s[0]`，`s[1]`，`s[2]`，…，`s[7]`，有如下 Python 程序段：

```python
n = 8
for i in range(1, n-1):
    for j in range(1, n-i-1):
        if s[j] > s[j-1]:
            s[j], s[j-1] = s[j-1], s[j]
```

该程序段实现的是（   ）

- A. `s[0]` 到 `s[5]` 的降序排序
- B. `s[1]` 到 `s[6]` 的降序排序
- C. `s[1]` 到 `s[7]` 的升序排序
- D. `s[2]` 到 `s[6]` 的升序排序

---

## 答案

**正确答案：** A

---

## 解析

当 `i=1` 时，内层循环的 `j` 取 1 到 5，参与比较的是 `s[j]` 与 `s[j-1]`，因此排序范围为 `s[0]` 到 `s[5]`。若后一个元素大于前一个元素就交换，使较大元素向前移动，最终形成降序，故选 A。
