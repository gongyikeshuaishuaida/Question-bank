# 题目 11

定义如下函数：

```python
def rf(n):
    if n < 3:
        return n
    return rf(n-1) + rf(n-3)
```

执行语句 `v = rf(5)`，函数 `rf` 被调用的次数是（   ）

- A. 1
- B. 5
- C. 7
- D. 15

---

## 答案

**正确答案：** C

---

## 解析

设调用 `rf(n)` 所需的函数调用次数为 `T(n)`。当 `n<3` 时 `T(n)=1`；当 `n>=3` 时，`T(n)=1+T(n-1)+T(n-3)`。因此 `T(3)=3`，`T(4)=5`，`T(5)=7`，故选 C。
