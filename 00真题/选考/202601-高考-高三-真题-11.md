# 题目 11

有如下 Python 程序段：

```python
s = 0
while topa != -1:
    while topb != -1 and stka[topa] > stkb[topb]:
        if (stka[topa] + stkb[topb]) % 2 == 1:
            topa += 1
            stka[topa] = stkb[topb]
        topb -= 1
    if topb != -1:
        topb -= 1
    s += stka[topa]
    topa -= 1
```

若 stka 为 `[6,0,0,0,0,0]`，topa 为 0，stkb 为 `[2,7,2,1,5]`，topb 为 4，执行该程序段后，s 的值为（   ）

- A. 13
- B. 14
- C. 15
- D. 16

---

## 答案

**正确答案：** C

---

## 解析

第一轮从栈 b 依次处理 5、1、2，满足奇偶条件的 5、2 压入栈 a，随后 7 被直接出栈，栈 a 的 2 出栈并累加。下一轮 b 中的 2 压入 a，此后 b 为空，栈 a 中元素依次出栈累加，最终 `s=2+2+5+6=15`。
