# 题目 11

有如下 Python 程序段：

```python
tag = [0] * len(data)
p = i = 0
while i < len(data):
    if tag[p] == 0 and data[p][1] != -1:
        tag[i] += 1
        p = data[p][1]
    else:
        tag[i] += tag[p]
        i += 1
        p = i
```

若 data 为 `[[11,3],[23,-1],[15,0],[26,1],[63,2]]`，运行该程序段后，`tag[4]` 值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** D

---

## 解析

程序沿 data 中第二个数据项表示的后继下标进行遍历，并利用已经得到的 tag 值减少重复访问。处理下标 4 时，先从 4 到 2，使 `tag[4]=1`；此时 `tag[2]=3` 已计算完成，于是累加得到 `tag[4]=1+3=4`。
