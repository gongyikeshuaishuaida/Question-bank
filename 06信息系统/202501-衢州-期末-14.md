# 题目 14

14. 某地下停车场每个车位都装有车位探测器和车位指示灯，如第14题图a所示。车位探测器探测车位；系统根据探测结果记录车位状态信息，用户可以查询车位状态。小明使用Flask Web框架编写该系统服务器程序。部分代码如下：

![[attachments/202501衢州_14_图1.png]]

```python
@app.route("/")
def hello():
    #欢迎界面，代码略
    return "欢迎访问"

if __name__ == "__main__":
    app.run(host="192.168.31.21", port=8080)
```

（1）为方便升级和维护，该系统网络应用软件的实现架构应选____（单选，填字母：A. B/S架构 / B. C/S架构）。

（2）下列属于该系统硬件的是____（多选，填字母：A. 车位探测器 / B. 车位指示灯 / C. Flask框架 / D. 服务器 / E. 车位状态）。

（3）当前网页显示“欢迎访问”，则浏览器访问的URL是____。

（4）小明导出该停车场某日的数据进行分析，部分数据如第14题图b所示。现编程统计每小时的平均空余车位数，部分程序如下，请在划线处填入合适的代码。

![[attachments/202501衢州_14_图2.png]]

```python
df = pd.read_excel("data.xlsx")
df.insert(5, "时", "")      #插入列
for i in ____①____:
    t = df.at[i, "驶入时间"]
    df.at[i, "时"] = t[11:13]
dfh = df.groupby("____②____", as_index=False)["空余车位"].mean()
```

（5）小明已经从停车场空余车位数分析得出每小时车位使用情况，基于第14题图b的数据，还可以从____角度分析，得出____。

---

## 答案

**正确答案：** （1）A；（2）A、B、D；（3）`http://192.168.31.21:8080/`；（4）①`df.index`；②`时`；（5）示例：从车牌号角度分析，得出不同省份进入停车场的数量

---

## 解析

停车场查询系统面向浏览器访问，便于升级维护，适合B/S架构。车位探测器、指示灯和服务器是硬件，Flask是软件框架，车位状态是数据。Flask服务监听主机 `192.168.31.21` 的8080端口，根路由返回欢迎页面。遍历DataFrame行索引用 `df.index`，按提取出的“时”列分组求平均空余车位数。
