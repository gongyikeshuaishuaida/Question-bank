# 题目 14

14. 小智设计了一款智能大棚监测系统，在每个大棚设置一个环境监测点。每个监测点的智能终端连接传感器，每隔 1 小时采集 1 次温度和光照数据，通过无线通信方式上传至服务器；服务器分析数据并判断有异常情况时，通过监测点智能终端控制执行器调节温度或光照。用户可通过浏览器查看实时与历史环境数据。请回答下列问题：

（1）该系统服务器中的数据 ▲ （单选，填字母：A. 需要传输至传感器 / B. 可以传输至智能终端 / C. 只能传输至浏览器）

（2）为使系统能采集到更准确的环境数据，下列做法不合适的是 ▲ （单选，填字母：A. 增加传感器的数量 / B. 更换灵敏度更高的传感器 / C. 增加传感器的采集间隔时长）

（3）该系统服务器端程序采用 Flask Web 框架编写，服务器的 IP 地址是 192.168.1.100，端口是 8000，部分功能页面规划如下表所示。

![[attachments/202511-杭州-_03_图1.jpg]]

某监测点智能终端的 IP 地址是 192.168.1.1，若该监测点某次采集到的温度 t 为 27，光照数据 s 为 600，则该监测点将数据提交到服务器的 URL 为 http:// ▲

（4）系统正常运行一段时间后，发现某监测点无法调节温度。假设仅传感器、执行器这两个设备可能存在故障，更换新的传感器后发现温度仍然无法调节，再更换新的执行器后，温度可正常调节。根据上述现象，说明 ▲ （选填：传感器 / 执行器）一定存在故障。在上述操作的基础上，请你描述判定原来另一个设备是否存在故障的方法。

（5）小智将某日 8 个监测点的温度数据导出到文件 data.xlsx 中，部分数据如第 14 题图 a 所示。若温度数据低于 22 或超过 28，则认为温度异常。现要统计每个监测点温度异常的数据条目数量，按数量升序排列后绘制如第 14 题图 b 所示的柱形图。

![[attachments/202511-杭州-_04_图1.jpg]]

![[attachments/202511-杭州-_05_图1.jpg]]

实现上述功能的部分 Python 程序如下:

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_excel("data.xlsx")
list1 = [0] * len(df)
for i in range(len(df)):
    t = df.at[i, "①"]    # 通过行、列标签取单个值
    if t < 22 or t > 28:
        list1[i] = 1
df["abnormal"] = list1  # 创建列"abnormal"，列内容为 list1

# 方框中应填入的语句依次为（选 3 项，填字母序列）
②
plt.bar(df.index, df.abnormal)  # 绘制柱形图
# 设置绘图参数，显示如图第 14 题图 b 所示的柱形图，代码略
```

方框可选代码：
- A. `df = df[df["abnormal"] != 0]`（筛选）
- B. `df = df[df["abnormal"] == 0]`
- C. `df = df.sort_values("abnormal")`（升序排序）
- D. `df = df.groupby("监测点编号").count()`（分组计数）
- E. `df = df.groupby("abnormal").count()`

---

## 答案

**正确答案：**

（1）B

（2）C

（3）`192.168.1.100:8000/input?t=27&s=600`

（4）执行器；更换为原传感器后温度可正常调节，则说明传感器未故障；更换为原传感器后温度不可正常调节，则说明传感器故障。

（5）① 温度数据；② A、D、C（顺序为 ADC）

---

## 解析

（1）服务器数据可以下发到智能终端（如控制指令），选 B。

（2）增加采集间隔会降低数据密度，不能提高准确性，选 C。

（3）Flask 路由 `/input`，参数 `t=27&s=600`，完整 URL：`192.168.1.100:8000/input?t=27&s=600`。

（4）换传感器后仍不行，换执行器后正常，说明执行器一定故障。判断传感器：装回原传感器测试，若正常则传感器未故障，若仍不行则传感器也故障。

（5）① 读取温度列：`df.at[i, "温度数据"]`。
② 统计异常条目：先筛选异常行(A)→按监测点分组计数(D)→按数量升序排列(C)。
