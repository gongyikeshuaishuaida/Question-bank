# 题目 11

11. 某智慧健身房引入智能设备管理系统。每台跑步机内置传感器，每 5 分钟采集 3 次设备使用率（0～100%），取中位数后通过无线网络上传至云端服务器。服务器把数据存入数据库；当某设备连续 1 小时使用率低于 10% 时，自动向工作人员发送维护提醒，并控制设备屏幕显示推荐使用教程。会员可通过“运动助手”APP 查看各设备实时使用情况。

（1）设备使用率数据从采集到入库的正确流程是______（单选）。

- A. 传感器 → 智能终端 → 服务器 → 数据库
- B. 传感器 → 服务器 → 智能终端 → 数据库
- C. 智能终端 → 传感器 → 服务器 → 数据库
- D. 传感器 → 数据库 → 智能终端 → 服务器

（2）设备使用率中位数的计算，正确的是______（单选）。

- A. 全部在服务器端完成
- B. 全部在智能终端处完成
- C. 由传感器完成
- D. 由会员手机完成

（3）若某台跑步机与服务器之间的网络连接发生故障，正确的是______（多选）。

- A. 工作人员会收到该设备使用率过低的维护提醒
- B. 会员可通过 APP 查看该设备的实时使用率
- C. 该跑步机仍能正常采集使用率数据
- D. 该跑步机无法把使用率数据上传至服务器

（4）某台跑步机 2026 年上半年使用率数据存于 `gym_2026上半年.xlsx`。现找出平均使用率最低的月份，并绘制该月使用率低于 10% 的日分布柱形图，示例数据与目标图如下。

![[attachments/202604新力量_11_图1.png]]

请选择代码填入①～③。

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_excel("gym_2026上半年.xlsx")
df1 = df.groupby("月", as_index=False)["使用率(%)"].mean()
df2 = ①
m = df2["月"].values[0]
print("平均使用率最低的月份为：", m)
df3 = ②
df4 = df3[df3["使用率(%)"] < 10]
df5 = ③
plt.bar(df5["日"], df5["次数"])
plt.title("平均使用率<10%的日分布情况")

```

- A. `df[df["月"] == m]`
- B. `df2[df2["月"] == m]`
- C. `df.sort_values("使用率(%)", ascending=False)`
- D. `df4.groupby("日", as_index=False)["使用率(%)"].count()`
- E. `df1.sort_values("使用率(%)", ascending=True)`
- F. `df4.groupby("时", as_index=False)["使用率(%)"].count()`

---

## 答案

（1）A

（2）B

（3）C、D

（4）① E　② A　③ D

---

## 解析

传感器采集原始数据，智能终端计算每组三次采样的中位数，再上传服务器并入库。网络中断不会妨碍本地传感器采集，但数据无法上传，服务器也就不能据此生成实时提醒或供 APP 查看。

数据分析先把各月平均使用率升序排列，首行月份即最低月份；再从原始明细 `df` 中筛选该月数据，过滤使用率低于 10% 的记录，最后按“日”分组计数。
