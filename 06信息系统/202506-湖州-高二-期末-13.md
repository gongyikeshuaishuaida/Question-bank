# 题目 13

某工业车间配备 CO 浓度监测系统，可定时采集 3 个不同监测点的 CO 浓度，但采集顺序不固定。每分钟采集的数据格式为 `[[m1,n1],[m2,n2],[m3,n3]]`，监测点名称为 `a`、`b`、`c`。若数值为 0 或超出传感器量程（最大 200 ppm），则传感器失效并停止；若同一监测点连续 3 次低于 20 ppm 或高于 50 ppm，则报警。

（1）前 2 分钟数据为 `[["c",16],["a",54],["b",27]]` 和 `[["b",28],["c",18],["a",30]]`，则 `cnt[2]` 的值为____。

（2）补全程序：

```python
n=3;L=20;H=50
cnt=[0]*n
flag=True
while flag:
    # 将每分钟采集到的监测点数据存入 cv 中，代码略
    for i in ____①____:
        k=ord(cv[i][0])-97
        if ____②____:
            print("监测点",cv[i][0],"传感器失效")
            flag=False
        elif cv[i][1]<L or cv[i][1]>H:
            cnt[k]+=1
            if cnt[k]>=3:
                print("监测点",cv[i][0],"异常")
        else:
            ____③____
    sleep(60*1000)  # 延时1分钟
```

---
## 答案

（1）2

（2）① `range(n)`（或 `range(len(cv))`）；② `cv[i][1]==0 or cv[i][1]>200`；③ `cnt[k]=0`。

---
## 解析

监测点 c 两次浓度 16、18 均低于 20，因此计数为 2。每分钟有 3 条记录，故循环使用 `range(n)`；0 或超过量程表示失效；恢复到安全范围时连续异常次数清零。
