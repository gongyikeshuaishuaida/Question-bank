# 题目 14

14. 小李的父亲在乡村经营一家茶叶仓库。茶叶对温度和湿度敏感，小李设计并开发了“智能茶叶仓储与销售管理系统”。系统实时监控并记录各区域温湿度，支持用户通过网页或手机端查看当前及历史数据，并可远程控制除湿设备；温湿度超出阈值时自动触发报警。系统选用物联网模块实现无线通信，并增加销售数据分析功能。

（1）小李深入了解仓储条件与设备控制要求后，开始进行模块结构设计和系统物理配置。这属于信息系统设计前期准备工作中的______（单选，填字母：A.需求分析 / B.可行性分析 / C.概要设计）。

（2）茶厂人员需要在手机或电脑浏览器上实时查看数据并操作设备，最合适的系统结构开发模式是______（单选，填字母：A.B/S 模式 / B.C/S 模式）。

（3）以下信息系统搭建方案中合理的是______（多选，填字母）。

- A. 为每种茶叶配置一个单独的物联网模块
- B. 将温湿度传感器与报警装置连接在同一智能终端
- C. 租用云服务器作为 Web 系统部署平台
- D. 建立用户权限分级系统，限制普通员工修改系统设置

（4）写出可以增加的两个新功能，并简单说明用途。

## 解析

模块划分和物理配置属于概要设计。浏览器跨设备访问适合 B/S 模式。传感器与执行器可接入同一智能终端，Web 系统可部署于云服务器，权限分级也属于合理安全措施；为每种茶叶配置独立通信模块成本高且没有必要。

日期转成字符串后，`m[4:6]` 是月份。应分别从原始表 `df` 筛选 4 月和 5 月记录，再合并后按茶叶品种汇总。题面代码缺少显式合并步骤，因此其原始程序仍不完整；若 `df2` 预期包含 4、5 月数据，应改为：

```python
df2 = df[(df["月份"] == 4) | (df["月份"] == 5)]
```

然后按销售量降序取前 5 行。
