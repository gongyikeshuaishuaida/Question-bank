# 题目 05

下列关于智慧校园电子班牌系统网络的说法，正确的是（   ）

- A. 同一年级的电子班牌需设置为同一 IP 地址
- B. 云服务器无需安装操作系统
- C. 路由器是组建校园网络的重要设备之一
- D. 智慧校园中的数据通信必须通过移动通信网络实现

---
## 答案
**正确答案：** C

---
## 解析
路由器负责不同网络间的数据转发，是组网的重要设备；同一网络中的设备不能共用同一 IP，服务器仍需操作系统，校园网通信也不必依赖移动通信网络。
