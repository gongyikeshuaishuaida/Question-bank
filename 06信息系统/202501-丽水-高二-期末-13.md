# 题目 13
某场所要求环境温度低于阈值（30℃）。温控系统每隔1分钟采集一次实时温度：若实时温度连续6分钟都未低于阈值，启动制冷设备；若连续6分钟都低于阈值，关闭制冷设备，并统计一天制冷设备启用的总时长。

（1）若设备当前处于开启状态，依次采集到 `30℃、31℃、30℃、29℃、29℃、28℃` 后，设备处于______（开启/关闭）状态。

（2）补全程序：

```python
t_last=0; time=dtime=0
run=False  # 初始关闭
t0=30
while True:
    # 接收实时温度，存入 temp，代码略
    # t_new=0 表示低于阈值，1 表示未低于阈值
    if ____①____:
        t_new=0
    else:
        t_new=1
    if t_new==t_last:
        ____②____
        if time>5:
            if temp>=t0:
                run=True
            else:
                run=False
    else:
        time=1
    if run==True:
        dtime=dtime+1
    ____③____
    # 延时1分钟，代码略
print("开启制冷设备的总时长（分钟）：", dtime)
```

---
## 答案
（1）开启

（2）① `temp<t0`；② `time=time+1`；③ `t_last=t_new`

---
## 解析
“低于阈值”是严格小于30℃，所以①为 `temp<t0`。采样状态与上次相同就把连续计数加1，②为 `time=time+1`；每次处理完还要保存本次状态，③为 `t_last=t_new`。给出的序列中低于30℃只连续出现3次，未达到关闭所需的6分钟，设备仍保持开启。
