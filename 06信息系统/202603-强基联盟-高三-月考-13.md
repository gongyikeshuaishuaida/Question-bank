# 题目 13

13. 某超市搭建了智慧管理系统，该系统利用 RFID 实时监测库存信息；通过温湿度传感器采集冷链食品区的数据；借助 wifi 网络将采集的数据传输至服务器；系统根据实时数据自动更新货架上的智能电子价签、并自动调节冷柜温度；库存不足时向供货商发送补货指令。请回答下列问题：

（1）该系统工作时，下列关于数据流向的描述正确的是 ______（单选）。

- A. 补货指令由供货商发起，流向超市服务器
- B. 库存数据由 RFID 采集，经读写器上传至服务器
- C. 该系统只有数据采集，没有数据输出功能

（2）下列关于该系统的组成及功能的说法正确的是 ______（单选）。

- A. 智能电子价签和冷柜压缩机属于该系统的执行器
- B. 智能终端必须通过有线网络连接服务器才能保证数据稳定传输
- C. 为提高安全性，智能终端连接 wifi 时不应设置任何验证机制
- D. RFID 读写器是发送端，其主要功能是向智能价签发送最新的价格指令

（3）在系统开发的前期准备过程中，下列说法正确的有 ______（多选）。（注：全部选对得 2 分，选对但不全得 1 分，不选或有错得 0 分）

- A. 需求分析阶段应明确系统是否需要实现“自动补货预警”功能
- B. 概要设计阶段通常需要绘制系统功能模块图，确定系统硬件配置
- C. 服务器端程序应包含数据库查询逻辑，以实现历史库存走势分析
- D. 只要服务器性能足够高，系统搭建前就不需要进行可行性分析

（4）系统拟实现“分级预警”功能，`stock` 用于存储当前库存，`limit` 用于存储预警阈值。若库存量低于阈值的 20% 显示“紧急补货”，若库存量低于阈值但在 20% 及以上显示“建议补货”，否则显示“库存正常”。下列代码段中能正确实现该功能的有 ______（多选）。

- A.

```python
if stock < limit * 0.2:
    ans = "紧急补货"
if stock < limit:
    ans = "建议补货"
else:
    ans = "库存正常"
```

- B.

```python
ans = "紧急补货"
if stock >= limit:
    ans = "库存正常"
elif stock >= limit * 0.2:
    ans = "建议补货"
```

- C.

```python
if stock < limit:
    ans = "建议补货"
elif stock < limit * 0.2:
    ans = "紧急补货"
else:
    ans = "库存正常"
```

- D.

```python
ans = "紧急补货"
if stock >= limit * 0.2:
    ans = "建议补货"
if stock >= limit:
    ans = "库存正常"
```

（5）当冷链区的某批次生鲜食品临近保质期时，系统会自动调低该商品在智能价签上的显示价格。管理员发现某商品已临近保质期，智能价签仍显示原价，经检测智能价签本身无故障，请简要说明系统中可能造成上述问题的原因。（注：回答 2 项，1 项正确得 1 分）

---

## 答案

**正确答案：** （1）B；（2）A；（3）ABC；（4）BD；（5）① RFID 读写器未能正确读取该批次商品的保质期信息；② 智能价签与服务器间的通信中断，导致调价指令未送达。

---

## 解析

RFID 采集库存数据并经读写器上传到服务器，智能电子价签和冷柜压缩机负责执行系统输出。系统开发前需要进行需求分析、概要设计和数据库等功能设计，可行性分析不能省略。分级预警中应先区分“紧急补货”，再根据阈值覆盖为“建议补货”或“库存正常”，B、D 均可实现。价签未调价可能来自保质期数据采集失败，也可能来自服务器到价签的通信或指令传递异常。
