# 题目 13

**13．** 某智能鱼缸系统服务器端程序采用 Flask Web 框架开发。通过与智能终端连接的水质、溶氧传感器等监测鱼缸的清洁度、含氧量等指标，智能终端通过 IoT 模块与 Web 服务器建立数据通信，使用自动换水器、氧气泵等装置实现自动控制。请回答下列问题：

（1）系统会通过自动换水器调节水质，开启或关闭该装置的过程中使用了 **____**。（单选，填字母：A.传感技术 / B.控制技术 / C.网络技术）

（2）编写服务器端程序时，需要知道 **____**。（多选，填字母）
（注：全部选对的得 2 分，选对但不选全的得 1 分，不选或有选错的得 0 分）
A.服务器的 CPU 型号
B.智能终端和传感器连接的引脚
C.数据库中存放数据的数据表名
D.服务器提供 Web 服务的端口号

（3）氧气泵处于工作状态，变量 `f` 值为 1；不工作状态，变量 `f` 值为 0。氧气泵气量为高挡，变量 `d` 值为 1；气量为低挡，变量 `d` 值为 0。当检测到水中溶氧量 `y < 5mg/L` 时，启动氧气泵，气量调至低挡；`y < 3mg/L` 时，气量调至高挡；`y ≥ 5mg/L` 时，关闭氧气泵。下列代码符合要求的是 **____**（单选，填字母）。

```
A                              B
if y >= 5:                     if y < 5 and f == 0:
    if f == 1:                     f = 1
        # 关闭氧气泵，代码略        # 启动氧气泵，代码略
        f = 0                      d = 0
else:                              if y < 3:
    if f == 0:                         d = 1
        # 启动氧气泵，代码略   elif y >= 5:
        f = 1                      if f == 1:
    if y < 3:                          # 关闭氧气泵，代码略
        d = 1                          f = 0
    else:
        d = 0
```

（4）若要喂养某种金鱼，其适宜水温为 10~22 摄氏度。现要为该系统添加自动水温调节功能，请写出需要增加的传感器和执行器名称及其功能：**____**。

---

## 答案

**正确答案：**

（1）**B**（2 分）

（2）**C、D**（2 分）

（3）**A**（2 分）

（4）传感器：温度传感器 —— 采集温度数据；（1 分）执行器：恒温器（或加热棒和制冷片等）—— 控制温度升降（1 分）

---

## 解析

（1）开启或关闭自动换水器属于执行控制操作，使用了**控制技术**。传感技术负责采集数据，控制技术负责执行动作。

（2）编写服务器端程序时需要知道**数据库中存放数据的数据表名**（C）和**服务器提供 Web 服务的端口号**（D）；CPU 型号和硬件引脚连接是嵌入式/硬件层面的问题，服务器端不需关心。

（3）选项 A 逻辑正确：优先判断 `y >= 5`（需要关闭）→ 若正在工作中则关闭；否则 `y < 5`（需要启动）→ 若未工作则启动，再根据 `y < 3` 判断高低挡。选项 B 没有处理 `y >= 5` 时需关闭的情况，且 `y` 在 3~5 之间时 `d = 0` 未正确设置。

（4）需增加**温度传感器**采集水温数据，以及**恒温器**（或加热棒+制冷片组合）作为执行器来调节温度。
