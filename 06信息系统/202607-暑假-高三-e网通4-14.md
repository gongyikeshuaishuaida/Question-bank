# 题目 14

小明搭建“阅览室环境检测系统”，结构及部分噪声数据如下图。请回答：

![[attachments/202607暑假高三e网通4_14_图1.png]]

![[attachments/202607暑假高三e网通4_14_图2.png]]

（1）不属于信息系统详细设计的是______①______（A. 输入输出设计 / B. 模块结构设计 / C. 人机界面设计 / D. 安全设计）。

（2）Web 服务器功能描述正确的是______②______（A. 数据处理和网络控制 / B. 用于连接网络中的各种设备）。

（3）程序以 `app.run(host='192.10.5.2', port=8080)` 启动，视图路由为 `@app.route('/read')`，访问 URL 为 `http://`______③______。

（4）智能终端显示正常，但安静时红灯仍持续警报。已排除通信网络、传感器、数据库和智能终端故障，请写出两种可能原因。

（5）补全程序：

```python
import pandas as pd
df = pd.read_csv("______④______")
i = 0; maxc = 0; cnt = 0; g = []
tsv = 45
while i < len(df):
    if df.at[i, "检测值db"] > tsv:
        st = i; i += 1; cnt = 1
        while i < len(df) and df.at[i, "检测值db"] > tsv:
            i += 1
            cnt += 1
        if cnt > ______⑤______:
            maxc = cnt
            g = [df.at[st, "时间"], df.at[i-1, "时间"]]
    i += 1
print("警示红灯持续点亮的最长持续时间为：", maxc*30, "秒")
print("对应的开始时间为：", g[0], "，结束时间为：", g[1])
```

---

## 答案

**正确答案：** （1）B；（2）A；（3）`192.10.5.2:8080/read`；（4）执行器（警示灯）损坏、阈值设置不合理或控制程序逻辑错误（任答两项）；（5）④ `data.csv`，⑤ `maxc`

---

## 解析

模块结构设计属于系统总体设计。Web 服务器承担数据处理与网络控制。URL 由主机、端口和路由组成。异常可从剩余硬件执行器和软件/阈值两方面排查。程序用 `maxc` 保存历史最长连续记录数。
