# 题目 13

某校兴趣小组搭建一个多肉生长环境监测系统，采集大棚内的温度、土壤湿度和 pH 值等数据。该系统有若干个监测点，每个监测点均配备智能终端、传感器、执行器和 IoT 模块。智能终端通过 IoT 模块连接 Web 服务器上传各项数据，并从服务器获取阈值。若土壤湿度低于阈值，智能终端将启动洒水装置；若 pH 值异常，服务器将异常信息发送至用户手机。用户可以通过浏览器查看各项数据。请回答以下问题。

（1）下列关于该信息系统的说法，正确的是 ________（多选，填字母）。

（注：全部选对得 2 分，选对但不全得 1 分，不选或有选错得 0 分。）

- A. 各项阈值可以存储在服务器的数据库中
- B. 传感器和执行器可以连在不同的智能终端上
- C. 确定传感设备的型号，属于搭建信息系统前期准备中的概要设计
- D. 实时判断 pH 值是否异常的程序只能在服务器端运行
- E. 调试并观察该系统运行时的行为，属于静态测试

（2）下列关于系统中数据流向的说法，正确的是 ________（多选，填字母）。

- A. 土壤湿度低于阈值时：`服务器 ↔ 智能终端 → 执行器`，且 `湿度传感器 → 智能终端`
- B. 上传温度数据时：`温度传感器 → 智能终端 ↔ 服务器 → 数据库`，且 `服务器 → 执行器`
- C. pH 值异常时：`pH 传感器 → 智能终端 → 手机`
- D. 浏览器查看各项数据时：`浏览器 ↔ 服务器 ↔ 数据库`

（3）智能终端上的程序具有如下功能：每 2 分钟从传感器获取 1 次温度数据值，并将温度值传输到服务器端存储。已知服务器的地址为 `192.168.1.6`、端口为 `5000`，部分程序如下：

```python
while True:

    errno, resp = Obloq.get("toph?tid=3&t=" + str(temp), 10000)
    # 其他代码略
```

下列说法不正确的是 ________（单选，填字母）。

- A. 传感器接在智能终端的 `pin0` 引脚上
- B. 向服务器传输温度数据的 URL 可以为 `http://192.168.1.6:5000/toph?tid=3&t=23.5`
- C. 若将服务器 IP 地址改为 `192.168.1.100`，则只需修改服务器端程序即可

（4）在有些时间段内，大棚内的环境数据不会有很明显的变化，太多相同的数据会造成数据冗余，从而浪费存储空间。请给出两种解决方案（每种 1 分）。

## 答案

（1）A、B

（2）A、D

（3）C

（4）示例：

- 根据服务器承受能力设置合理的数据采集时间间隔，减少无意义的高频采集；
- 当本次数据与上次相同时不重复存储，沿用上次数据记录。

（5）① B；② E；③ D

---

## 解析

（1）阈值可以保存在服务器数据库中；不同位置的传感器和执行器可以连接不同智能终端。设备型号选择属于详细设计或设备选型，判断程序也可以部署在不同端，运行时观察属于动态测试。

（2）土壤湿度低于阈值时，智能终端既接收服务器阈值，又接收传感器数据并控制执行器，A 正确；浏览器查询时，数据在浏览器、服务器和数据库之间双向传递，D 正确。B 多出了服务器到执行器的数据流，C 缺少服务器转发。

（3）服务器 IP 改变后，智能终端访问服务器的地址也必须同步修改，不能只改服务器端程序。

（5）先用最低气温筛选下限，再用最高气温筛选上限；按月份分组计数后，把计数字段重命名为“适宜天数”，最后按该字段降序排列。
