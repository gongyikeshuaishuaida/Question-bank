# 题目 13

13. 某小组搭建地下停车场智能照明控制系统，智能终端连接传感器采集环境数据，通过 IoT 模块上传至服务器，并存储到数据库。服务器根据环境数据，通过智能终端控制照明灯的开关及亮度。管理员通过浏览器可查看并管理系统。请回答下列问题：

(1) 下列可与智能终端连接，并能向其发送数据的硬件有 ______（多选）。

- A. 操作系统
- B. 服务器
- C. 光敏传感器
- D. 照明灯
- E. 浏览器

（注：全部选对的得 2 分，选对但不全的得 1 分，不选或有选错的得 0 分）

(2) 控制照明灯的智能终端部分代码如下：

```python
while True:
    errno, resp = Obloq.get("input?id=1&val="+str(light), 5000)  # 语句A
    if errno == 200:
        if resp == "1":
            pin16.write_digital(1)  # 语句B
```

其中修改路由可以通过语句 ______ 实现（单选）。

(3) 下列需要在服务器端程序进行配置的是 ______（多选）。

- A. 视图函数名
- B. 与传感器连接的引脚
- C. Web 模板文件
- D. 数据采集间隔时间

（注：全部选对的得 2 分，选对但不全的得 1 分，不选或有选错的得 0 分）

(4) 下列关于该系统的说法，正确的有 ______（单选）。

- A. IoT 模块损坏会导致服务器发出的开灯指令无法执行
- B. 不能通过浏览器访问服务器实现亮度的远程控制
- C. 数据库必须为每个传感器建立对应的数据表
- D. 智能终端负责处理所有数据

---

## 答案

**正确答案：** (1) B、C；(2) A；(3) A、C；(4) A

---

## 解析

(1) 服务器可向智能终端返回数据，光敏传感器可向智能终端发送采集数据；操作系统和浏览器不是硬件，照明灯主要接收控制信号并执行输出。

(2) 路由体现在访问服务器的 URL 中，因此修改语句 A。

(3) 视图函数和 Web 模板属于服务器端程序；传感器引脚和采集间隔通常在智能终端端配置。

(4) IoT 模块承担智能终端与服务器之间的通信，损坏后服务器指令无法传到终端。浏览器可实现远程控制；数据表不必与传感器一一对应；系统数据由终端和服务器共同处理。
