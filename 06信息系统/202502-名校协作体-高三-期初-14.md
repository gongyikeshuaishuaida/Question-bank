# 题目 14

小华搭建仓库温湿度监控系统，智能终端编号为 0～9，状态码的第 1 位为终端编号，后两位为温度、湿度状态；服务器用 Flask 提供查询页面并统计连续异常段长度超过阈值 `m` 的次数。

## （1）系统设备

- A. 温湿度传感器
- B. IoT 模块
- C. 蜂鸣器
- D. 无线路由器

不能与智能终端直接连接的是 D。

## （2）支撑技术

- A. 智能终端具有一定的程序存储和数据处理能力
- B. 服务器端运行的软件均为系统软件
- C. 在服务器端无法使用浏览器访问该系统

正确的是 A。

## （3）访问 URL

```python
@app.route("/select")
def index():
    pass

app.run(host="192.168.1.1", port=8000)
```

访问：`192.168.1.1:8000/select`（完整写法为 `http://192.168.1.1:8000/select`）。

## （4）异常段统计

```python
# 数据保存到 res，阈值保存到 m，代码略
size = [0] * 10
c = [0] * 10
for code in res:
    k = int(code[0])                 # ①
    if code[1:] != "11":
        size[k] += 1
    else:
        if size[k] > m:
            c[k] += 1                # ②
        size[k] = 0
for i in range(10):
    if size[i] > m:
        c[i] += 1
for i in range(10):
    print("编号为" + str(i) + "的智能终端异常段长度超过阈值次数：" + str(c[i]))
```

填空：① `int(code[0])`；② `c[k] += 1`。

## （5）功能扩展

例如增加烟雾/温度火灾传感器，异常时联动声光报警器并向管理员发送短信；所需硬件可包括烟雾传感器、蜂鸣器（或警示灯）和通信模块。

---
## 答案
**正确答案：** （1）D　（2）A　（3）`192.168.1.1:8000/select`　（4）①`int(code[0])`；②`c[k]+=1`　（5）合理的功能与硬件扩展均可

---
## 解析
路由器负责网络转发，不能像传感器、IoT 模块和蜂鸣器一样直接作为终端外设；Flask 路由、主机地址和端口共同构成访问地址。状态码首字符需转换为整数下标，每结束一个超过阈值的异常段就累计一次。
