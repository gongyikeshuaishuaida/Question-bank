# 题目 14

某植物光照监控系统，采用智能终端连接光敏传感器，每 10 分钟采集一次光照数据，并通过网络将数据传输至服务器，用户可通过移动终端的浏览器或 APP 查看数据。系统服务器端程序采用 Flask Web 框架编写，部分代码如下：

```python
@app.route("/")
def index():
    # 首页，代码略


@app.route("/que")
def query():
    # 查询光照数据页面，代码略
    return render_template(________, data=data)


if __name__ == "__main__":
    app.run(host="10.197.105.155", port=8066)
```

（1）为了实现每 10 分钟采集一次光照数据，可用于控制采集时间的设备是 ________（单选，填字母：A. 光敏传感器 / B. 智能终端）。

（2）下列关于该系统支撑技术的说法，正确的有 ________（多选，填字母）。

（注：全部选对的得 2 分，选对但不全的得 1 分，不选或有选错的得 0 分。）

- A. 该系统的性能仅由网络决定
- B. 该系统使用了 B/S 和 C/S 两种网络架构
- C. 一个智能终端可以连接多个光敏传感器
- D. 服务器和移动终端需要使用相同的操作系统

（3）若要通过浏览器查看光照数据，则访问的 URL 是 `http://________`；输入 URL 后自动跳转到以 `views.html` 为模板所生成的页面，则程序中划线处的代码为 ________。

（4）系统运行后，为验证光敏传感器采集的数据准确性，请写出 1 种合理的验证方法。

---

## 答案

（1）B

（2）B、C

（3）`10.197.105.155:8066/que`；`"views.html"`

（4）将该光敏传感器与经过校准的光敏传感器或光照计置于同一环境中，对比测量结果。（使用标准光源进行对比验证等合理方法也可。）

---

## 解析

（1）传感器负责感知光照，采集时间间隔由智能终端中的程序控制，因此选 B。

（2）浏览器访问服务器属于 B/S 架构，APP 与服务器通信可采用 C/S 架构；一个智能终端可以连接多个传感器，因此 B、C 正确。系统性能还受硬件、软件等因素影响；服务器与移动终端可以使用不同操作系统。

（3）服务器地址为 `10.197.105.155`，端口为 `8066`，查询页面路由为 `/que`，所以 URL 为 `http://10.197.105.155:8066/que`。模板名称作为字符串传入 `render_template`，代码为 `"views.html"`。

（4）可采用对比实验：在相同光照条件下，同时读取被测传感器和标准仪器的数据，比较误差是否在允许范围内。
