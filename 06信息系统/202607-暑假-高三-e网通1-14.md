# 题目 14

小华想要搭建一个厨房中的环境监测系统，该系统能通过温度传感器和烟雾传感器实时监测厨房温度和颗粒物浓度并显示在厨房安装的电子显示屏上，用户也通过浏览器查看实时监测结果和历史数据，当出现异常时系统控制蜂鸣器发出警报，预防火灾的发生。该系统结构示意图如图所示。请回答下列问题：

![[attachments/202607暑假高三e网通1_14_图1.png]]

(1) 该系统结构示意图中①处和②处缺少的设备分别为______（单选，填字母）。

- A. 服务器和智能终端
- B. 智能终端和服务器

(2) 若温度传感器的编号 `id` 为 1，温度值 `t` 为 25，提交数据到 Web 服务器的 URL 为 `http://192.168.1.0:8080/trans?id=1&t=25`，则服务器端应用实例 `app` 中与该 URL 关联的路由设置语句是 `@app.route("______", methods=["GET"])`。

(3) 智能终端的部分代码如下所示，实现功能：每隔 15 秒从传感器获取 1 次温度值，当连续 4 次检测到的温度值大于 60℃ 时，判断为温度过高，打开蜂鸣器报警。请在划线处填入合适的代码。

```python
# 导入相关库，代码略
k = 0
while True:
    t = pin2.read_analog()
    if t > 60:
        k += 1
        if k == 4:
            # 蜂鸣器报警，开始播放设定频率的曲调，代码略
    else:
        ______
    sleep(1000 * 15)
```

(4) 小华外出时通过移动终端在相关网页上查看厨房的环境监测数据，页面正常运行一段时间后不再发生变化，刷新页面后仍不变，但电子显示屏能实时显示正确信息。造成此结果的原因可能是______（多选，填字母）。

- A. 智能终端损坏
- B. IoT 模块损坏
- C. 传感器与智能终端连接异常
- D. 移动终端与服务器通信异常

---

## 答案

**正确答案：** (1) B；(2) `/trans`；(3) `k = 0`；(4) B、D

---

## 解析

①直接连接传感器和执行器，应为智能终端；②连接数据库并响应浏览器请求，应为服务器。URL 的路由路径是 `/trans`。要统计连续超阈值次数，未超阈值时必须把 `k` 清零。电子显示屏仍正常，说明传感器和智能终端正常；IoT 模块或移动终端至服务器的通信异常都可能使网页数据停止更新。
