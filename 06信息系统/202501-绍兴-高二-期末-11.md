# 题目 11
小张为小区游泳池搭建环境监测系统。系统由智能终端、温度传感器、pH传感器和 IoT 模块组成：智能终端获取温度和 pH 数据，通过无线通信传输到 Web 服务器；服务器判断异常（`pH<7.2` 或 `pH>7.8`）后，通过智能终端控制执行器发出提示信号；用户可用浏览器查看实时及历史数据。

系统结构图如下：

![[attachments/202501绍兴_11_图1.jpg]]

Web 服务端代码如下：

```python
app=Flask(__name__)
@app.route("/show")
def show_info():
    # 查看实时监测数据页面，代码略
    # 服务器其他功能代码略
if __name__=="__main__":
    app.run(host="192.168.1.10",port=81)
```

请回答：

（1）图中①、②、③处对应的设备分别是（单选，填字母）：

- A. 执行器、传感器、IoT模块
- B. 传感器、执行器、IoT模块
- C. 执行器、IoT模块、传感器
- D. IoT模块、执行器、传感器

（2）若用户通过浏览器查看实时监测数据，需要在浏览器地址栏输入的 URL 是 `http://` ______。

（3）游泳池 pH 值标准为7.2～7.8（包含边界）。符合标准时 `flag=0`，低于标准时 `flag=1`，高于标准时 `flag=2`。下列 Python 程序段符合要求的是（多选）：

- A.
  ```python
  if p>=7.2 and p<=7.8:
      flag=0
  elif p<7.2:
      flag=1
  else:
      flag=2
  ```
- B.
  ```python
  if p<7.2:
      flag=1
      if p>7.8:
          flag=2
      else:
          flag=0
  ```
- C.
  ```python
  if p>7.8:
      flag=2
  elif p<7.2:
      flag=1
  else:
      flag=0
  ```
- D.
  ```python
  flag=0
  if p>7.8:
      flag=2
  else:
      flag=1
  ```

（4）系统运行一段时间后，页面显示 `pH=8.5`，但智能终端控制的执行器没有发出提示信号。已知 Web 服务器、数据库和程序代码均无问题，请写出可能原因（答两项）。

---
## 答案
（1）B

（2）`192.168.1.10:81/show`

（3）A、C

（4）执行器故障；执行器与智能终端连接故障；或 pH 传感器/智能终端到执行器的控制链路故障等。

---
## 解析
传感器负责采集输入，执行器负责发出提示，IoT模块负责智能终端与网络之间的通信，因此①、②、③分别为传感器、执行器、IoT模块。浏览器 URL 由服务器地址、端口和路由组成。pH 在闭区间[7.2,7.8]内才是正常状态，A、C完整覆盖三种情况；B和D在部分分支中赋值错误。页面已经显示8.5，说明采集、上传、服务器处理和数据库环节基本完成，故障更可能在执行器本体或执行器与智能终端的连接、控制链路。
