# 题目 11

小张正在开发一个智能家居空调控制系统，该系统使用 Flask 框架构建 Web 应用，家里每个房间设置一个监测点，通过传感器采集环境数据并上传到服务器，实现如下功能：

| 序号 | 功能 |
|---:|---|
| 1 | 实时显示室内环境温度、湿度数据 |
| 2 | 根据室内环境自动控制空调开关 |
| 3 | 用户能够通过网页界面手动控制空调开关 |

（1）“根据室内环境自动控制空调开关”属于系统功能需求中的 **A．核心需求**（B．拓展需求 / C．创新需求）。

（2）系统硬件搭建时，下列连接方式不正确的是（   ）

- A．传感器与智能终端连接
- B．智能终端与执行器连接
- C．传感器与执行器连接

（3）服务器端部分代码如下：

```python
from flask import Flask
app = Flask(__name__)

@app.route('/view')
def ser():
    # 实时显示室内环境温度、湿度数据，代码略
    pass

@app.route('/control')
def con():
    # 用户能够通过网页界面手动控制空调开关，代码略
    pass

if __name__ == '__main__':
    app.run(host='192.168.1.100', port=8080)
```

小张通过浏览器查看室内环境实时温、湿度数据时，访问的页面地址是：

`http://192.168.1.100:8080/view`

（4）变量 `f` 为 `True` 表示空调当前开着，为 `False` 表示空调当前关闭。只有空调关闭且实时温度 `t`（不一定为整数）不低于 28 ℃ 时才能开启空调，条件表达式可写为：

```python
if f == False and t >= 28:
    f = True
```

也可写为 `not f and t >= 28` 或其他等价表达式。

## 答案

（1）A；（2）C；（3）`192.168.1.100:8080/view`（含 `http://`）；（4）`f == False and t >= 28` 或等价表达式。

## 解析

自动控制是系统必须实现的核心功能。传感器和执行器应通过智能终端联动，不能直接连接。Flask 路由 `/view` 对应查看页面；判定条件必须同时满足空调关闭和温度大于等于 28 ℃，由于温度不一定为整数，不能用整数截断或不等式替代。
