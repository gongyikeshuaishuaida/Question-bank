# 题目 10

10. 智能交通系统用地磁线圈和雷达测速仪采集车流与车速，终端上传服务器；
服务器判断路况并向终端发送指令，控制诱导屏显示绕行提示。

（1）在该系统中，车流量数据最终存储在______（单选，填字母）。

- A. 地磁感应线圈
- B. 服务器
- C. 交通诱导屏

（2）下列关于该系统的说法，正确的是______（多选，填字母）。

- A. 智能终端与服务器之间的数据传输是双向的
- B. 处理数据的程序全部部署在服务器端
- C. 一个智能终端只能连接一个雷达测速仪
- D. 网络中断时交通诱导屏无法实时接收拥堵指令

（3）系统管理员将 1 月份的数据导出到 `data.xlsx`，统计 1 月 1 日建国路一天 24 小时内拥堵次数最多的 3 个小时。实现该功能的部分 Python 程序如下，请选择合适的代码填入划线处（单选）。

```python
import pandas as pd

df = pd.read_excel("data.xlsx")
df = df[df["日"] == 1]
df = df[df["道路状况"] == "拥堵"]
df = df[df["监测点"] == "建国路"]
①
②
print(df[0:3])
```

①②处可选代码有：

- A. `df = df.sort_values("道路状况")`
- B. `df = df.sort_values("道路状况", ascending=False)`
- C. `df = df.groupby("时").count()`
- D. `df = df.groupby("分").count()`

（4）系统测试过程中，发现某路段早高峰期间已拥堵，但交通诱导屏未显示绕行提示。经检查，地磁感应线圈、雷达测速仪、网络通信均正常。请分别从数据采集和数据处理环节分析可能造成此问题的两个原因：

① 数据采集：______

② 数据处理：______

---

## 答案

（1）B

（2）A、D

（3）① C　② B

（4）

- 数据采集：采集频率过低或采集间隔过长，未及时捕捉拥堵变化；也可能监测点位置不合理。
- 数据处理：拥堵判定阈值设置不合理，或处理算法存在缺陷。

---

## 解析

数据集中存入服务器，终端既上传数据也接收指令。分时统计后按计数列降序即可取前三。故障分析须分别落在采集配置与处理规则，不能归因于题干已排除的传感器或网络故障。
