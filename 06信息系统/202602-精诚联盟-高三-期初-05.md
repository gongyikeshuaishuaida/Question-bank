# 题目 05

阅读下列材料，回答第 05 题。

某城市智慧交通系统实现红绿灯动态配时，车道旁的摄像头实时分析采集到的图像中行人和车辆的数量，并上传至服务器，服务器根据数量调整绿灯时间；路口设备使用 RFID 技术实时获取网联公交车、救护车的编号等数据，实现优先通行；该城市智慧交通系统还可以根据历史车流数据预测交通情况，实现红绿灯配时提前优化。

下列关于该系统中网络的说法，正确的是（   ）

- A. 服务器必须部署在局域网中才能正常工作
- B. 网络摄像头工作时无需获取 IP 地址
- C. 公交车只能通过 5G 联网
- D. 仅上传采集到的数据可有效节省带宽

---

## 答案

**正确答案：** D

---

## 解析

服务器并非只能部署在局域网中；网络摄像头接入基于 IP 的网络时需要 IP 地址；公交车也可以通过 4G、Wi-Fi 等方式联网，因此 A、B、C 均错误。摄像头在本地完成图像分析后只上传提取出的数量等数据，相比上传完整图像能减少传输量、节省带宽，D 正确。
