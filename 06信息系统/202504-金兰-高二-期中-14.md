# 题目 14

某智慧农场使用温湿度控制系统。传感器获取温度和湿度数据，由智能终端经 IoT 模块发送到 Web 服务器；温度低于阈值时开启加热棒，湿度低于阈值时启动加湿器，用户可通过浏览器查看历史数据。

![[attachments/202504金兰高二_14_图a.jpg]]

（1）图a中①和②处的设备依次为（单选，填字母：A.执行器、传感器 / B.传感器、执行器）。

（2）提交数据至 Web 服务器的 URL 为 `http://192.168.0.10:5000/input?tem=32&hum=66`，则 Web 服务器的 IP 地址是____，接收数据网页的路由是“____”。

（3）测试系统时发现湿度低于阈值时加湿器没有工作，其他设备均正常运转。请说明系统中可能造成该问题的原因（回答2项）。

（4）导出某天0—11时的数据，统计每小时湿度值小于45%的次数，并绘制如下图所示线形图。

![[attachments/202504金兰高二_14_图c.jpg]]

```python

for data in df["上传时间"]:
    hour.append(____)
```

## 答案

**参考答案：** （1）A；（2）192.168.0.10，/input；（3）加湿器故障、智能终端与加湿器连接故障；（4）data[-8:-6]（或 data[11:13]）；（5）①③④。

---
## 解析

（1）图中①接收智能终端的控制输出，属于执行器；②采集温湿度，属于传感器，选 A。  
（2）URL 的主机部分是 `192.168.0.10`，路径 `/input` 是接收数据的路由。  
（3）其他设备正常而加湿器不动作，可能是加湿器本体故障，也可能是智能终端到加湿器的连接或控制线路故障。  
（4）时间字符串形如 2025-02-01 00:00:00，小时字符位于索引 11、12，data[11:13] 或负索引 data[-8:-6] 可取出。  
（5）①筛选湿度低于45%的记录，③按小时计数，④使用分组结果的索引和值绘图；②不是合法列访问语法，⑤分组后的 Series 没有“小时”“湿度”两列。
