# 题目 05

阅读下列材料，回答第 05 题。

某校开发的暖心驿站系统，该系统利用多模态技术（语音特征、人脸识别和面部表情等）分析学生情绪状态，并基于深度学习算法，为其匹配并推荐个性化的手工创作方案，从而为学生提供心理支持。系统借助 3D 记录仪全程捕捉、采集学生手工创作过程中的数据，所有数据加密后通过 Wi-Fi 上传至云服务器，辅导员可通过 APP 或浏览器查看报告。

05. 下列关于该系统中网络技术的说法，正确的是（   ）

- A. 辅导员只能通过移动终端查看报告
- B. 数据上传云服务器不需要遵循网络协议
- C. Wi-Fi 传输数据的传输介质是无线电波
- D. 该系统中可通过网络共享的资源不包括软件

---

## 答案

**正确答案：** C

---

## 解析

- A 错误：辅导员可通过 APP 或浏览器查看报告，浏览器可在 PC 等非移动终端上使用。
- B 错误：任何网络数据传输都必须遵循网络协议（如 TCP/IP）。
- C 正确：Wi-Fi 属于无线局域网技术，其物理传输介质是无线电波。
- D 错误：网络共享的资源包括硬件、软件和数据，软件（如应用程序、数据库系统）也是可共享的资源之一。
