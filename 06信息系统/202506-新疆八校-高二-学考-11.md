# 题目 11

学校为每个教室搭建亮度监控系统。系统的智能终端获取光线传感器数据，通过无线通信将数据传输到 Web 服务器，服务器将数据存储到数据库，并与阈值进行判断后通过智能终端控制 LED 照明灯。用户通过浏览器查询实时和历史数据。

（1）下列不属于该系统硬件设备的是（   ）

- A．智能终端
- B．数据库
- C．网络设备
- D．服务器

（2）下列关于该系统中服务器端和客户端的说法，正确的是（   ）

- A．搭建该系统需要编写服务器端和客户端程序
- B．数据在服务器端与客户端之间双向传输
- C．客户端和服务器端不可连接在同一个局域网内

（3）搭建完系统正常运行一段时间后，发现 IoT 模块出现故障，其他设备正常，此时系统不能完成的功能是（   ）

- A．光线传感器无法采集光线强度数据
- B．用户访问服务器无法查看历史数据
- C．智能终端无法向执行器发送指令
- D．服务器无法发送指令到智能终端

（4）若 2 号监测点（`id=2`）采集的光线数据（`light=350`）上传至服务器的 URL 为 `http://192.168.0.1:8080/s?id=2&light=350`，则服务器的 IP 地址为：**192.168.0.1**。

（5）若发现每个监测点的 LED 照明灯一直在工作，可能原因包括：阈值设置不合理（过大）；采集到的光线数据一直低于阈值；程序缺少控制关闭 LED 照明灯的分支或代码错误（任答两项）。

## 答案

（1）B；（2）B；（3）D；（4）`192.168.0.1`；（5）阈值设置不合理、数据一直低于阈值、缺少关闭灯程序等任答两项。

## 解析

数据库是软件或数据资源，不属于硬件设备。客户端与服务器之间既有请求也有响应，数据可以双向传输。IoT 模块故障会阻断服务器向智能终端发送控制指令，但不直接改变传感器本身的采集能力。URL 的主机部分给出服务器 IP；照明灯一直工作可能由阈值、数据或控制分支问题造成。
