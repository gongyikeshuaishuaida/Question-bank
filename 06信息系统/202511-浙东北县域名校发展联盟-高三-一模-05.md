# 题目 05

阅读下列材料，回答第 05 题。

某健身房部署智能健身管理系统，所有健身设备组成局域网，并与服务器建立连接。会员刷卡或扫码登录后，通过触摸屏选择训练模式，智能器械自动调节参数。运动数据实时同步至服务器，运动结束生成个性化报告并累计健康积分，积分可兑换课程或礼品。管理员可远程监控设备状态。

05. 下列关于该健身系统中网络技术的说法，正确的是（   ）

- A. 服务器必须与其他设备在一个局域网内
- B. 会员查看实时数据需通过移动通信网络
- C. 运动数据同步至服务器仅需物理连接无需协议
- D. 健身设备需分配唯一 IP 地址以接入网络

---

## 答案

**正确答案：** D

---

## 解析

- A 错误：服务器可在局域网内（本地服务器），也可通过互联网连接（远程服务器），并非"必须"在同一局域网。
- B 错误：会员查看实时数据的网络方式可通过健身房 Wi-Fi 或移动通信网络。
- C 错误：数据上传至服务器必须依赖网络协议（如 TCP/IP、HTTP），物理连接只是基础。
- D 正确：联网设备必须分配唯一 IP 地址，以便在网络中被识别和通信。
