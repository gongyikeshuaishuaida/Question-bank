# 题目 13

教室的温度监控系统中，智能终端根据阈值和传感器采集的温度值控制制冷设备，并将温度值等数据传输至 Web 服务器。制冷设备初始处于关闭状态，每隔 10 分钟从传感器获取 1 次温度值：设备关闭时，若连续 3 次温度值均大于阈值 t，则打开制冷设备；设备工作过程中，若连续 3 次温度值均小于等于阈值 t，则关闭制冷设备。请回答以下问题：

（1）若阈值为 26 度，系统开始运行后，连续 10 次采集到的温度数据为：28、26、27、28、29、28、25、24、25、26，则制冷设备处于的状态是 ______（单选，填字母）。

- A. 开启
- B. 关闭

（2）部分 Python 程序如下，请在程序中划线处填入合适的代码。

```python
s=0
flag=False
while True:
    # 间隔10分钟接收一次采集到的温度数据，存入 newt，代码略
    if newt>t and flag==False:
        s+=1
        if ____①____:
            flag=True
            # 打开制冷设备，代码略
    elif ____②____:
        s-=1
        if s==0:
            flag=False
            # 关闭制冷设备，代码略
    else:
        ____③____
    # 将 newh 等数据传输到服务器，代码略
```

---
## 答案

**参考答案：** （1）A；（2）① s==3；② newt<=t and flag==True；③ s=0

---
## 解析

温度 28、26、27、28、29 中连续三次大于 26 的数据 27、28、29 使设备开启；随后仍有一次高于阈值的 28，设备继续工作，后续低温数据不足以连续三次让 s 从 3 减到 0，因此最终仍为开启。程序中分别在高温计数达到 3 时开机，在设备工作且温度不高于阈值时递减计数，其他情况将计数清零。
