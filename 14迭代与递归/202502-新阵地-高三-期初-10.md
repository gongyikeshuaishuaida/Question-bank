# 题目 10

```python
def dig(n, k):
    k = k - 1                 # ①
    if k == 0:
        return n % 10
    else:
        return dig(n // 10, k) # ②

print(dig(52617, 3))
```

下列说法不正确的是（   ）

- A. 执行后输出结果为 6
- B. 函数 `dig` 一共被调用了 3 次
- C. `dig(n,k)` 的功能是输出 n 中从右往左数第 k 个元素
- D. 若删除语句①，将语句②改成 `return dig(n//10,k-1)`，不影响程序运行结果

---
## 答案
**正确答案：** D

---
## 解析
按原程序，`k` 依次变为 2、1、0，递归调用 3 次并返回 `526` 的个位 6。若删除①并仅把递归实参改为 `k-1`，第一次判断仍从 `k=3` 开始，递归会多调用一次，最终返回 `52%10=2`，所以 D 的“不影响运行结果”错误。
