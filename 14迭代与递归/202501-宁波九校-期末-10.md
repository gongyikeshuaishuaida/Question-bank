# 题目 10

10. 定义如下递归函数，计算正整数 `n` 的每位数字值和，例如 `n=123`，函数返回值为 6。

```python
def f(n):
    x =      (1)
    if n == 0:
        return n
    else:
        y =      (2)
        return      (3)
```

上述程序段中划线处可选代码为：

① `n % 10`  
② `n // 10`  
③ `x + f(n-y)`  
④ `x + f(y)`

A. ①②③  
B. ①②④  
C. ②①③  
D. ②①④

---

## 答案

**正确答案：** B

---

## 解析

计算各位数字之和时，`x` 应取当前个位数字 `n % 10`，`y` 应取去掉个位后的整数 `n // 10`，递归部分继续计算剩余各位数字之和，即 `x + f(y)`。因此依次为 ①②④。
