# 题目 11

对于任意非空的列表 `a`，甲、乙程序段输出结果相同，则乙程序段加框处的代码为（   ）

```python
# 甲
tot = 0
for i in range(len(a)):
    if a[i] > 0:
        tot += a[i]
print(tot)

# 乙
def find(a,i):
    if i == len(a):
        return 0
    cur = a[i]
    if cur < 0:
        cur=0
    return cur + ____  # 此处是方框处

print(find(a, 0))
```

- A. `find(a,len(a)-i)`
- B. `find(a,len(a)-1-i)`
- C. `find(a,i+1)`
- D. `find(a,i-1)`

---
## 答案

**正确答案：** C

---
## 解析

递归函数从下标 `i` 开始处理当前元素，递归到 `i==len(a)` 时结束，因此下一次调用必须处理 `i+1`。负数先置为 0，累加结果正好等于甲程序对所有正数的求和，故选 C。
