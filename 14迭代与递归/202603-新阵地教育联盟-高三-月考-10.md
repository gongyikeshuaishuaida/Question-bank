# 题目 10

10. 定义如下函数：

```python
def f(n):
    if n <= 2:
        return n
    else:
        return f(n-1) + f(n-2)
```

执行语句 `s=f(5)` 时，函数 `f` 被调用的次数为（   ）

- A. 5
- B. 8
- C. 9
- D. 15

---

## 答案

**正确答案：** C

---

## 解析

记调用次数为 `T(n)`，则 `T(1)=T(2)=1`，`T(n)=1+T(n-1)+T(n-2)`。因此 `T(3)=3`，`T(4)=5`，`T(5)=9`。
