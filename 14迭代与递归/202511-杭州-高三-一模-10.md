# 题目 10

10. 对于任意正整数 n（n≤10¹⁰⁰），调用函数 `cal(n)` 返回的结果为 n 的各位数之和，要实现上述功能，如下程序段中，加框处的代码不能为（   ）

```python
def cal(n):
    if n < 10:
        return n
    return ___
```

- A. `cal(n//10) + n%10`
- B. `cal(n//10) + cal(n%10)`
- C. `cal(n//100) + n%10 + n//10%10`
- D. `cal(n//100) + cal(n%100)`

---

## 答案

**正确答案：** D

---

## 解析

各位数之和递归：将 n 拆分为高位部分和低位部分。

- A：去掉个位递归 + 个位，正确。
- B：去掉个位递归 + 个位递归（个位 <10 时等于自身），正确。
- C：去掉末两位递归 + 十位 + 个位，正确。
- D：`cal(n//100)` 对高位求各位和 + `cal(n%100)` 对末两位求各位和，然而 `n%100` 可能 ≥10（如 45），递归调用 `cal(45)` 返回 4+5=9，正确——但问题在于：若 n 有奇数位数且 n%100 是两位数，这会跳过中间部分？不对，实际上 D 也是正确的...

等等，D 的问题在于：`cal(n%100)` 在 n%100 的值 < 10 时正常工作，但 `cal(n//100) + cal(n%100)` 从逻辑上讲也是各位数之和的正确分解。验证：n=12345，cal(12345) = cal(123) + cal(45) = (cal(1)+cal(23)) + (4+5) = 1+2+3+4+5 = 15。结果正确。

实际上 D 的问题在于... n≤10¹⁰⁰ 是一个非常大的数。当 n%100 < 10 时（如 n=101），cal(101) = cal(1) + cal(1) = 1+1 = 2，但正解应为 1+0+1=2。所以 D 也是正确的？让我再想想...

啊，关键是 n//100 丢弃了中间位。递归分解 n→n//100+n%100，对于奇数位数会漏掉中间的一位数！例如 n=12345（5 位），n//100=123, n%100=45，中间丢失的没有！cal(123)=cal(1)+cal(23)=1+5=6, cal(45)=9, 总=15。正确值是 1+2+3+4+5=15。没错...

Hmm，那 D 也是对的。让我重新想想为什么 D 不行。

实际上答案就是 D。让我重新分析：递归分解 cal(n//100)+cal(n%100) 在处理小于 100 的数字时有问题。比如 n=10，n//100=0, n%100=10。cal(0)+cal(10) -> cal(0) 会无限递归（0<10 返回 0... 等一下，n 是正整数）。但 n//100=0 时 cal(0)=cal(0//10)... 这会导致无限递归！因为 0<10 返回 0 没问题。那 0//100=0 同样。cal(0) = 0（<10 返回 0）。

但问题是 D 选项 `cal(n//100) + cal(n%100)` 在递归过程中对某些 n 可能有更深的递归导致溢出或循环。比如 n=10: cal(0)+cal(10)=0+(cal(0)+cal(10)) = ... 等等不对。

n=10: n//100=0, n%100=10, cal(10)=cal(0)+cal(10)=0+cal(10)，这会导致无限递归！cal(10) = cal(0) + cal(10) 又调用了自己。

所以 D 不能！因为当 n 是两位数（10-99）时，n//100=0，n%100=n，cal(n) = cal(0) + cal(n) → 无限递归。

故选 D。
