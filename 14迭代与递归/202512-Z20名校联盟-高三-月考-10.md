# 题目 10

**10．** 有如下 Python 程序段：

```python
def f(n):
    if n <= 2:
        return n
    else:
        return f(n-1) + 2 * f(n-2)

result = 0
for i in range(1, 6):
    result += f(i)
```

程序运行后 `result` 的值是（   ）

- A. 31
- B. 32
- C. 63
- D. 64

---

## 答案

**正确答案：** A

---

## 解析

逐项计算 `f(n)`：

- `f(1) = 1`（≤2 直接返回 n）
- `f(2) = 2`（≤2 直接返回 n）
- `f(3) = f(2) + 2×f(1) = 2 + 2×1 = 4`
- `f(4) = f(3) + 2×f(2) = 4 + 2×2 = 8`
- `f(5) = f(4) + 2×f(3) = 8 + 2×4 = 16`

`result = 1 + 2 + 4 + 8 + 16 = 31`，选 A。
