# 题目 10

10. 定义如下函数：

```python
def dedup(s):
    if len(s) <= 1:
        return s
    if s[0] in s[1:]:
        return dedup(s[1:])
    else:
        return s[0] + dedup(s[1:])
```

执行语句 `print(dedup("keeper"))` 后，输出结果是（   ）

- A. kepr  
- B. kper  
- C. kpr  
- D. ke

---

## 答案

**正确答案：** B

---

## 解析

函数从左到右判断字符是否还会在后续字符串中出现，若会出现则丢弃当前字符，因此保留每个字符的最后一次出现。dedup('keeper') 的结果为 kper。
