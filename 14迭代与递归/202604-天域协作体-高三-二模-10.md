# 题目 10

有如下 Python 程序段：

```python
def f(n):
    if n <= 2:
        return n
    return f(n-1) + f(n-2)

def g(n):
    a, b = 1, 2
    for i in range(3, n+1):
        a, b = b, a + b
    if n >= 2:
        return b
    else:
        return a

x = int(input())
if f(x) == g(x):
    print(True)
else:
    print(False)
```

下列说法正确的是（   ）

- A. 函数 `f` 采用迭代算法，函数 `g` 采用递归算法
- B. 当输入 `x` 为 5 时，函数 `f` 被调用的次数为 7 次
- C. 函数 `f` 的时间复杂度低于函数 `g`
- D. 对于任意正整数 `x`，程序输出的结果均为 `True`

---

## 答案

**正确答案：** D

---

## 解析

`f` 用递归、`g` 用迭代计算同一个数列：1、2、3、5、8……，因此对任意正整数输入，两函数返回值相等，程序输出 `True`。`f(5)` 共发生 9 次函数调用，且递归实现的时间复杂度高于线性迭代实现。
