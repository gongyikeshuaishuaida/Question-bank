# 题目 11

有如下 Python 程序：

```python
a = [0] * 10
def fn(n):
    if a[n] != 0:
        return a[n]
    if n == 1 or n == 2:
        a[n] = 1
    else:
        a[n] = fn(n - 1) + fn(n - 2)
    return a[n]
```

执行语句 `print(fn(5))`，函数 `fn` 的调用次数为（   ）

- A. 11
- B. 9
- C. 7
- D. 6

---
## 答案

**正确答案：** C

---
## 解析

数组 `a` 记录已经求出的结果。调用 `fn(5)` 时依次展开 `fn(5)、fn(4)、fn(3)、fn(2)、fn(1)`，随后 `fn(2)` 和 `fn(3)` 命中缓存直接返回，共调用 7 次；记忆化避免了重复递归。
