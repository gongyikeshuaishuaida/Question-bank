# 题目 10

10. 有如下 Python 程序段：

```python
def p(x,n):
    if n==0:
        return 2
    else:
        return x * p(x,n-1)
```

执行语句 `k=p(3,2)` 后，`k` 的值为（   ）

- A. 8
- B. 9
- C. 16
- D. 18

---

## 答案

**正确答案：** D

---

## 解析

`p(3,2)=3*p(3,1)`，`p(3,1)=3*p(3,0)`，而 `p(3,0)=2`，所以 `k=3×3×2=18`。
