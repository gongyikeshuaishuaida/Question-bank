# 题目 11

11. 函数递归统计字符串中的元音字母：

```python
def f(s):
    if s == "":
        return 0
    elif s[0] in "aeiou":
        return 1 + f(s[1:])
    else:
        return f(s[1:])

result = f("studyroom")
```

`result` 的值是（　）

- A. 1
- B. 2
- C. 3
- D. 4


---

## 答案

**正确答案：** C

---

## 解析

`studyroom` 中的元音是 `u、o、o`，共 3 个。
