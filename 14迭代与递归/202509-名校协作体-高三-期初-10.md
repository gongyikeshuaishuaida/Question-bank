# 题目 10

10. 执行程序，输出结果是（　）

```python
def calc(x, y):
    if x == 1:
        return y
    elif y == 1:
        return x * 2
    return calc(x-1,y) + calc(x,y-1) - calc(x-1,y-1)

print(calc(2, 3))
```

- A. 4　B. 5　C. 6　D. 7

---

## 答案

**正确答案：** C

---

## 解析

`calc(2,2)=2+4-1=5`，所以`calc(2,3)=3+5-2=6`。
