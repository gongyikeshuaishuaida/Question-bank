# 题目 10

10. 有如下 Python 程序段：

```python
def f(n, sign):
    if n == 0:
        return n
    return n * sign + f(n - 1, -sign)
```

执行语句 `print(f(5, 1))`，输出的结果为（   ）

- A. -5  
- B. 3  
- C. 7  
- D. 15

---

## 答案

**正确答案：** B

---

## 解析

递归展开为 5 - 4 + 3 - 2 + 1 + 0，结果为 3。
