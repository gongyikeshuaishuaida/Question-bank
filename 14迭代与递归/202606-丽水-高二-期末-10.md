# 题目 10

10. 对于任意非空字符串 `s`，甲、乙程序段输出结果相同，则乙程序段划线处的正确代码为（   ）

甲程序段：

```python
def f1(s):
    ans = ""
    for char in s:
        ans = char + ans
    return ans
```

乙程序段：

```python
def f2(s):
    if len(s) <= 1:
        return s
    return ______
```

- A. `s[-1]+f2(s[:-1])`
- B. `f2(s[:-1])+s[-1]`
- C. `s[0]+f2(s[0:])`
- D. `s[0]+f2(s[1:])`

---

## 答案

**正确答案：** A

---

## 解析

甲程序每次把当前字符放到 `ans` 前面，最终得到字符串的逆序。递归实现时，应取最后一个字符 `s[-1]`，再递归逆序处理前面的子串 `s[:-1]`，即 `s[-1]+f2(s[:-1])`。
