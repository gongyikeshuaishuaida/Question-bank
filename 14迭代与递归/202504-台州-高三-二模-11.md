# 题目 11

某 Python 程序段如下所示：

```python
def f(x,k):
    if x<=0:
        return 1       #①
    if x==1:
        return k       #②
    return (f(x-1,k)+f(x-2,k))*k  #③
```

关于以上程序，说法正确的是（   ）

- A. 当 `x=0` 时，函数直接返回 `k`
- B. 调用函数 `f(3,2)`，则①和②处的语句均访问1次
- C. 若将 k 值增大，则该函数的执行总次数一定会增加
- D. 调用函数 `f(4,1)`，则该函数返回值为5

---
## 答案

**正确答案：** D

---
## 解析

x=0时命中第一处返回1。调用 f(3,2) 时，x=0的分支访问1次，但 x=1的分支访问2次。递归调用的次数由 x 决定，与 k 的大小无关。令 k=1时，f(0)=1、f(1)=1，递推得到 f(2)=2、f(3)=3、f(4)=5，因此 D正确。
