# 题目 10

10. 有如下 Python 程序段：

```python
def f(n):
    if n <= 1:
        return 1
    return 1 + f(n // 2)
```

执行语句 `print(f(11))`，输出的结果为（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C

---

## 解析

递归调用过程为 `f(11)→f(5)→f(2)→f(1)`。`f(1)=1`，向外逐层各加 1，因此 `f(11)=4`，选 C。
