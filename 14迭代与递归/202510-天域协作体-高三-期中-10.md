# 题目 10

10. 丑数是指仅包含质因子2、3、5的正整数，且1被视为第一个丑数。编写如下甲、乙Python程序段实现判断正整数`n`是否为丑数：

```python
# 甲
def ugly(n):
    for p in [2, 3, 5]:
        while n % p == 0:
            n = n // p
    return n == 1

# 乙
def ugly(n):
    if n == 1:
        return True
    for p in [2, 3, 5]:
        if n % p == 0:
            return ugly(n // p)
    return False
```

下列描述不正确的是（   ）

- A. 甲、乙分别使用了迭代算法和递归算法
- B. 执行`f=ugly(25)`，甲的返回结果为`True`
- C. 执行`f=ugly(12)`，乙中函数`ugly`被调用3次
- D. 对同一正整数`n`，甲、乙加框处代码的执行次数不一定相同

---

## 答案

**正确答案：** C

---

## 解析

乙处理12时调用链为`ugly(12)→ugly(6)→ugly(3)→ugly(1)`，共调用4次，不是3次。
