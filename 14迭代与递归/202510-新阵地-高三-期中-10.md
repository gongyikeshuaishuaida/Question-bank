# 题目 10

10. 有如下程序：
```python
def f(x, n):
    if n == 0:
        return x
    return f(x - 1, n - 1) + x
```
执行`r=f(2,5)`后，`r`的值是（   ）

- A. -3
- B. 0
- C. 3
- D. 9

---

## 答案

**正确答案：** A

---

## 解析

展开为`f(-3,0)+(-2)+(-1)+0+1+2=-3-2-1+0+1+2=-3`。
