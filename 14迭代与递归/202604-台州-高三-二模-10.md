# 题目 10

10. 定义如下函数：

```python
def f(n):
    if n <= 2:
        return 1
    elif n == 3:
        return 2
    else:
        return (n-1) * (f(n-1) + f(n-2))
```

执行语句 `x=f(5)` 后，`x` 的值为（   ）

- A. 24  
- B. 28  
- C. 44  
- D. 70

---

## 答案

**正确答案：** C

---

## 解析

`f(1)=1`、`f(2)=1`、`f(3)=2`；`f(4)=3×(f(3)+f(2))=3×3=9`；`f(5)=4×(f(4)+f(3))=4×11=44`。
