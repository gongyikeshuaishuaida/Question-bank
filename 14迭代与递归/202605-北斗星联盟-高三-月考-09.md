# 题目 09

9. 定义如下函数：

```python
def f(n):
    if n <= 2:
        return 1
    if n <= 5:
        return f(n-1) + n
    else:
        return f(n-3) + f(n-4)
```

执行 `print(f(7))` 后，输出的结果是（   ）

- A. 10
- B. 11
- C. 12
- D. 13

---

## 答案

**正确答案：** C

---

## 解析

`f(7)=f(4)+f(3)`；`f(3)=f(2)+3=4`；`f(4)=f(3)+4=8`，所以 `f(7)=8+4=12`。
