# 题目 11

11. 执行如下 Python 程序，输出结果为

```python
def f(s, i):
    if i + 2 > len(s):
        return s
    if s[i] == s[i+1]:
        s = s[:i] + s[i+2:]
        return f(s, max(i-1, 0))
    return f(s, i+1)

s = "PPTTPAPPTATAAT"
print(f(s, 2))
```

- A. PATATT
- B. PPPATA
- C. PATA
- D. PTA

---
## 答案

**正确答案：** C

---
## 解析

程序从下标2开始检查相邻字符，相同则删除这两个字符并回退一位，不同则前进一位。按过程递归删除相同相邻字符，最终得到字符串 PATA，故选 C。
