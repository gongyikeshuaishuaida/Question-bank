# 题目 11

11. 对于任意非空字符串 `s`，若甲、乙两个程序段输出结果相同，则乙程序段方框处的正确代码是（   ）

甲程序段：

```python
def f(s, t):
    if t < 0:
        return ""
    return s[t] + f(s, t - 2)

print(f(s, len(s) - 1))
```

乙程序段：

```python
r = ""
n = len(s)
for i in range(n - 1, -1, -2):
    【方框】
print(r)
```

- A. `r = s[i] + r`
- B. `r += s[i]`
- C. `r = r + s[n-i-1]`
- D. `r = s[n-i-1] + r`

---

## 答案

**正确答案：** B

---

## 解析

递归从末字符开始，每次将下标减 2，并按访问顺序拼接。循环中 `i` 的取值顺序完全相同，因此应把 `s[i]` 追加到 `r` 末尾，即 `r += s[i]`。
