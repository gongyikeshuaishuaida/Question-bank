# 题目 11

有如下 Python 程序段：

```python
def fun(x):
    c="0123456789ABCDEF"
    if x<16:
        return c[x]
    return fun(x//16)+c[x%16]
```

执行 `r=fun(31)`，变量 `r` 的值是（   ）

- A. `"10F"`
- B. `"F10"`
- C. `"1F"`
- D. `"F1"`

---
## 答案
**正确答案：** C
---
## 解析
`31//16=1`、`31%16=15`，递归返回 `c[1]+c[15]`，结果为 `"1F"`。
