# 题目 10

有如下 Python 程序段：

```python
def f(x, n):
    if n == 0:
        return x
    return f(x - 1, n - 1) + x
```

执行语句 `r = f(3, 6)`，变量 `r` 的值是（   ）

- A. `-1`
- B. `0`
- C. `1`
- D. `2`

---

## 答案

**正确答案：** B

---

## 解析

递归展开得到：

`f(3,6)=3+2+1+0+(-1)+(-2)+f(-3,0)`

基例 `f(-3,0)=-3`，因此结果为 `3+2+1+0-1-2-3=0`，选 B。
