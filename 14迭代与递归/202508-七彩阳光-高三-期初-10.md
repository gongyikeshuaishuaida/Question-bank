# 题目 10

10. 已知某Python递归函数定义如下：

```python
def f(x):
    if a[x] != x:
        a[x] = f(a[x])
    return a[x]
```

若数组`a=[0, 1, 0, 5, 0, 4, 4]`，则执行`f(3)`后，函数返回值和数组`a`分别是（   ）

- A. `0`，`[0, 1, 0, 0, 0, 0, 4]`
- B. `1`，`[0, 1, 0, 0, 0, 4, 4]`
- C. `1`，`[0, 1, 0, 5, 0, 0, 4]`
- D. `0`，`[0, 1, 0, 0, 0, 4, 4]`

---

## 答案

**正确答案：** A

---

## 解析

递归调用路径为`3→5→4→0`，`a[0]==0`时返回0。回溯时依次把`a[4]`、`a[5]`、`a[3]`设为0，因此返回值为0，数组变为`[0,1,0,0,0,0,4]`。
