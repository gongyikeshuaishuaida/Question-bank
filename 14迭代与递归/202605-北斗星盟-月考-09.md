# 题目 09

有如下 Python 程序段：

```python
def f(m,n):
    if m%n==0:
        return n
    return f(n,m%n)
```

执行语句 `f(32,12)`，函数 `f` 被调用的次数是（   ）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** A

---

## 解析

调用过程为 `f(32,12)`、`f(12,8)`、`f(8,4)`，第三次满足整除返回，因此共调用 3 次。
