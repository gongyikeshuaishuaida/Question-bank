# 题目 10



某 Python 递归函数定义如下：



```python

def f(x):

    if a[x] != x:

        a[x] = f(a[x])

    return a[x]

```



若数组 `a=[1,3,1,4,4,5]`，则执行 `f(0)` 后，函数返回值和数组 `a` 分别是（   ）



- A. `4 [4,4,1,4,4,5]`

- B. `4 [4,3,1,4,4,5]`

- C. `5 [1,3,1,4,4,5]`

- D. `4 [1,3,1,4,4,5]`



---



## 答案



**正确答案：** A



---



## 解析



递归路径为 0→1→3→4，根为 4。回溯时路径压缩，`a[1]` 和 `a[0]` 都改为 4，返回 4。
